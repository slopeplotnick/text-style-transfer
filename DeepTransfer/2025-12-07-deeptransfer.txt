  DeepTransfer性能改进方案

  当前问题诊断

  你说得对，当前系统虽然使用双编码器生成了风格嵌入（vector_store.py:110），
  但在整个工作流中：
  1. 检索阶段：仅使用内容嵌入计算相似度（vector_store.py:79）
  2. 生成阶段：从未访问返回结果中的style_embedding字段
  3. 结果：风格编码器的计算资源被浪费，风格信息未被利用

  🎯 改进方案（按优先级排序）

  方案1：混合检索策略（Hybrid Retrieval） ⭐⭐⭐⭐⭐

  核心思想：结合内容相似度和风格相似度进行检索

  实现方式：
  # 在 vector_store.py 的 search_chunks 方法中
  def search_chunks(self, query_emb: np.ndarray, query_style_emb: np.ndarray
   = None, 
                    top_k: int = 3, alpha: float = 0.7, filter_dict: 
  Optional[Dict] = None):
      """
      alpha: 内容权重，(1-alpha): 风格权重
      """
      # 内容相似度
      content_sims = cosine_similarity(query_emb,
  self.chunk_content_embeddings)[0]

      # 风格相似度
      if query_style_emb is not None:
          style_sims = cosine_similarity(query_style_emb,
  self.chunk_style_embeddings)[0]
          # 混合得分
          hybrid_sims = alpha * content_sims + (1 - alpha) * style_sims
      else:
          hybrid_sims = content_sims

      # 基于混合得分排序和过滤...

  优点：
  - 同时考虑语义和风格相似性
  - 可调节的权重（alpha参数）
  - 实现简单，效果显著

  建议配置：
  - Abstract: alpha=0.8 (更重视内容)
  - Results: alpha=0.6 (平衡内容和风格)
  - Discussion: alpha=0.5 (更重视风格)

  方案2：风格感知的重排序（Style-Aware Reranking） ⭐⭐⭐⭐

  核心思想：先用内容检索，再用风格重排

  实现方式：
  def search_chunks_with_reranking(self, query_emb, query_style_emb, 
  top_k=3, 
                                    retrieve_k=10, style_weight=0.3):
      # 第一阶段：内容检索（召回更多）
      content_results = self.search_chunks(query_emb, top_k=retrieve_k)

      # 第二阶段：风格重排序
      for result in content_results:
          style_sim = cosine_similarity(
              query_style_emb.reshape(1, -1),
              result['style_embedding'].reshape(1, -1)
          )[0][0]

          # 重新计算得分
          result['reranked_score'] = (
              result['score'] * (1 - style_weight) +
              style_sim * style_weight
          )

      # 按新得分排序
      reranked = sorted(content_results, key=lambda x: x['reranked_score'],
  reverse=True)
      return reranked[:top_k]

  优点：
  - 保留内容召回的高精度
  - 提升风格一致性
  - 计算开销小（仅对候选集重排）

  方案4：风格一致性验证（Style Consistency Validation） ⭐⭐⭐

  def _transfer_paragraph_with_validation(self, para_text, section_type, 
  target_journal):

  target_journal)

  target_journal)

          generated_style_emb.reshape(1, -1),
          avg_target_style.reshape(1, -1)
      )[0][0]

      return self.llm_client.generate(feedback_prompt)

  方案5：对比学习优化检索器（Contrastive Learning） ⭐⭐⭐

  核心思想：微调编码器使其更适合风格迁移任务

  实现步骤：
  1. 收集正负样本对：
    - 正样本：同一期刊/章节的文本对
    - 负样本：不同期刊/章节的文本对
  2. 训练目标（InfoNCE Loss）：
  def contrastive_loss(anchor_emb, positive_emb, negative_embs, 
  temperature=0.07):
      """
      anchor_emb: 源文本的风格嵌入
      positive_emb: 同风格文本的嵌入
      negative_embs: 不同风格文本的嵌入列表
      """
      # 计算相似度
      pos_sim = cosine_similarity(anchor_emb, positive_emb) / temperature
      neg_sims = [cosine_similarity(anchor_emb, neg) / temperature for neg
  in negative_embs]

      # InfoNCE Loss
      exp_pos = np.exp(pos_sim)
      exp_neg_sum = np.sum([np.exp(s) for s in neg_sims])
      loss = -np.log(exp_pos / (exp_pos + exp_neg_sum))

      return loss

  3. 微调风格编码器（保持内容编码器冻结）

  优点：
  - 编码器学习任务特定的风格表示
  - 提升检索质量
  - 可迁移到新领域

  方案7：风格强度控制（Style Intensity Control） ⭐⭐

  核心思想：允许用户控制风格迁移的强度

  实现方式：
  def transfer_document(self, source_file, target_journal, 
  style_strength=1.0):
      """
      style_strength: 0.0-1.0

      """
      # 在混合检索中动态调整权重

      # 在Prompt中调整指令
      if style_strength > 0.7:
          instruction = "Strongly adapt to the target style..."
      elif style_strength > 0.3:
          instruction = "Moderately adjust the style..."
      else:
          instruction = "Lightly polish while preserving original style..."
