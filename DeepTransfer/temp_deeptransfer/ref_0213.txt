UnresolvedRetry represents the scenario where an agent performs multiple consecutive edits on the same file, all of which fail to yield a successful modification. For example, as shown in Figure 12-a, the SWE-agent Dev repeatedly executes str_replace commands on utils.py a total of 183 times, ultimately reaching the cost limit without success. Similarly, StrNotFound occurs when an edit fails because the specified old string cannot be found in the file, as illustrated in Figure 13-a. These failures are often attributed to formatting issues or minor text differences. NoEffectEdit arises when the old and new strings are identical, resulting in a meaningless replacement. Figure 13-b exemplifies this scenario, where a string is replaced with itself, producing no change to the file and incurring unnecessary computational expense. AmbiguousTarget captures cases where the specified old string appears multiple times in the file, creating ambiguity about which occurrence should be replaced. Figure 13-c illustrates such a case, where multiple identical if statements prevent the editor from deterministically applying the replacement, highlighting a key limitation of string-based editing mechanisms. To further investigate, we formalized these identified patterns and analyzed them across 4000 GRAPHEC-TORY cases. Figure 14 summarizes the distribution of four localization inefficiency patterns across all agents and models for both resolved (Figure 14-a) and unresolved instances (Figure 14-b). The percentages below the Venn diagrams indicate the proportion of instances exhibiting at least one inefficiency pattern. Notably, inefficiencies, though less frequent, remain prevalent in resolved instances, underscoring the importance of process-centric analysis to better understand agent behavior. Furthermore, unresolved cases often involve multiple inefficiency patterns within a single trajectory. Interestingly, more advanced models, such as Claude Sonnet 4, achieve higher success rates yet exhibit a greater prevalence of these inefficiency patterns. A qualitative analysis suggests that these models engage in extended internal reasoning before producing a solution. While this approach proves beneficial for solving complex problems, as evidenced by the higher success rate, it can also lead to inefficiency when additional steps fail to improve the solution.
