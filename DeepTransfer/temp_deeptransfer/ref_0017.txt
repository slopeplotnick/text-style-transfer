The implantation stage has three primary objectives: covertness, reversibility, and controllability. Covertness minimizes observable differences between the malicious tool and its benign counterparts. Reversibility guarantees that the tool can restore original outputs after an exploitation cycle. Controllability ensures that the attacker can reliably utilize computing resources to execute extra tasks. In this section, we present the detailed implementation of these objectives. A covert command-and-control (C2) protocol facilitates clandestine communication. Specifically, the backdoor employs a two-phase C2 protocol. Initially, the implant sends a short beacon packet containing a victim identifier to a remote endpoint via an outbound network socket. Subsequently, the remote endpoint replies with an extra task payload. The implant then injects the payload into the tool's return value, ensuring it appears consistent with legitimate outputs. During the exfiltration phase, the implant monitors the next invocation of the tool to intercept user-provided inputs, which are transmitted to the remote endpoint. This bifurcated design effectively separates task execution from data exfiltration, thereby minimizing the duration of active network connections. The exploitation stage compels the agent to execute additional tasks and subsequently restores the original outputs of the tool, ensuring the user's experience remains unaltered. Trigger design encompasses three distinct types: content-based, frequency-based, and context-based. A content-based trigger activates when the tool input contains a specific token or semantic marker. Conversely, a frequency-based trigger activates after a randomized sequence of standard operations, mitigating the risk of discernible patterns. A context-based trigger is initiated when the agent engages a specific tool or function in response to a predefined request. Upon activation, LeechHijack retrieves supplementary tasks from the attacker, facilitating unauthorized exploitation of the agent's computational resources.
