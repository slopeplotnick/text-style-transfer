Unresolved runs often accumulate multiple localization or editing anti-patterns within a single trajectory. Although stronger models, such as Claude-4, demonstrate higher success rates, they also tend to exhibit greater inefficiencies, likely due to their more extensive internal exploration processes. In recent years, there has been a notable increase in the deployment of Software Engineering (SWE) agents for automated issue resolution and various software engineering tasks. These agents can be broadly categorized into two architectural approaches: single-agent systems and multi-agent systems. Single-agent systems, such as SWE-agent and OpenHands, utilize a unified ReAct loop. In contrast, multi-agent systems, exemplified by CodeR, Magis, and MASAI, employ multiple specialized agents to perform distinct tasks, such as the collection of relevant code snippets, the creation and verification of reproduction scripts, the implementation of code modifications, and the validation of changes. GRAPHECTORY can be easily applied to multi-agent systems by integrating the trajectories of various agents into a unified framework. Another dimension for categorizing SWE-agents is their tool usage. Certain agents, such as Agentless, operate without external tools, relying solely on prompting strategies. Conversely, other agents employ conventional retrieval mechanisms and embeddings to facilitate the identification of pertinent files. TRAE, CGM, and MarsCode Agent leverage code knowledge graphs alongside language server protocols to enhance project comprehension and code entity retrieval capabilities. Without GRAPHECTORY, undertaking a comparative analysis of these approaches would present significant challenges. The integration of GRAPHECTORY and LANGUTORY facilitates the categorization of these advanced tools within the Localization phase. Following the release of Claude 3.5 Sonnet, SWE agents such as SWE-agent and OpenHands have adopted the use of bash commands for code search and the 'str_replace editor' tool for file viewing and modification. Consequently, SWE-agent and OpenHands were selected as the SWE agents for our experimental investigations.
