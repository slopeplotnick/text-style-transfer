To systematically address this question, we conducted an in-depth deconstructive analysis of the relevance task, as detailed in Section 2. This process is divided into two stages: (1) Path Construction, which involves mapping the query requirements to specific product attributes and establishing semantic connections between the query and the product space; and (2) Path Following, which entails executing precise discrimination at the attribute-product level based on the constructed paths. The model’s capabilities required for this process can be categorized into three key areas. First, Knowledge and Reasoning Ability is essential. The model must leverage its knowledge base to interpret domain-specific terminology and latent details within the query. Building on this, reasoning enables the model to infer the true intent behind the query and identify the corresponding product attributes. For instance, as shown in Fig. 1(a), the model must first determine that "morning C, evening A" refers to a regimen involving Vitamin C and retinol, and subsequently deduce that "for mom" implies suitability for middle-aged women. Second, Multi-modal Matching Ability is critical, as product attributes are often presented across multiple modalities. The model must integrate information from textual and visual data to align the parsed query intent with the multimodal representations of product attributes. For example, in Fig. 1(b), the query specifies "yellow," which is absent in the textual description, requiring the model to analyze visual information to identify the color attribute. Finally, Rule-Aware Ability is indispensable for ensuring that decisions adhere to predefined, quantifiable criteria. As illustrated in Fig. 1(c), when a query specifies "LV bags" but the item is a second-hand bag, the model must go beyond attribute matching and apply rule-based criteria to determine the item’s relevance.
