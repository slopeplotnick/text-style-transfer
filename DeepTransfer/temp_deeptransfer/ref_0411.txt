The system achieves improved performance primarily through dynamic prompt generation, which constructs task-specific prompts tailored to the current operational context, including system state, robot capabilities, workload characteristics, and task phase guidance. This approach eliminates the need for 5,000-6,000 redundant example tokens in each prompt, which are extraneous to specific task requirements. Token reduction is achieved through two complementary mechanisms: first, a targeted allocation scope that eliminates the overhead associated with task decomposition and code generation, previously accounting for approximately 14,000 tokens per task; second, the replacement of few-shot example concatenation with structured context provision, thereby significantly reducing the token count in allocation-stage prompts from 6,700 to 1,100. The evaluation of the system's efficacy in task allocation among multiple robots demonstrates its effectiveness across several key metrics, including task completion rates, workload distribution, and adaptability to varying operational scenarios. The analysis was conducted across three distinct configurations, wherein the robots possessed differing skill sets, while the task sequence remained constant, comprising 36 tasks. Each configuration emphasized distinct robotic proficiencies by modifying the success rate matrices for specific tasks. The system demonstrated its ability to sustain robust performance while ensuring equitable task distribution among the robots, a critical consideration in environments such as construction where both efficiency and fairness are paramount. In the configuration termed "Medium Excels," robots with medium-level capabilities achieved the highest overall success rate, successfully completing 87.8% of the tasks. However, this configuration predominantly allocated tasks to the robot exhibiting proficiency across all task categories, resulting in a pronounced imbalance in workload distribution. Success rates for specific task categories in this configuration were as follows: 92.5% for careful tasks, 86.6% for dexterous tasks, and 85% for heavy tasks. Although this configuration achieved optimal overall performance, it simultaneously highlighted the trade-off between maximizing performance and maintaining equitable workload distribution.
