The tool library comprises the Segmentator Tool for region localization, the Analyzer Tool with the Think with Image paradigm [19] for region analysis planning, the Report Generator Tool utilizing strategic template selection, and the Quality Controller Tool, which performs quality assessment of radiology reports and provides feedback for feedback-driven adaptive refinement. Together, these tools support the entire process of automated radiology reporting. Figure 2 illustrates the operational workflow of the Radiologist Copilot. 

Datasets. To validate the effectiveness of our proposed Radiologist Copilot, we focus on the liver radiology reporting task. Specifically, we utilize the publicly available 3D CT dataset AMOS-MM [9], which includes over 2,000 CT scans accompanied by comprehensive radiology reports. This dataset provides 1,287 CT scans with reports for training and 400 CT scans with reports for validation. For the liver radiology reporting task, we filter the AMOS-MM dataset to extract reports containing liver-specific descriptions, designating these as liver radiology reports. As a result, the training set consists of 1,149 CT scans with liver reports, while the validation set includes 367 CT scans with liver reports. The validation set is reserved for performance evaluation, whereas the training set is used for comprehensive report analysis. Initially, we obtain report embeddings using BioBERT [11], followed by K-means clustering to derive template reports. These templates are then summarized into liver-specific elements, including liver surface, liver parenchyma, bile ducts, and liver lesions, which are incorporated into the Analyzer Tool.

Implementation Details. The Radiologist Copilot is implemented using the agentic framework OctoTools [14] in Python 3.10.18, with experiments conducted on NVIDIA L20 GPUs. The system operates in a training-free manner by integrating pretrained models. Specifically, Qwen3-32B [24] serves as the LLM backbone for agent reasoning. The Segmentator Tool employs TotalSegmentator [21] for region localization, while the Analyzer Tool leverages the 3D medical VLM Hulu-Med [10] for CT scan analysis. The system is configured to execute a maximum of 10 iterative steps, with an execution time limit of 500 seconds per case.
