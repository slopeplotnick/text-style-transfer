Prompt engineering is a technical methodology designed to optimize and control how pre-trained language models respond to input instructions. Specifically, we employed prompt chaining, which enhances the efficacy of language models by decomposing complex tasks into manageable sub-tasks. In the context of story parsing, the task was systematically divided into four distinct sub-tasks: entity extraction, event extraction, story outline generation, and relationship identification. The outputs generated from each sub-task were subsequently utilized as inputs for the ensuing sub-task, ensuring a coherent progression and integration of information throughout the parsing process. Prompt frameworks are instrumental in ensuring that models adhere to instructions with precision. In this study, we adopted the TIDD-EC prompt framework, which comprises five components: task specification, comprehensive instructions, delineation of permissible and impermissible actions, illustrative examples, and user-generated content. This framework is designed to enhance the accuracy and relevance of model responses. Table III delineates the prompts employed for the "Entity Extraction" task using the TIDD-EC framework. Furthermore, we investigated four distinct prompting methodologies and evaluated their efficacy in converting narratives into JSON format: Zero-shot prompting, which involved articulating the task in natural language without the provision of specific examples; the TIDD-EC framework, wherein the task was structured using the TIDD-EC framework; TIDD-EC + CoT, which augmented the second strategy by integrating chain-of-thought (CoT) reasoning; and TIDD-EC + prompt chaining, where the parsing task was segmented into four distinct subtasks, each articulated through the TIDD-EC framework, and these subtasks were systematically interconnected via prompt chaining.
