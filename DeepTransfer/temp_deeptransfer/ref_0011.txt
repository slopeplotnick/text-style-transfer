The AgentHarm public test dataset contains 176 samples from 44 unique tasks across 8 categories, such as disinformation and fraud. Each task can be expanded with two modes: one providing a hint about the initial tool to use and the other offering detailed, step-by-step instructions. Combining these modes results in four variations of each task description. In our experiments, we focus on the simplest subset to reduce costs and provide an upper bound on model capabilities, ensuring that capability is not the limiting factor and that context length is the primary determinant of performance (see Section A). AgentHarm uses automatic scoring and evaluation by LLM judges (Zheng et al. 2023). We focus on two metrics: (1) the Harm Score, a rubric-based metric ranging from 0 to 1 that assesses performance on harmful tasks using manually implemented evaluation criteria, and (2) the Refusal Rate, defined as the fraction of samples flagged as refusals by the LLM model. Further methodological details are provided in Section B. We primarily use the Harm Score as the main metric and exclude semantic evaluation, assuming reliable assessment on the simplest subset of tasks. In the context of refusal judgment, we apply minor modifications to both the prompt and the underlying model, as detailed in Section E. To examine context length within a controlled framework, we experiment with four types of context padding: random padding, which uses tokens randomly sampled from the tokenizer; non-relevant padding, which incorporates coherent text from various fiction genres such as humor, mythology, science fiction, crime, and romance, unrelated to the task category; relevant padding, which uses coherent text from Wikipedia articles related to the task category; and multi-task padding, which samples task descriptions from the validation dataset. These padding types allow us to isolate different factors: random padding ensures full control over reproducibility, non-relevant and relevant padding use coherent in-distribution text, and multi-task padding tests the model's robustness to semantically confounding context. For further elaboration, refer to Sections F and G.
