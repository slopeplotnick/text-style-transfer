This research not only advances the application of LLMs in financial forecasting but also introduces a novel paradigm for designing memory mechanisms tailored to specialized domains. By constructing a domain-specific memory system, it effectively addresses the adaptation challenges inherent in general frameworks within professional contexts, thereby laying a solid foundation for future research in this area. The contributions of this study align with the track's objectives in three key dimensions: (1) Structured Knowledge Extraction: By transforming noisy web news into a temporally-structured event knowledge base, this approach supports the scalable creation of structured knowledge from web sources. (2) Semantic-LLM Synergy: The dual-layer memory system enhances the integration of structured knowledge with the reasoning capabilities of LLMs, fostering more effective collaboration between these components. (3) Web Application: The proposed methodology demonstrates practical utility in financial prediction, improving the interpretability of web news-based decision-making systems. Moreover, this work addresses the critical challenge of extracting dynamic semantic knowledge from web corpora, aligning closely with the track's focus. Memory mechanisms have become indispensable for enhancing the ability of large language models to manage complex tasks, evolving from parametric internal storage to external memory systems. Parametric memory encodes knowledge within the model's weights, offering advantages such as rapid access and persistent retention. However, it suffers from poor interpretability and significant challenges in selective updating. To overcome these limitations, researchers have developed external memory augmentation mechanisms, which effectively mitigate the constraints of limited context lengths and knowledge integration in LLMs by constructing sustainable and precisely accessible external knowledge systems. The evolution of external memory systems has unfolded in distinct phases, beginning with retrieval-augmented generation (RAG), which stores unstructured text fragments in vector databases. While RAG partially addresses the issue of knowledge updating, it achieves only shallow semantic matching. As research has progressed, the focus has shifted from simple information storage to systematic memory management. This shift has led to the development of innovative architectures such as GraphRAG, which employs knowledge graph-based structured memory; MemGPT, which functions as an operating system for memory management; and Zep, which integrates temporal knowledge engines to enable the joint retrieval of historical and dynamic contexts. These advancements significantly enhance the reasoning capabilities and management efficiency of memory systems.
