Building on these innovations, this research introduces Lang2Logic, a novel framework designed to bridge the gap between natural language and computational logic. Lang2Logic converts natural language inputs into Conjunctive Normal Form (CNF), a required format for logical reasoning tasks, thereby facilitating the transformation of human-readable statements into machine-processable logical representations. To ensure accurate conversion from natural language to CNF, the Lang2Logic framework integrates symbolic computation libraries with a custom grammar-based parsing approach. This structured pipeline enables the seamless translation of unstructured natural language into a canonical Satisfiability (SAT) problem representation, making SAT solvers more accessible for real-world applications that require human-readable inputs. By enabling the conversion of English text into CNF, Lang2Logic addresses the critical requirement of SAT solvers to operate on CNF representations, thus bridging the divide between natural language understanding and computational logic. The framework comprises three core components: (1) Natural Language to Logical Expression, (2) Logical Expression to CNF Conversion, and (3) CNF Simplification. Each component is essential for ensuring an accurate and efficient transformation from natural language to a machine-readable CNF format. 

The first stage, Natural Language to Logical Expression, employs the ChatGPT o1-mini model API to translate natural language input into a logical expression. The prompt for the o1-mini model was meticulously designed to identify repeated variables across clauses, generate structured logical expressions compatible with downstream systems, and ensure alignment with the input format required by the Sympy converter. This use of the ChatGPT API eliminates the need for complex grammar rule definitions, thereby simplifying the conversion process. However, this approach is not without limitations, as it incurs higher costs and may exhibit reduced performance with larger input sizes. To address these challenges, the Natural Language Toolkit (NLTK) was utilized to preprocess the input data. Specifically, NLTK's Punkt tokenizer segments the text into individual sentences, enabling the o1-mini model to process each sentence independently. This sentence-by-sentence approach prevents errors such as sentence merging or omission, thereby enhancing the precision of the generated logical expressions.
