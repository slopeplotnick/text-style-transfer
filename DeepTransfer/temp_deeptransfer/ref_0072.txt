Such formula-based fault localisation (FBFL) methods either produce an excessive number of redundant diagnoses (e.g., SNIPER) or fail to return a minimal set of solutions sufficient for program repair (e.g., BugAssIST). Recently, Graussam [65] introduced a model-based software fault localisation approach for ANSI C, which incorporates a well-defined fault model capable of addressing complex language features, such as pointers and arrays. This approach builds on CBMC encodings, performing the relaxation step at the CBMC level rather than directly within the code, as in our methodology. Moreover, it addresses multiple failing test cases by formulating standard MBD instances and solving them using Hierarchical Set Decomposition (HSD) [2], thereby ensuring minimal diagnoses for each failing test case. However, Graussam [65] applies an additional aggregation step after diagnosis enumeration, which may compromise the minimality of the final diagnoses. We excluded this tool from our evaluation for two main reasons. First, it requires manual annotations for the functions to be analysed, which is impractical given the scale of our study (over 1500 programs). Second, its current implementation supports only integers and floats in C, making it unsuitable for analysing the C-PACK-IPAs benchmark. Model-Based Diagnosis has been successfully applied to restore consistency across various domains, including Boolean circuits [4, 5, 8, 9, 10, 2, 64], C software [7, 11, 12, 66], knowledge bases [13, 14, 15], and spreadsheets [16, 17]. Additionally, program slicing [67, 57, 68] has emerged as a complementary technique for fault localisation in software systems. One syntactic fault localisation approach [57] employs program slicing to enumerate all minimal sets of repairs for a given faulty program, while another method identifies the causes of faulty behaviour by analysing differences between successive software versions [68]. This paper introduces a novel formula-based fault localisation technique for C programs and Boolean circuits, capable of addressing multiple faults. By leveraging Model-Based Diagnosis (MBD) with multiple failing test cases, CFAULTS consolidates all failing tests into a single MaxSAT formula, ensuring consistency throughout the localisation process and avoiding redundant diagnoses.
