In analyzing images for 3D hand pose estimation (HPE), it is crucial to account for both occluded joints and the global context, which encompasses cues from inter-joint, inter-hand, hand-object, and scene relationships. Convolutional neural networks (CNNs) are widely adopted as backbone architectures in this domain, with ResNet-50 [26] being particularly popular [31, 32, 37, 38, 46, 49, 55, 73]. These CNN backbones leverage local convolution operations, offering a favorable trade-off between accuracy and inference speed. However, their reliance on local receptive fields limits their capacity to effectively capture global context. To address this, recent studies have explored the use of vision transformers (ViT) [12] as feature extractors for hand mesh reconstruction [11, 52, 80]. Despite their potential, the high computational complexity of ViTs often poses a bottleneck in practical applications, highlighting the need for more efficient backbone architectures to enhance feature learning for hand poses. As an emerging alternative, the Mamba model [20], originally developed for natural language processing, has gained significant attention due to its state space modeling (SSM) capabilities. Mamba excels at selectively focusing on input tokens, enabling efficient global context capture from long token sequences. Building on this foundation, several studies have extended Mamba to image processing. For instance, VisionMamba [81] introduced the Vim block, which employs a 2D bidirectional scan for spatially-aware sequence modeling, while VMamba [40] proposed the VSS block, incorporating four distinct scanning paths. However, these scanning mechanisms rely on a fixed grid, as illustrated in Figure 1(a), which restricts their ability to model intricate hand pose variations in 3D HPE. To overcome this limitation, we propose Deformable Mamba (DF-Mamba), an efficient backbone architecture that integrates deformable state space modeling (DSSM) to enable robust visual feature extraction in 3D HPE. The key innovation of DF-Mamba lies in its dynamic modeling of local features and global context through flexible state spaces. Specifically, DSSM blocks aggregate local features along deformable paths and selectively retain critical cues to represent the global context. The scanning path is dynamically adjusted using deformable point sampling with local anchors and learnable offsets, as depicted in Figure 1(b).
