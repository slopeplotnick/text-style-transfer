In total, the dataset contains 81 questions, each addressing a health issue and a potential treatment. These issues span 50 disease and condition categories, such as "Cancer," "Low back pain in adults," and "AIDS," as well as one general well-being category labeled "Other," which covers topics like weight management. Figure 2 illustrates 10 example disease and condition categories most commonly addressed by the health questions. The complete list of all questions and their corresponding categories is provided in Appendix Table A4. To investigate how language models respond to real-world biomedical knowledge conflicts, we developed five prompt templates to evaluate their performance under different question-answering scenarios. As illustrated in Table 2, for each annotated instance from the HEALTHCONTRADICT dataset, we generated five question prompts based on these predefined templates: Question: { Question } Question: { Question } Question: { Question } Context: { Correct Document } Question: { Question } Context: { Incorrect Document }. Our baseline selection was motivated by two objectives: first, to evaluate whether biomedical fine-tuning enhances performance within the biomedical domain, and second, to assess whether increasing model size leads to performance gains. Additionally, we selected language models with extended context lengths to process long documents. Details of the selected models are shown in Table 3. Each biomedical model was obtained by fine-tuning the general-domain model presented in the same row. "Instruct" refers to models that have been fine-tuned to follow user instructions, known as instruction-tuned models. In this study, we do not fine-tune any models; instead, we perform zero-shot inference for the selected baseline models. We evaluate open-source language models ranging from 1 billion to 8 billion parameters to ensure applicability within resource-limited healthcare settings. As shown in Table 4, the difference among larger language models (7-8B) is minor. Moreover, the fine-tuned biomedical model MEDITRON3-QWEN2.5-7B underperforms compared to QWEN2.5-7B. These state-of-the-art evaluation benchmarks are weak at comprehending differences among models' capabilities because they primarily assess a model's parametric knowledge.
