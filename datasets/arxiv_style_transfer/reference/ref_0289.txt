Prompt engineering is a technical methodology designed to optimize and control how pre-trained language models respond to input instructions. Specifically, we employed prompt chaining [40], [59], which enhances the accuracy and reliability of processing outcomes in LLMs by decomposing complex tasks into consecutive sub-tasks. We decompose the task of story parsing into four sub-tasks: extract entities, extract events, extract story outline, and extract relationships. The prompts from preceding steps are provided to the LLMs, with the results incorporated as components of prompts for subsequent sub-tasks, as shown in Figure1.b. Prompt frameworks have been shown to optimize interactions with LLMs, ensuring the precise execution of instructions [60]. In this paper, we adopt the TIDD-EC prompt framework [61], which consists of five key components: task type, detailed instructions, dos and don'ts, examples, and user content. By clearly defining the task type, providing detailed execution guidelines, outlining error-prevention measures, using specific examples to enhance understanding, and incorporating user-specific content, the TIDD-EC framework ensures the generation of more accurate and relevant responses. Table III presents the prompts used during the "Entity Extraction" task based on the TIDD-EC framework. Additionally, we experimented with four prompting strategies and compared their performance on the task of parsing stories into JSON format: - Zero-shot prompting: Described the parsing task in natural language, without providing specific examples [62]. - TIDD-EC framework: Framed the parsing task using the TIDD-EC framework [61]. - TIDD-EC + CoT: Built upon the second strategy by incorporating chain-of-thought (CoT) reasoning [63]. - TIDD-EC + prompt chaining: Divided the parsing task into four subtasks, each described using TIDD-EC, and linked these subtasks via prompt chaining [40].
