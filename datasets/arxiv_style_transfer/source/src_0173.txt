We simplify formulas by cutting out extra parts and keeping only the important pieces, so the formula stays small but still works the same. This makes it easier for SAT solvers to handle. Hallucinations happen when variables or parts of the formula are reused wrong, labeled incorrectly, or translated badly, which messes up how SAT solvers work. These issues can come from models not translating certain sentence structures properly during training or from sentences that don’t follow normal word order, making it harder to turn them into CNF. To fix this, we used NLTK and Sympy together to spot and deal with these problems. NLTK helps break down sentences based on strict grammar rules that have been tested and proven over time. This ensures the sentences are broken down correctly. Then, we use Sympy to make sure the logical structure of the original sentence is kept when turning it into CNF. When we get a paragraph, we split it into sentences at the periods and treat each sentence as its own piece. These pieces are then joined together using logical AND to make a CNF. We use a big set of grammar rules with NLTK to break each sentence into a tree structure that shows how the sentence is built. The tree starts with the main part and splits into smaller parts like conditions, statements, and other sentence elements like nouns, verbs, and punctuation. Using rules we set up beforehand, we turn this tree into a logical formula with Sympy. Sympy then changes this formula into CNF using its built-in tools.
