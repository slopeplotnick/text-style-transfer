Model innovation is still happening, but when it comes to actually using these models, some choices that don't get much attention in academic papers are really important. These choices include how we define virality, what kind of data we can collect (like text or numbers), and how we evaluate models considering real-world limits like access, time, and class imbalance. This paper focuses on evaluation first when making these decisions. We look at two recent datasets and show that how we design labels and what data we use (just text or text plus other signals) can be as important as changing the model itself. We provide clear examples that show these trade-offs. Even though we're focusing on evaluation design instead of new models, we show that simpler models can perform as well or better than newer multimodal and graph-based systems on standard tests like FAKENewsNET. We specifically look at two tasks: detecting fake news and predicting early virality. We want to know what data and definitions are most important to keep performance stable under real-world conditions. We compare text data (like sentence-level transformer embeddings) with simple numeric data (like user stats, early engagement numbers, and timing info). These tasks are tested on datasets with different setups: one with standalone news items and another with social media posts in order. We tackle two supervised classification tasks across two datasets, creating four test scenarios: detecting fake news and predicting virality on EvONS and FAKENewsNET. For fake-news detection, we predict if an item (article or tweet series) is fake or true. This is done on both Evons articles and FakeNewsNet tweet series, and we report results using standard metrics. For FAKENewsNET, we use tweet series built from the repository. The data is anonymized with IDs and needs API hydration; we got the Politifact split from previous academic sharing, but GossipCop couldn't be recovered due to current limits. Each example is a series of tweets about the same news article, showing how it spreads.
