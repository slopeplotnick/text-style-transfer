To tackle this big issue, researchers have come up with two main ways: Fact Verification (FV) and Hallucination Detection (HD). Fact Verification is a well-known area that focuses on checking facts using information from things like web pages or databases. It doesn't matter if the statement is written by a person or a machine; FV just checks if it's true based on the evidence found. On the other hand, Hallucination Detection is newer and came about with the rise of large language models (LLMs). HD looks specifically at stuff created by these models. Unlike FV, which looks at text by itself, HD also considers how the text was generated. HD can use outside information like FV, but it mainly focuses on signals from the model itself, like how sure the model is about each word, how it activates, and how consistent it is across different tries. So, HD is more about the model and can spot made-up stuff even without outside proof. Although both aim to find factual mistakes, they've developed separately, using different tests, ways to measure success, and places to publish their work. This split is because their ways of evaluating are fundamentally different. FV is all about the text itself, using tests like FEVER, where claims are looked at as separate pieces of text.
