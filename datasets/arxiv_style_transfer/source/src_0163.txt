We also want to see if there's a link between how the process is measured and whether the agent can fix the issue. We noticed many early stops because of runtime problems when the model didn't respond correctly, which is a known issue. The way the process is measured is linked to both fixing success and how hard humans think it is. Successful attempts are usually shorter and focused, while ones that don't work have longer paths and repeat steps. The complexity of organizing information is also influenced by how the agent is designed and the backbone language models. Stronger models create a denser organization with more exploration. Besides whether agents succeed or fail in fixing an issue, we look into how agents behave using Phase Flow Analysis. Successful attempts usually follow a structured plan for finding, fixing, and checking that matches what the agents are supposed to do. As tasks get harder, the successful paths get longer but stay clear, while unsuccessful ones repeat or change phases in a messy way. Stronger language models show better and more flexible strategies.
