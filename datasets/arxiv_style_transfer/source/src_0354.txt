Making virtual characters move like real people is important for making games and virtual reality feel real. It's also important in robots because moving naturally can make them safer and use less energy. Learning from how people move helps robots learn skills they can use in different situations. To make characters move realistically, people use data-driven methods that learn from real movement data. Some methods use models like autoregressive models, variational autoencoders, or diffusion models to create believable animations. But these methods often don't follow the rules of physics, so the movements can look fake, especially in new situations. Physics-based methods try to make movements that follow real-world physics by using control policies and dynamic equations. These methods use techniques like trajectory optimization or reinforcement learning. Older methods that didn't use data could make robots move, but the movements often looked unnatural. It's hard to make robots move like real people by just guessing how they should move. Instead, newer methods use data-driven approaches like model predictive control or trajectory optimization to copy human movements better. Recently, methods using reinforcement learning have helped make movements look more real and agile by copying real movement clips. But these methods can limit the robot to only doing what the clip shows, which makes it hard to do new tasks. To fix this, some systems use special planners or high-level policies to choose the best movements or skills for the task at hand.
