We added a step-by-step process to the PPTPilot so it can improve its predictions over time. The agent suggests changes to the XML files, which are then turned into a temporary PPT file. A verifier checks the PPT against the original instructions and gives feedback if something’s wrong. Based on that feedback, the agent updates the PPT and fixes its mistakes. Even though our design is simple, it works well and is efficient for editing PPTs compared to other tools out there. We hope PPTPilot can be a starting point for more research into PPT editing. For evaluation, we use top vision-language models like Gemini 2.5 Pro and GPT 5. Most of the results we show in the main comparison (Table 3) come from GPT 5, but we also include details about Gemini 2.5 Pro and other implementation info in the supplementary materials. For testing, we compared PPTPilot with other PPT tools like ChatGPT in extended thinking mode, Gemini-CLI, GPT-Agent (which acts like a computer and can use a desktop), MiniMax Agent (which is good at multimodal tasks and marketed as a helpful PPT tool), as well as PPTAgent and Poster2Agent. Some tools, like ChatGPT and MiniMax Agent, have strict usage limits and high costs, so we tested a smaller set of 25 samples to stay within budget. We focused on the hardest tasks where PPTPilot and ChatGPT didn’t do well and added a few extra cases to cover a variety of scenarios. More details about these cases are in the supplementary materials.
