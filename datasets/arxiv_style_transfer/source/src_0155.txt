Code Interpreter Agent We use Jupyter Notebook to help solve tough problems. We pick a bunch of different problems from math, logic, and data science that need the model to run code to figure out the answers. General Agent To make agent environments and tasks bigger in RL, we have an automatic agent that creates 1,827 task-focused environments. These tasks are tough to solve but easy to check. The process mainly involves making environments and tools, creating tasks, and coming up with solutions. Here's how it works: 1. For a task type like planning a trip, and with a setup that has a bash and a search tool, the agent first uses these tools to get or find data online and save it in the database. 2. The agent then makes a set of tools for the task, each as a function. 3. To make tasks that are hard but can be checked automatically, the agent starts with a simple task using the current database, along with its answer and checking functions made in Python. The answer function can only use tool functions or do logical calculations, and can't call other functions or directly use the database, so the task can only be solved using the tools. Also, the results from the answer function must be checked by the verification function. If the answer isn't checked right, the agent will change the answer or checking functions until the answer is accepted. The agent then makes the task harder and updates the answer and checking functions. If the tools aren't enough to solve the task, the agent will add more tools.
