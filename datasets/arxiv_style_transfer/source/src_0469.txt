Probabilistic programming languages are types of programming languages that include features for handling probability, like distributions and their samplers. There are many well-known examples, both in imperative and functional styles. The main issue with current languages is that they don't easily work with text-heavy graphs, which are important for defining specifications for language model systems (LMS). This led to the creation of LUMOS. These languages usually generate things based on user-defined probability distributions. For instance, one language is used to create random images or scenes for things like self-driving cars using user-defined scene graphs. But to make real-world specifications, we use a fixed graph and sample parts of it to define scenarios. DSLs for LLMs are query languages that don't have probabilistic features. They help with writing, optimizing, and securing prompts to get the right kind of response from a target LMS. They work alongside LUMOS, which evaluates LMS behaviors over distributions of prompts specified with LUMOS. LMS alignment involves showing LMS weaknesses by testing their performance or conducting attacks on them. Recent work has made probabilistic certifiers for certain LLM properties, which provide formal guarantees for evaluating LMS properties. In this work, we expand LMS certification with LUMOS to specify and certify any desirable properties.
