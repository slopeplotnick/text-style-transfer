We trained both CNNs and VITs using the same adversarial training methods to see how this training affects how attacks can be transferred. You might think that models trained to be robust would make attacks that don't transfer well, but we found the opposite. Models trained with adversarial methods actually make attacks that transfer better than those trained normally. This suggests that the features these models learn might create vulnerabilities that work across different types of models, as shown in Figure 1. We found that adversarial training models make attacks that transfer better, which is surprising and challenges what we think about robustness. There's a new attack called Momentum Integrated Gradient (MIG) that builds on integrated gradient (IG). MIG changes the attack step-by-step using a momentum method guided by IG, targeting the most important parts identified by IG, which makes misclassifications more likely. IG has a key feature called implementation invariance, which lets MIG attacks work across different model types like CNN and ViT, or between both. This wasn't possible with older attacks like PGD, as shown in Figure 2. IG is a method to understand which features are most important for a model's predictions. It works by adding up gradients from a starting point to the actual input. The starting point is a reference.
