Sentiment analysis is really important in today's Natural Language Processing (NLP) and helps with things like digital government stuff, keeping an eye on public health, making sure everyone can use financial services, and checking user content online. But even though deep learning and language modeling have gotten better worldwide, South African languages that don't have a lot of resources aren't getting enough attention in sentiment analysis research. This means there aren't many datasets with annotations, not enough word resources, and limited ways to transfer language knowledge across different languages. Because of this, models that work well for languages like English and French don't do as well in African settings, which makes it harder for people there to access NLP technologies equally. Most of the work done on multilingual sentiment analysis has been about translating languages, embedding languages across each other, or building word lists for one language. These methods have shown some good results, but they have problems. First, when lexicons are translated by machines, they often have mistakes and don't match cultural meanings, especially in African languages that have complex word structures. Second, methods that extract words from large datasets need specific datasets that aren't usually available for languages with fewer resources. Third, even though African language models like AfroXLMR and AfriBERTa have gotten better, they still struggle because there aren't enough good sentiment word lists to help with classification in many languages. To tackle these issues, this paper introduces TriLex, a new three-step framework to help expand sentiment word lists for African languages with fewer resources. TriLex includes: 1. Using datasets to find words that might show sentiment; 2. Mapping these words across English, French, and African languages to make sure they match; and 3. Using Retrieval-Augmented Generation (RAG) to improve, check, and grow the word list with large language models that use multilingual retrieval signals. 1. We're introducing TriLex, a new framework to build sentiment word lists for South African languages with fewer resources. 2. We're creating and sharing a big multilingual sentiment word list for several South African languages to help with research. 3. We're doing the first detailed evaluation of AfroXLMR and AfriBERTa using a resource with expanded word lists for isiXhosa and isiZulu.
