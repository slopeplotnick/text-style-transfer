Vision-Language-Action (VLA) models have shown great results in robot tasks by using big datasets collected by people or set programs. When these models are trained, they use techniques like flow-matching or diffusion to learn different ways to handle tasks. After this training, the VLA model is adjusted for specific tasks using smaller datasets. Using a trained VLA model for new tasks usually works better than starting from scratch because the model already knows a lot about seeing, understanding language, and recognizing objects and spaces. Even though VLA models generally perform well, they have a weakness when used in real situations. This issue is because they keep unnecessary actions that don't help with the task after fine-tuning. During training, VLA models learn many actions from different data, making it hard to focus only on the needed actions for a specific task. So, even after fine-tuning, they still have extra actions that aren't needed. Also, the datasets used for fine-tuning might have different styles because they're collected from different people or methods, some of which aren't ideal. These extra actions create a gap between what the VLA model does and what it should do for the task. This gap shows up when the model is used.
