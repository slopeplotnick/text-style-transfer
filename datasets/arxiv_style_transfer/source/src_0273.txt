CAPO is designed to use a dynamic signal called advantage that matches how the model gets better over time. In the past, curriculum learning methods, starting with Bengio et al. in 2009, mostly used fixed rules like organizing tasks from easy to hard. Later methods tried to adapt by using things like expert feedback or how well the model was doing, but these were still based on outside rules and not directly tied to how the model was improving. This is why we created CAPO, which uses advantage estimates as a built-in signal to guide how tasks are scheduled for the model. Tests show that CAPO helps models get better at solving math problems across different advantage-based reinforcement learning methods like GRPO, PPO, RLOO, and Reinforce++. It also works well for tasks involving graphical user interfaces (GUIs), showing it can handle different types of reasoning tasks. In short, our main points are: we use advantage as a dynamic signal and built CAPO, which has two phases—imitation and discrimination—that adjust as the model improves. CAPO works well with different reinforcement learning methods and can be used for tasks involving multiple types of data, like GUIs. CAPO, shown in Figure 2, works by taking samples made by the policy model, calculating advantage estimates with different algorithms, and combining them into one framework. Using these signals, CAPO organizes training into an imitation phase for stability at the start and a discrimination phase for better results when harder samples are added.
