System prompts help control how large language models (LLMs) act, like setting roles or styles for different tasks. Previous research shows things like personas, emotions, and jailbreak triggers can change how responses sound and how they think, but they don't always make tasks more accurate. Even though they're used more now, we don't really know much about how to make system prompts better in a structured way. Some leaked system prompts from Grok and Claude are full of complicated rules made by hand. New methods show that system prompts can be improved automatically with genetic algorithms, but this has only been done for one language and one type of measurement. When using multiple languages, there are problems like language-specific issues and differences between languages. Multilingual LLMs often give different answers to the same question in different languages because they know more about some languages than others. Techniques like Cross-Lingual Thought Prompting and multilingual self-consistency help a bit, but they usually need several rounds of prompting. There's still no overall way to make system prompts work well in all languages. Besides standard measurements, recent studies look at how LLMs think by breaking down responses into understandable parts. But these studies mostly look at surface-level things, like using text prefill to control the language of the output, without really digging into how the model thinks. Our work fills this gap by connecting system prompt design to how models think in multiple languages and showing how these thinking patterns relate to working well across different languages.
