To make sure the simulated data works for research done on a computer, the different groups in the data need to be easy to compare. To check this, we split the simulated data into "Male" and "Female" groups and tested if they were consistent with each other. If this worked, it would mean we could compare specific groups in the data. In this part, we explain the general process we used in all four studies unless we mention something different in their specific sections. Figure 1 shows how the experiments were set up for all four studies. The simulated data was made using GPT4o-mini, which is a version of GPT-4 updated until October 2023. We used the default settings for the model, like Temperature 1.0 and Top P 1.0, and didn’t add any penalties for frequency or presence. The model was given a prompt that described a person with certain characteristics, like their age, gender, and ethnicity, and it was asked to answer a questionnaire we wanted to test. The prompt included the questions, the answer options, and instructions to give the answers as a single string of values separated by commas so it would be easier to process. Each time we sent a prompt, it was done separately with no memory of previous prompts, so the answers wouldn’t be affected by anything else. Here’s an example of what one of the prompts looked like: "Pretend to be a [Ethnicity] [Gender] who is [Age] years old and lives in the UK. Answer this [Number of items]-item questionnaire. Each question uses a Likert scale from [Likert scale range]. Use this key to answer: [Response Key]. The questions are: [Questionnaire Items]. Give your answers as a single string of values separated by commas."
