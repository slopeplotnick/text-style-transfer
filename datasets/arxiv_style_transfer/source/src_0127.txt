This study improves how large language models (LLMs) are used for financial forecasting and introduces a new way to design memory systems for specific areas of work. By creating a memory system tailored to a particular field, we solve problems with adapting general frameworks to professional situations and set a strong base for future research in this area. Our work fits the goals of the track in three main ways: first, we organize messy web news into a structured event database that makes it easier to create organized knowledge from the web; second, we use a dual-layer memory system to improve how structured knowledge works with the reasoning abilities of LLMs; and third, we show how this approach can be used in financial prediction, making web news-based decision systems easier to understand. We deal with the big challenge of getting meaningful, changing knowledge from web content, which matches the focus of the track. Memory systems are now a key part of helping LLMs handle complicated tasks, evolving from storing information inside the model to using external memory systems. Internal memory stores knowledge in the model's weights, making it fast and long-lasting, but it’s hard to interpret and update. To fix these issues, researchers have created external memory systems that help LLMs deal with limits like short context lengths and trouble combining knowledge. External memory has developed in stages, starting with retrieval-augmented generation (RAG), which keeps unstructured text in vector databases. While RAG helps with updating knowledge, it only matches information on a basic level. As research has progressed, the focus has shifted to managing memory systematically. This has led to new designs like GraphRAG, which uses knowledge graphs for structured memory, MemGPT, which works like an operating system for memory management, and Zep, which combines time-based knowledge engines to connect historical and dynamic information, improving reasoning and memory efficiency.
