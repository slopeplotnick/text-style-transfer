The daughter language model is made for the MOD-OMA. It's like Delilah, acting as a parser and generator, but it's different from the adult language model because its grammar isn't fully detailed and gets more detailed as it learns. Both the adult and child systems use graph structures to show grammar knowledge, and their parsers and generators work by combining word structures to create correct sentences and judge grammar based on the current rules. The child agent's parser and generator can work with incomplete grammar, like humans learning their first language, and the daughter model needs to talk with the mother before it's fully learned. The daughter agent has three parts: a parser and generator called the automaton, a grammar that gets detailed through learning, and a language acquisition device. The parser and generator don't change during learning. Learning results in clear grammar knowledge shown by new word entries and grammar details that limit how words can be combined. An example of a word entry is shown in Figure 2. These structures give detailed info about words and constructions, including grammar details like phonological form, semantic content, and other grammar properties. Grammar properties are shown by pairs like [CONTENT OR FUNCTION WORD: content word] and [CONTENT OR FUNCTION WORD: function word], which is what this study aims to learn. The learning is unsupervised, so the daughter model doesn't know the labels used by the mother model or grammar descriptions. The learned grammar properties and semantic content are marked by unique labels like property type 'A' and property value 'b' in Figure 2, and Figure 3. These structures also include other grammar properties not covered by this study. For example, the terminal feature separates terminal words from abstract constructions, and the semantic content index helps represent things like reflexives. Technical details like session id and word entry number are included to uniquely identify each rule. As language learning is simulated, the grammar can have more complex structures as the HEAD and ARGUMENT can include structures like word items.
