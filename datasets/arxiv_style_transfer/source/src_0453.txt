These results show that using reasoning to improve safety alignment makes omnimodal guardrails work better across different types of inputs and helps us understand and generalize in tricky safety situations where just using labels doesn’t work. To see if safety knowledge learned from one type of input can work on another type, we did some tests. For each test, we trained OMNIGUARD using data from three types of inputs and tested it on those same types, leaving one type out to test how it works on something new. We averaged the F1 scores and accuracy for all the tests and put the results in Table 5. From this, we learned two main things. First, OMNIGUARD does a good job transferring what it learns from one type of input to another. The performance on new types of inputs is almost as good as on the ones it was trained on (79.4 vs. 81.8 F1 on average). This means OMNIGUARD can figure out harmful patterns across text, images, videos, and audio and learn safety rules that work for all of them. Second, there was one exception with audio. The F1 score for audio it was trained on (64.6%) was a little lower than for audio it wasn’t trained on (65.1%). This happened because the version of OMNIGUARD trained without text didn’t do as well on the WildGuard-TTS test, which is an audio version made from text using a text-to-speech model. Not having text data during training made it harder for the model to handle audio, showing that harmful content in different forms, like text and speech, can affect each other when learning safety rules. It also shows that knowledge from one form can be used in another form that means the same thing.
