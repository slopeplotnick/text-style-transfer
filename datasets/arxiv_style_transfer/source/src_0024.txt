We combined different types of CoT data to train the Qwen2.5-VL-7B model using a two-step process. This model is similar in size to the LLM base model we used in our study. When we compared the performance of models based on VLM and LLM, we found that the LLM-based method did better on both easy and hard datasets, especially in macro-F1 scores. This shows that LLMs are better at reasoning and knowledge than VLMs when they have the same CoT capability. However, VLMs are better at handling visual details because they don't need to turn images into text, which can lose information. Over three phases, our LORE model has improved in five main areas: goals, model setup, data and prompts, evaluation methods, and how it's used. These phases show how we've made the model better with advanced designs, good data, and practical ways to use it, especially for making search results better in online shopping. At first, we had trouble understanding queries in e-commerce, especially finding product names that aren't standard. To fix this, we made large, high-quality e-commerce datasets and used In-Context Learning to add domain knowledge to the model, which helped it understand e-commerce language better.
