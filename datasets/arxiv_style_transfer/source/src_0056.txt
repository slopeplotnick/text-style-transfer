The model gets better by learning from its mistakes, but using too many unrelated negative examples can mess things up and make the learning process unstable. We've noticed that using Off-Policy Sequence Masking helps keep things stable in some training situations that would otherwise be shaky. Keep Routing Mixture-of-Experts (MoE) models work more efficiently by only using some expert parts during inference. But differences between how things are done during inference and training, along with policy changes, can cause the experts to be used inconsistently even with the same inputs. This inconsistency can suddenly change which parameters are active, messing up the optimization and making off-policy problems worse. To fix this, we keep the expert routing paths used during inference and make sure the same paths are used during training so that the same expert parameters are optimized. This Keep Routing method is crucial for keeping MoE models stable during RL training, and we've been using it in our RL training since DeepSeek-V3-0324. DeepSeek-R1 showed that thinking through problems can really help a model solve tough problems. Based on this, we want to add thinking skills to tool-calling situations. We found that following DeepSeek-R1's method—throwing away reasoning content when a second round of messages comes in—wastes a lot of tokens. This makes the model go through the whole problem again for each new tool call. To fix this, we made a context management system just for tool-calling situations as shown in Fig 4: - We only throw away old reasoning content when a new user message comes in. If only tool-related messages (like tool outputs) are added, we keep the reasoning content throughout the interaction. - When we remove reasoning traces, we still keep the history of tool calls and their results in the context.
