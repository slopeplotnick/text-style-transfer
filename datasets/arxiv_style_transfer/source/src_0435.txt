XAI explanations need to be clear and true to the model. First, they should be easy for people to understand, and second, they should accurately show what the model does. Being easy to understand depends on who is receiving the explanation, but it usually means the explanation should be clear and to the point. Being true to the model means the explanation should correctly show how the model works, without any bias. Bias can happen if the explanation is limited on purpose. Even though being clear and true are separate things, making each one better isn't easy. For example, explanations that match what people expect are often seen as easier to understand, but this can lead to bias if it affects which explanations are chosen. Also, if a true explanation is misunderstood, it can mislead the person explaining it. This work introduces a way to explain models after they are used, to help make explanations both clear and true. First, it says explanations should use simple language and show cause and effect, because that's how people usually explain things. This helps make sure people understand the explanation the way it was meant. It also means you don't need extra instructions on how to understand the explanation, making it simpler. Using simple language is important because the data the model uses might be different from the best way to explain it. This idea is part of a group of methods called Concept-based XAI, which assumes that while models can handle data like pictures and graphs, people usually communicate using meaningful concepts.
