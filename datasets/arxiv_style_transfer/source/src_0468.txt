We created a tool called promptsolution, which is a Python framework that helps with automatically improving prompts. It’s open-source and works for both people who just need to optimize prompts for one task and researchers doing big studies with lots of benchmarks. The tool is designed to be easy to use and flexible, so you can swap out parts or try different optimizers if one isn’t working well. Even though not every optimizer in the library is perfect for every task, there’s always at least one that works well for each situation. It’s also easy to compare different optimizers in promptsolution because the tool is set up to handle those kinds of tests with very little extra work. We showed how the framework works, explained how its parts fit together, and proved that it’s useful and competitive by comparing it to other tools. In the future, we want to make it work with other frameworks like DSPy so users can combine features from both. We’re also planning to add tools to make managing big experiments easier, like connecting it to configuration tools such as hydra. To make it more user-friendly, we’re working on a simple interface where you can track experiments and see results in real-time. Since multi-agent systems are becoming more popular, we’re also looking into ways to optimize prompts and communication setups for systems with multiple agents. Inspired by AutoML, we’re thinking about adding features that combine multiple optimizers to get better results. Overall, the framework is built to grow and include new methods as the field keeps changing.
