We looked at how well models handle math problems using five tests: AMC, Minerva, MATH-500, GSM8K, and Olympiad-Bench. To check if the answers were correct, we used GPT-4o to compare them with the right answers, following methods from some earlier studies. For general reasoning, we tested how well models work across different subjects like physics, biology, business, economics, and law using benchmarks like MMLU-Pro, SuperGPQA, GPQA-Diamond, and BBEH. These tests are harder and help us see how good the models are at complex reasoning. We measured accuracy using a method called Exact Match, which checks if the answers match perfectly, and used greedy decoding to get the results. To figure out how important different parts of the model are, we did tests where we turned off certain features in the Qwen3-8B-Base model and saw how it affected performance on math and general reasoning tasks. The results are in Table 2. Turning off challenger training made the biggest difference, lowering math and general scores by 1.9 and 1.0 points. Removing challenger warm-up and curriculum learning also hurt performance, showing these parts are important. Math tasks were more affected than general tasks, which matches what we saw in Table 1, where math scores varied more depending on the method used. Overall, the results show that using a mix of human data helps improve performance in general, but focusing on specific types of data works better for improving performance in those areas. This is useful because it means developers can guide how the model improves by choosing certain types of data, which helps keep the model focused on what it’s supposed to learn and avoids it going off track.
