We check how well the timing of the source and edited videos match up using four measures: speech, where we look at mouth movements; gaze, where we track eye movements; blink, where we check how often eyes blink; and pose, where we look at body movements. These measures help us see different parts of how things move. We use them to pick and check the data, but not to train the model. For checking if the edits are done right and stay the same throughout the video, we use two measures based on CLIP. The first one, Directional CLIP Score, is about making sure the changes in each frame match the overall edit direction. We have two types: one that looks at how the first edited frame matches the rest, and another that checks if the changes match the text prompt. The second type is fairer for methods that only use text, like LucyEdit. The first type checks if the changes in the video look like the changes in the first frame, while the second type checks if the changes match what the text says. The other measure, CLIP-Text Alignment Score, checks if each frame matches the text description well, making sure the video sticks to the text's meaning over time. This measure works with the Directional CLIP Score to see if the video stays true to the text.
