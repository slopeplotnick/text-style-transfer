There are different systems for handling memory in financial tasks. FinMem is a system that uses short, mid, and long-term memory to help make trading decisions. MemP is a framework that turns trajectories into step-by-step instructions and overall strategies, using procedural memory. MemGPT works like an operating system, managing storage and interruptions to make the context window bigger for large language models. Zep is a system that uses temporal knowledge graphs to connect past relationships and changing contexts. To measure how well these systems work, we use accuracy (ACC) and Matthews Correlation Coefficient (MCC). ACC checks how correct the predictions are overall, while MCC is better for balanced datasets, especially when predicting stocks where the classes might not be evenly distributed. We tested these systems on four stocks and found that our approach did better than all the others in both ACC and MCC. This shows that our system works well. The tests also showed problems with the other systems. FinMem doesn’t model events over time, so it misses important market changes. MemP simplifies trajectories too much and loses important financial details. MemGPT isn’t focused on events, so it misses key financial patterns. Zep doesn’t connect events well, so it misses important relationships in financial data. Our system fixes these problems by turning unstructured news into structured event knowledge. It captures how events are connected and makes it easier to trace and reason through the data, helping to make better financial predictions.
