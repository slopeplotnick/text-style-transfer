We don’t look at where they come from. HD methods rely on internal model states that FV settings can’t give. People have tried to fix this by making static benchmarks for LLM outputs, like HELM, but those don’t work well because they can’t test new or unusual models or track changes in generative signals. This mismatch has caused two separate research paths, which wastes effort and leaves big questions unanswered. We don’t know if one approach is better, how their strengths are different, or if they can work together. Keeping them separate also stops us from using their strengths together: HD’s internal signals could help FV’s reasoning based on evidence, and FV’s context could help ground HD’s uncertainty signals. So, we’ve taken a big step to fix this divide. We’ve done the first large-scale study to directly compare Hallucination Detection and Fact Verification in one setup. This isn’t just about benchmarks; it’s a deep look at how these two approaches are connected. By combining them, we can finally answer three big questions: (1) How do HD and FV perform when spotting factual errors in the same LLM outputs? (2) Do HD and FV focus on different types of errors, showing strengths that complement each other, or do they fail on the same things? (3) Can we combine signals from both methods to make a hybrid system that works better than either one alone? People thought this comparison couldn’t be done because the two approaches are so different, but we made it possible with UniFact, a framework that solves the incompatibility that split the field. Instead of using fixed outputs from LLMs, UniFact uses a dynamic process where it asks any LLM to answer factual questions live. Then it uses an automated system to check if the answers are correct by comparing them to true answers and reference knowledge that’s already labeled. This dynamic setup is key because it gives both the outputs FV needs and the internal signals HD needs. This lets us directly compare the two approaches side by side on the same content.
