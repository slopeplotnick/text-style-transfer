This part explains how we calculate each evaluation method and what the results mean, including checking word overlap, meaning similarity, and whether the information is accurate. ROUGE-L looks at the longest matching sequence of words between what the model writes and a reference summary. It focuses on how sentences are structured and doesn’t worry much about the order of words. People usually use it to compare a system’s output with a human-written summary. Here, we’re not looking at the exact ROUGE-L score but comparing how it changes depending on the order of the input to see if the order affects the results. Since ROUGE-L only checks for matching words, we also use BERTScore and SummaC to check meaning and accuracy. To go beyond just matching words, BERTScore uses a pre-trained model to compare the meaning of words in context. It matches each word in the model’s summary to the most similar word in the reference and calculates precision, recall, and F1 based on these matches. This method works well for checking meaning because it can handle synonyms and rephrased sentences. In our study, we’re looking at how BERTScore changes depending on the input order, not the exact scores, which might be low because the summaries are more abstract. SummaC checks if the summary matches the original documents to see if the information is accurate. There are two types: SummaC-ZS, which doesn’t need training, and SummaC-Conv, which is a trained model. We use SummaC-Conv because it works better. The RoBERTa-based model behind it has a limit on the amount of input it can handle.
