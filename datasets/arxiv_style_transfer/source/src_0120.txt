TokenPowerBench is a tool that helps measure how much power and energy is used when running large language models (LLMs) on different types of hardware, models, and tasks. It focuses on making these measurements simple, flexible, and easy to repeat. The tool uses energy-based metrics like how many joules are used per token or per response, and how much power is being used at any moment. These measurements are tied to specific parts of how LLMs work, like the prefill and decode stages, so you can see exactly where the energy is being spent. Unlike other metrics like speed or how much data can be processed at once, these energy metrics focus on sustainability and cost, which are big concerns for AI systems today. The way TokenPowerBench measures power is very detailed and depends on the hardware and tools being used. It has three levels of measurement, from just looking at GPU data to monitoring the whole system using advanced tools, so it can work in small setups or big testing environments. It also uses a setup that makes sure experiments can be repeated the same way every time. The tool is designed to handle different types of LLM tasks, which can change based on the size of the system, the model, or how it’s being used. It looks at things like batch size, context length, and how the system is set up to see how these affect energy use. It works for setups ranging from single GPUs to large multi-node systems, showing both small details and big-picture energy use. Since LLM technology is changing fast, TokenPowerBench is made to keep up. It will expand to work with new types of GPUs, chips, and other hardware, and it will also add features to measure how saving energy might affect the quality of the model’s results. This will help users decide how to balance energy use and model performance.
