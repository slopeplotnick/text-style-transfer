The interviews will cover these questions: 1) What parts of your thinking are hard to explain when you're being creative? 2) Which of the four main parts helps you the most with being creative? 3) Do you face any problems, and how do you solve them? 4) Do you get any new ideas while being creative? Volunteers (P1-P4) liked making stories with a drag-and-drop card setup more than using text outlines because they found it more fun. But some volunteers also had issues with editing the card details over and over (P1, P4). P1 said, "When I make a story, I first think about the big picture, so I start with event cards and entity cards to set up the story. Then, I add details to the event and entity cards." P4 mentioned, "I had to make changes several times while creating. If editing the details was easier, I'd use this method more." Some volunteers also thought that some story details could be shown through interactive ways (P2, P3). P2 said, "I like putting entity cards that are part of the same event on top of the event cards. This way, I can easily see which entities are part of the event." P3 suggested, "We could use relationship cards to link different entity cards. If event cards had lines connecting them, it would show the order and flow of events better." Based on these ideas, we see important interaction patterns (Figure 2) and suggest these three design goals: - DG1: The system should let users enter details for each main part to help build the first story outline. - DG2: The system should help users understand the whole story setup, making it easier to see how entities and events are connected. - DG3: The system should give feedback and specific tips to make the story framework better.
