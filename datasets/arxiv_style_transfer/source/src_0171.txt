The MODOMA system helps study how people learn language by acting like a lab setup. Both adults and kids are part of it. You can change settings in the system, and it clearly shows the grammar rules it learns, which researchers can easily check out. This study shows that using a computer setup with multiple agents to learn a first language is doable. Zipf's law is a key part of checking how well the MODOMA system works for learning language. The experiments in this study use a mix of methods to figure out different word types, like function and content words, and include all the parts of more complicated experiments. The results give a good base for more research. Future studies could look at how changing settings affects the grammar the kid agent learns, what it says, and how it talks with the adult agent. This could include how often the word learning process happens and if old word types should change with new info. Another area to look into is how feedback from the adult agent affects the kid agent's language learning and talking. The success of these experiments means more complex learning methods can be tested. The MODOMA system can also be used to study more complicated grammar stuff. For example, Shakouri and others in 2025 show that you can learn grammar categories like nouns and verbs in similar ways to learning function and content words. They use advanced stats methods to find these categories without direct teaching. This study's results are a big step for more research in this area.
