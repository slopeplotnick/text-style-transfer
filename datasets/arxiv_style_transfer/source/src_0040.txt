Most systems store info as separate documents or facts, but predicting finance needs to store events in order, so it can understand how things affect each other over time. For predicting stocks, you need to think about similar past situations, and just looking at one document for meaning isn't enough. Regular systems forget things based on time or simple human memory models, but finance needs to remember important patterns for a long time. This paper suggests a new way to improve memory for finance, making a detailed and up-to-date collection of financial knowledge for language models. Here's what we did: We made a system that turns market info into memory units with dates, event types, and related things like companies and industries. This helps connect market info into organized sequences, which is useful for finding and understanding patterns. We created a way to find similar event sequences, which is better than just looking at one document for meaning. By using the current event sequence to search, our system can find complex past patterns that match the current market. This helps move from just matching text to finding patterns. We tested how well this system works and found it predicts stocks better than other models. Because it models event sequences, it can show the key events affecting stock prices and how they change, making predictions more trustworthy and clear.
