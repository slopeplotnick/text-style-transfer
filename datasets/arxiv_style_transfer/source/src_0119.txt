We're checking how OMNIGUARD works using different public safety tests that cover both single and mixed types of data. For single types, we look at text, images, videos, and audio. For text, we use tests like BeaverTails, ToxicChat, WildGuardMix, Aegis2.0, and OpenAI Moderation. For images, we use UnsafeBench, VLGuard, and LlavaGuard. For videos, we check SafeSora and SafeWatch-Bench. For audio, we use MuTox English split and WildGuardMix-TTS, which turns WildGuardMix test samples into speech. For mixed types, we test OMNIGUARD with image-text, video-text, and audio-text setups using MM-SafetyBench, VideoSafetyBench, and AIAH. We look at how accurate and reliable the system is, using Accuracy and F1 as main measures. If tests only have unsafe samples, we just report accuracy. We also compare OMNIGUARD with other models, including big and small ones, to see how well they protect. We check against specialized models too, like those based on LLM and VLM.
