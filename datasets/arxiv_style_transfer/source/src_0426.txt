In this study, we're looking at finding patterns that show when things aren't working well or are going backwards. We use a tool called GRAPHECTORY to help us find these patterns more easily. We're focusing on a few signs that might mean something's not working right: H1 is when someone keeps doing the same actions that don't fix the problem, so they need to try something different. H2 is when someone keeps jumping around in the project instead of moving forward steadily. H3 is when someone spends a long time on a task without making progress. H4 is when something doesn't work right, which might mean they're not using their tools well. RepeatedView is when someone keeps looking at the same part of the project, like a file, over and over, which means they're checking the same code again, often after edits that didn't work or when they haven't found the problem yet. For example, after two failed tries to edit (step 9), they open the same file client.py again (step 10) to try to find the problem. ZoomOut is when the order of actions doesn't match the project structure, meaning someone goes from a deeper part to a shallower part of the project. This shows they're going back because they realize they're in the wrong place. For instance, after going into the wrong directory postgres (step 3), they go back to the main folder /testbed/db (step 4) and then go into the right folder /testbed/db/postgreSQL (step 5) to find the problem file client.py (step 6).
