We made a tool called promptolution. It’s a simple, open-source Python framework to help automatically improve prompts. It’s been tested and works well. The tool works with different language models, NLP tasks, and methods for improving prompts, and you can swap out parts or add your own. It’s useful for people who want to improve one prompt at a time, but it’s also good for researchers because it helps run organized and repeatable experiments. Prompt optimization means using automated methods to test and improve prompts, including the instructions and examples in them. There are two main types: continuous and discrete. Continuous methods work with numbers, while discrete methods work directly with text. Our tool focuses on the discrete kind, which is easier to understand and works with any language model. It improves prompts step by step, often using another language model to suggest better versions. The tool includes these methods: OPRO, which uses a language model to suggest better instructions based on task descriptions, examples, and previous results; EvoPrompt, which uses genetic algorithms and differential evolution to improve instructions, with a language model handling the changes; and CAPO, a newer method that uses AutoML to make improvements more efficiently and works on both instructions and examples. CAPO is better at saving costs and performs better than the other methods.
