We show that SR-GRPO helps with reasoning in different tests, proving that geometric signals can be a good basis for aligning language models. Besides reinforcement learning, we also prove that stable rank is a good zero-shot reward proxy for checking language model responses and fits well into best-of-N decoding. We suggest using stable rank (Rudelson & Vershynin, 2007) as an unsupervised quality signal from language model representations. Here, we define the metric, explain why it's useful geometrically, and prove it's effective as a reward proxy. Theoretical motivation comes from two areas. The softmax bottleneck (Yang et al., 2018; Godey et al., 2024) says that expressive language modeling needs high-rank representations, while representation collapse is a known issue with bad generation (Gao et al., 2019). Stable rank measures this dimensionality, making it a good choice for quality checking. We prove this connection with tests and correlation analysis in Section 5. We test stable rank as a zero-shot proxy for human preference by seeing if it can predict the preferred response in a pair. This test checks if stable rank can be a reliable reward signal without specific model training. Setup involves using RewardBench (Lambert et al., 2025), a benchmark with 2,985 preference pairs in five categories: Chat, Chat-Hard, Safety, Code, and Math. For each pair, we calculate stable rank for both responses and predict the one with the higher stable rank as preferred. We compare against three baseline methods: (1) Pointwise Scoring (Point.) (Kim et al., 2024): asking the language model to score each response from 1 to 5; (2) Pairwise Comparison (Pair.) (Kim et al., 2024): asking the language model to directly compare two responses; (3) IPO (Garg et al., 2025): using preference scores from Yes/No token probabilities. We test five models: Qwen2.5-1.5B-Instruct (Yang et al., 2024), Qwen3-0.6B (Yang et al., 2025), Qwen3-8B (Yang et al., 2025), Llama-3.1-8B-Instruct (Dubey et al., 2024), and Phi-3.5-mini-Instruct (Abdin et al., 2024). For stable rank, we format inputs as prompt-response pairs using each model's chat template and get final-layer outputs.
