We came up with something called Score-Matching Motion Priors (SMP), which is a tool you can reuse to help with physics-based character animation. It works using score-matching, and once it's trained, you can use it to teach control policies for different tasks. It helps make the movements look natural and match the original data it was trained on. You don’t need to keep the original motion data to use it. There are techniques, like classifier-free guidance, that you can use to tweak the motion prior and create new styles so agents can do tasks in specific ways. We tested this method in a bunch of situations, like movements for single characters and interactions between people and objects. You can build SMPs using all kinds of datasets, whether it's just a few seconds of motion clips or big datasets with up to 20 hours of motion data. In our tests, we showed that using reinforcement learning with score distillation sampling (SDS) can create movements that are just as good as those made with adversarial imitation learning, and you don’t have to keep updating the prior while training the policy. SMP also works better in most cases because it uses a more stable reward system compared to adversarial models. But, like other methods that focus on specific modes, policies trained with SMP can sometimes get stuck only doing a limited set of behaviors from the original data. Even though we mainly focused on humanoid motion control, we think SMP could be useful for other control problems too. We hope this idea leads to new ways to make general motion tools that help create more flexible controllers for animation and robotics, not just for motion tracking.
