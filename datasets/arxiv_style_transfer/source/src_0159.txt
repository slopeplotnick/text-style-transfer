People care about saving energy in things like mobile apps and software in data centers. Take languages like Java, Scala, or Kotlin, which run on a virtual machine using Java bytecode. How much energy the software uses depends on the compiler, the Java Virtual Machine (JVM), the garbage collector, the operating system, and the hardware it's running on. To really get how software design choices affect energy use, a software engineer needs to know a lot about these different layers and the platform where the software will run.
