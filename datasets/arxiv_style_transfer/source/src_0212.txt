We came up with a way to make diffusion language models stop early without needing extra training, called SchED. It uses a schedule, like linear or cosine, to decide when to stop based on how confident the model is, and it works with any model setup. By looking at how confident the model gets over time, we can see that tuning the instructions helps the model stabilize faster, which matches the schedule and lets it stop early without messing up the quality. SchED works by setting a confidence level that changes smoothly as the model generates text, using the strengths of diffusion models to make the process efficient without needing retraining. The code is available online. Diffusion language models are a newer option compared to autoregressive ones, and they can be trained from scratch or by tweaking existing autoregressive models. One approach, LLaDA, trains a model to mask text in one direction and fix it in the other, showing good results in training and fine-tuning. Some methods turn autoregressive models into diffusion ones to compare them fairly across different sizes and tasks, while others, like Dream-7B, focus on improving recipes and making different versions of the model. New designs, like LLaDA-MoE, use sparse setups to get good results with fewer active parts. Diffusion models are also being improved to handle longer texts, like UltraLLaDA, which uses a method called RoPE scaling to work with up to 128K tokens. Seed Diffusion focuses on making code models run faster. Studies on how these models scale show they grow as well as autoregressive ones. Papers summarizing the field talk about the benefits, like working in parallel, filling in gaps, and handling big-picture context, as well as the questions that still need answers.
