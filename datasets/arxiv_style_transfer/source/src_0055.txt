To simplify a program statement, you wrap it in an if-statement with a condition that's a relaxation variable. For example, in the program on Listings 3, lines 5 and 6 are changed by CFAULTS using relaxation variables _rv1 and _rv2, which show up as lines 11 and 12 on Listings 4. When you relax if-statements, the stuff inside the then and else parts follows the same relaxation rule. But for the conditions of if-statements, you use a ternary operator, like in line 14 of Listings 4. If the relaxation variable is true, the original if condition runs. If not, another relaxation variable (like _ev4 in Listings 4) decides if the program goes into the then-block or the else-block, if there is one. These relaxation variables are specific to each failing test and help decide if you go into the then or else-block. For expression lists, CFAULTS does something similar to general program statements, putting each expression in a ternary operator instead of an if-statement. If a program part is turned off, the expression becomes 1. For example, the start of variable i in line 11 of Listings 3 changes into a ternary operation in line 17 of Listings 4. All relaxation variables in a loop are Boolean vectors to relax statements in the loop. Each part of these vectors relaxes the loop's statements for each round. The CFAULTS user sets the maximum number of loop rounds. CFAULTS does the same for inner loops, making arrays of arrays. For simple program statements in a loop, CFAULTS wraps them with if-statements, with relaxation variables linked to the round number. Line 20 of Listings 4 shows a relaxed statement in a loop. The loop's condition is relaxed by the relaxation variable, as shown in line 18 of Listings 4. Each loop has its own offsets to index relaxation variables, which are set up just before the loop and increased at the end of each round, like in line 19 in Listing 4.
