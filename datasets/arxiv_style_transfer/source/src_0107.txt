LLMs have made it possible to change how we predict things based on events. Unlike older methods, LLMs can pull out full details about events—like what kind of event it is, who’s involved, and when it happened—straight from regular text. They keep the information accurate so we can figure out causes and provide clear reasoning. But current research hasn’t fully used what LLMs can do. For example, methods like CAMEF[25] use LLMs to pull out event details but then shrink those details into small data chunks for older types of neural networks to process. This turns LLMs into just fancy tools for finding features. Doing this loses a lot of event details, doesn’t clearly show how events are connected or change over time, and doesn’t create a memory system that can be reused or traced back. Our approach is different. Instead of squeezing detailed event info into small data bits, we use those details as building blocks to create a structured memory of events. By clearly tracking, combining, and organizing events, our method helps us directly understand how events change over time and compare patterns across different situations. This fixes the problems with current LLM methods when it comes to linking event sequences and spotting patterns that repeat over time. This is the main point of our work. We’ve created a system to analyze events for predicting stock prices. It builds a knowledge base of events from news and improves it with feedback from the model.
