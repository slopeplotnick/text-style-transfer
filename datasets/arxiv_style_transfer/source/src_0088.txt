Figure 1 shows how the fine-tuned model works. First, it picks out important details from the query and item descriptions, like product names, brands, model details, and who the product is for. Then, it checks how well these details match up between the query and the item to see if they're relevant. The CoT tuning helps the model not only guess the relevance labels right but also explain why. When we look at the outputs of the fine-tuned model, we see it tends to be too strict about relevance. It often labels products as "Irrelevant" if some details from the query aren't in the product description, even if those details don't really matter for buying decisions. This strictness causes more false negatives, which lowers the model's recall rate and hurts the platform's transactions and revenue. To fix this, we make sure the model's predictions match what real users do and say. We use the fine-tuned model to predict pairs of queries and items that were bought from past data and pick the ones it said were "Irrelevant" to make a training set. We treat these strict predictions as losers and use GPT-40 to make "Relevant" reasoning results for the original query-item pairs as winners. Then, we use the KTO algorithm to align the model with these preferences. Unlike other alignment methods, the KTO algorithm uses simple binary labeled data for model alignment, making it easier and faster to set up.
