People have started using system prompts as a simple way to guide how large language models (LLMs) behave when they’re being used. Studies show that if you design prompts carefully, you can make the models reason better and reduce bias. But most of this research has been done in English and hasn’t really focused on making one prompt work well in different languages. When you try to use these models in multiple languages, it gets tricky because prompts that work in English don’t always work as well when translated or used for tasks in other languages. This can cause problems like less accuracy, unstable reasoning, and inconsistent results across languages. So, the big question is: how can we make one prompt that works well and consistently across many languages and tasks? To figure this out, we broke the problem into three main questions: First, what kinds of prompts help models behave better in multiple languages? Second, can we find good prompts automatically without needing a lot of human effort? Third, how do good prompts affect things like reasoning and the language used in responses? To answer these, we came up with a way to evaluate prompts based on four things: average accuracy, how much accuracy changes, how consistent the results are across languages, and how much the response length varies. By looking at how different models perform on various tasks, we came up with a method to improve prompts for these goals. Then we looked at the model outputs to see how these improved prompts change reasoning and make results more consistent across languages. We also introduced a new way to optimize multilingual prompts automatically. Plus, we studied a lot of reasoning data and found that good prompts tend to make models reason in a more organized and consistent way, with less switching between languages. This suggests that the way models reason might be a big factor in making them work better in multiple languages. Overall, our work shows that improving system prompts is a useful and not fully explored way to get better and more reliable results from multilingual LLMs. You can find the code and dataset at https://github.com/orange0629/multilingual-system-prompt.
