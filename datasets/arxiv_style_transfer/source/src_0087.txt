When we look more closely at the results for each sample, we see that sometimes using a different resolution gives better results than when the resolution is set to 112, like it shows in Figure 3. The results from cropping images at different resolutions and looking at the semantic similarity map help explain why this happens. Basically, when the whole object gets split into different parts, some parts have higher semantic similarity (measured by VisRAG), and others have lower similarity. After filtering, only the parts with higher similarity are kept. But this messes up the full picture of the object and makes it harder for MLLM to make accurate judgments. To fix this, we came up with a new framework called Multi-resolution Retrieval Detection (MRD). The main idea behind MRD is to use multiple resolutions at different scales to better find the areas that have the target objects. This makes it easier for the system to find the right image crops that match the target objects, cutting out distractions and helping MLLMs better understand high-resolution images. Based on what we found in subsection 3.2, we think that using different resolutions to calculate semantic similarity works better for objects of different sizes and positions. With this in mind, we created a simple but effective method called Multi-resolution Semantic Fusion. It calculates semantic similarity maps at different resolutions on a local scale and combines them in a way that improves the accuracy of the similarity results. To make it easier to find target objects, we also use an open-vocabulary object detection model that scans the whole high-resolution image using a sliding window, giving confidence scores for areas that might have the objects. By combining these confidence scores with the multi-resolution semantic similarity maps, our method not only helps locate target areas more accurately but also tells apart small differences between the crops in those areas. This makes it easier for the system to find the important parts of the image. The next sections will explain each part of this process in more detail.
