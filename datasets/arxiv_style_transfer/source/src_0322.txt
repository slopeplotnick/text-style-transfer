We used a multimodal language model to work with images. After making the images, we described what was in them by pulling out key details in a structured way. To do this, we used an open-source model called LLaMA 3.2 Vision through the Ollama framework. This model was picked because it can handle images and turn them into clear, detailed descriptions in natural language. It’s good at describing things with lots of details, so it works well for turning what’s in an image into structured information. Even though our main goal was to pull out structured triples, this process is kind of like writing captions for images. Studies show that multimodal language models perform similarly when it comes to understanding visuals. All the models we looked at were pretty reliable, but since our focus was on how the information is structured and compared, we stuck to using one model as an example. To make sure the triples we pulled out were consistent and focused on fashion, we used the Fashionpedia ontology. This is a detailed guide that lists categories, parts, and features related to clothes and accessories. By using this guide and giving it to the model as part of the instructions, we made sure the information we got followed a clear and specific structure. We also ran a test where we didn’t use the ontology to see what would happen. The results, shown in Table 1, showed that using the ontology led to more triples per image and covered more relationships. Without it, the model only picked up on a few obvious details and didn’t create as much useful information. This shows that using the ontology is really important for getting detailed and consistent results, which are needed for comparing the information in a graph-based way.
