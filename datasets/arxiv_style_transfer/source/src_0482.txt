As far as we know, PPTArena is the first tool that looks at PPT editing as a step-by-step process based on the meaning of the deck, provides detailed info for each element, style goals, and error checks to make sure edits are correct, and uses instructions and visual checks to allow different ways of editing while keeping the task clear. Along with this tool, we’ve made PPTPilot, which is a smart editing tool for detailed PPT changes. PPTPilot breaks down each instruction into smaller steps, picks between using APIs like python-pptx or directly editing XML files, and checks the results against the task goals. Two main ideas make it work: planning based on the structure, where the tool looks at slide templates, placeholders, shapes, text, and visual info before editing, and exact execution, where XML edits and strict rules control fonts, colors, positions, and template changes while automated tools handle repetitive tasks like translations and normalizing styles. A cycle of planning, editing, and checking, along with XML and visual validations, makes it better at handling tricky and long edits. We tested different tools on PPTArena, including advanced PPT tools like ChatGPT Agent and MiniMax Agent, visual-language models, and simpler versions of PPTPilot. Even with detailed instructions and access to tools, current systems have trouble keeping instructions accurate while making edits that look good and work well for complex, multi-step tasks. They often mess up when edits depend on connections across slides or template-level style changes that our tool highlights. PPTPilot, on the other hand, scores much better, beating advanced tools and models by over 10 percentage points on complex edits while still doing well on easier tasks. But even PPTPilot and other tools don’t do well on very hard tasks that depend on visuals, showing how challenging PPTArena is and how much room there is to improve in the future.
