The project is about adding new features and updates to the framework. It's about tech stuff and farming improvements too. The main idea is to develop things quickly, like making a new app faster than the last one. The project combines ideas like reusing code, being innovative, and working fast. It started as a code base that could be used again. This helps with the migration project. We found 7 good practices. Factorization and Reuse came up the most, 9 and 8 times. Figure 1 shows this. Knowing the benefits is important because it motivates the team. Customization is a big part of an SPL and was mentioned a lot by IT, UX, and AGRO folks. An SPL is seen as a platform that can make customized software from existing ones. Speed is the second most mentioned idea by IT, PO, and UX people. It means making new software quickly. Automation was also mentioned, which is making new software automatically. IT and PO folks see automation and speed as linked. Industrialization was mentioned by IT and UX people, meaning making apps on demand and cheaply. Improving code quality was only mentioned by IT people, which means making the code consistent, testable, and reliable. Selling advantages were mentioned by IT and PO folks, which means selling more software or responding quickly to opportunities. These 7 benefits are shown in Figure 2. Customization, mentioned 10 times, is the most talked about idea, followed by speed.
