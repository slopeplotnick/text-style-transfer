AI agents can now think, plan, and use tools on their own. Recently, we've seen medical agents doing tough medical jobs. Like, MMedAgent uses different tools to do medical tasks, such as writing reports for chest X-rays. MedRAX is a special agent for reading chest X-rays and uses the latest tools for that. CT-Agent is good at understanding 3D CT scans and helps with reasoning. But for making radiology reports, these agents usually use one tool and don't work well together. Our Radiologist Copilot is different because it uses many tools that work together and can plan and do more complicated tasks. Writing radiology reports is important but takes a lot of time and can have mistakes, especially with 3D images. Checking the quality of these reports is really important but can be boring and is often skipped in other studies. To solve these problems, we made Radiologist Copilot, an AI helper with a set of tools for making radiology reports and checking their quality, to help radiologists and make things more efficient. Radiologist Copilot, as shown in the picture, helps radiologists with the whole process of making radiology reports. First, it sets up the tool library and then uses the action planner and executor to plan and do tasks. It has a memory module that keeps track of what actions are done and their results, so it can check if tasks are finished. The action executor makes and does commands based on the next action planned. For each action, it makes the right command for the chosen tool, does the command, and gets the result of the action.
