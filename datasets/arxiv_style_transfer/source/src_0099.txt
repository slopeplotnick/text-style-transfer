We looked into how using structured climate data affects retrieval-augmented generation. We thought adding this data would make answers more accurate and easier to understand, but the results show it’s still in the early stages. In Table 1, the DATA_RAG setup, which uses both literature and data, didn’t do as well as the RAG setup, which only uses literature. The biggest drop was in accuracy. This shows the current model isn’t great at using structured climate data to back up or improve reasoning in the text. CAIRNS is a question-answering system for agricultural climate adaptation that tries to balance being easy to read, accurate, and clear about sources. It uses structured prompts (SGP), multi-step reasoning, and a consistency-weighted Hybrid Evaluator. Tests show that SGP makes the structure and source reliability better without losing accuracy, which is a good step toward making QA outputs fit what domain researchers prefer. But using data-augmented retrieval isn’t very effective yet. The Hybrid Evaluator uses agreement between models as a signal to weigh credibility and performs best among automated evaluations without needing fine-tuning or reinforcement learning. It works well in situations with limited resources or experts for question-answering. In the future, we want to improve location-specific reasoning by adding detailed geographic data like latitude and longitude. This would help transfer documents across areas with similar climates and make literature-based insights more general. We also plan to create a bigger evaluation benchmark that covers different question types and topics. This will help calibrate the Hybrid Evaluator and provide training data for future models, supporting reliable and reproducible QA research in climate adaptation.
