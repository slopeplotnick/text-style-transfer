We're checking out our knowledge graph-based system using two different ways to see how data affects generative models. First, we try removing certain data from a model we trained ourselves to see if our method can spot important training examples. Second, we look at how style influences things by using Ghibli-style images in a situation where we can't see inside the model. We made a "Ghibli World" knowledge graph from the original movies and compared it to styled images. These tests help us see both direct data influence and how style can be traced in generative models. To make sure our comparison is fair and easy to understand, we copied the setup from a recent method that looks at influence without needing access to training details. This method works in two steps: first, it finds training examples that are most like what the user wants, and second, it ranks them based on how similar they are to the generated result using a method called cosine similarity. The most similar training images are then taken out, and the model is trained again to see how much they mattered. We used our graph-based method in the same way, with the same data, prompts, and model. Instead of using text and hidden-space similarity, we found important examples based on how similar the knowledge graphs were. This let us directly compare the two methods in terms of finding influence and understanding it. For the generative model, we used a small one based on the open-source dalle-pytorch package, trained on a set of 44,000 fashion images with captions. We kept the same setup and settings as the original. This way, we could fully control the training data, which was good for testing data removal and retraining.
