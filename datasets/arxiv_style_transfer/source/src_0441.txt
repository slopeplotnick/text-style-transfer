PEFT methods are used to deal with the growing size of large language models. Right now, a lot of new PEFT methods are hard to copy, use, or compare with each other. To fix this, PEFT-FACTORY was made as a single system to make fine-tuning large language models easier using both ready-made and custom PEFT methods. It’s built to be flexible and can be expanded, but it already includes 19 PEFT methods, 27 datasets for classification and text generation covering 12 tasks, and evaluation tools for both general and PEFT-specific metrics. This makes PEFT-FACTORY a simple and reliable setup that helps with copying results and comparing PEFT methods. PEFT-FACTORY is based on LLaMAFactory and can be found at https://github.com/kinit-sk/PEFT-Factory. Large language models have done really well in many natural language processing tasks, especially after the transformer architecture was introduced. But because these models scale so well, their size keeps getting bigger in terms of trainable parameters. This increase in parameters makes fine-tuning expensive, requires a lot of data, and is hard for many researchers and practitioners to access. PEFT methods try to solve these problems by training only a small part of the model’s parameters while still getting results similar to training the whole model. This reduction in trainable parameters can be done by adding new ones, picking specific ones to train, or changing the model to use fewer parameters.
