While we’ve found some great prompts using SPRIG, it’s still hard to find ones that work well across all four tests. Our tests show that good prompts guide models to think in certain ways that improve how they perform, but we don’t fully understand why this happens. Figuring out what’s going on underneath is something we need to explore in the future. We’ve tried to avoid ethical problems in this research, but there are still some issues. First, optimizing prompts and running these tests use a lot of computing power, which means high energy use and a big carbon footprint. Second, optimizing prompts might accidentally make biases worse, like if a prompt makes a model act like a certain type of person, such as a professor. Since the data we use includes things like roles and instructions, it’s important to make sure this doesn’t create or worsen harmful biases.
