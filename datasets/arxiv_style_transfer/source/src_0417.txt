Engineers have started using systems where supervisors act as middlemen between people and worker agents. These supervisors check the work, point out problems, and can stop things if limits are passed. This idea is part of what's called "Institutional AI," which will be explained later. But just having supervisors isn't enough. These supervisors use the same type of system as the agents they watch, so they can have the same problems or get stuck in the same loops. If supervisors agree with each other too much, it can lead to group mistakes or even intentional bad decisions. To manage things better, you need more layers of supervision, different ways of checking, backup observation methods, and clear separation of power between supervisors. When systems start working on their own with multiple agents, safety becomes a bigger challenge. You can't just rely on one central system or fixed rules anymore; you need networks that can spot, handle, and fix problems on their own. If one model fails, it doesn't fail alone—it affects others too. To keep AI safe, we need to figure out how these group problems start and how to measure them. When language models start talking to each other, it shows the limits of current ways to think about risks like bias, misuse, or weaknesses. You can check one model by itself, but when models interact, the ways they can go wrong grow in ways we don't fully understand yet. To deal with this, we came up with the idea of the Emergent Systemic Risk Horizon (ESRH). This is the point where the group behavior of models starts to break down, even if each model on its own is fine.
