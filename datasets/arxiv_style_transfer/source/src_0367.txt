As we use AI tools with big language models more, making sure they're safe is really important. This is even more true when we use them in places with different languages and ways of communicating, which can bring new risks. We need systems that can block bad or unsafe stuff in lots of languages and situations. Without these systems, using these models worldwide could accidentally hurt or leave out many people. Most studies have looked at safety in languages like English, Chinese, Spanish, German, and French, but most languages don't have much data to help with this. This makes it hard to check and keep things safe in places with many languages. Some tests exist to see how well these models work in different languages, but they don't cover languages with less data and don't show the variety of people using them. Also, making training data for languages with less information to help build safety systems hasn't been done much. Some recent work has made training data for languages with lots of information by using real and translated data, but it's not enough for truly safe systems. Another big problem is that current safety systems need a lot of computer power. They're usually too big, slow, and need too many resources to work on small devices or places with less power. Because they take a long time to work, it's hard to use them in real-world settings. This shows we need smaller, more efficient systems that can protect both the language model and the user from harm.
