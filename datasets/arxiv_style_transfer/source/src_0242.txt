Li and others in 2025 talk about using feedback to improve predictions when testing, with outside help giving some guidance. Zuo and others in 2025 talk about Test-Time Reinforcement Learning, where they try different things, vote on the results, and use the agreed-upon answer to make changes. These ways work but need a lot of tries to get a good answer. Wang and others in 2025 show that using rewards that can be checked makes learning better with very few examples, showing that this way of learning can be good when testing. Our work looks at making this process more efficient by stopping early when needed. Policy optimization is a big part of reinforcement learning, especially with language models. Proximal Policy Optimization (PPO) is a common method to keep changes steady and is used a lot when learning from human feedback. Group Relative Policy Optimization (GRPO) adds to this by using group advantages to make learning more stable with limited feedback. OptPO uses these ideas to make the process more efficient without changing the main method. In short, past work has shown that training during testing helps models adapt better, using different methods like reducing uncertainty, learning with help, and reinforcement learning. But current methods need a lot of tries, which is not efficient. Our work helps by introducing OptPO, which cuts down on computing needs while keeping performance good, adding to and improving current test-time methods.
