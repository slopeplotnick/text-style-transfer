The way this system works is by having the mother agent interact with others using the grammar it knows. This is a new way of doing things because usually, language learning models just use a bunch of text to learn from. In this paper, we don't just mean "language model" like the usual computer programs that predict the next word, like GPT or BERT. We're talking about all kinds of methods, like rules, statistics, and neural networks, because they all help with language tasks. This is important because our system uses clear language rules, while the learning agent uses statistics to figure out these rules. The study looks at whether the MODOMA daughter agent can learn and show different parts of language by using a certain distribution in the MODOMA system. We check if a system with multiple agents can figure out language parts from computer-made sentences and show them with rules. We want to know if these sentences have patterns like human language and how much data we need to see these patterns. We also see if these patterns can turn into rules. Lastly, we check if the categories we find match the original grammar and if the system can learn language structure on its own.
