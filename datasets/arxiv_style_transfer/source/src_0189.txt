We decided not to use the KL divergence regularization term because, after a good start, the model already knows how to reason and format its output. Using KL constraints would limit how the model explores new ways to solve problems, so we let it optimize freely based on what it already knows. With our reward system, we aim for three goals: (1) Format standardization: we use special tokens to clearly separate the reasoning process from the final answer, making it easier to understand and use later; (2) Output space constraint: we strictly control the types of mismatches (like "price mismatch" or "functionality mismatch") to a set list, stopping the model from creating random outputs; (3) Progressive reward: if the model gets the relevance right but makes small mistakes, we still give it some positive feedback to help it learn faster and more steadily. We also set up a three-step learning plan to help the model get better by making the training data harder over time. Table 6 shows how we divide the samples for each step. Our plan is based on three ideas: (1) Rapid Bootstrap Principle: Step 1 uses mostly medium-difficulty samples to give the model quick and useful feedback while keeping it challenged, avoiding early training problems; (2) Progressive Challenge Principle: Steps 2 and 3 slowly add more difficult samples, helping the model move from solving common issues to handling tough cases, which expands its skills; (3) Knowledge Retention Principle: The last two steps keep using easy samples as "memory anchors" to stop the model from forgetting old skills while learning new ones, and these samples also help keep training stable.
