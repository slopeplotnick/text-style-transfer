The last part of Phase Flow Analyses, described in Algorithm 3, is about finding shared strategies that an agent uses across different tasks. It works by looking at actions the agent takes to solve various problems. First, Algorithm 3 takes a list of LANGUTORY examples and figures out their phase transition sequences. Then, it uses the Generalized Sequential Pattern (GSP) method to find the longest shared sequences in those transitions. After that, it checks where the shared pattern starts in each LANGUTORY and figures out the phase lengths using run-length encoding. To deal with differences in phase lengths, it picks the smallest run-length across all LANGUTORY examples and adjusts the shared strategy pattern based on that. Phase Flow Analysis, especially Shared Strategy Analysis, is useful for finding common patterns, even ones that aren’t obvious. Pattern Detection Analysis adds to this by helping search for known patterns in GRAPHECTORY or LANGUTORY. A big use of pattern detection is spotting known problems or inefficiencies in GRAPHECTORY. As explained later, this lets people study programming agents’ failure modes in a systematic way. They can look at a small sample of failures, figure out patterns or anti-patterns from those, and then search for those patterns in other runs automatically. GRAPHECTORY and LANGUTORY are helpful tools for analyzing programming systems and answering research questions about how agents work.
