Education is going global and online learning is growing fast, so making educational content work for different places is a big deal. Lectures mix talking with slides, so we need systems that can handle both. To make learning easy for everyone, translations have to keep all parts: text for reading, slides for looking at, and speech for listening. We made BOOM, a tool that translates lecture audio and slides together, giving outputs in three ways: translated text, slides that keep their look, and speech that sounds right. This lets students hear lectures in their own language while keeping the original stuff. Our tests show that slides help with things like making summaries and answering questions. We shared our Slide Translation code at https://github.com/saikoneru/image-Translator and put it in Lecture Translator at https://gitlab kit.edu/kit/isl-ai41t/lt-middleware/ltpipeline. When students can learn in their own language, it really helps them understand better. Making lecture material work for different languages cuts down on communication problems, makes it easier to access, and helps students get into tough ideas. As colleges get more international, having lecture content in different languages both in-person and online is key to making educational resources more available. With teaching going digital, lecture content mixes different types of media. The main part is the lecture audio, which can be turned into text using Automatic Speech Recognition. Teaching stuff comes through slides, and other things like summaries, chapters, and question-answer sessions can be made from the text using new systems based on Large Language Models to make learning better. To make sure all students, even those who don't speak the language well, can access this, these outputs should be in different languages too. Good localization has to deal with all this different content, covering audio, text, and visuals, making lecture translation a real challenge.
