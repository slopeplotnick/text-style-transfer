We can't easily use our LLM or deep BERT classifier for online searches because of speed and cost issues. So, we use a method where a simpler model learns from a more complex one, as shown in Figure 1. Our online model is a basic version of BERT. To make sure the simpler model learns well, we use a deep BERT model as the teacher, instead of a different type of model. We also add important details found by another model into BERT to help it understand why some searches match better with products. To clean up the extra and noisy details from long explanations, we have a model that picks out and tidies up product details that match or don't match the search. This helps the simpler BERT model focus on what's important. Since the simpler model can't use these details in real-time, we only add them to the teacher model to keep things consistent. Then, the simpler model learns from the teacher model. We don't have public data for Chinese e-commerce searches, so we tested on a big dataset from JD app search logs, which includes search and product pairs checked by experts.
