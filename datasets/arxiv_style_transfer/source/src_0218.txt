We use Gemini-2.0-Flash for our baseline models, which don't use outside info and only have the original question. We try different versions of CAIRNS: one just uses literature, and the other uses literature plus climate data with a two-step API reasoning. Gemini-2.0-Flash is the main model for CAIRNS and all its versions. All models use the same corpora, prompts, and evaluation settings to keep things fair. The ScholarGuide Prompt helps make things easier to read, with better context, structure, and language. It also fixes citation issues, making the info more reliable, even though it slightly lowers the overall citation rate. It uses unified reference numbers and ties each fact to clear evidence, helping the model give clearer and more specific answers. This works well in both zero-shot and few-shot situations, showing that structured prompts are important for CAIRNS's success. Multi-turn ReAct helps the model improve its answers by aligning literature and climate data, leading to more complete answers with better context. While its impact isn't as big as SGP, it helps with the structured process and makes the model better at handling complex questions. Location-Weighted Retrieval helps the model give region-specific answers, especially for questions focused on geography, and removing it slightly lowers specificity but doesn't change other metrics much.
