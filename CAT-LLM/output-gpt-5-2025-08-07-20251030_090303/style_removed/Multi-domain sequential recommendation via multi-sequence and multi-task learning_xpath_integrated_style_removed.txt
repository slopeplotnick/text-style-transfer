Lately, more people in research and industry have been working on multi-domain CTR prediction and have made good progress. Even though user behavior is sequential, there isn’t much work on multi-domain sequential recommendation (MDSR). Most current MDSR methods just sort all interactions from all domains by time and then predict the next items for each domain, but they ignore the separate sequences within each domain, so they don’t make good use of what’s shared or different across domains. Cross-domain sequential recommendation (CDSR) models are usually built to improve one target domain instead of all domains. You can turn a CDSR model into an MDSR model, directly or indirectly, but that leads to high time cost. These methods also often overlook data imbalance across domains, which can cause negative transfer. To address this, we propose a new MDSR method called multi-sequence multi-task learning (MML). It has three parts: hybrid-domain sequential preference learning (HSPL), intra-domain sequential preference learning (ISPL), and multi-task learning & prediction (MLP). HSPL learns preferences from mixed-domain sequences, and we also create augmented sequences and use contrastive learning to get less biased hybrid-domain preferences and reduce negative transfer. ISPL learns preferences within each domain. In MLP, we use three specific tasks and a behavior regularizer to make sure each part learns its own preferences well and to improve knowledge transfer across domains. We run extensive experiments on public datasets with different backbone models and show that MML performs significantly better than state-of-the-art methods in two or more domains in most cases, and it has the same time complexity as MDSR models that only use hybrid interaction sequences. The source code is at https://github.com/plw2019/MML.
