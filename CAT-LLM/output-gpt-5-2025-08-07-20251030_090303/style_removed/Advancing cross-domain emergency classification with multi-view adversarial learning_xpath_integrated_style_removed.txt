There’s more and more emergency data from both natural and human-made events on social media, and we need to categorize it in real time across different types of emergencies. But current unsupervised domain adaptation (UDA) methods have two big problems: they’re mostly built around natural disasters so they don’t generalize well, and they struggle when the domain changes because the data distributions, the way people write or speak, and the emotional tone are different. To address this, we introduce MARDA (Multi-View Adversarial Neural Networks for Robust Unsupervised Domain Adaptation), which combines adversarial domain adaptation with multi-view feature learning. First, it has a cross-view processor with semantic and emotion processors plus interactive integrators, so it can build rich features from multiple views. Second, it uses an adaptive weighted domain enhancer that adjusts how much each view should count, pulling together the most useful signals across different domains. Third, it includes an adversarial cross-view optimizer that trains with a minimax setup and a feature consistency rule to improve generalization across domains. In tests on four real-world emergency datasets with 24,008 samples, MARDA beat strong baselines by 7.39% and did 1.59% better than large language models on average F1 score, showing it works well as a general solution for cross-domain emergency event classification.
