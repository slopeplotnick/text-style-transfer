Trust is the basis for secure interactions between network entities, but current trust evaluation models are easy to hit with global attacks, depend on stacking many layers, and struggle with networks that change and are sparse. To fix this, we propose a dynamic and robust trust evaluation model based on graph neural networks called DLGTrust. It uses dynamic line graph snapshots to map indirect trust to direct links, which helps it capture complex interactions and handle sparse data better. It extracts multimodal spatial features and uses a GRU to fuse spatial and temporal information, so it can model complex interactions in a fine-grained way. At the same time, it uses adversarial perturbation injection and global robustness constraints to improve defense against global attacks. Tests on three real-world datasets show that its overall performance is at least 26.3% better than the baseline. The F1-macro is over 98% for both observed and unobserved node scenarios. When bad-mouthing, good-mouthing, and global attack rates are each 10%, the F1-macro improves by 24.5%, 23.7%, and 76.7%, respectively. This strengthens the robustness and defense ability of DLGTrust. So DLGTrust effectively supports secure interactions among entities.
