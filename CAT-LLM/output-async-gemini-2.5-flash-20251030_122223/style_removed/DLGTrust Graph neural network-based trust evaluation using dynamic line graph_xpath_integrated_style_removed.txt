Trust is super important for keeping things safe when different parts of a network talk to each other. But the current ways we check trust have problems: they can be hit by big attacks, rely too much on layered systems, and struggle with networks that keep changing and have few connections. So, to fix these issues, we came up with a new way to check trust that's strong and can change, using something called a graph neural network. We call it DLGTrust. It uses changing "line graph snapshots" to clearly show how indirect trust actually links up to direct connections. This helps the model understand complicated interactions better and work well even when there's not much data. By putting together a way to pull out different types of spatial features and a system that mixes space and time (a "gated recurrent unit"), it can model tricky interactions in a very detailed way. At the same time, we add "adversarial perturbations" and "global robustness constraints" to make the model better at defending against big attacks. Tests on three real datasets show that DLGTrust works at least 26.3% better overall than the old model. The F1-macro score, which measures how well it works, is over 98% for both parts we've seen and parts we haven't. When people try to mess with it by "bad-mouthing" or "good-mouthing" or a big attack, all at 10% rates, the F1-macro score gets better by 24.5%, 23.7%, and 76.7% for each of those. So, DLGTrust is tougher and better at defending itself. This means DLGTrust really helps keep things safe when different parts need to talk to each other.
