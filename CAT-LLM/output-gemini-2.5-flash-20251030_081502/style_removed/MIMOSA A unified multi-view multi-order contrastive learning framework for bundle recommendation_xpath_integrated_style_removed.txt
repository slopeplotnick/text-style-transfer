Bundle recommendation is a popular online service now. It gives users custom sets of items they'll probably like. Other methods try to combine different kinds of information, but they often have trouble really using the connections between things, like users and bundles. They especially struggle to tell the difference between things that go together and things that don't. So, to fix this problem, our study suggests a new way to recommend bundles. We call it MIMOSA, which stands for multi-view multi-order contrastive learning. It figures out the hidden connections from different angles and between different things at the same time. This method uses a single framework that looks like a graph and learns by comparing things. It sorts out connections both inside the same thing and between different things. It does this by looking at how close things are in the user-bundle network, in different ways. To be more specific, MIMOSA has special ways to find good examples and calculate how far off it is. This helps it understand the different meanings behind how various things are connected. This makes sure that things that belong together are grouped closely, and things that don't belong together are spread far apart. Also, there's a special 'center-matching' plan. It's made to quickly line up how things are shown from different angles. This speeds up how it learns by comparing things. We did a lot of tests using two big sets of data, called Youshu and NetEase. The tests show that MIMOSA works better than the old ways. The numbers tell us that compared to the best old method, our new method improved things by about 2.87% (for R@20) and 3.02% (for N@20) on Youshu, and by 5.19% (for R@20) and 4.07% (for N@20) on NetEase.
