In this section, we illustrate the features of our interface using a use case scenario of "Picture Composition". Picture composition offers users obvious information, such as the number of entities and events, and types of relationships, providing an overview to guide the creation process. Figure 5.a illustrates a diagram for picture composition, while Figure 5.b illustrates the story creation process of P4 with TaleFrame. drops the event "Jack shoves Ryan", which represents the first grid in the diagram, onto the canvas (Figure 6.f). Next, P4 attaches the two entities involved in this event to the box (Figure 6.g). Then, P4 connects the two entities (Figure 6.h1) clicks on the connection line, and edits the relationship attributes (Figure 6.e) (e.g., emotion_type: intense; action_type: shove; relationship_strength: low; relationship évolution: being stronger). The "action_direction" attribute of the relationship is represented by the "connect node", which defaults to the start point and end point (e.g., "from Jack to Ryan"). However, for the event "confront each other" in the second grid, where the action "confront" is mutual, a switch button labeled "is bidirectional" is provided. When activated, this switch automatically sets the action_direction to "bidirectional". By repeating above process, P4 completes the remaining three grids, linking the four event boxes to finalize the entire story framework (Figure 6.h2). Finally, P4 clicks the "Modify Story" button, edits the title and description, and assigns the four events to the appropriate stages of the story. the story is scored on seven dimensions according to the same evaluation criteria (Figure 6.1). And a comprehensive suggestion will also be generated based on the feedback (Figure 6.m). According to the suggestion, P4 modifies aspects with lower scores (e.g., adding relationships to certain events). After that, P4 clicks the "Regenerate" button to generate a new version. Finally, P4 clicks the "Export" button to obtain the final story, the framework diagram, and the JSON file.
