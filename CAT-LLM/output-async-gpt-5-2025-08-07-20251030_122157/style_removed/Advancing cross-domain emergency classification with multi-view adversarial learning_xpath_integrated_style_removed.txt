There’s more and more emergency data from natural and human-made events on social media, and we need to sort it in real time across different types of emergencies. But current Unsupervised Domain Adaptation (UDA) methods for this task have two main problems: they mostly focus on natural disasters so they don’t generalize well, and they struggle with domain shifts caused by different data distributions, wording differences, and emotional language. To address this, we introduce MARDA (Multi-View Adversarial Neural Networks for Robust Unsupervised Domain Adaptation), which combines adversarial domain adaptation with learning features from multiple views. First, it has a cross-view processor with a semantic processor, an emotional processor, and components that let them interact, so it can build detailed multi-view features. Second, it uses an adaptive weighted domain enhancer that adjusts how much each view contributes, pulling together the information that helps tell things apart across different domains. Third, it includes an adversarial cross-view optimizer that uses a minimax setup and a rule to keep features consistent, which helps it generalize across domains. Tests on four real-world emergency datasets with 24,008 samples show that MARDA beats strong baselines by 7.39% and does better than large language models by 1.59% in average F1-Score, showing it works well as a general solution for cross-domain emergency event classification.
