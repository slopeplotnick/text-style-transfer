To keep network entities interacting safely, you need trust, but current trust evaluation models are vulnerable to global attacks, rely on multi-layer stacking, and struggle to adapt to networks that are dynamically sparse. To fix this, we propose a graph neural network-based trust evaluation model called DLGTrust that is dynamic and robust. It uses dynamic line graph snapshots to map indirect trust to direct connections in a clear way, which helps it capture complex interactions and handle sparse data better. It also combines multi-modal spatial feature extraction with a GRU-based spatiotemporal fusion so it can model complex interactions in detail. At the same time, it injects adversarial perturbations and adds global robustness constraints to improve defense against global attacks. Tests on three real-world datasets show DLGTrust improves overall performance by at least 26.3% compared to the baseline. Its macro F1 is over 98% for both seen and unseen nodes. With bad-mouthing, good-mouthing, and global attacks each set at 10%, macro F1 improves by 24.5%, 23.7%, and 76.7%, respectively. This makes DLGTrust more robust and better at defense. So DLGTrust helps keep interactions among entities secure.
