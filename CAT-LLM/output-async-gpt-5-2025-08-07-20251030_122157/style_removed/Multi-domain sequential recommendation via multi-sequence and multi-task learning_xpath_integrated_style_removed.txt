Recently, more researchers and practitioners have worked on multi-domain CTR prediction and got great results.Even though users’ behavior is often sequential, there has been little work on multi-domain sequential recommendation (MDSR).Most MDSR methods put interactions from all domains into one time order and then predict the next items a user will interact with in each domain.But they ignore that each domain has its own separate interaction sequence, so they do not make good use of what is shared and what is different across domains.Cross-domain sequential recommendation (CDSR) models are usually built to improve performance in one target domain, not in every domain.You can extend a CDSR model to an MDSR model directly or indirectly, but that leads to high time complexity.They also often ignore data imbalance across domains, which can cause negative transfer.To address this, we propose a new MDSR method called multi-sequence multi-task learning (MML).MML has three modules: hybrid-domain sequential preference learning (HSPL), intra-domain sequential preference learning (ISPL), and multi-task learning & prediction (MLP).HSPL learns hybrid-domain sequential preferences.We also build augmented sequences and use contrastive learning to learn more unbiased hybrid-domain sequential preferences and reduce negative transfer.ISPL captures intra-domain sequential preferences.In the MLP module, we use three specific tasks and a behavior regularizer to make sure each module learns its own preferences well and to enhance knowledge transfer across domains.We run extensive experiments on some public datasets with different backbone models and show that MML achieves significantly better performance than state-of-the-art methods in two or more domains in most cases.At the same time, MML has the same time complexity as MDSR models that only use hybrid interaction sequences.The source code is at https://github.com/plw2019/MML.
