Recent advances in multi-domain click-through rate prediction have produced strong results, yet users’ behavior is inherently sequential and multi-domain sequential recommendation (MDSR) remains underexplored. However, most existing MDSR methods merge interactions from all domains into a single temporal order and then predict, for each domain, the next items a user will interact with. This design ignores the fact that each domain exhibits its own separate interaction sequence and thereby fails to exploit what is shared and what is distinct across domains. Cross-domain sequential recommendation (CDSR) models are typically built to improve performance in a single target domain rather than across all domains, and direct or indirect extensions to MDSR incur high time complexity. Data imbalance across domains is often ignored, which can cause negative transfer. We propose a novel MDSR method, termed multi-sequence multi-task learning (MML), comprising hybrid-domain sequential preference learning (HSPL), intra-domain sequential preference learning (ISPL), and multi-task learning and prediction (MLP). HSPL learns hybrid-domain sequential preferences, for which we construct augmented sequences and apply contrastive learning to obtain more unbiased hybrid-domain sequential preferences and mitigate negative transfer. ISPL captures intra-domain sequential preferences, and the MLP module leverages three specific tasks with a behavior regularizer to ensure that each module learns its own preferences and enhances knowledge transfer across domains. Extensive experiments on public datasets with different backbone models demonstrate that MML achieves significant performance gains over state-of-the-art methods in two or more domains in most cases. At the same time, MML retains the time complexity of MDSR models that use only hybrid interaction sequences, and the source code is available at https://github.com/plw2019/MML.
