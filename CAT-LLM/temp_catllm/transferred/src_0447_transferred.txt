The initialization of the PEFT model is facilitated through the init_adapter method, which prepares the model loader for subsequent processes. Subsequently, the loading, training, and saving of the model are managed by the PEFT provider libraries and the LLaMA-Factory framework. In contrast to LLaMA-Factory, PEFT-FACTORY employs a more adaptable approach for loading custom PEFT methods, thereby enabling greater ease of extension and modification. This configuration permits researchers and users to incorporate custom PEFT methods without necessitating alterations to the core PEFT-FACTORY codebase. To illustrate the functionality of the Custom PEFT Interface, two PEFT methods, BitFit and SVFT, which are not included in standard PEFT frameworks, were replicated for demonstration purposes. During the dynamic loading process, the peftloader module identifies and loads PEFT methods from a systematically organized folder structure. Each custom PEFT method is contained within a distinct folder comprising two primary components: a config.py file defining a subclass of PeftConfig and a model.py file containing a subclass of BaseTuner. The loader verifies each configuration by inspecting requisite attributes, such as peft_type for configurations and prefix for model classes, prior to their registration. The config and model subclasses are subsequently loaded and registered via the register_peft_method function, which integrates them into the constants of the Hugging Face PEFT library. Additionally, the procedural details are elaborated in Algorithm 1, located in Appendix B.1. Following the loading phase, custom PEFT methods are treated equivalently to standard methods, as detailed in Section 3.1. To incorporate a new method, adherence to the prescribed folder structure within the PEFT methods directory is required, which can be determined by the environment variable PEFT_DIR, defaulting to ./peft, to ensure consistency in organization and class inheritance. Example templates for methods are provided in Appendix C and further elaborated within the PEFT-FACTORY documentation.
