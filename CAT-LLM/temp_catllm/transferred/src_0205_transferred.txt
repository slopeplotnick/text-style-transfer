To address this research question, the task was divided into two distinct components, which are elaborated upon in Section 2. Initially, it was necessary to establish connections between the query's requirements and specific features of the products, thereby creating systematic links between these elements. Subsequently, these links were utilized to compare the features of the products with the specifications outlined in the query. The model is required to perform three primary functions to effectively execute this process. Firstly, it must interpret specific terminology and implicit details within the query by leveraging domain knowledge, followed by employing reasoning mechanisms to deduce the underlying meaning of the query and the corresponding product features that are desired. For instance, as illustrated in Fig. 1(a), the model must recognize that "morning C, evening A" refers to Vitamin C and retinol, while "for mom" implies that the product is intended for middle-aged women. Secondly, the model is tasked with integrating information from multiple formats, such as textual and visual data, to establish connections between the query and the product features. For example, in Fig. 1(b), the query mentions "yellow," which is not explicitly stated in the textual description, necessitating the model to analyze the product's image to ascertain the color. Lastly, the model must adhere to predefined decision-making protocols. As demonstrated in Fig. 1(c), when a query references "LV bags" but the product is identified as a second-hand bag, the model must go beyond feature matching and apply specific rules to determine the compatibility of the product with the query.
