Large Language Models (LLMs) are increasingly utilized to autonomously address issues in C programming assignments. Specifically, CFAULTS collaborates with LLMs through a method that identifies defective segments within a C program, subsequently presenting the LLM with a version of the program that lacks these erroneous components. Thereafter, the LLM endeavors to reconstruct the absent sections, and the proposed corrections undergo testing to ascertain their efficacy. Should the rectification prove ineffective, feedback from the tests is provided to the LLM, facilitating iterative improvement. This methodology enables LLMs to rectify a greater number of programs while implementing more granular modifications as compared to alternative strategies that do not employ formula-based fault localization (FBFL) techniques or symbolic tools for program correction. Fault localization techniques are categorized into spectrum-based (SBFL) and formula-based (FBFL) types. SBFL leverages test outcomes to hypothesize potential erroneous program segments; however, it lacks accuracy as it does not ensure that these segments are indeed the root cause of the issue. Conversely, FBFL methods exhibit greater precision by conceptualizing fault localization as a problem of identifying the minimal set of defective components. For each failed test, FBFL methods engage in a process to determine the minimal diagnosis specific to that failure, subsequently amalgamating all findings into a comprehensive explanation elucidating the program's malfunction.
