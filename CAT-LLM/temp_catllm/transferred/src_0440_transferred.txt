In certain agent frameworks, such as Roo Code and Terminus, user interaction with tools is facilitated through message exchanges. However, these frameworks may not fully exploit the enhanced reasoning persistence due to the context management rules previously mentioned. Consequently, it is proposed that employing models which do not engage in reasoning may yield improved performance within these configurations. Given the existence of both reasoning data, which is non-agentic, and non-reasoning agentic data, a straightforward approach to integrate these is through the utilization of well-structured prompts. It is anticipated that the model demonstrates proficiency in adhering to explicit instructions, thereby incorporating tool execution effectively into the reasoning process. For elucidating the cold-start mechanism, certain training data were selected, as illustrated in Appendix Tables 6-8. It is essential to acknowledge that distinct tasks necessitate distinct system prompts. Tables 6-8 provide an exemplar pertaining to a competitive programming prompt. Table 6 presents our reasoning data example, wherein the system prompt instructs the model to engage in contemplation prior to delivering the final answer, marked by a specific tag <think></think> to denote the reasoning trajectory. Table 7 delineates the prompt for non-reasoning agentic data, wherein the system prompt directs tool invocation. Table 8 comprises the system prompt devised to instruct the model to employ multiple tool calls within its reasoning process. Although the reasoning in tool-use patterns might exhibit limitations, the model occasionally succeeds in generating requisite pathways, thereby facilitating subsequent stages of reinforcement learning. A diverse array of RL tasks is paramount for enhancing the model's robustness. For tasks encompassing search, code engineering, and code interpretation, authentic tools, such as web search APIs, coding utilities, and Jupyter Notebooks, are utilized. Despite the real nature of these RL environments, the prompts employed are sourced either from the Internet or fabricated, rather than derived from genuine user interactions.
