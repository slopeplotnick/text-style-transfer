The robotic system evaluates operational status and workload intensity, subsequently determining actions based on the probability of successful outcomes. It articulates the rationale for its decisions concisely, while assessing anticipated workload implications and the degree of confidence in the decision, categorized as high, medium, or low. Additionally, it examines the trade-offs necessitated by the chosen course of action. The decision-making framework integrates two principal components, Nodes 2 and 3, to facilitate informed choices. Specifically, Node 2 generates contextually relevant prompts, whereas Node 3 employs these prompts for analytical deliberation. Within Node 3, as illustrated in Figure 11, the system implements a structured reasoning methodology by invoking the large language model (LLM). This process involves two distinct elements: a system prompt designed to guide overarching cognitive and decision-making processes, and a user prompt tailored to reflect the current situational dynamics. These prompts are synthesized to construct the model's input. The system prompt provides generalized directives, while the user prompt incorporates specific parameters, including success probability, workload levels, and current operational stage. The invocation process is executed by the LLM client through the invoke() function, transmitting the composite prompt as a message. Subsequently, the LLM generates a natural language response, detailing the decision rationale, estimated success likelihood, and associated confidence level. This response undergoes verification and validation in a subsequent procedural step. The system consolidates the initial prompts, comprising the static system prompt that delineates operational rules and the dynamic user prompt enriched with situational specifics, into a unified message for transmission to the LLM client. During execution, the model utilizes this input to produce a natural language explanation encompassing the decision, supporting reasons, anticipated success rate, and confidence classification. The resulting output from the node serves as an input for subsequent stages, thereby ensuring clarity and procedural coherence.
