In this study, both Convolutional Neural Networks (CNNs) and Vision Transformers (ViTs) were subjected to identical adversarial training methodologies to examine the influence of this training on the transferability of attacks. Conventionally, it might be anticipated that models engineered for robustness would generate attacks with limited transferability; however, our findings indicate a contrary outcome. Specifically, models trained using adversarial techniques facilitate attacks that manifest higher transferability compared to those trained via conventional methods, as illustrated in Figure 1. This phenomenon implies that the features acquired by these models potentially engender vulnerabilities applicable across various model architectures. A comprehensive set of adversarial training was conducted on 36 CNN and ViT models, and the entirety of the trained models along with the code will be disseminated on GitHub to enable reproduction and further investigation by the research community. Notably, adversarial training models enhance attack transferability, posing a challenge to conventional perceptions of robustness. A novel attack strategy, termed Momentum Integrated Gradient (MIG), has been developed, building upon the integrated gradient (IG) method. MIG iteratively modifies the attack using a momentum technique, which is guided by IG to target the critical components identified by IG, thereby increasing the likelihood of misclassification. IG possesses a distinctive feature known as implementation invariance, which allows MIG attacks to be effective across diverse model types such as CNN and ViT, or even between them, a capability unattainable with prior attack methods like Projected Gradient Descent (PGD), as demonstrated in Figure 2. IG serves as a mechanism to elucidate which features hold the greatest significance for a model's predictions, operating by aggregating gradients from a reference point to the actual input. The reference point functions as a baseline for comparison, providing insight into model behavior and feature importance.
