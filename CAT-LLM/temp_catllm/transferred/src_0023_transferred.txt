The performance enhancement of large language models can be achieved without employing few-shot examples by leveraging algorithms such as OPRO and EvoPrompt, which demonstrate efficacy even with straightforward methods for example selection. Promptsolution introduces an additional module that facilitates post-hoc example selection through random selection and search, thereby integrating few-shot examples within a predetermined instruction. Initial prompt generation necessitates a set of foundational prompts, provided automatically via tools that derive prompts from task descriptions, basic prompt structures, or dataset examples. Optimizers are equipped with callback functions designed to monitor optimization progress, enabling state assessments at each iteration and conditional termination of the optimization process. Examples of such callbacks include mechanisms that track token usage to prevent exceeding predefined limits and functionalities for recording prompts and scores for subsequent analysis. Comparative evaluations of promptolution's capabilities relative to other tools were conducted using GSM8K (mathematical problem-solving) and SST-5 (sentiment classification) datasets, employing the gemma-3-27B model as the primary language model and occasionally as the meta-model for optimizers necessitating model integration. Comprehensive details regarding datasets and experimental configurations are delineated in Appendix A.2. The comparative study encompassed optimizers CAPO, EvoPromptGA, and OPRO within promptolution, alongside leading optimizers from AdalFlow and DSPy. To ascertain the extent of optimization benefits, manually crafted prompts were tested across datasets, with results averaged for consistency. To ensure equitable comparisons, settings across all optimizers were standardized, and the token budget was capped at one million tokens for both input and output, maintaining expenditure below $0.15 for the model. All frameworks were initialized solely with task descriptions, absent of initial prompts, to evaluate autonomous performance. Both unoptimized and optimally refined prompts from each optimizer were subjected to evaluation using a distinct test set, thereby establishing a robust comparative framework.
