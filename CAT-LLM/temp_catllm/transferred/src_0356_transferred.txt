In the utilization of Claude 3.5 Haiku and GPT-4, divergent outcomes are occasionally observed despite identical queries being posed. While at times functionality is achieved, errors in code execution are also evident. Additionally, GPT-4 exhibits a tendency to reiterate previously demonstrated examples, which may result in errors such as the employment of incorrect objects for specific tasks. It was revealed that the initial system lacked mechanisms for error detection, thereby necessitating the incorporation of verification and retry methodologies within the LangGraph framework. This setup integrates examples from three distinct components: task decomposition, assignment, and code generation, executed concurrently. However, the inclusion of supplementary examples to address complex tasks rendered the input excessively lengthy, leading to system failure. This challenge, wherein extended context aids yet contributes to input length constraints, necessitated modifications to enhance input and context management within the LTAA system. These dual challenges, namely inconsistent outputs and input length limitations, informed the requirements for dependable robotic collaboration, emphasizing the necessity for quality assurance and a design accommodating input constraints. In response to these issues, a system emphasizing error detection, with iterative feedback and corrective steps, was developed. To address obstacles identified during the SMART-LLM setup and evaluate the efficacy of LLMs in robotic task support, the Self Corrective-Agent Framework was established. Unlike the previous single-agent configuration, this novel system employs three agents tasked with decomposing tasks, assigning them, and generating code. As illustrated in Figure 2, each agent is endowed with unique error-checking capabilities and is orchestrated by the LangGraph system. The initial agent undertakes the transformation of comprehensive instructions into manageable steps, delineating necessary actions, requisite objects, and their sequence. Subsequently, the following agent aligns these steps with optimal robots based on their capabilities and available resources, determining the execution order.
