The efficacy of the GraphMatch model is contingent upon the integration of both random and hard negatives, a factor deemed crucial for optimal performance. GraphMatch, when exclusively trained with random negatives, exhibits comparable performance to the TextMatch-small model. A comparative analysis of node features within GraphMatch revealed three configurations: "no-feat," which utilizes TextMatch node embeddings; "no-text," which employs number-based node features devoid of text embeddings; and "full," which amalgamates TextMatch node embeddings with number-based node features. Notably, GraphMatch-full, trained with hard negatives, demonstrates superior performance, whereas GraphMatch-no-feat achieves results akin to TextMatch-large, despite being a considerably smaller model. It is evident that the inclusion of text context is paramount for accurate predictions, as exemplified by the diminished accuracy of GraphMatch-no-text. The importance of temporal data sampling is underscored by the necessity of selecting appropriate subgraphs and node features at opportune times to effectively train models that adapt to new nodes. To investigate this, GraphMatch was trained using two distinct methodologies: the "no-temporal-nodes" variant, which excludes time-specific node features during training while consistently applying the latest feature version; and the "no-temporal-graph" variant, which similarly omits time-specific subgraphs yet retains access to all graph edges during training.
