Upon closer examination of the results for each sample, it is observed that employing varied resolutions occasionally yields superior outcomes compared to maintaining a resolution of 112, as illustrated in Figure 3. The findings derived from cropping images at diverse resolutions and analyzing the semantic similarity map elucidate the rationale for this occurrence. Essentially, the segmentation of the entire object into distinct components results in certain segments exhibiting higher semantic similarity, as quantified by VisRAG, while others manifest lower similarity. Consequently, after the application of filtering, only the segments with elevated similarity are retained, which disrupts the comprehensive representation of the object and complicates the ability of MLLM to render precise judgments. In response to this issue, a novel framework termed Multi-resolution Retrieval Detection (MRD) was devised. The fundamental concept underpinning MRD involves the utilization of multiple resolutions at varying scales to enhance the identification of regions containing target objects. This approach facilitates the system in discerning the optimal image crops corresponding to the target objects, thereby eliminating extraneous elements and aiding MLLMs in comprehending high-resolution images more effectively. The insights gleaned from subsection 3.2 indicate that employing different resolutions to compute semantic similarity proves advantageous for objects of varied dimensions and positions. With this understanding, a straightforward yet efficacious method named Multi-resolution Semantic Fusion was developed, which computes semantic similarity maps at differing resolutions on a localized scale and amalgamates them to augment the accuracy of the similarity results. To streamline the process of identifying target objects, an open-vocabulary object detection model is employed, scanning the complete high-resolution image via a sliding window, which assigns confidence scores to regions that potentially contain the objects. By integrating these confidence scores with the multi-resolution semantic similarity maps, the proposed method not only facilitates more precise localization of target areas but also distinguishes subtle variances between the crops within those areas. This enhancement enables the system to isolate the salient features of the image. Subsequent sections will elaborate on each component of this process in greater detail.
