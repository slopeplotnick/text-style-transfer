GraphMatch demonstrates effective performance in addressing cold start challenges, analogous to TextMatch, as it leverages text embeddings in the absence of graph information, thereby facilitating solutions to the cold start issue. The framework is structured into three integral components: a feature store, an inference service, and a graph database, which collectively enable the utilization of specific node features by various GNN models while maintaining a shared graph structure to cater to diverse requirements. Node sampling is facilitated through Cypher queries, allowing users to define the required node and edge types for inference purposes. The feature store predominantly contains statistical measures such as counts and averages, with Snowflake employed to replicate production databases alongside business data. Feature tables are systematically updated on an hourly basis using SQL Mesh jobs and are stored in Feast, while default values are applied in instances where features are absent for graph nodes but unavailable in the feature store. The graph database, implemented through Neo4j Aura, is updated via two pipelines: a Kafka pipeline designed for fast-changing entities such as job postings and an hourly Airflow pipeline for other entities. The database retains fundamental node details, including type, ID, and timestamp, thereby facilitating subgraph sampling processes during inference. The inference service executes the model within a Python/FASTAPI microservice, which is deployed on EC2 instances equipped with Nvidia A10G GPUs, and autoscaling mechanisms are employed based on requests per second due to the unreliability of GPU/CPU usage as predictors for latency-related concerns. To optimize inference speed, TextMatch embeddings are cached whenever freelancer profiles or job post descriptions are updated, ensuring that online inference is confined to the GNN layers. This methodology ensures that embedding generation times remain below 70 milliseconds per embedding for all entity types, thereby achieving scalability and supporting real-time application scenarios.
