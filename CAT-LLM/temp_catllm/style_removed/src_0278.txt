All the language knowledge is clearly shown and researchers can check it for both agents. This way of doing things adds something useful to systems that learn language but don't use clear representations like big language models. MODOMA uses unsupervised learning because the language learning device gets data that isn't labeled, and it can't see what's going on inside the mother agent. Plus, the daughter agent can use the grammar it already knows to help learn more. This new way of learning, made for MODOMA, is called internal annotation, which is a kind of self-supervised learning. The mix of features and research options in the multiagent MODOMA setup is new. This system can be used for language learning experiments with a grown-up language model and a learning one. These agents interact, and everything about the system, like settings, input, learning steps, interaction, what they say, and the grammar they learn, can be controlled, repeated, measured, and checked by users. Ter Hoeve and others in 2022 made a plan for a teacher-student setup to model language learning and did two early experiments. The first one looks at separate areas with 'two completely separate vocabularies' of a made-up language, and the second one looks at different structures using repeated tokens. In these experiments, the teacher picks a set number of training data from ready-made sentences to give to several student language models. After training, these student models are tested with different sentences from the made-up language. Also, a teacher model is trained on another group of sentences and then tested. This setup is different from MODOMA mainly in the training and test data: ter Hoeve and others used ready-made sentences from a made-up language, while MODOMA uses data that show a natural language and are made online by Delilah using a clear Dutch grammar model during interaction.
