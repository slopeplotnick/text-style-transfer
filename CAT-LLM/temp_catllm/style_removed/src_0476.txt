There are some other tools for improving prompts that haven’t been added to promptsolution yet, like GEPA, TextGrad, MIPRO, and PromptWizard. Most of the tools mentioned are only available in research setups that are hard to use because they’re not updated often, don’t have proper instructions, and aren’t tested well. This makes them tricky to use for comparing with other tools or for real-world tasks. There are also a lot of libraries and tools for prompt optimization now, both free and paid. Some free ones only work with one specific optimizer, like TextGrad, AdalFlow, Microsoft’s PromptWizard, and PromptIM, each using their own methods. prompt-ops works with two optimizers but focuses on prompts for Llama models. On the other hand, promptsolution is a system that lets you use different optimizers for any LLM. DSPy is one of the most popular tools for building LLM setups and has a part for optimizing prompts. It includes tools like MIPROv2 and GEPA and can combine LLM training with prompt optimization. But DSPy is more about being a general tool for building AI programs, while promptsolution is all about prompt optimization and is better for researchers and experts who want to do detailed studies. Another tool, promptomatix, is based on DSPy but is simpler and offers its own way of optimizing prompts.
