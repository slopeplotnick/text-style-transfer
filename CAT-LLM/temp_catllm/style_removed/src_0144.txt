Some other methods include CoT2, which is a system that learns to mix tokens like training-free methods and is used with GPT-2 for logical reasoning tasks. Then there's CODI, which uses a teacher-student setup to make GPT-2 and Llama 3.1 1B models better at GSM8k tasks. Another one is Token Assorted, which creates new token embeddings using VQ-VAE and trains Llama 3.1 8B for math and logical reasoning. Our LiteReason method is different from these because we don’t use big datasets like GSM8k-Aug for reasoning traces since those datasets don’t exist for our tasks. Instead, we only use traces made by the model itself. We also just train a small Reasoning Projector for reasoning instead of training the whole model because we think training the base model too much for token embedding might mess up its ability to generate tokens. Plus, we let the model mix latent and discrete reasoning during RL training, thinking it’ll figure out a good balance over time. Lastly, while other methods compare their results to Chain-of-Thought prompting and some use RL, we haven’t seen any of them compare their results to a non-latent RL-trained model, which we think is a better way to measure performance for tough tasks. So, we include that comparison in our tests as a top performance and compute limit. About narrative tasks, even though a lot of reasoning work has been done in areas like math and coding, there’s also a lot of research on using LLMs for understanding and creating stories. Some studies focus on specific parts of story generation like planning events or making character details, which can be seen as different reasoning styles. But these tasks are hard to use with RL because they don’t have clear rewards. In this work, we focus on two tasks that test reasoning based on narratives.
