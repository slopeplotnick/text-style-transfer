The usual way to do things is to first do a deterministic inversion and then use that to make a deterministic interpretation, like what's shown in Figure 2. After that, a geologist who knows their stuff will look at the deterministic inversion and figure out the shapes, like intrusions that matter for exploration. They use software that focuses on one deterministic model to make these interpretations. With this method, you do the geophysical inversion before you interpret the geology. Some people might say the regularization terms help bring in geological knowledge, but that's not clear and doesn't do much. It's like we're using the same geological knowledge twice: first in the regularization term and then again in the interpretation. It's like we're just going around in circles and fooling ourselves. With Bayes', you handle both things together as one problem. Bayes' makes you think about possible solutions (geometries) before doing any inversion. Bayesian inversion gives pretty straightforward solutions that are easy to code and work generally. Let's look again at Figure 2 and talk about how to set up a prior probability model. We start by asking: what's the least we know about the subsurface before we get any data? First, we've seen before that petrophysical properties have certain ranges, and if we know what types of rocks we're dealing with, we might be able to get more specific about these ranges. Second, we know these properties don't change randomly or stay the same over huge areas. We know that how deposits form causes specific changes in these properties. Basically, the minimum info is limits on histograms and spatial correlation. In math terms, we can turn this into a spatial covariance model (in geostatistics: variogram), but we're not sure about the parameters like the mean, ranges, and anisotropy; they could be almost anything (except random!).
