Predicting stock prices is tough because the market is unpredictable and reacts quickly to current events. Big language models (LLMs) have created new ways to predict stock prices using text. These models are great at understanding text, but to handle complicated real-world tasks, they often need special memory systems to use past information consistently. A lot of research has gone into building these memory systems, but they struggle when dealing with the huge amount of messy online news. The news doesn’t directly explain price changes and has a lot of irrelevant information. The main problem is figuring out how to pick out the important details and logic from all this unstructured text that actually affect stock prices. To solve this, this paper suggests a new memory system with two layers. First, it organizes events in two ways: it combines daily event details to get a clear picture and tracks how events change over time. This helps build a knowledge base that understands how market expectations shift over time. Then, it looks at how event patterns connect to stock price changes and creates another knowledge base focused on analyzing this connection. Together, these steps build a system that learns and organizes knowledge on its own. When using this system, there are two main steps: finding and thinking. First, it uses recent events to search for similar past situations in its memory, which helps make better decisions now. Then, it combines the recent events, new information, and past examples to predict stock price changes. Tests show this system predicts prices better than older ones and is easier to understand because it can clearly show how it connects events to price changes and explain why.
