This research is about using robots in construction. To show how well it works, the authors check the system against other known methods by doing a lot of tests. They use ideas from robot modeling and construction rules to compare how LLM-based reasoning stacks up against older methods for assigning tasks to robots in construction. The LTAA system includes models that know what each robot can do, strategies that change with different phases, and LLM decision-making to solve specific construction coordination problems found in earlier studies. They compare this system with older methods like Brute Force and Greedy Method, as well as learning methods like Q-learning and Deep Q-Network. This study gives a solid LLM coordination system and shows how reasoning-based methods compare to traditional ones for automating construction tasks. The paper is organized like this: Section 2 looks at past research on multi-robot task allocation using optimization, learning, and LLM methods. Section 3 explains the LTAA system. Section 4 talks about how the experiments were set up. Section 5 shows how the results compare with older methods. Section 6 wraps up with conclusions and future plans. MRTA is the theory behind how robot teams share tasks, considering limits on resources, time needs, and different robot abilities. Gerkey and Matarić in 2004 set up a basic system for understanding task allocation problems, looking at things like whether robots do one task or many, and whether tasks need one robot or many, and if tasks are quick or take time. But this system didn't cover everything needed for real-world situations with different robot abilities and time needs. So in 2013, Korsah and others made a better system that included different robot skills, task connections, and changing limits, showing how the field is moving towards using mixed teams for complicated tasks.
