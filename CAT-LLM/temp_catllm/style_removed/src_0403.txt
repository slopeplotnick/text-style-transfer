STL is a system that uses what the model already knows to get better by making and learning from its own explanations. A big question is how these explanations should be set up. To answer questions about pictures well, the model needs to see and think clearly. STL helps with this by using a method where the model first talks about what's in the picture, then thinks about it, and finally gives an answer. This way of doing things is like how people naturally think and helps the model organize its thoughts better. Just using explanations from right answers doesn't help much because the model only sees the good ways of thinking. This makes it hard to do tough tasks where telling right from wrong thinking is important. To fix this, we add explanations for wrong answers too. This is like how people learn by looking at both what went well and what didn't. These wrong answer explanations show where the thinking went wrong and help the model see the difference between right and wrong answers, so it doesn't make mistakes like imagining things or making guesses without proof. We use this idea in our Self-Taught Multimodal Reasoner (STL), which is a system where a model learns to make both good and bad explanations and gets better by training on these. As shown in Figure 1, STL makes more detailed and correct thinking. Tests in different areas like common sense, science, and language show STL does better than models that only learn from final answers and is almost as good as models trained with human explanations (Table 4), even though results vary across different data. These findings show STL could be a useful option instead of methods that need a lot of human explanations.
