When you're looking at images, you need to think about things like hidden joints and the overall picture, like how joints, hands, and objects relate to each other. People often use convolutional neural networks (CNNs) for 3D hand pose estimation, with ResNet-50 being a favorite. These CNNs use local operations that balance accuracy and speed, but they aren't great at seeing the big picture. Some newer studies use vision transformers (ViT) for hand mesh reconstruction, but they can be slow because they need a lot of computing power. This means there's a lot of room to make these systems better at understanding hand poses. A new model called Mamba, originally used for language processing, is getting attention because it's good at focusing on important parts of the input, which helps it understand the overall picture from long sequences. Some recent work has adapted it for images. For example, VisionMamba uses a special block for spatial sequence modeling, and VMamba introduced a block with different scanning paths. But these methods use a fixed grid, which isn't great for capturing detailed hand movements in 3D. So, we've come up with a new system called Deformable Mamba (DF-Mamba) that uses a flexible approach to better extract visual features in 3D hand pose estimation. DF-Mamba works by dynamically modeling local and global features with flexible state spaces. Our system uses blocks that gather local features along a flexible path and keep important information to understand the global context. The scanning path changes with deformable point sampling, using local anchors and adjustable offsets based on the input features.
