When using language models for evaluation, it's often better to have the model think through its reasoning before giving a final answer. This method, known as Chain-of-Thought prompting, helps the model explain why it made a decision, making its judgments more accurate and understandable. Our research uses these thinking steps and looks at how to best combine the results. When making decisions, there are different ways to use the computing power available at the time. If you have multiple samples, you need a way to combine them. One method is Self-Consistency, which uses majority voting to combine different outputs. There are versions that use confidence levels, like Soft Self-consistency, which chooses based on confidence scores in different categories. Confidence-Informed Self-Consistency uses weighted voting based on confidence scores, which are calculated either by the probability of the sequence or by asking the model. Some methods use the model itself to combine results. Generative Self-Aggregation asks the model to create a new response based on several samples. Universal Self-Consistency uses the model to pick the most consistent answer from several options. Also, research shows that using computing power during testing, especially majority voting, can make reasoning-based generative verifiers work better.
