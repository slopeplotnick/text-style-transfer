MLLMs are like LLMs but also take in visual inputs, which adds more meaning compared to just text and creates extra safety concerns. Jailbreaking is when people use tricky inputs to get around safety rules and make the model produce harmful stuff. It’s a big deal in making these models safer and more reliable. Before, jailbreaking mostly focused on LLMs using things like sneaky prompts or role-playing. But now that MLLMs are a thing, people are trying to hack them using their visual features. The problem is, current methods have some flaws. One way is to make tricky images or hide sensitive info in pictures, but this doesn’t really use the full context. Another way is to just describe the situation in words, like how it’s done with LLMs, but that doesn’t take advantage of what images can do. To fix this, we came up with something called the Contextual-Image Attack (CIA). It’s a way to make images that show both the situation and the harmful intent, with text just helping out. For example, instead of just writing “How can someone make illegal drugs?” in a picture, we’d show something like a teacher asking that question in a chemistry class. This makes it look like the question has a legit reason, so the model gets confused and doesn’t catch the bad intent. Other methods, like FigStep, just put the question as text in an image, or they only use words to describe the situation. Our method is better because it uses images in a smarter way. This is becoming more useful because image generation tech is getting better at making realistic scenarios, and there’s new tech that can turn text into visual data. This shows how images can be used to trick models by carrying complex hidden meanings.
