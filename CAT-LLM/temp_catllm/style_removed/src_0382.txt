We looked at how strong pretrained VLA models are and found that their performance drops when there are changes in what they see because the way they understand space changes. We came up with a new way to quickly adjust these models to handle changes better, using something called Feature Token Modulation and Feature Linear Adaptation, which tweaks how they see things without changing much. Our method works really well with new camera angles and changes in what the models see, as shown in the Libero test, showing that these VLA models can be more robust than we thought. VLA models try to bring together how they see things, understand language, and decide what to do in one system. By using the basics of vision and language in robots, recent VLAs like RT-2, Pi0, PaLM-E, Octo, and OpenVLA show they can handle different tasks well. They use big datasets that include different visual inputs, language instructions, and body states, along with messy actions, to create a shared way for robots to act in different ways. But even with these improvements, studies show that the best VLAs are still fragile when things change, like new camera angles, lighting, or scene noise, even if they've been trained a lot. This weakness needs to be fixed for these systems to work well in the real world, where things are more complicated than in the Libero tests. Making VLAs handle visual changes better has been a big challenge. Previous work tried to make them see things the same way from different angles by using more varied data through random changes, multiple views, or big datasets of visual changes. While these methods work, they need a lot of data collection or labeling, which makes them hard to scale up.
