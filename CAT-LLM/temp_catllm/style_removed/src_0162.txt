We use both audio and visual inputs to see which one shows emotions more in each sample. After making a good dataset with human help and another filtered one, we mix them together for training. We then find the mutual information (MI) for each sample. Once we know which input shows emotions more, we change the order of the reasoning text. For each training example, we split the reasoning into two parts: one for audio and one for video. We use special markers, <aud_desc> and <vis_desc>, to show which part is which. We then arrange these texts based on the MI. If audio shows more emotion, we put the audio part first, then the video part. If video shows more, we do the opposite. If both are equally good, we make two versions: one starting with audio and one with video. This way, the model learns to start reasoning with the input that shows emotions best. After the initial stage, we improve the model's reasoning with Modality-Aligned Reward Optimization. Previous methods used two types of rewards: one for the right answer and one for good structure. But these don't help with focusing on the input that shows emotions best. So, we add two new rewards: one for the right order and one for good reasoning based on the input that shows emotions.
