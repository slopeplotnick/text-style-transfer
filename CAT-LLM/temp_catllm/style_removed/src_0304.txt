We put together 5,500 Level 3-5 problems from the MATH dataset based on previous studies. We check how things work on AIME 2024, AMC, MATH500, GSM8K, Minerva, OlympiadBench, and College Math. For stuff outside the usual, we also look at ARC-C and GPQA-Diamond. We use a method called greedy decoding with a 3,000 token limit. We test CAPO with four main reinforcement learning methods: GRPO, PPO, RLOO, and Reinforce++. For each one, we also try a version with CAPO to see how much it helps. This way, we can look at how well the original methods do on their own and how much better they get with CAPO. We make sure everything's fair by keeping the details about how we set things up the same for all methods. Since each method needs different settings, all the training details are in Appendix B. We use a dataset called GUI-R1-3K from OS-Atlas, which has 3,000 examples of vision-language-action across web and mobile. It matches visual states with natural language instructions and action sequences, making it a good test for checking how well things work with different types of reasoning and planning. For planning, we look at GUI-Act-Web, OmniAct-Web, and AndroidControl-Low/High. For perception, we use Screenshot Pro. We compare GRPO with its CAPO version using the main GUI benchmark setup. This is extra testing to show how well CAPO works in different reasoning situations, not just math.
