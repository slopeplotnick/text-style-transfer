Node 6 handles retrying tasks with feedback, allowing up to three tries for each one. It uses better prompts that mix the original info with specific feedback to help improve reasoning when retrying. The system uses advanced methods to adjust strategies based on the phase of the project, turning weights into reasoning instructions. The prompts change depending on the project's stage, focusing on different priorities. Early on, they aim to maximize success rates with instructions like "pick robots with the best success rates" and "it's okay if workloads aren’t perfectly balanced." Later, the focus shifts to balancing workloads with phrases like "make workload fairness the main goal." This setup helps the system follow the strategies for each phase naturally. The authors make this work using three methods: (1) modeling robot abilities to predict how likely they are to succeed at tasks, (2) creating prompts that include numbers and workload details, and (3) formatting responses in a way that makes them easy to check and validate. There are three types of robots—Light, Medium, and Heavy—each with different strengths and chances of succeeding at tasks. These chances are based on how well the robot's abilities match the task's needs. The success rate for each robot is calculated by combining how well it can handle each feature of the task. A robot's ability to do a task depends on how much the task's needs match what the robot can do. Tasks are handled one by one from a list of 36 tasks in the TEACH dataset. Each task goes through the full process, including figuring out the phase, creating prompts, reasoning, checking, and assigning, before moving to the next task. After each task is done, the system updates progress and reduces the number of tasks left until all tasks are assigned.
