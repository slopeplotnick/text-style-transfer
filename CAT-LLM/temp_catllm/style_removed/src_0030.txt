Score Distillation Sampling is a technique where pretrained diffusion models can not only create samples by cleaning up noise but also be used as optimization goals. This method, known as SDS, has helped these models be used for many different tasks in generating images and videos. Because SDS worked well in making images, people have started using it in reinforcement learning to help with control tasks. Some methods swap out the usual discriminator in a setup like GAIL with a diffusion model, which helps tell the difference between real and fake actions. But these methods still need adversarial training and often have to keep updating the diffusion model while optimizing policies. Besides adversarial setups, other approaches try to use SDS-like techniques directly for learning policies. For instance, some guide policy training with pretrained image or video diffusion models that respond to text prompts. These methods can make behaviors that follow text instructions, but the movements sometimes look odd. The work most like ours is called SMILING, where controllers are trained using a method similar to variational score distillation. But unlike SMILING, which needs specific diffusion models for each task, our approach trains a general motion model from random motion data. This model can then be used to train different control policies by mixing it with specific task goals in a goal-based reinforcement learning setup. We also introduce some important design choices that help create high-quality, natural-looking movements for a wide range of tasks.
