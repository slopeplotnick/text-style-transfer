We tested WorldMM using five benchmarks for answering questions about long videos that last from hours to weeks. Our method did better than other strong approaches, including models made for long videos and ones with extra memory features. We ran detailed tests to show how useful our design is, which uses different types of memory. Episodic memory helps the model think about events happening at different times, visual memory makes it better at answering questions about objects and actions, and semantic memory helps it understand long-term context. When all these memories are combined in a smart way, the model performs the best overall. This shows that our memory system is a good step forward for understanding long videos. Models made for short videos are already pretty good, and newer research is focusing on longer videos. Current advanced models, like GPT-5 and Gemini 2.5, can handle videos that last minutes to hours by using longer context lengths. But these models are expensive to run and don’t work well when every frame is treated the same, especially for questions about specific events. To fix these problems, people have tried different methods. Compressing visual tokens makes things faster by using fewer tokens, but it can miss small details or rare events. Picking key frames helps cut down on extra information, but it doesn’t always find the right frames in very long videos and can miss important moments. Training models to focus on reasoning and using smarter methods during testing has helped with understanding longer videos, but it still doesn’t work well for videos over ten hours. For videos lasting days or weeks, new benchmarks are pushing models to handle continuous recordings over long periods. The methods mentioned earlier don’t work well for these kinds of videos because there are too many frames and the dependencies between events over time are too complex. This shows the need for better ways to deal with very long videos that are efficient, aware of context, and scalable.
