Editing PowerPoint slides with code. Using python-pptx, you can change PowerPoint slides by writing code, like others have done before. This is great for doing the same thing over and over, like finding and replacing words on all slides or translating text. But it's not good for making big changes to the slide's look, like changing the main design or layout. Editing XML directly. To fix what the code method can't do with design and layout, we made PPTPilot able to read and change the raw XML files of the slides. This lets you make precise changes, like moving things to exact spots. Since XML has most of the info for a PowerPoint, using XML works well with existing tools for editing PowerPoints. But XML is hard to edit exactly, especially if you have to change a lot of slides, so using code is usually better. Choosing the right method. To decide how to edit based on what a user wants, we use a tool that picks the right method. When a user asks for something, this tool looks at what they want and the presentation's setup, including pictures and text, and then decides whether to use code or XML. Fixing mistakes.
