We had different sets of data: one with everything, one missing events, one missing relationships, one missing entities, and one missing the story outline. We checked them using both quality and quantity measures. We used the same test data with 196 samples to check the models we adjusted. We looked at how good the stories were in terms of how they worked and how nice they were. We used stories from a preference set as a baseline to compare, so we could see how similar the stories from different models were. We looked at how the four main parts affected the stories. For the quantity check, we mainly looked at how similar the stories were from different models using the same input and the original text. Each model made three stories for each input. We used the original text as a standard and checked similarity with three measures: ROUGE-L, BERTScore, and METEOR Score. ROUGE-L looks at how similar two sequences are based on their longest common part. BERTScore looks at meaning similarity, avoiding surface-level matching issues. METEOR Score uses different matching methods for more flexibility and strength. Figure 7 shows how different setups did compared to the baseline. The setup with all parts did best for controlling content, keeping meaning consistent, and making natural-sounding stories. We got 2 experts and 17 volunteers to do a study on using TaleFrame. To help with creativity, we gave volunteers different pictures. They could pick topics they liked and use TaleFrame to make stories. If they didn't like a story, they could change the four main parts to make a story they liked. Volunteers had to use all the interactive features of TaleFrame.
