We put values in brackets for each prompt from a table of fake participants. Each row in this table was a made-up person with a mix of age, ethnicity, and gender based on a UK sample from Prolific. Prolific sorts ages into ranges, so we picked a random age within those ranges for each fake person. After creating them, we used a simple R script to read each survey answer from the AI and saved it in a spreadsheet. We used three different prompts to get varied answers. Following a method by Hewitt and others in 2024, we averaged scores from different prompts for each question. You can find all the prompt types in the Supplementary Materials of this article. We thought the AI might give answers that weren't in the right format, like not in comma-separated values. We kept these wrong answers to mimic a real workflow and treated them as missing data later, replacing them by averaging other prompt answers. In Studies 1 and 2, we used existing data with prompts like "Pretend to be a [Ethnicity] [Gender] of [Age] years from the UK. Answer the questionnaire [...]". In Studies 3 and 4, we validated new data. The first part shows the process for studies 1 and 2, and the second part shows the two-step process for studies 3 and 4. We tested H3.1 by checking the link between real and fake scores using Spearman's correlation. H3.2 was tested with an ICC. H4 was tested using Mann-Whitney U, Kolmogorov-Smirnoff, and Levene's tests to compare data types. We tested H5 with the same multigroup CFA method as H2 but only on fake data, using gender as a group. All CFA and M-CFA models were done with the MLR estimator because it's good with non-normal data (Hox et al., 2010).
