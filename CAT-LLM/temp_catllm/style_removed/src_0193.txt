First, there's how agents talk to each other and influence each other. Then, there's how hard it is to understand what they're thinking or saying. Lastly, there's how much their goals start to differ. These things together can help predict when and how group risks show up. Each one can be measured and tested in controlled settings with multiple agents. How information moves through the network is important. Systems that are closely connected can work together quickly but can also spread mistakes fast. Systems that aren't as connected slow down the spread of mistakes but also make it harder to fix things together. How information is set up affects how a single mistake can become a common belief. We can measure things like how fast errors spread and how many agents pick up risky behaviors to understand these dynamics. Safety checks for systems with multiple agents should consider how information is set up. Cognitive opacity is about how much we can't see or understand the agents' thinking processes. This can happen by accident or on purpose when trying to meet certain goals hides real thinking. In these situations, one model might accept what another says without question, even if it's wrong. The intent-opacity rate is a way to measure how much we can't trace back the reasoning behind outputs.
