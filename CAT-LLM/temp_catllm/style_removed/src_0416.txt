To compare results from different studies, the samples need to be similar in certain ways. We checked this by using a method called Multigroup-CFA to look at our two samples, one from real life and one simulated, as separate groups and added more rules as we went. We broke this down into different parts: checking if the basic setup is the same (H2.1), if the measurements are the same (H2.2), if the averages are the same (H2.3), and if the leftover differences are the same (H2.4). If the basic setup is the same, it means the pattern is the same in both groups. If the measurements are the same, we can compare differences between hidden factors. If the averages are the same, we can compare hidden average scores. If the leftover differences are the same, we can compare visible averages and do more analysis with visible scores. If we find that the real and simulated samples are very similar in these ways, it means the data from simulations can be trusted to be like real-world data. We also thought that the answers from the real-world data and the simulated data would be very similar (H3), and that the score distributions from both would be pretty much the same (H4). We wanted to see if the simulated data acted like real-world data, so we first used a Mann-Whitney U test to check for average differences, and then used a Kolmogorov-Smirnoff test to compare how the data was spread out.
