To get multilingual models to work well for different tasks, we use the natural connections between languages to make them share information easily. In models like XLM-RoBERTa, languages that are similar in meaning or structure, or that look alike in writing, end up close to each other in the model's space. We start with the 100-language setup of the XLM-R model, which covers a lot of languages, both common and rare. Instead of needing data for every language, we pick a few common ones to train on, which helps us apply what we learn to all the other languages. This way, we can share knowledge between languages by focusing on just a few, without needing to train on the rare ones. We translated the MultiJail dataset into all 100 languages using top translation systems for each language. For common languages, we use the best models like GPT-4o, M2MBart-50, and Helsinki-NLP OpusMT. For rare languages, these models don't translate well, so we use SarvamTranslate for Indic languages, which works well even for rare ones, and GPT-4.1 for other rare languages. To make sure translations are accurate, we check some of them with Google Translate, especially for rare languages. By using these models together, we get translations that are smooth, good quality, and accurate.
