This research is about Lang2Logic, a new way to connect everyday language with computer logic. Lang2Logic changes regular language into a form called Conjunctive Normal Form (CNF), which is needed for logical thinking tasks. This helps turn what people say into something computers can understand. Lang2Logic uses special computer tools and a custom way to read language to make sure it changes correctly from regular language to CNF. This setup lets you change regular language into a SAT problem, which is a kind of logic problem that computers can solve, making it easier to use SAT solvers for real-world problems. Lang2Logic wants to connect regular language understanding with computer logic by changing English into CNF, which SAT solvers need because they work with CNF. Lang2Logic has three main parts: changing regular language into a logical expression, changing that expression into CNF, and making CNF simpler. Each part is important to make sure the change from regular language to CNF is correct and works well. The first part uses the ChatGPT o1-mini model API to turn regular language into a logical expression. The setup for the o1-mini model was made to check for repeated parts, give logical expressions in a way that works with other tools, and make sure it fits the format needed for the Sympy converter. Using the ChatGPT API means you don't need to write complex grammar rules, making the change easier, but it can cost more and might not work as well with bigger inputs. To help with these problems, NLTK was used to get the input ready. NLTK's Punkt tokenizer breaks the text into sentences so that the o1-mini model can handle each one separately, stopping mistakes like mixing or missing sentences. By doing it sentence-by-sentence, the o1-mini model can make more accurate logical expressions. Example 1 shows how an English sentence is turned into a logical expression.
