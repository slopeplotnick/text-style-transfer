We're talking about a new way to separate seeing and thinking in AI models. We add examples of wrong reasoning to the training data so the model can learn what's right and wrong. We also have a new method called STL that helps improve both seeing and thinking, unlike older methods that only focused on thinking. We tested our method in areas like common sense, language, and science, and found it works better without needing human help. In vision-language reasoning, reasoning is important for making models better. While new models do well on tests, using visual info in reasoning is still tough, especially for open-source models. Some methods use prompts to help models think step-by-step. For example, one method looks at context first, then creates features, while another uses scene graphs to understand object relationships. Other methods train models on datasets with reasoning examples, but these can be expensive to make. Our approach lets models learn to reason better on their own without needing special datasets. Self-training is when a model learns by using its own outputs as training data. In large language models, this helps improve reasoning by creating and reusing reasoning steps. This process makes models better without needing human input. Some research has improved reasoning by picking and fine-tuning correct reasoning examples. But self-training for vision-language models hasn't been explored much yet.
