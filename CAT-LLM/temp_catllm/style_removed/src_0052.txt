When the target is far away, the character starts running fast to get closer. These actions come from combining a stationary motion setup with a simple task of moving toward the target. There's no need for a motion planner to decide how the character should move. SMP lets the system use behaviors from the dataset and adjust them to create new skills for different tasks. In the Dodgeball task, agents trained with SMP learn how to jump and dodge quickly on their own, like how humans play dodgeball. These moves weren’t in the original dataset but look similar to real human strategies. AMP doesn’t work well for this task, probably because the dodging skill needed is too different from the motions in the dataset, which only has basic movement. AMP policies that use a frozen discriminator also fail to create natural movements or perform well in tasks, showing that adversarial methods can’t be reused effectively, even for the same tasks. SMP, on the other hand, lets one motion setup be used for different tasks and policies. The task results in Figure 7 show that SMP is more efficient, giving steady and helpful guidance during training. Being able to get up after falling is an important skill for humans and humanoid agents. But this is hard to learn because many methods use extra rewards to stop the character from moving too wildly. AMP, which updates the motion setup during training, can learn natural ways to get up. But our method shows that even with a fixed motion setup, SMP can train a strong get-up skill that works from random fallen positions.
