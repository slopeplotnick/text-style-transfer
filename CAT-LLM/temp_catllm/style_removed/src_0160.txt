When you want to check how good a summary is, you need to look at a few things: how much the words match, how similar the meaning is, and if the facts are correct. Older methods like BLEU and ROUGE-L compare the words in the summary to the original text, but they don’t work well when the wording is different but the meaning is the same. To fix this, BERTScore was created. It uses a pre-trained model to compare meanings instead of just words, which makes it better for summaries that are short and to the point. Besides meaning, it’s also important to check if the summary sticks to the facts in the original text. Some tools have been made for this. FactCC uses a model to check if each sentence in the summary matches the original, but sometimes it makes mistakes and says something doesn’t match when it actually does. Another tool, BLANC, doesn’t need a reference text and checks how well the summary helps a language model guess missing parts of the original, but its results depend on the model used and sometimes focus too much on word matching instead of meaning. SummaC is another tool that checks if the facts in the summary match the original by using a method called Natural Language Inference (NLI). It looks at each sentence and sees if the original text supports it. Tests show SummaC usually works better than older tools like FactCC. In this study, we use a mix of methods to check summaries: ROUGE-L for word overlap, BERTScore for meaning, and SummaC for factual accuracy.
