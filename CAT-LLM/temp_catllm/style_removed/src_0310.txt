Auditors use Journal Entry Tests (JETs) to find weird stuff in tax records, but these tests often give too many false alarms and miss small issues. We're checking if big language models (LLMs) can spot these problems in bookkeeping. We tested top LLMs like LLaMA and Gemma on fake and real anonymous ledgers and compared them to JETs and basic machine learning methods. Our findings show LLMs do better than the usual JETs and old-school ML methods, plus they explain things in plain language, which makes them easier to understand. This shows how AI can help in auditing by working with human auditors to keep financial records honest. Financial auditors are important for spotting strange transactions that might mean mistakes, fraud, or tax dodging in a company's books. Finding these problems is crucial for keeping trust in financial reports. But going through a lot of accounting data is really hard; current manual and rule-based ways are often not efficient and can make mistakes, so auditors might miss big warning signs. Standard JETs, which depend on set rules and known patterns, usually flag too many transactions. These tests only catch expected problems and overwhelm auditors with alerts, many of which are false alarms that take a lot of time to check. In reality, auditors still mostly use sampling and manual work, which can miss small issues in today's huge, complicated datasets. This gap between more complex data and the limits of old audit methods shows we need smarter, automated tools for finding problems in auditing.
