The first test done in the MODOMA lab was based on a certain connection. This test is a way to check how well the MODOMA method works for learning languages using Zipf's law. This study helps develop research so that MODOMA can get better by doing more complex tests. This way, we can get more experience with MODOMA as a model for language learning tests and improve the system before trying other language learning methods. Even though Chaabouni et al. (2019) and Rita et al. (2020) look at how languages start, they also use Zipf's law to better understand language models compared to human languages. This process uses most of the parts and steps needed for more complicated learning tests. The parts of the MODOMA system and how they work together can be checked and improved to do more computer-based language learning tests. If the learning works, the daughter agent learns the difference between functional and content categories from examples of the target language given by the mother agent during their interaction. It's important that once the daughter agent understands this grammar difference, it uses the new grammar knowledge right away to update its grammar and create new sentences during talks with the mother agent and understand new sentences from the mother. So, this study shows if the MODOMA lab method for language learning can lead to learning important grammar knowledge that can be used well in understanding and creating language.
