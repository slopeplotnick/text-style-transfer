We're dealing with a task where some things are not important (L1 and L2) and others are (L3 and L4). To measure how well we're doing, we use a method called acc@2, which is basically checking if we get things right or wrong. We also use something called the macro F1 score to balance things out when the data labels aren't evenly spread. We compare two types of models: first, big language models that are either open or closed-source. We test them by giving them prompts that explain the task and rules. We follow the best practices for each model, like using certain settings that work best for them (like a temperature of 0.7 for GPT-4 and 0.6 for Llama-3). Second, there's a basic model called Vanilla SFT. It's trained with labels but doesn't use extra techniques like CoT or RL, which helps us see how much those extra techniques help. This basic model does pretty well, with scores of 0.929 for acc@2 and 0.722 for macro F1, even better than advanced models like GPT-4. Another model, LORE, does even better by improving acc@2 by 0.4 points. This shows that while the basic model is already good with regular data, LORE can still make it a bit better.
