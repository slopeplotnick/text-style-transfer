Some researchers are looking into ways to make systems more robust by keeping things consistent in how they interpret shapes and geometry. Studies have shown that when the viewpoint changes, it can mess up how pretrained ViT encoders process information, which then causes problems with how perception and decision-making parts of the system work together. Based on this, we’re checking if fixing these mismatches in how things are processed—without changing the whole VLA setup or gathering more data—can make the system handle viewpoint changes better. There’s this method called parameter-efficient finetuning (PEFT) that’s become popular because it lets models adapt to new tasks or situations without needing to change a lot of stuff. Examples of this are things like adapters, LoRA, Prefix-Tuning, and BitFit, which add small, adjustable parts to the system while leaving most of it untouched. These methods are widely used in big language models and multimodal systems because they’re efficient and stable. In embodied AI, PEFT is mostly used for updating language or decision-making parts, like tweaking decision transformers or instruction encoders. But when it comes to handling viewpoint changes, most methods don’t really focus on directly adjusting the visual part of the system. There aren’t many approaches that make small, focused changes to the visual processing part of VLA models. Instead, most methods try to adapt the whole system. Our work looks at whether making small, efficient changes to just the visual parts—like vision tokens or the vision encoder—can fix these problems. Usually, other methods deal with visual issues by retraining big parts of the system or even the whole visuomotor policy. But we think that’s not necessary. The main issue with visual changes is that they cause predictable shifts in how visual data is processed, which throws things off.
