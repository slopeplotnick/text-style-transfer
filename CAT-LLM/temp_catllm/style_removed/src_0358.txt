DeepSeek-V3.2 works about as well as Kimi-k2-thinking and GPT-5 on different reasoning tests. It also makes big improvements in how open models handle tasks, doing really well on some specific agent tasks from EvalSys and other studies in 2025. DeepSeek-V3.2 is a cheaper option for agent tasks, closing the gap between open and top private models while being much cheaper. To push open models further in reasoning, we made DeepSeek-V3.2-Speciale by relaxing length limits. This version matches the performance of the top closed-source system, Gemini-3.0-Pro, and does great in competitions like IOI, ICPC World Final, IMO, and CMO in 2025. DeepSeek-V3.2 has the same setup as DeepSeek-V3.2-Exp. The only change from the last version, DeepSeek-V3.1-Terminus, is adding DeepSeek Sparse Attention (DSA) with more training. DSA has two main parts: a fast indexer and a detailed token selection system. We started with DeepSeek-V3.1-Terminus, which has a longer context length of 128K, and did more training to make DeepSeek-V3.2. This extra training had two stages, using the same kind of data as the longer context data for DeepSeek-V3.1-Terminus. In September 2025, we tested DeepSeek-V3.2-Exp on various benchmarks and compared it to DeepSeek-V3.1-Terminus, showing similar results. DeepSeek V3.2 Exp is much better at handling long sequences efficiently without losing much performance compared to DeepSeek-V3.1-Terminus on both short and long tasks.
