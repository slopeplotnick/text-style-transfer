To work with long videos better, some methods called retrieval-augmented generation (RAG) have been created. Instead of just picking random frames, these methods find and use the important parts of the video, like specific frames or clips, based on text and visuals. This helps the model focus on the key parts of the video. Some newer methods go further by using graphs to connect and understand how different parts of the video relate to each other. But these models often depend too much on text or simple comparisons between visuals and text, which makes it hard for them to fully understand and reason through long videos. To improve on this, some memory-based methods have been developed to organize and store information from videos in a structured way. For example, EgoRAG organizes text-based memories from videos to help understand activities that happen over a whole day. Ego-R1 builds on this by using tools focused on visuals and reasoning step by step to handle longer tasks. HippoMM uses two types of memory, combining summaries and multimodal information. M3-Agent creates a memory system focused on entities and uses step-by-step reasoning to find the right information. Even with these improvements, current methods still have trouble fully combining text and visuals and adjusting to different time lengths in videos to deal with complex situations. To address this, we created WorldMM, a new system that uses both text and visuals from videos to build a memory system for better understanding and reasoning with long videos. The system works in three steps: first, it creates multiple types of memory, including two for text and one for visuals. Then, it uses a retrieval process to gather the information it needs from these memories and different time periods until it has enough to answer a question. Finally, it uses this information to generate a response.
