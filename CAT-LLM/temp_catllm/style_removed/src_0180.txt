The language learning experiments are about adding clear grammar knowledge to a word list. Then, the daughter agent can use this knowledge to talk with the mother. The system uses machine learning techniques to create a clear grammar representation. This helps current systems that use statistical methods and neural networks by providing a more understandable, rule-based way to model language. By using Zipf's law, this study checks how well a multi-agent simulation of learning a first language can work. The study's goal isn't just to classify function and content words, but to use this classification to test this new way of modeling first language learning. Zipf's law is useful because it gives a strong and reliable way to evaluate the system's performance. This is a common practice. For example, Chaabouni et al. (2019) and Rita et al. (2020) use Zipf's law to create a multi-agent framework to model language evolution, and there are recent studies by Dębowski (2021), Takahashi and Tanaka-Ishii (2019), and Takamichi et al. (2024). The experiments in this study confirm all parts needed to make a multi-agent model of first language learning. Specifically, learning function and content words uses a mixed language learning strategy based on statistical trends that help learn specific grammar rules. These results support modeling more complex grammar and show the MODOMA research plan can work. A study based on these results is by Shakouri et al. (2025), which shows how grammar categories like noun, verb, and preposition can be learned using unsupervised techniques. This paper presents two experiments showing this approach: the first simulation in Sections 6 and 7 was applied to a training data set made by the mother agent. These experiments were used to find the settings for learning this language feature. The second experiment used a new test data set made by the adult language model to check this setup, see Section 8. The results suggest that MODOMA can learn these grammar categories and show them through the grammar system of the daughter agent.
