One big issue in creating psychometric scales is the "Jingle-Jangle Fallacy." This happens when two tests with the same name measure different things (jingle fallacy) or when two tests with different names measure the same thing (jangle fallacy). In the second case, because psychological stuff is complicated and the definitions aren't clear, scales that seem different can actually be very similar and show high correlation. Avoiding these fallacies is mostly about figuring out the concepts correctly, which means checking if the scales actually measure what they’re supposed to, if they relate to other things in expected ways, and if they’re different from other scales. This involves testing scales over and over, which can take up more resources and time. Not dealing with this problem has led to many similar measuring tools, causing a lot of confusion in psychological research. Also, new AI software like Open AI's "Chat GPT" might help develop new methods for areas like social psychology, where computer models haven’t worked well before. AI could help researchers make psychometric tools by quickly creating draft questions that can be tested later. Because AI is built on understanding language and trained on lots of text, it's good at solving problems in scale development related to words and meanings.
