Big language models keep getting bigger and more complex, which makes them use up a lot of memory and computing power when being trained or used. Quantization is a way to deal with this by storing data in fewer bits and swapping out expensive floating-point calculations for simpler and cheaper integer math. There are two main ways to do quantization. One is called post-training quantization (PTQ), which is easy to use and doesn’t need retraining, but it doesn’t work well when using very few bits, like 1 or 2, because the accuracy drops a lot. This happens for a few reasons, like not having enough calibration data, scaling methods not working well enough, or certain channels messing up the ranges. The other method is quantization-aware training (QAT), which adds the quantization process into training so the model can adjust to it. QAT works better than PTQ when using very few bits, but it takes a lot of time and can be unstable because it still has limited flexibility to handle the data. We used FAIRY2 on popular open-source language models like the LLaMA series, and the results showed it works well. Here’s what we did: we came up with a way to change any layer into a different form without changing how the model works before quantization, we kept training the model at very low bit levels using a special quantizer while reusing existing checkpoints, and we reduced errors by applying the same method to the leftover data, which helped make the errors much smaller.
