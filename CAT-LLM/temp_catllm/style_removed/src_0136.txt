Unlike image-based IC-LoRA methods that need separate training for every editing task, our single Sync-LoRA module works for different edits and balances good image quality with keeping motion accurate, as we show in our tests (check section 4). In-context learning (ICL) in diffusion models helps models handle new tasks by using structured input examples instead of direct instructions. This has been studied a lot in language models, but more recently, people have looked at how it works in image generation using diffusion models. In these cases, the model makes a group of images where the images relate to each other. This is useful for things like creating storyboards, where the images need to be consistent. When you use a real image to guide these panels, ICL methods can handle many image-to-image tasks, like personalizing images or editing them. The work most similar to ours is IC-LoRA, which noticed that transformer-based diffusion models can naturally make panels where some features stay the same across the images. They improved this by fine-tuning the model with a low-rank adapter (LoRA) on consistent panels and using specific prompts. Their method has been used for things like making storyboards, designing fonts, and decorating homes. Our work takes this idea further by applying it to videos, creating an IC-LoRA for video editing that focuses on syncing portraits frame by frame. Also, recent research has shown that large video diffusion transformers can naturally learn in-context behavior, letting them create related video clips in one process. That research looked at how this ability works, using inpainting to control scenes but without ensuring the clips match up over time. Building on that, PoseGen introduced in-context LoRA fine-tuning for generating human videos with controllable poses, making long, smooth motions from a reference image. Our method takes this further by specifically training the in-context behavior to focus on synchronized editing.
