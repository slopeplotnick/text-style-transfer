In 2024, we break down content into clear sections and summarize it in different languages for interactive Q&A. We use transcribed multimodal ST output as context for this. Modern LLMs can handle long contexts but have limits, so we do this: we translate lectures into multiple languages, split them into chapters to prevent overflow, and make summaries clearer because chapters stick to one topic. We create compressed versions of each chapter, like transcripts at different compression levels (50%, 70%, 90%) and summaries based on the original section's length. We start with English summaries since LLMs work better with English and then translate them into other languages. For Q&A, we do something similar: use English transcripts organized by chapters with Retrieval-Augmented Generation (RAG) to ask an LLM questions, then translate the answers. Another issue is translating slides into different languages. Slides have editable text and images with text. We use a Python PowerPoint parser to pull out text and translate it with standard MT, avoiding multimodal models because they're expensive. Text in images can't be easily extracted, lacks context, and needs visual elements for meaning, so we need multimodal translation. After translating, we put the text back into the image to keep the layout and meaning. We suggest an image-translation process that finds, reads, translates, and puts text back in slide images.
