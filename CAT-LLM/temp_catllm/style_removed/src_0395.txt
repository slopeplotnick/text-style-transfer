As far as we know, this is the first time anyone has used an open-vocabulary object detector to help MLLMs understand high-res images better. Tests show that the detector accurately finds targets and ignores unrelated areas. We came up with MRD, a framework that doesn't need training and works generally. It fixes semantic similarity with a multi-resolution fusion strategy and uses open-set detection results to improve target areas, making everything work better together. Lots of tests show our method works well and can be used in different situations. It does really well on both single-object and multi-object tasks in various MLLMs and high-res tests. To understand high-res images better without making visual tokens more complicated, some studies have added high-res visual encoders to MLLMs. For example, Vary and Deepseek-VL use the SAM encoder to make models work better on HR images. Another approach is using Native/Dynamic-Resolution MLLMs that handle images at their original resolution. The main idea is to create a sequence of visual tokens that fits the original size of the image, keeping the details and spatial accuracy. These models use different methods to deal with the long sequences and complexity, like sliding window attention, dynamic masking, and patch-based encoding. Important works in this area have shown a lot of progress. For example, the InternVL series splits a high-res image into fixed-size patches. On the other hand, models like Qwen2.5-VL train a ViT directly on native-resolution images, letting the model turn the whole image into a single token sequence in one go, which might help understand the overall context better.
