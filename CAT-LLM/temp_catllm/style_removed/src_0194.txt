You can use this approach anywhere: geologists talk about models with diagrams in their papers, mathematicians use these to set rules for probability models, and geophysicists use them for Bayesian inversion. Another example is other data, because the first idea might be wrong. This problem is part of a bigger science issue: how do we prove our assumptions are right? Karl Popper, an Austrian philosopher, spent his life thinking about questions like this. Popper believed science shouldn't use induction, which is making theories from observations. Instead, theories are guesses made by people to fix problems with old theories. Once you have a theory, you need to test it with observations. If a theory doesn't match the observations, it should be thrown out. Theories that pass the tests are the best ones we have. In terms of uncertainty quantification, models are seen as guesses about reality. You have as many guesses as models. These guesses can be limited by what we already know, but real data shouldn't be used to prove a model right; it should be used to prove a model wrong if it doesn't match the data. Popper gives a way to deal with the subjectivity in Bayesian reasoning, which is a type of inductive reasoning, unlike the deductive way of proving things wrong. If the prior distribution can't predict the current data, then the Bayesian prior is proven wrong. This means no matter how many models you try from the prior, each one doesn't match the data. While Popper's idea might make the prior less subjective after testing, he doesn't provide a way to change the prior, which is still up to human judgment.
