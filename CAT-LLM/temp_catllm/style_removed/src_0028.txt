Even though memory tech has come a long way, it’s still pretty tricky to use it for predicting stock prices. The main issues are that current systems aren’t great at breaking down event sequences in detail, they’re not good at matching past scenarios to new ones, and they don’t handle the way financial markets change over time very well. Because of these problems, there’s a real need to create memory systems that are made just for finance. This chapter looks at the research in two main areas: how we’ve moved from just matching past patterns to using memory systems, and how event-driven prediction is becoming more important. While there’s been a lot of progress, there’s still a big problem with combining structured event knowledge with memory systems you can track, and that’s what this work focuses on. When it comes to predicting stock prices, people used to focus on finding patterns in past data that looked like what’s happening now to make predictions. This idea is similar to how memory systems in LLMs work, where the goal is to store and pull up past experiences or contexts. At first, researchers used statistical methods, which were good at spotting number patterns but couldn’t handle more complicated market info. Then, with deep learning, they started using models like LSTM and Transformer to figure out time-based features automatically. Transformer models were especially good at spotting long-term connections using self-attention, which helped move things forward. The FinSeer framework also brought in LLMs to find past data that’s similar in numbers, which helped dig deeper into features.
