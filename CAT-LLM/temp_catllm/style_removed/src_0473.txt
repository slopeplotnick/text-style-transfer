We used scikit-learn to set up some basic models like Majority, Random, n-gram SVM, Logistic Regression, Random Forest, and Decision Tree. We got the features using TF-IDF and count-vector methods. The basic models were run on a CPU, but we did all the transformer model tests on a GPU (Google Colab T4). We mainly checked how good the models were using the micro-averaged F1-score, but we also looked at accuracy, precision, and recall to compare them fairly. We tested different models like m-BERT cased, XLM-RoBERTa base, BanglaBERT, DistilBERT cased, and the basic models to see how well they could spot hate speech in the BLP2025 dataset. Table 2 has the results for subtask 1A. BanglaBERT did the best with an accuracy of 0.71, beating all the other models we checked. It also had a precision of 0.70 and recall of 0.71. The main score for the shared task 1a was the micro F1 score, and BanglaBERT got a 0.71. The BERT multilingual base (m-BERT) got an F1 score of 0.66, and XLM-RoBERTa base got 0.67, both better than the basic models. DistilBERT got an F1 score of 0.57, which was lower than the basic SVM and LR methods. BanglaBERT's micro F1 score was the best for this dataset in our study. Among the basic models, SVM did the best with an F1 score of 0.61, while the random baseline did the worst with an F1 score of 0.16. DistilBERT didn't do as well with an F1 score of 0.57. Among the basic models, SVM and LR did the best with F1 scores of 0.63 and 0.62.
