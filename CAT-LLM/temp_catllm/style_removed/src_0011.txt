The AgentHarm test dataset has 176 examples from 44 tasks in 8 categories like disinformation and fraud. Each task can be adjusted with options: one gives a hint about which tool to use first, and the other gives detailed step-by-step instructions. Mixing these options makes four versions of each task description. For the experiments, the focus is on the simplest group to save money and check the model’s abilities, making sure the model’s capability isn’t the problem and that the length of the context is the main thing affecting how well it works (check Section A). AgentHarm uses automatic scoring and evaluation by LLM judges (Zheng et al. 2023). Two things are measured: (1) Harm score, which is a score between 0 and 1 based on rubrics for harmful tasks done manually, and (2) Refusal rate, which is the percentage of examples marked as refusals by the LLM model. Details are in Section B. Harm Score is the main focus, and semantic judging isn’t used because the simplest tasks are assumed to be evaluated reliably. For refusal judging, small changes are made to the prompt and the model, explained in Section E. To test context length in a controlled way, four types of padding are used: random padding uses random tokens from the tokenizer; non-relevant padding uses text from fiction genres like humor, mythology, sci-fi, crime, and romance that don’t match the task category; relevant padding uses text from Wikipedia that matches the task category; and multi-task padding uses task descriptions from the validation dataset. These padding types help test different things: random padding is good for reproducibility, non-relevant and relevant padding use text that fits the style, and multi-task padding checks how well the model handles confusing context. More details are in Sections F and G.
