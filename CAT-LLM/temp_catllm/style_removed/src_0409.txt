So, the main question here is whether modern language models (LLMs), which are trained just to predict the next word without being specifically taught to understand things like perception, end up figuring out similar ways to process information. If we can figure out how these models handle uncertain information, it could help us build better systems that can deal with different types of input quality. To look into this, we used methods from psychophysics, which is a field that studies how people perceive things, to see how these models work. We treated the models like black boxes, meaning we didn’t look inside them but instead studied their behavior to figure out how they process information. By controlling how uncertain the input is and checking for signs of Bayesian processing (which is a way of making decisions based on probabilities), we can see if these models behave like humans when it comes to perception, even though they weren’t trained for it. We found that some classic tasks used in psychophysics work well with these models and show interesting patterns. These tasks are good for testing how well the models can handle different types of input, especially in controlled situations where we can measure everything precisely. Unlike real-world tasks where there’s too much noise to measure properly, this setup lets us test specific strategies and find weaknesses that wouldn’t show up in regular benchmarks. We made three main contributions: First, we created a psychophysics framework for LLMs, which includes four tasks that measure things like length, location, distance, and duration. This setup lets us control things like noise and context to see how the models’ behavior changes. Second, we made a new benchmark called BayesBench that measures how well the models perform, how efficiently they combine information, and how consistent they are with Bayesian reasoning, using a new scoring system. Third, we found that some advanced models show behavior that matches Bayesian reasoning, but we also found a big issue where even very accurate models fail to use reliable strategies in certain situations. Psychophysics, which is the study of how people perceive things, has shown that there are consistent patterns in how physical stimuli relate to what people perceive, and these patterns are described by well-known laws like Weber-Fechner’s and others.
