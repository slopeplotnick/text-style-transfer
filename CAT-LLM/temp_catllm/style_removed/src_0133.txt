Test-time learning lets models adjust themselves while they're being used. Early methods focused on simple ways to adapt without changing the model's settings, like reducing uncertainty or using batch normalization. Later approaches took this further by allowing models to update their settings during use, which makes them better at handling specific tasks. For example, research shows test-time training helps models learn better when the data changes, and some methods let large language models fine-tune themselves using helpful feedback. A newer idea in this area is test-time policy optimization, which treats the process of using the model like a reinforcement learning problem. Techniques like RLVR and TTRL use feedback from multiple tries, like majority voting, to guide updates. This helps make sure the model's reasoning is consistent and correct without needing labeled data. But there's a big problem: these methods usually need a lot of repeated tries for every question to get reliable results, which wastes time and computing power. Easy questions don’t need much effort, but hard ones do, and this makes the process slow and expensive. To fix this, we came up with a framework called OptPO to make the process more efficient. Instead of deciding ahead of time how many tries are needed, OptPO uses a method to test the results step by step and stops when there's enough evidence for a clear answer within a set error limit. The tries that have already been done are then used to improve the model's settings, so computing power is only used when it's really needed. OptPO can also work with supervised fine-tuning methods for test-time training.
