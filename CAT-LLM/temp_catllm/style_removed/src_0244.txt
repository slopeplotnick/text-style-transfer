Starting a character in a random state from a motion dataset helps in exploring motion imitation methods better. But you need the dataset to pick starting states during training. To avoid needing the original dataset, SMP uses a generative model to make starting states for training. When using SMP, starting states come from a diffusion model that's already trained as a motion guide. SMP acts as both a reward and a way to start new training. This generative state method means you don't need to keep the original dataset once SMP is trained because it uses diffusion models to create varied and good starting states. Our setup uses a trained diffusion model as a flexible motion guide for learning imitation. The motion model checks if the agent's moves look natural in a learning setup. This helps train control policies that do different tasks while looking like the original dataset's moves. Here, we explain important choices in the learning setup. Making a good motion representation is key for training the diffusion model to understand the dataset and using it as a guide for training policies. The representation needs enough info to rebuild motion and should be easy to get from motion clips and simulator observations.
