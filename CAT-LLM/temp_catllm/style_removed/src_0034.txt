We’re introducing a method called MIGR that figures out which type of input to focus on first using something called MI. The goal is to reduce biases in how the system starts reasoning and make sure it focuses on the type of input that has the strongest emotional signals. The method has two main steps. First, there’s something called modality-aligned SFT, which helps the system learn where to start reasoning by focusing on the input type that MI says has the strongest emotional signals. Second, there’s Modality-Aware Reward Optimization, which helps the system stick to focusing on the right input type and keeps the reasoning emotionally grounded while making the training process more stable. To do this, we use two rewards: one that encourages focusing on the right input order and another that supports reasoning based on emotional signals. The next parts explain these steps in detail. Some recent research has shown that SFT works well for understanding emotions, even when there’s only a small amount of high-quality training data, like from the EMER dataset. Based on this, we start our training with a similar approach. Even though EMER gives good training data, we can make the SFT step better by adding more examples that clearly show consistent emotional signals. To do this, we add extra examples to the training data. We find these examples by looking at facial action units (FAUs) from video frames, which are closely linked to emotions. Then, we check if the FAU patterns match the target emotion using a table that maps FAUs to emotions. We only keep examples where the FAUs match the emotion exactly. For these examples, we create reasoning-answer pairs using the emotional evidence from the FAUs to guide the reasoning process.
