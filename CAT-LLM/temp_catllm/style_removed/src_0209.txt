In all three models, the way young affects the image and prediction is the same, showing it's a good measure no matter the level of detail. But if an explanation model treats variables as separate and doesn't consider how they actually affect each other, it only shows the direct effect, which can be the same as the total effect in the first model but zero in the last one. So, direct influence isn't always a reliable measure. Section 5.3.1 talks about problems when model assumptions aren't right, suggesting careful model choices. If assumptions cause bias in explanations, the model needs to be changed or the explainer should know about the biased context where explanations work. This doesn't mean complex models are always better than simple ones. To make sure explanations match how they're supposed to be understood, the causal model should match the level of detail the person understands about the world. Making things easier to understand is important, so leaving out some detailed causal mechanisms is better, putting important info into a simpler form. Another big plus of the causal explanation model in Section 5.3.1 is that it uses expert knowledge to better find and remove fake correlations compared to models based only on data. So, the explanation model can spot fake relationships learned by the predictor, even if the same data is used to learn the explanation model. With expert knowledge easier to get through LLMs, as shown in the example, this is especially useful for improving models by finding unintended behavior.
