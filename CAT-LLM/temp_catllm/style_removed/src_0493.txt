Most video model tests right now focus on basic physical knowledge, sticking to everyday situations that just need a simple understanding of how physical stuff works. We’ve created something called VideoScience-Bench to see how well video models can understand and think through scientific ideas. Each test includes several science topics and needs college-level knowledge, covering 103 ideas from physics and chemistry. We check if these video models can figure out scientific setups and predict what should happen without extra help. The test looks at five main things: how consistent the model is with the prompt, if it predicts what should happen, how well it handles movement, if it respects unchanging rules, and if it all makes sense together. We also made VideoScience-Judge, a system that uses a checklist to evaluate the models. It creates a checklist based on the test, picks out important video frames, and finds key moments where things happen. This helps score the videos, and the scores are combined into one number that shows how good the model is at reasoning. When we checked, the scores from VideoScience-Judge matched expert opinions better than other tests that focus on basic physical knowledge or how realistic the videos look. To sum it up, this study looks at whether video models can handle multiple science ideas at once. We’ve done three main things: 1. Made VideoScience-Bench, a high-quality test for checking if video models can reason scientifically without extra help, using real-world examples from 103 physics and chemistry topics. 2. Built VideoScience-Judge, a system that uses checklists, picks out important video frames, and uses computer tools to spot things like motion and object interactions, giving scores for how scientifically valid and visually good the videos are. 3. Ran a detailed study using VideoScience-Bench. Even though today’s video models can make realistic and smooth videos, VideoScience-Bench is still tough for them. Many models can’t handle complex science ideas and often mess up basic physical rules. Out of the models we tested, Sora-2 and Veo-3 did the best and showed some early ability to think scientifically.
