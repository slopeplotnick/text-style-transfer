We're talking about the Autonomous Domain-Oriented Relevance Engine, or ADORE. It has three main parts: a module that figures out what's relevant using rules specific to the domain, a module that creates data based on error types, and a module that improves knowledge using key attributes. The first module uses a reasoning model to automatically make hard samples by looking at products shown online. The second module uses a model that makes different kinds of tough samples to make the system stronger. The third module uses key features from analysis to boost knowledge and make the online model better at reasoning and representing things. We've done a lot of tests to see how well ADORE works, both with big offline datasets and online tests. The results show ADORE does way better than other methods, improving both offline and online metrics. This shows ADORE is really good at dealing with complex relevance tasks in e-commerce. To make our online model better, we made a model that figures out relevance using Large Language Models. Research has shown that using Chain-of-Thought prompts makes these models much better at reasoning. We used this idea to fine-tune our model. We started by using GPT-4o to make data labeled with Chain-of-Thought. This is like how humans annotate data, using guidelines and examples. This gives us a dataset with detailed reasoning like human annotation. To make the labeled data more accurate, we only used data that could be checked with human labels and left out any data that didn't match human labels. This is our final training set. Then, we used these samples to fine-tune the LLaMA-3 model by optimizing a standard Language Model loss.
