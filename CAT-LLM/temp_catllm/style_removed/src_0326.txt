A journal entry in accounting is just a basic record of a financial transaction. It usually includes a debit and a credit entry in one or more accounts. Each entry has details like the date, an ID, the currency used, who made the entry, tax rates, amounts, and sometimes a description. These details can be numbers, categories, or text, which makes journal entries a good way to test systems that look for unusual patterns in mixed types of data. Both fake and anonymized datasets have the same key features, so they can be used to build and test models consistently. Researchers have been using machine learning (ML) to improve how we find unusual or suspicious entries in accounting data. Unsupervised methods like clustering and Isolation Forest can go through journal entries and find ones that don’t match the usual patterns Herreros-Martinez et al. [2025]. Some recent work with fake general ledger data has shown that these methods can work better than older rule-based systems Gronewald et al. [2024]. But there are still challenges. Traditional ML models usually work with structured data and might not understand the context well enough to tell if something is really risky or just looks unusual. On the other hand, Large Language Models (LLMs), like GPT-4, have opened up new ways to handle auditing. These models are good at understanding and reasoning with language. Early research suggests they could help as AI assistants for analyzing financial data Gu et al. [2023]. Some recent studies show that LLMs can also help find unusual patterns, like SigLLM for time-series data Alnegheimish et al. [2024] and AnoLLM for tabular data Tsai et al. [2025]. These models perform well without needing a lot of extra work to prepare the data. However, using LLMs in important tasks like auditing needs to be done carefully. LLMs can sometimes give inconsistent answers, show bias, or make things up. Because of this, people have started creating tools to check the work of these models, like AuditLLM Amirizaniani et al. [2024a] and LLMAuditor Amirizaniani et al. [2024b]. These tools show that while LLMs are very useful, it’s important to have rules and oversight when using them for decisions in areas like auditing.
