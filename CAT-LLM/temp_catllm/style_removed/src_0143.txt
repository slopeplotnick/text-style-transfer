The LLM-as-a-Judge method is cheaper than having people check, but it only works with known risks and isn't great for new security problems. We look at a modern LLM-agent setup that uses the Model Context Protocol (MCP). The LLM in the agent acts like a manager, understanding user instructions, figuring out steps, and using outside tools to finish tasks. Each MCP tool works on its own within the agent, talking to the LLM through a standard API. While doing tasks, the LLM keeps track of what's going on, even when switching tools, to help with complex reasoning. The LLM is the main thinker, and the tools do specific jobs. The bad guy wants to use the agent's computing power without getting extra access or breaking into the system. We see the bad guy as someone who makes MCP tools and shares them in the open market.
