Instead of tracking motions frame by frame, distribution matching trains controllers to copy the overall behavior patterns from a motion dataset. GAIL uses a discriminator to tell the difference between the agent's motions and the dataset's motions. AMP builds on this idea to let controllers create realistic behaviors for new tasks that weren’t in the original dataset. But adversarial priors need to be trained with a specific policy for each new task, which means retraining and needing the dataset again. Our method works just as well as these approaches but uses a reusable motion prior that can also be adapted for different styles not in the original dataset. Diffusion models have become popular because they perform really well in many areas, and people are now using them for control tasks. They can generate high-quality motion, so one way to use them is as motion planners that predict future movements, which are then followed by a tracking controller. They’ve also been used to directly control behaviors for tasks like manipulation and character control, allowing for flexible and varied actions. Unlike these methods that use diffusion models as part of a controller, our approach uses pretrained diffusion models as general behavior guides. We use them as a reward function in reinforcement learning to help policies learn through score distillation sampling.
