We used a method called Supervised Fine-Tuning (SFT) with the Qwen-1.5 model as the main framework. This helped the model learn general language skills and apply them to e-commerce tasks. For data, we used knowledge graphs and added domain-specific information through carefully designed prompts to help the model understand e-commerce-related patterns and relationships. To check how well the model worked, we used standard tests and relevance metrics to make sure it was accurate and could handle different types of queries. Once trained, the model was used to help with labeling tasks, making the process faster and better by catching errors and improving data quality. It also worked on harder tasks like understanding complex queries, hidden meanings, and logical reasoning for building paths. Simple instructions weren’t enough for these tasks, so we used a method called Chain-of-Thought (CoT), which helped the model break down problems, understand relationships, and compare paths step by step. This made the model much better at handling tricky queries. We also created a system to find difficult cases and improve the model through feedback. Later, we used CoT data for tasks like extracting and matching attributes and trained the model again with the SFT method using Qwen-2, which helped it handle reasoning steps while staying focused on specific tasks.
