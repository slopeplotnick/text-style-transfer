TCAS is a well-known program used a lot in studies about finding faults in code. It's a C program from Siemens with 41 versions that have known bugs added on purpose. On the other hand, C-PACK-IPAs is a bunch of student programs from a beginner programming class. For this study, they used the whole C-PACK-IPAs set, which has 25 assignments and 1431 buggy programs from three lab classes. These programs cover things like numbers, input-output, loops, character handling, and working with vectors. C-Pack-IPAs has been useful for checking different program analysis tasks. CFAULTS uses a tool called pycparser to work with C programs, and CBMC version 5.11 is used to turn C programs into CNF formulas. For finding bugs, since the original code for BugAssIST and SNIPER isn't available or doesn't work anymore, they made new versions of their algorithms. The old SNIPER could only work with some C programs and had trouble with loops, recursion, and some variables. They also made a new version for HSD to find faulty code in C programs, with and without a feature called core minimisation, because the old version only worked with Boolean circuits. So now, BugAssIST, SNIPER, and HSD can work with C programs using parts of CFAULTS. All the algorithms they tested give results that match certain criteria, meaning they check if the results are right using CBMC. This check is mainly for BugAssIST because it can give results that don't match all the failing tests. But CFAULTS' MaxSAT solution and HSD's method always match all the observations. SNIPER's method gives correct results, but they might not be the simplest ones. For BugAssIST, they go through all the results it gives based on a scoring system until they find one that matches everything they observed.
