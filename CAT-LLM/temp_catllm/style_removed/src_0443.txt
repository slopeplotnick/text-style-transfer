We're using two main ways to check how well things are working: Toxic Score and Attack Success Rate (ASR). Like some earlier studies, we use GPT-4o to see how harmful a response is. If there's a harmful question and an answer from the model, the evaluator gives it a Toxic Score from 1 to 5. A higher number means it's more harmful, and a 5 means the answer completely matches the harmful intent of the question. We say an attack worked only if it gets a score of 5. You can find the evaluation prompt in App. B.3. We have four different parts in our study, and each part works better in different situations and with different models. So, an attack is considered successful if either the original target image or any of the four improved target images gets a successful attack. When we figure out the Toxic Score, we pick the highest score from five tries for each example in a specific situation.
