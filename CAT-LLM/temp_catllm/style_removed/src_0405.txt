First, we used signal processing methods like Common Spatial Patterns (CSP), which is often used in EEG signal classification. CSP was first talked about by Koles and others. This method is used to pick out and tell apart features by changing the variance between two different motor imagery tasks or mental states. It changes EEG signals into a new space, where the variance for one class is made bigger and for the other class is made smaller. The goal is to find and use spatial filters to show important differences between classes. CSP is a step-by-step process that starts with figuring out the covariance matrices for each EEG signal class. The covariance between two variables X and Y can be calculated using a specific formula.
