SMP, on the other hand, can copy a wide range of motions, even difficult ones, just as well as AMP, and it doesn’t need reference data to train. SMP does better than SMILING and AMP-Frozen across all skills. AMP-Frozen tries to get rid of AMP’s need for data by using a pre-trained discriminator, but it doesn’t work well and leads to bad motion imitation. DeepMimic uses phase synchronization to lower tracking errors for some motions, but SMP still competes well. DeepMimic doesn’t do well with harder motions like spinkicks and cartwheels, especially when pose termination is turned off, which makes some runs settle for bad solutions. Our system is one of the first to use score-matching to create a reusable motion model that works as well as top adversarial imitation learning methods. In this section, we talk about how ensemble score-matching helps make training more stable and results better. We compare our ensemble score-matching method, which averages multiple SDS evaluations over set diffusion timesteps, to the usual method from past research, which uses SDS at one random timestep. The comparison looks at single-clip imitation tasks like Run, Cartwheel, and Backflip. Table 5 shows that using SDS at one timestep works okay for simple motions but has trouble with harder ones. For example, when trying to copy a backflip, policies trained with one SDS evaluation often end up standing still or falling backward instead of doing a full flip. Using multiple SDS evaluations over set timesteps gives a more reliable reward signal, which helps train policies for complex motions like acrobatics.
