MODOMA is a system set up for language learning experiments, and you can adjust how each experiment works by choosing certain settings. It covers everything about language learning, including the adult, the daughter, and the language processes. You can change settings for all these parts. Table 1 shows the settings for the current experiments. MODOMA can run different language learning processes, like the one Shakouri and others talked about in 2025. The first setting in Table 1 is about whether learning functional categories is turned on, and in all the experiments we're talking about, it is. The other settings decide important parts of the experiments. The setting for the mother agent controls how Delilah's speech is structured, deciding if it makes sentences or noun phrases. The training and test experiments in this paper change this setting in different ways. Also, the minimum data the daughter agent needs to process before learning functional and content categories changes in all experiments. These two settings set up the experiments. In the training experiments, learning functional and content categories starts after processing 1,000 noun phrases and 1,000 sentences, then 10,000 noun phrases and 10,000 sentences. This helps us figure out how many examples from Delilah are needed to notice this pattern. Plus, the setting for functional category learning decides the ratio used to turn differences between function and content words into clear language knowledge. The training sessions in this paper help find the right values for these settings, and the test experiments check these settings with new data from Delilah.
