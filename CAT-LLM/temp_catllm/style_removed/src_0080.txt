This setup makes it easy to reuse code and quickly try out new PEFT methods. Researchers can work on and test new methods on their own, and the system will automatically include them when it’s running. The way it loads things dynamically is especially useful for comparing different PEFT methods because it lets researchers test them all under the same conditions without having to repeat code or deal with version issues. For the SuperGLUE benchmark, we’ve got 7 datasets split into 4 tasks: natural language inference (NLI), which includes CB; question answering, which includes MultiRC, ReCoRD, BoolQ, and COPA; word sense disambiguation, which includes WiC; and coreference resolution, which includes WSC. We’ve also added datasets for text generation that are often used to test generative LLMs. These include 6 datasets for reasoning and understanding language, split into 3 tasks: question answering, which includes MMLU, PIQA, SIQA, and OBQA; natural language inference (NLI), which includes Hellaswag; and commonsense reasoning, which includes WinoGrande. There are also 3 datasets for solving math problems, split into 3 tasks: question answering, which includes MathQA; math word problems, which includes GSM8K; and simple math problems, which includes SVAMP. Lastly, there are 3 datasets for generating code, which are Conala, CodeAlpacaPy, and APPS. Some datasets might need small format changes to work with the input setup of PEFT-FACTORY. We explain more about this in Appendix B.2.
