These methods have some big problems in two main areas. First, when it comes to data, most studies still mostly use numbers and time-based data. They don’t really use text information in a deep way, so it’s hard to bring together different types of info like market feelings or how policies are explained. Second, the models themselves have issues. Neural networks are good at learning patterns, but they don’t really understand the deeper meaning behind situations. They can’t figure out cause-and-effect relationships between events and price changes, so they don’t work well in complicated market situations. Large language models (LLMs) have changed things by moving from just looking at past patterns to using memory. For example, FinMem built a financial memory system that stores summaries of news and events, and MagicNet made a layered memory system that organizes market data by time. But these approaches still have problems with how their memory systems are set up. They mostly store separate pieces of text or data without connecting them into a full story of how events unfold. They also rely on finding similar meanings, which makes it hard to handle more complicated situations. Overall, while these methods are moving from just looking at past patterns to using memory, there’s still a lot of work to do in understanding and using the right information. That’s what this paper focuses on. Now, about event-driven stock prediction: this approach tries to figure out the main reasons behind stock price changes. Before LLMs, this area developed from studying how events affect stock returns to automatically finding event signals in text using simple models like Bag-of-Words, topic models, and later deep learning tools like BERT. But all these methods have the same basic problem: they’re still focused on numbers. Even when they pull out event labels or sentiment scores, they just turn them into features for time-based models like LSTM or Transformer. These models end up learning patterns in the data instead of the actual logic of events. They lose a lot of important details during this process and can’t really think through things deeply.
