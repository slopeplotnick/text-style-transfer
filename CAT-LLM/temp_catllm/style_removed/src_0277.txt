We’re using advanced AI tools to improve our online strategies and system setup. On the strategy side, we’re using better relevance scores from the upgraded model to improve how we rank things, balancing everything using a method called Pareto optimization. On the system side, since the model performs well, we’re getting rid of or replacing old rule-based methods we used before. Combining these changes has shown big improvements. For example, studies like DeepSeek-R1 noticed the model can handle long reasoning steps and even has moments where it suddenly figures things out. We also looked at how the length of the model’s answers changed during training, and the results (shown in Fig 17) showed that as the model got better, its answers got shorter and eventually stayed consistent. This means long reasoning steps aren’t always needed for the model to get better; they just happen during training. We also found that different tasks need different reasoning lengths. For example, math and coding tasks need more detailed step-by-step reasoning, but for tasks like figuring out what a user wants and matching it to the right item, a simple and clear reasoning process works best. Extra reasoning doesn’t really help in those cases. For tasks that involve images, it’s easier to use models that already understand images (like VLMs) instead of adding extra steps like creating captions. We tested this idea by using a teacher model called Qwen2.5-VL-72B to handle two steps: generating knowledge and reasoning, and then applying rules.
