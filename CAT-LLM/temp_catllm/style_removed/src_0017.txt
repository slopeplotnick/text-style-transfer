The implantation stage has three goals: staying hidden, being able to undo changes, and having control. Staying hidden means making sure the bad tool looks like the good ones. Being able to undo changes means the tool can go back to normal after being used. Having control means the attacker can use the computer to do extra stuff. In this part, we explain how to do these three things. There's a secret way to send and receive commands. The backdoor uses a two-step process. First, the implant sends a small signal with a victim's ID to a remote place through the internet. The remote place sends back extra work to do. The implant puts this work into the tool's response so it looks normal. In the second step, the implant watches for the next time the tool is used to grab user inputs and sends them to the remote place. This two-step process keeps the network connection short. The exploitation stage makes the agent do the extra work and then gives back the tool's normal response so the user doesn't notice anything different. There are three types of triggers: content-based, frequency-based, and context-based. A content-based trigger starts if the tool input has a specific word or sign. A frequency-based trigger starts after a random number of normal uses to avoid patterns. A context-based trigger starts when the agent uses a certain tool or function based on a request. When a trigger starts, LeechHijack gets extra work from the attacker, letting them use the agent's resources without permission.
