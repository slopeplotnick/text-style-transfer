RAG has made big improvements in how large language models handle tasks that need a lot of knowledge. But most systems are focused on general topics or news, and they don't work as well for important things like helping farms deal with climate changes. Some recent studies have tried to use document retrieval and climate data for specific questions, but they still use basic methods that don't give detailed or checked answers for specific areas. There have been attempts to make geography-aware question answering in other fields, but they're not really made for thinking about climate. Plus, current studies treat climate data and research as separate things, missing a combined approach. CAIRNS is a process with four steps: first, it gets climate info from Elsevier and a climate data API; second, it makes answers using something called ScholarGuide Prompt; third, it checks the answers; and fourth, it evaluates them in a mixed way. To find the right documents, we made a retriever that uses both word matching and meaning-based retrieval. But just using this isn't enough because where something happens is really important for climate questions. So, we add a location similarity score to make sure the answers are relevant both in meaning and location. CAIRNS then uses a loop where it gets evidence, makes an answer, and checks if it's enough. If there's missing info, it creates new questions and goes back to find more info until the answer is good enough. The ScholarGuide Prompt is key to making answers in CAIRNS. It helps balance how easy the answer is to read with how factual it is. For climate questions, this prompt acts like a guide, telling the language model how to structure answers, use scientific reasoning, and give specific advice.
