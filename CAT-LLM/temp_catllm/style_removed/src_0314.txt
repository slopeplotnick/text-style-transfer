LLMs are being used to help fix problems in C programming assignments automatically. CFAULTS works with LLMs using a method where it spots the buggy parts of a C program and gives the LLM a version of the program with those broken parts taken out. Then, the LLM tries to fill in the missing pieces, and those fixes are tested to see if they work. If the fix doesn’t work, the LLM is given feedback from the tests to try again. This process helps LLMs fix more programs and make smaller changes compared to other methods that don’t use FBFL techniques or symbolic tools for fixing programs. Fault localisation methods are split into two types: spectrum-based (SBFL) and formula-based (FBFL). SBFL uses test results to guess which parts of the program might be broken, but it’s not always accurate because it doesn’t guarantee those parts are actually causing the problem. FBFL methods, on the other hand, are more precise. They treat fault localisation like a problem where you try to figure out the smallest set of broken components. For each test that fails, FBFL methods use a process to find the minimal diagnosis for that specific failure, then combine all the results into one explanation for why the program isn’t working.
