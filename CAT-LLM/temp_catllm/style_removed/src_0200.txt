Curriculum learning is a way to train models by starting with easy tasks and moving to harder ones. It was first talked about by Bengio and others in 2009 and is used a lot in developing large language models. New methods like Speed-RL and ones by Kim and Lee still use this approach, sorting tasks from simple to complex based on how hard they are. Another method, LBS3, trains models by starting with easy questions and moving to harder ones. But these ways don't really match good curriculum design because they use fixed difficulty levels instead of adjusting to how well the model is doing. Good curriculum learning should change based on how the model is improving. CAPO uses a system that looks at how well the model is doing and adjusts the training accordingly. It starts with positive feedback to set up stable behavior, then adds negative feedback later to help the model learn better. Unlike other methods that use fixed difficulty levels, CAPO changes as the model gets better, making early learning stable and later learning adaptable. CAPO is a new way to train models that uses feedback to build a curriculum that adapts as the model learns. It starts with learning from positive examples and then moves to learning from both positive and negative examples, similar to how people learn. This helps avoid problems that happen when mixing feedback too early. Tests show CAPO improves model performance compared to other methods across different tasks and model sizes. CAPO also works well in different areas, from math to tasks involving different types of data. By focusing on how the model is improving rather than just using fixed difficulty levels, CAPO helps create learning algorithms that are more flexible and inspired by how people think.
