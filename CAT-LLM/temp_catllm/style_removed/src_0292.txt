Getting a set number of clips makes it hard for the model to deal with questions that need different time lengths. Like, if you ask "Where did I leave my glasses?" you might just need a few seconds of video. But if you ask "What happened in the second half of the soccer match?" you need a lot more video. The usual way is to get clips of a set length because it's easier, but this misses how events in real life can be different lengths, so it's not very flexible. We came up with WorldMM to fix this. It's a new system that uses memory to keep track of text and video separately and has a smart way to pick the best type of memory and time length for each question. The text memory has two parts: episodic memory, which keeps track of different events over time, and semantic memory, which holds big-picture knowledge like relationships and habits, organized in knowledge graphs. The video memory splits a long video into short clips stored in a way that makes it easy to find when needed. The system picks the most relevant memory from different types and times, so it only gets the info needed for each question. This design stops the model from having to use unnecessary memory types when getting info for a question, which helps keep it focused. WorldMM can get info at different detail levels over the right time span by using several graphs that work at different time lengths, like seconds, minutes, and hours. When it picks episodic memory to get info, it looks through each memory to find useful info from all time levels. Then it checks all the collected info to see what should be used to answer the question. In the end, it uses both short and long video clips to get just the info needed to figure things out. Plus, the model gets info in several steps by picking memories and questions over and over, which lets it try different combinations and find more options.
