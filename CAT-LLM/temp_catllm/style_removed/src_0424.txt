We want to make a system that helps train policies to move in a natural way without needing the original data. This system should work for different tasks and policies without having to retrain it. To do this, we came up with Score-Matching Motion Priors (SMP), which helps train control policies to act naturally in various tasks. We start by training a model to understand the motion data without focusing on any specific task or policy. Once this model is trained, we use it to compare simulated motions with the behaviors in the original data. By using this learned SMP as a reward, we can train new policies to do different tasks with natural behaviors. The main idea here is to create a system that makes motion priors that can be used again and again for character animation by mixing reinforcement learning with score distillation. Our system makes high-quality motions that are as good as the best methods out there, and it improves how reusable and modular they are. SMP lets us ignore the original data when training policies. We show that you can make a motion prior from a model trained on big motion datasets without focusing on any task. This motion prior can then be changed into style-specific ones with prompts and guidance. Plus, we show that you can mix different style priors to create new styles that weren't in the original data.
