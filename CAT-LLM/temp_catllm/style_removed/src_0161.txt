Recently, technology for Large Language Models (LLMs) has gotten a lot better and is now being used in many areas like smart interactions and helping with scientific research. In healthcare, LLMs seem to be really useful for helping diagnose diseases and improving how diagnoses and treatments are handled. In Traditional Chinese Medicine (TCM), the main idea is called "Syndrome Differentiation and Treatment" (SDT). This means doctors look at a lot of different information to figure out what’s wrong and then come up with a treatment plan that’s tailored to the person, like treating the same illness differently depending on the situation. There are some TCM-focused LLMs, like Zhongjing and HuatuoGPT, but they’re still hard to use in real-life medical settings because the way TCM works is so complex and personalized. One big problem is that there aren’t any good ways to fully evaluate how well these models work in clinical decision-making, and there aren’t specific tools to measure how they reason through problems. Because of this, researchers and companies really need a dataset that can fairly and thoroughly test how well these models can be used in TCM. This kind of dataset would help improve the models, figure out how well they perform, and eventually make it possible to use them in real medical cases. But making a dataset like this is really hard because TCM is all about treating people as individuals, looking at the whole picture, and dealing with a lot of variety. For example, two people with the same illness might show different symptoms because of things like their body type, how their illness has progressed, or their lifestyle, which makes it harder to create a standard way to evaluate the models. TCM diagnosis is also a big-picture process that uses a lot of different methods to gather information, figure out what’s causing the problem, and decide on treatment, so the dataset would need to cover a lot of ground. Plus, patients often have more than one issue at the same time, and the different ways of diagnosing can make the evaluation results more subjective. All of this makes it really challenging to create a complete dataset to test how well TCM-focused LLMs work in real-life medical situations.
