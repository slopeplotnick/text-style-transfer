The robot checks how well things are going and how busy it is. It decides what to do based on how likely it is to succeed. It explains why it made that choice in a few sentences. It also looks at how busy things will be after making the decision and how sure it is about the choice (high, medium, or low confidence). It talks about what it had to give up to make the decision. The system uses two parts, Nodes 2 and 3, to make smart decisions. Node 2 makes prompts that fit the situation, and Node 3 uses these prompts to think things through. In Node 3, as shown in Figure 11, the system uses a method to think things through by calling the LLM. It uses two parts: a system prompt that guides the overall thinking and decision-making, and a user prompt that changes based on what's happening now. These prompts are put together to form the input for the model. The system prompt gives general guidance, and the user prompt gives specific details like how likely success is, how busy things are, and what stage things are at. The LLM client runs the call using the invoke() function, sending the combined prompt as a message. The LLM then gives a response in natural language, explaining its decision, how likely it is to succeed, and how confident it is. This response is checked and validated in the next step. The system takes the combined prompts from before, which include the fixed system prompt with the rules and the changing user prompt with specific details. These are put together into a message and sent to the LLM client to figure things out. While running, the model uses this input to give a natural-language explanation with a decision, reasons, expected success rate, and confidence level. This answer is the output of the node and is used in the next step to keep things clear and on track.
