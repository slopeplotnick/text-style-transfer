To systematically address this question, we deconstructed the task into two distinct components, as elucidated in Section 2. We decompose the relevance discrimination process into two stages: (1) Path Construction: establishing a connection between query requirements and specific product attributes to construct semantic pathways; (2) Path Following: utilizing these pathways to execute a comparative analysis of the product attributes against the query specifications. The model must undertake three primary tasks to effectively manage this process. First, it must comprehend domain-specific terminology and obscure details within the query through the application of knowledge. Subsequently, reasoning capabilities are employed to ascertain the true intent of the query and the requisite attributes of the products. As exemplified in Fig. 1(a), the model must initially rely on its knowledge base to ascertain that "morning C, evening A" denotes a regimen involving Vitamin C and retinol, while "for mom" signifies appropriateness for middle-aged women. Moreover, the model must integrate information from diverse modalities, such as textual and visual data, to establish a connection between the query and the product attributes. For instance, as depicted in Figure 1(b), the query specifies the attribute "yellow," which is absent from the textual description. Consequently, the model is required to analyze the product's image to ascertain the color attribute. Furthermore, the model must adhere to established rules to facilitate decision-making processes. As depicted in Fig. 1(c), when a query seeks "LV bags" and the item in question is a second-hand bag, the model cannot solely depend on feature matching. Instead, it must adhere to established rule definitions to ascertain the item's relevance to the query.
