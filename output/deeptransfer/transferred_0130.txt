All components of the system operate within a unified configuration framework, ensuring seamless interchangeability and full compatibility with the overall architecture. While each component can be configured individually, a centralized configuration mechanism, termed `ExperimentConfig`, is provided to enable convenient parameterization of all settings within a single, cohesive structure. The LLM component interfaces with any large language model to generate responses. Its base configuration supports parallel operations and monitors token utilization. Three distinct configurations are implemented: (1) APILLM facilitates interaction with models via APIs, supporting providers such as OpenAI and Anthropic. Listing 3 (L.1-5) illustrates the setup process using the DeepInfra API. (2) LocalLLM enables local deployment of models, leveraging the transformers library (Wolf et al., 2020). (3) VLLM integrates the v11m library for efficient high-throughput inference, demonstrating optimal performance with GPU utilization. The Predictor component defines the methodology for extracting predictions from the model's output. For classification tasks, it isolates the predicted category, whereas for mathematical reasoning tasks, it retrieves the final solution. The FirstOccurrencePredictor identifies the initial occurrence of a potential answer and extracts it, while the more robust MarkerBasedPredictor extracts predictions demarcated by specific tags. It also defines methodologies for prompt evaluation, ensuring that exhaustive testing of all prompts is avoided when unnecessary, thereby optimizing time and resource efficiency.
