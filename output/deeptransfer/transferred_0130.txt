All components within the system operate cohesively through a standardized configuration framework, ensuring seamless interchangeability and compatibility with the overarching architecture. While each component can be individually configured, a centralized configuration mechanism, referred to as *ExperimentConfig*, is provided to streamline parameter management through a unified interface. The LLM component provides an interface for generating responses from any large language model. Its base class supports parallelization and monitors token usage to ensure efficient operation. Three implementations are available: (1) APILLM, which facilitates interaction with models via APIs from vendors such as OpenAI and Anthropic, as illustrated in Listing 3 (L.1-5) using the DeepInfra API; (2) LocalLLM, which enables local model deployment using the Transformers library; and (3) VLLM, which integrates the v11m library to efficiently handle high-throughput inference and optimize GPU utilization. The Predictor component defines how task-specific outputs are extracted from the model's predictions. For classification tasks, it identifies the predicted category, whereas for mathematical reasoning tasks, it isolates the final computed solution. Two types of predictors are implemented: the FirstOccurrencePredictor, which extracts the first occurrence of a potential answer, and the more robust MarkerBasedPredictor, which identifies answers enclosed within predefined tags (e.g., <final_answer>65</final_answer>). For example, to calculate the total number of fish across all fishbowls, one would sequentially aggregate the quantities, such as adding 62 fish and 3 fish to arrive at a total of 65 fish. The Task component retains task-specific data and specifications, including criteria for evaluating prompts. It strategically omits exhaustive testing when unnecessary, thereby optimizing time and resource efficiency. This component is essential for ensuring reliable outcomes while minimizing resource expenditure. To address key challenges in natural language processing, we have implemented a set of tasks specifically designed for this purpose.
