FinMem[22] is a financial-domain memory system that implements a layered memory structure, encompassing short-term, mid-term, and long-term memory components to guide trading decisions. Similarly, MemP[5] is a general framework that abstracts trajectories into both step-by-step instructions and high-level strategies, thereby maintaining and utilizing procedural memory. MemGPT functions analogously to an operating system, managing hierarchical storage and interrupt handling to dynamically expand the effective context window of large language models. In contrast, Zep employs a long-term memory framework that incorporates temporal knowledge graphs to support the joint retrieval of historical relationships and dynamic contexts. To evaluate these systems, we adopt accuracy (ACC) and Matthews Correlation Coefficient (MCC) as metrics. ACC measures overall prediction correctness, while MCC provides a more reliable assessment for balanced datasets, particularly in stock prediction tasks where class distributions may be uneven. Evaluations conducted on four representative stocks demonstrate that our framework consistently outperforms all baseline models in both ACC and MCC metrics, as shown in Table 1. These findings underscore the robustness and efficacy of our approach. Moreover, the results reveal fundamental mismatches between baseline architectures and stock prediction requirements. Specifically, FinMem's isolated news storage lacks temporal event modeling, causing its retrieval mechanism to miss critical incremental information by failing to match evolving market contexts. Similarly, MemP's procedural abstraction discards semantic event details during trajectory compression, undermining financial scenario reasoning. Furthermore, MemGPT's general-purpose memory management lacks event-aware retrieval, frequently overlooking financially significant patterns during memory updates. Zep's graph-based approach fails to capture inter-event dependencies, missing decisive correlations in financial environments. To address these limitations, our framework introduces a new paradigm that converts unstructured news into structured temporal event knowledge. This approach systematically captures event logic and dependencies, establishing a traceable, reasoning-capable system that mirrors human analytical processes for more accurate and trustworthy financial predictions.
