GAIA requires robust tool use for multi-step real-world tasks; following prior work (Li et al., 2025b), we evaluate its performance on 103 text-only validation cases. XbenchDeepSearch, designed for professional-grade, in-depth information retrieval, is assessed using the WebSailor agent pipeline with the recommended decoding hyperparameters: temperature 0.6, top-p 0.95, and context length 32,768. To further explore the applicability of THINKMERGE in agentic deep-research settings, where models must interleave internal reasoning (e.g., <think>...</think>) with tool usage before generating answers, we evaluate three Tongyi-WebSailor agents—WebSailor-3B, WebSailor-7B, and WebSailor-32B—on four challenging web-based benchmarks: BrowseComp-en (Wei et al., 2025), BrowseComp-zh (Zhou et al., 2025), GAIA (Mialon et al., 2023), and XbenchDeepSearch (Chen et al., 2025a). The BrowseComp-en/zh benchmarks focus on retrieving elusive, multi-hop factual information in English and Chinese. Given the large size of BrowseComp-en (1,266 questions), we randomly sample 200 questions to create a test subset comparable in scale to BrowseComp-zh (289 questions). For computational efficiency, we replace the evaluator model Qwen2.5-72B with GPT-4.1 and substitute the Google Search API with the Serper API (Serper.dev) to reduce costs. Under this configuration, all baselines are re-evaluated, and the average results across five runs are reported in Table 8. A single response is generated by averaging next-token logits across traces at every step, with the selected token fed back into all contexts to guide subsequent decoding. THINKMERGE preserves compatibility with standard decoding controls and integrates seamlessly with modern inference frameworks (e.g., vLLM, SGLang), enabling deployment in both online serving environments and offline batch pipelines. Empirical results on closed-ended math and science questions show that the proposed method performs competitively with, and sometimes surpasses, majority voting. On open-ended reasoning tasks, such as LiveCodeBench, THINKMERGE improves overall pass@1 performance across multiple models. These findings demonstrate that token-level logit averaging effectively leverages additional parallel test-time computation, yielding significant performance improvements on both closed- and open-ended tasks without requiring further training.
