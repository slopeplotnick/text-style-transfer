Findings indicate that inefficiencies remain prevalent even in resolved instances, albeit to a lesser extent. In unresolved cases, trajectories frequently exhibit multiple localization or editing inefficiency patterns concurrently. However, while stronger models, such as Claude-4, demonstrate higher success rates, they also exhibit a greater prevalence of inefficiencies, likely attributable to their more extensive internal exploration processes. In recent years, there has been a notable increase in the deployment of Software Engineering (SWE) agents for automating issue resolution and executing software engineering tasks. These agents can be broadly categorized into two architectural paradigms: single-agent and multi-agent systems. Single-agent systems, exemplified by SWE-agent and OpenHands, employ a unified ReAct loop. In contrast, multi-agent systems, such as CodeR, Magis, and MASAI, utilize multiple specialized agents to perform distinct functions, including the retrieval of relevant code snippets, the creation and verification of reproduction scripts, the implementation of code modifications, and the validation of changes. GRAPHECTORY can be effectively applied to multi-agent systems by integrating the trajectories of various sub-agents into a singular comprehensive trajectory. Another perspective for classifying SWE-agents involves examining their tool usage. Certain agents, such as Agentless, operate independently of external tools, relying exclusively on prompting strategies. Conversely, other agents employ traditional retrieval mechanisms and embeddings to identify relevant files. Moreover, TRAE, CGM, and MarsCode Agent utilize code knowledge graphs and language server protocols to facilitate project comprehension and code entity retrieval. Without GRAPHECTORY, it would be an arduous task to compare and contrast these methodologies. The integration of GRAPHECTORY and LANGUTORY facilitates the alignment of these tools within the broader framework of the Localization phase. Since the release of Claude 3.5 Sonnet, SWE agents, such as SWE-agent and OpenHands, have increasingly adopted bash commands for code search and the 'str_replace editor' tool for file inspection and modification. Consequently, SWE-agent and OpenHands were selected as the primary SWE agents for the experimental framework employed in this study.
