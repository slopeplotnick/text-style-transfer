The efficiency gain primarily stems from the system's enhanced ability to generate task-specific prompts that incorporate only the current operational context, including system state, robot capabilities, workload conditions, and task phase guidance. This approach eliminates the need for 5,000-6,000 redundant example tokens in every prompt, which were previously unnecessary for task execution. The reduction in token usage is achieved through two complementary mechanisms: first, a targeted allocation scope that removes decomposition and code generation overhead, previously accounting for approximately 14,000 tokens per task; and second, dynamic prompt generation that replaces the concatenation of few-shot examples with structured contextual inputs, thereby optimizing token utilization. Consequently, this method reduces the prompt token count from 6,700 to 1,100. The system's performance in multi-robot task allocation was evaluated based on metrics such as task completion success rates, workload distribution efficiency, and adaptability to varying operational conditions. The evaluation was conducted across three distinct experimental configurations, wherein the robots possessed differing skill sets while the task sequence remained constant, consisting of 36 tasks. Each configuration emphasized distinct robotic proficiencies by modifying task-specific success rate matrices while preserving a consistent 36-task allocation sequence. This approach demonstrated the framework's capability to sustain robust performance metrics while ensuring equitable task distribution among robots—a critical consideration in construction environments where both operational efficiency and fairness in resource utilization are paramount. Notably, the Medium Excels configuration achieved the highest overall success rate (87.8%), attributed to the balanced capabilities of medium-skilled robots and their effective task allocation. However, the allocation strategy predominantly favored the balanced-generalist robot, which exhibited competitive proficiency across all task categories, resulting in a pronounced workload imbalance. In this configuration, feature-specific success rates were recorded as follows: 92.5% for careful tasks, 86.6% for dexterous tasks, and 85% for heavy tasks. While this approach achieved optimal performance outcomes, it simultaneously underscored the inherent trade-off between maximizing operational efficiency and maintaining equitable workload distribution.
