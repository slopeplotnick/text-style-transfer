The temporal phase classification, workload balance quantification, and phase-specific strategic frameworks are integrated into the workflow through Node 1 (Phase Detection), which serves as the initial reasoning checkpoint in the nine-node LTAA architecture. This node functions as the starting point for evaluating the system's state and computing the temporal context necessary for downstream reasoning stages. Within the LTAA framework, the Phase Detection Node assesses task progress and updates workload-related metrics. As shown in Figure 9a, this node receives four key state variables from the system: the number of completed and total tasks, the current workload distribution across robotic agents, and the ideal target workload allocation. These parameters collectively define the allocation context at each iteration of the process, facilitating informed decision-making and operational adjustments. Within this node, the framework computes the current progress ratio and uses it to determine the system's operational phase classification as early, middle, or late. Each phase represents a distinct decision context, guiding how subsequent reasoning nodes balance success rates and workload fairness. Subsequently, the node calculates a balance score to quantify how evenly tasks are currently distributed and assess imbalance severity based on deviation from the ideal workload. These metrics encapsulate both temporal progress and workload dynamics in a compact form. The node concludes by updating the system state with the derived parameters: allocation_phase, balance_score, imbalance_severity, and operational_mode, which are passed forward to the following node. This ensures that all downstream reasoning stages operate with up-to-date contextual awareness of progress and workload status. As illustrated in Figure 9a, this process forms a unidirectional flow where the Phase Detection Node transforms raw operational data into structured decision context for the subsequent reasoning phase. The phase-adaptive allocation strategy requires reliable LLM reasoning to make context-appropriate decisions. However, the inherent variability in LLM outputs may compromise their suitability for safety-critical construction applications. To address the generation inconsistencies identified during the implementation of the SMART-LLM framework, the authors developed a comprehensive validation framework that ensures reasoning quality through weighted multi-criteria assessment and structured feedback mechanisms.
