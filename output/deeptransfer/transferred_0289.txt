Prompt engineering is a technical methodology designed to optimize and control how pre-trained language models respond to input instructions. Specifically, we employed the technique of prompt chaining, which enhances the accuracy and reliability of processing outcomes by decomposing complex tasks into consecutive sub-tasks. In the context of story parsing, this approach involved dividing the task into four distinct components: extraction of entities, identification of events, formulation of a story outline, and determination of relationships. The outputs generated from each sub-task are subsequently utilized in the succeeding step, as illustrated in Figure 1.b. Prompt frameworks have been shown to optimize interactions with language models, ensuring the precise execution of instructions. In this study, we adopt the TIDD-EC prompt framework, which consists of five key components: task specification, comprehensive instructions, guidelines delineating permissible and impermissible actions, illustrative examples, and user-generated content. By clearly defining the task type and providing detailed execution guidelines, the TIDD-EC framework ensures the generation of more accurate and relevant responses. Furthermore, we experimented with four distinct prompting strategies and compared their performance in converting narratives into JSON format: Zero-shot prompting, where the task was articulated in natural language without specific examples; the TIDD-EC framework, which framed the task parameters; TIDD-EC + CoT, which built upon the second strategy by incorporating chain-of-thought reasoning; and TIDD-EC + prompt chaining, which divided the task into four distinct subtasks, each described using TIDD-EC, and linked these subtasks via prompt chaining.
