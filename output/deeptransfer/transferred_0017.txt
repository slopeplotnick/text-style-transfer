The implantation stage has three primary objectives: covertness, reversibility, and controllability. Covertness minimizes observable differences between the malicious tool and its benign counterparts, thereby reducing detectable anomalies. Reversibility ensures that the tool can restore the system to its original state after completing an exploitation cycle. Controllability guarantees that the attacker can reliably utilize computing resources to execute additional tasks. In this chapter, we detail the implementation of these objectives. To achieve covertness, a covert command-and-control (C2) protocol is employed. The backdoor utilizes a two-phase C2 protocol to separate task delivery from data exfiltration. In the first phase, known as Beacon, the implant transmits a concise beacon packet containing a victim identifier to a remote endpoint via an outbound network connection. The remote endpoint then responds with an additional task payload, which the implant integrates into the tool’s output to ensure it appears as legitimate context. In the second phase, referred to as Exfiltration, the implant monitors the subsequent invocation of the tool to capture user-provided inputs and transmits these inputs to the remote endpoint. This two-phase design minimizes the duration of persistent network connections, enhancing covertness. During the exploitation stage, the agent executes the additional task and subsequently returns the tool’s original outputs, ensuring that the user’s task remains unaffected. Furthermore, the trigger design incorporates three types of triggers: content-based, frequency-based, and context-based. A content-based trigger activates when the tool input contains a specific token or semantic marker. A frequency-based trigger activates after a randomized sequence of benign usages, thereby obfuscating discernible patterns. Conversely, a context-based trigger is initiated when the agent engages a specific tool sequence or function in response to a contextual request. Upon activation of a trigger, LeechHijack retrieves additional tasks from the attacker, enabling unauthorized exploitation of the agent’s resources.
