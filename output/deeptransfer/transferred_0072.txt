Formula-based fault localisation (FBFL) methods often suffer from limitations: some, like SNIPER, produce a large number of redundant diagnoses, while others, such as BugAssIST, fail to return a minimal set of fixes sufficient to repair the program. Recently, Graussam [65] proposed a model-based approach for fault localisation in ANSI C programs, introducing a well-defined fault model that accommodates complex language features, including pointers and arrays. This approach builds on CBMC encodings, performing the relaxation step at the CBMC level rather than directly within the code, as is done in our methodology. Moreover, it addresses multiple failing observations by formulating standard Model-Based Diagnosis (MBD) instances and solving them using Hierarchical Set Decomposition (HSD) [2], thereby guaranteeing minimal diagnoses for each failing test case. However, Graussam [65] applies an aggregation procedure after diagnosis enumeration, which may compromise the minimality of the final outcomes. For two main reasons, this tool was excluded from our evaluation: first, it requires manual annotations for the functions under analysis, which is impractical given the scale of our study (over 1500 programs); second, its applicability is restricted to integers and floats in C, rendering it unsuitable for the C-PACK-IPAs benchmark. Furthermore, Model-Based Diagnosis has been successfully applied across diverse domains, including Boolean circuits [4, 5, 8, 9, 10, 2, 64], C software [7, 11, 12, 66], knowledge bases [13, 14, 15], and spreadsheets [16, 17]. Complementary techniques, such as program slicing [67, 57, 68], have also emerged for software fault localisation. One syntactic approach [57] uses program slicing to enumerate all minimal sets of repairs for a given faulty program, while another [68] identifies the causes of faulty behaviour by analysing differences between successive software versions. This paper introduces a novel formula-based fault localisation technique for C programs and Boolean circuits, capable of handling multiple faults. By leveraging Model-Based Diagnosis (MBD) with multiple observations, CFAULTS consolidates all failing test cases into a single MaxSAT formula, ensuring consistency throughout the localisation process and eliminating redundant diagnoses.
