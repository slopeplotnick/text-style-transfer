This research not only advances the application of Large Language Models (LLMs) in financial forecasting but also introduces a novel framework for designing memory mechanisms in specialized domains. By constructing a domain-specific memory system, we effectively address the adaptation challenges of general frameworks in professional scenarios, thereby establishing a solid foundation for future research in this area. Our contributions align with the track's scope in three key aspects: (1) Structured Knowledge Extraction: We convert noisy web news into a temporally-structured event knowledge base, supporting the scalable creation of web-based structured knowledge. (2) Semantic-LLM Synergy: Our dual-layer memory system enhances the collaboration between structured knowledge and the reasoning capabilities of LLMs. (3) Practical Application: We demonstrate the practical value of our approach in financial prediction, improving the interpretability and utility of web news-based decision-making systems. Moreover, we address the essential challenge of deriving dynamic semantic knowledge from web corpora, fitting squarely within the track's focus. Memory mechanisms have become a critical component for enhancing the capacity of large language models to handle complex tasks, evolving from parametric internal storage to external memory systems. Parametric memory implicitly encodes knowledge within the model's weights, offering advantages in rapid access and persistent retention; however, it inherently suffers from poor interpretability and difficulties in selective updating. To overcome these limitations, researchers have developed external memory augmentation mechanisms. These approaches effectively compensate for LLMs' constraints in context length and knowledge integration capabilities by constructing sustainable, precisely accessible external knowledge systems. The development of external memory has demonstrated distinct phased characteristics: initially represented by retrieval-augmented generation (RAG), which stores unstructured text fragments in vector databases. While RAG partially addresses knowledge updating issues, it only achieves shallow semantic matching. As research deepens, the focus has gradually shifted from simple information storage to systematic memory management, giving rise to innovative architectures such as GraphRAG's knowledge graph-based structured memory, MemGPT's operating system-like memory management, and Zep systems that further integrate temporal knowledge engines to support the joint retrieval of historical relationships and dynamic contexts, significantly enhancing the reasoning capabilities and management efficiency of memory systems.
