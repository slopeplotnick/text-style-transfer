The AgentHarm public test dataset consists of 176 examples derived from 44 unique tasks across 8 categories, such as disinformation and fraud. Each task can be expanded using two modes: one provides a hint about the initial tool to be used, while the other offers detailed step-by-step instructions. Combining these modes results in four variations of each task description. In our experiments, we focus on the simplest subset to minimize costs and establish an upper bound on model capabilities, ensuring that capability is not the limiting factor and that context length is the primary determinant of performance (see Section A). AgentHarm employs both an automatic scoring system and evaluation by LLM judges (Zheng et al. 2023). Two metrics are assessed: (1) the Harm score, which is a rubric-based completion score ranging from 0 to 1 for harmful tasks, determined through manual implementation of rubrics, and (2) the Refusal rate, which represents the proportion of instances flagged as refusals by the LLM model. Further details are provided in Section B. We prioritize the Harm Score as the main metric and omit semantic judgment, assuming reliable evaluation of the simplest subset of tasks. For refusal judgments, we apply minor modifications to both the prompt and the underlying model, as detailed in Section E. To systematically examine the impact of context length within a controlled experimental framework, we utilize four distinct padding strategies: (1) *random padding*, which incorporates tokens randomly sampled from the tokenizer; (2) *non-relevant padding*, which uses coherent text extracted from fiction genres such as humor, mythology, science fiction, crime, and romance, unrelated to the task category; (3) *relevant padding*, which includes coherent text sourced from Wikipedia articles directly related to the task category; and (4) *multi-task padding*, which samples task descriptions from the validation dataset. These padding strategies enable the isolation of specific factors: random padding ensures reproducibility, non-relevant and relevant padding introduce coherent in-distribution text, and multi-task padding assesses the model's robustness to semantically confounding contexts. Additional details can be found in Sections F and G.
