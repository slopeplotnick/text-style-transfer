The MODOMA system serves as a laboratory model for conducting language acquisition experiments and is fully parametrized, enabling users to control the properties of each experiment by selecting predefined settings. Importantly, the system comprehensively incorporates all aspects of language acquisition, including the adult, the daughter, and the associated language procedures, with parameters applicable to each component. Table 1 provides an overview of the parameter settings utilized in the current experiments. The MODOMA system is designed to implement various language acquisition processes, including those described by Shakouri et al. (2025). The first parameter in Table 1, Acquisition of functional categories, specifies whether this feature is activated. Notably, in all experiments discussed in this paper, this parameter is consistently enabled. The remaining parameters define key aspects of the experimental design. For instance, the parameter associated with the mother agent determines the structure of Delilah's utterances, specifying whether sentences or noun phrases are generated. The training and test experiments presented in this paper systematically vary this parameter. Similarly, the minimum amount of data processed by the daughter agent before acquiring functional and content categories is adjusted across all experimental conditions. Together, these parameters establish the experimental configuration. Specifically, in the training experiments, the acquisition of functional and content categories is triggered after processing 1,000 noun phrases (NPs) and 1,000 sentences, subsequently increasing to 10,000 noun phrases (NPs) and 10,000 sentences. This allows us to determine the number of input exemplars generated by Delilah required to detect this statistical pattern. Furthermore, the parameter for functional category acquisition specifies the type-token ratio used to transform distributional differences between function and content words into explicit linguistic knowledge. The training sessions discussed in this paper are used to identify appropriate values for these parameters, while the test experiments validate the selected configurations using novel datasets generated by Delilah.
