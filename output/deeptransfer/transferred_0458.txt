In analyzing images, it is crucial to account for both occluded joints and the global context, including cues from inter-joint, inter-hand, hand-object, and scene relationships. Convolutional neural networks (CNNs) are widely used as backbone architectures in 3D hand pose estimation (HPE), with ResNet-50 being particularly popular due to its favorable balance between accuracy and inference speed. However, these CNN backbones rely on local convolution operations, which limit their ability to effectively capture global contextual information. To address this limitation, recent studies have explored the use of vision transformers (ViTs) for hand mesh reconstruction. While ViTs demonstrate promise in feature extraction, their substantial computational complexity often becomes a bottleneck in practical applications. This highlights significant opportunities for improving backbone architectures to achieve more efficient and effective feature learning for hand poses. Recently, the Mamba model, originally developed for natural language processing, has gained attention for its ability to selectively focus on salient input signals, enabling it to efficiently capture global context from long sequences. Building on this foundation, several studies have extended Mamba to image-based tasks. For instance, VisionMamba introduced the Vim block, which utilizes a 2D bidirectional scan for spatially-aware sequence modeling, while VMamba proposed the VSS block, incorporating multiple scanning paths to enhance feature extraction. However, these methods rely on a fixed grid structure, as shown in Figure 1(a), which inherently limits their ability to model the complex and dynamic variations of hand poses in 3D scenarios. To overcome this limitation, we propose a novel and efficient backbone, Deformable Mamba (DF-Mamba), which leverages deformable state space modeling (DSSM) to enhance visual feature extraction in 3D HPE. The core innovation of DF-Mamba lies in its ability to dynamically model both local features and global context through flexible state spaces. Specifically, DSSM blocks aggregate local features along deformable paths and selectively retain critical information to represent the global context. The scanning path is dynamically adjusted using deformable point sampling, which employs local anchors and learnable offsets based on the input features, as illustrated in Figure 1(b).
