Building on these innovations, this research introduces Lang2Logic, a novel framework designed to bridge the gap between natural language and computational logic. Lang2Logic transforms natural language inputs into Conjunctive Normal Form (CNF), a required format for logical reasoning tasks, thereby facilitating the translation of human-readable statements into machine-processable logical representations. The framework incorporates symbolic computation libraries and a custom grammar-based parsing approach to ensure accurate transformation from natural language to CNF. Consequently, this structured pipeline enables an end-to-end conversion from unstructured natural language to a canonical Satisfiability (SAT) problem representation, making SAT solvers accessible for real-world problems requiring human-readable inputs. Lang2Logic aims to bridge the divide between natural language understanding and computational logic by converting English text into CNF, which is essential for SAT solvers that operate on CNF representations. The framework consists of three core components: (1) Natural Language to Logical Expression, (2) Logical Expression to CNF Conversion, and (3) CNF Simplification. Each component is critical in ensuring an accurate and efficient transformation from natural language to a machine-readable CNF representation. The first stage utilizes the ChatGPT o1-mini model API to translate natural language input into a logical expression. The prompt for the o1-mini model was carefully designed to check and recognize repeated variables across different clauses, output fixed logical expressions in a structured format compatible with downstream processing, and ensure that the output aligns with the required input format for the Sympy converter. Using the ChatGPT API removes the need for hard-coded grammar definitions, thereby simplifying the conversion process. However, this approach has limitations, such as higher costs and potential instability in performance as the input size increases. To mitigate these issues, the Natural Language Toolkit (NLTK) was employed to preprocess the input effectively. By using NLTK's Punkt tokenizer, the input text is split into individual sentences, ensuring that the o1-mini model processes each sentence independently. This prevents errors such as sentence merging or skipping during translation. By working sentence-by-sentence, the o1-mini model can produce more accurate logical expressions.
