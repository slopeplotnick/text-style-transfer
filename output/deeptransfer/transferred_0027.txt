For GraphMatch, we observe that the combination of random and hard negatives is essential for achieving optimal performance. Notably, GraphMatch versions trained solely with random negatives exhibit performance comparable to TextMatch-small. To further analyze the impact of node features, we conduct an ablation study: the no-feat configuration uses only TextMatch node embeddings, the no-text configuration employs numerical node features without text embeddings, and the full configuration combines TextMatch node embeddings with numerical node features. Among these, GraphMatch-full, trained with adversarial negatives, achieves the best performance, while GraphMatch-no-feat performs comparably to TextMatch-large, despite being a significantly smaller model. Moreover, the inclusion of textual context proves critical for accurate predictions, as evidenced by the reduced accuracy of GraphMatch-no-text. 

The importance of temporally accurate sampling is also evident. Sampling point-in-time correct subgraphs and node features is necessary for training a model that generalizes effectively to unseen nodes. To verify this, we train GraphMatch under two distinct setups. The no-temporal-nodes configuration excludes temporally relevant node features during training but consistently uses the most recent feature version available in the training dataset. Similarly, the no-temporal-graph configuration does not sample temporally specific subgraphs but instead accesses all graph edges during training. As shown in Table 2, these approaches lead to poor generalization to the evaluation set, reflected in significantly lower NDCG@10 scores.
