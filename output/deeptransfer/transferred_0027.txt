For GraphMatch, the integration of random and hard negatives is identified as essential for achieving optimal performance. Versions of GraphMatch trained exclusively with random negatives perform comparably to TextMatch-small. We conducted an ablation study on the node features utilized by GraphMatch: the "no-feat" configuration relies solely on TextMatch node embeddings, the "no-text" configuration employs numerical node features without incorporating text embeddings, and the "full" configuration combines TextMatch node embeddings with numerical node features. Notably, GraphMatch-full, trained with adversarial negatives, demonstrates superior performance, whereas GraphMatch-no-feat achieves results comparable to TextMatch-large, despite its significantly smaller model size. This highlights that textual context is crucial for accurate predictions, as evidenced by the low accuracy of GraphMatch-no-text. Furthermore, the temporal accuracy of data sampling is of paramount importance. Sampling temporally appropriate subgraphs and node features is essential for training a model that effectively generalizes to novel nodes. To ascertain this, GraphMatch was trained under two distinct configurations. The "no-temporal-nodes" configuration does not incorporate temporally specific node features during the training phase but consistently utilizes the most recent feature version available within the training dataset. In contrast, the "no-temporal-graph" variant does not sample temporally relevant subgraphs but instead has access to the entirety of graph edges during training.
