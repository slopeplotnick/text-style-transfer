Programmatic Editing. Leveraging the python-pptx library, PowerPoint slides can be programmatically modified through code generation, a method extensively employed in prior research [9, 20, 25, 44, 45]. This approach is particularly advantageous for automating repetitive, well-defined, and content-centric tasks, such as performing batch find-and-replace operations across multiple slides or facilitating text translation. However, it lacks the fine-grained control required for complex structural modifications, such as altering slide masters, themes, or specific layout geometries. Direct XML Editing. To overcome the limitations of the programmatic method in structural and visual editing scenarios, PPTPilot has been developed to interpret and modify the raw XML files of the slides. This method provides the precision required for structured contexts, as it allows for the repositioning of elements to specific locations. Given that XML encapsulates most of the information pertinent to a PowerPoint presentation, this approach offers a unified interface well-aligned with existing tools for PowerPoint editing. Nevertheless, the long context and strict format requirements of XML make it challenging to perform precise edits, especially when modifications span a large number of slides. In such cases, the programmatic approach is significantly more reliable. Skill Routing. To determine the most appropriate editing method for a specific user query, a decision-making tool evaluates the user's request alongside the presentation's configuration, encompassing visual and textual elements. Based on this analysis, it routes the task to either the programmatic path or the direct XML editing path. Self-correction with Reflection.
