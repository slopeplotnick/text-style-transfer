The dataset contains a total of 81 questions, each addressing a health issue and a potential treatment. These issues span 50 disease and condition categories, including "Cancer," "Low back pain in adults," and "AIDS," as well as a general well-being category labeled "Other," which encompasses topics such as weight management. Figure 2 highlights 10 example categories most frequently addressed by the health questions. The full list of questions and their corresponding categories is provided in Appendix Table A4. To explore how language models handle real-world biomedical knowledge conflicts, we developed five distinct prompt templates to evaluate their performance across various question-answering scenarios. As shown in Table 2, for each annotated instance in the HEALTHCONTRADICT dataset, we generate five question prompts using these predefined templates: Question: { Question } Question: { Question } Question: { Question } Context: { Correct Document } Question: { Question } Context: { Incorrect Document }. Our selection of baseline models was guided by two main objectives: (i) to assess whether fine-tuning within the biomedical domain improves model performance, and (ii) to determine whether increasing model size enhances performance. Additionally, we selected language models with extended context lengths to process longer documents. Details of the selected models are presented in Table 3. Each biomedical model was derived by fine-tuning the general-domain model listed in the same row. The term "Instruct" refers to models fine-tuned to follow user instructions (i.e., instruction-tuned). In this study, we do not perform any fine-tuning; instead, we conduct zero-shot inference for the selected baseline models. To ensure applicability in resource-constrained healthcare settings, we evaluate open-source language models ranging from 1 billion to 8 billion parameters. As illustrated in Table 4, the performance differences among larger language models (7-8B) are minimal. However, the fine-tuned biomedical model, MEDITRON3-QWEN2.5-7B, underperforms compared to QWEN2.5-7B. These state-of-the-art evaluation benchmarks exhibit limitations in distinguishing differences in model capabilities, as they primarily assess a model's parametric knowledge.
