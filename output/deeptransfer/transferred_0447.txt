The model loader initializes the PEFT model through the init_adapter method. From this point, the processes of loading, training, and saving the model are delegated to the PEFT provider libraries and the LLaMA-Factory framework. However, unlike LLaMA-Factory, PEFT-FACTORY employs a dynamic and flexible mechanism for loading custom PEFT methods, thereby enhancing its extensibility and modularity. This design allows researchers and practitioners to seamlessly integrate custom PEFT methods without requiring modifications to the core codebase of PEFT-FACTORY. To demonstrate the functionality of our Custom PEFT Interface, we replicated two PEFT methods that are not included in any conventional PEFT framework, namely BitFit (Ben Zaken et al., 2022) and SVFT (Lingam et al., 2024). During the dynamic loading process, the peftloader module automatically identifies and loads PEFT methods from a well-organized directory structure. Each custom PEFT method resides in its own subdirectory, which contains two essential components: a config.py file defining a subclass of PeftConfig and a model.py file implementing a subclass of BaseTuner. Before registration, the loader validates each implementation by verifying the presence of required attributes, such as peft_type for configurations and prefix for model classes. It then dynamically loads the config and model subclasses, registering them via the register_peft_method function, which integrates the config and model into the constants of the Hugging Face PEFT library. This process is further detailed in Algorithm 1 in Appendix B.1. After loading, the custom PEFT method is managed in the same way as standard methods, as described in Section 3.1. To add a new method, it is necessary to follow the directory structure within the PEFT methods directory, which can be specified by the environment variable PEFT_DIR, with ./peft as the default directory, to ensure consistency in organizational structure and class inheritance. Further details and example method templates are provided in Appendix C and the PEFT-FACTORY documentation.
