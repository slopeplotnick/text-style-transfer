In this study, several classical machine learning classifiers were employed to analyze EEG data, focusing on classifying motor imagery tasks. The classification process began with a combination of feature extraction methods and preprocessing techniques, followed by the application of different classification algorithms. We utilized logistic regression with elastic-net regularization, which combines L1 and L2 penalties. This regularization is effective for handling sparse data and preventing overfitting by balancing these penalties. The saga solver was chosen for optimization due to its suitability for large datasets. To handle features on different scales, the intercept scaling was set to 1000, and a random state of 42 was applied for reproducibility. Additionally, a random forest classifier was implemented to classify EEG signals, leveraging an ensemble of decision trees. Random forest builds multiple decision trees and aggregates their predictions to improve accuracy and reduce overfitting, particularly effective at handling non-linear interactions between features. This algorithm was less prone to overfitting compared to individual decision trees. Moreover, both linear support vector machine (SVM) and radial basis function (RBF) kernel SVM were utilized for classification. The linear SVM was used to separate linearly separable data, while the RBF kernel SVM was applied to non-linearly separable data by mapping the features into a higher-dimensional space to capture complex relationships. Linear Discriminant Analysis (LDA) was also used as a classification method, maximizing the ratio of between-class variance to within-class variance, making it a powerful tool for linearly separable datasets. Furthermore, we explored a wide range of multilayer perceptrons (MLPs) with different architectures to classify EEG data. The MLP configurations included various numbers of hidden layers and neurons. Specific architectures ranged from basic MLPs with a single hidden layer to more complex models with three hidden layers, such as configurations of (10, 30, 10) or (20,) neurons, using ReLU or logistic activation functions. These MLPs were trained using stochastic gradient descent (SGD) solvers with constant learning rates or adam solvers, which were tuned to manage adaptive learning rates. L2 regularization was incorporated through the alpha parameter to prevent overfitting, with different alpha values tested to control the amount of regularization applied to the model. A constant learning rate was used in several MLP configurations to ensure steady convergence during training. Both SGD and adam solvers were fine-tuned to optimize performance across various feature extraction methods. For reproducibility and traceability, each unique architecture was indexed (MLP_1-MLP_17) and used consistently across all pipeline combinations.
