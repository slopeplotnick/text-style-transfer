2.3.1.3. Shared Strategy Analysis. The final step of the Phase Flow Analyses, as outlined in Algorithm 3, involves extracting shared strategic subsequences for an agent across different tasks, achieved by executing actions to solve various problems. Initially, Algorithm 3 processes a collection of LANGUTORY instances to compute their corresponding phase transition sequences (lines 1-3). Subsequently, the Generalized Sequential Pattern (GSP) algorithm [43] is employed to identify the longest common subsequences within these phase transition sequences (line 4). In the next step, the inception points of the identified common pattern are determined for each LANGUTORY instance (line 7), allowing for the calculation of phase lengths through run-length encoding (lines 8-10). To address variations in phase lengths, Algorithm 3 selects the minimum run-length across all LANGUTORY instances (line 11) to adjust the common strategy pattern accordingly (line 12). 2.3.2 Pattern Detection. GRAPHECTORY and LANGUTORY are robust structures that enhance the exploration of both known and unknown common patterns. Phase Flow Analysis, particularly Shared Strategy Analysis, highlights the utility of these structures in uncovering unknown common patterns. Moreover, Pattern Detection Analysis complements this by facilitating the search for known patterns within GRAPHECTORY or LANGUTORY structures of agents. A significant application of pattern detection is identifying known failure modes or suspected strategic inefficiencies in GRAPHECTORY. As elaborated in later sections (§3.4), this approach enables a systematic and large-scale analysis of programming agents' failure modes. Researchers can sample a relatively small number of failures, manually investigate them to identify a list of (anti-)patterns, and then systematically search for these patterns across other executions without manual intervention. Thus, GRAPHECTORY and LANGUTORY prove instrumental in enabling systematic analysis of agentic programming systems, addressing research inquiries regarding the operational dynamics of agents.
