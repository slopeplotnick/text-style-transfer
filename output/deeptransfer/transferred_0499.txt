In this section, we illustrate the features of our interface using a use case scenario titled "Picture Composition." This feature provides users with clear information, such as the number of entities and events, as well as the types of relationships, offering a comprehensive overview to guide the creation process. Figure 5.a illustrates a diagram for picture composition, while Figure 5.b depicts the process by which P4 creates a story using TaleFrame. P4 begins by placing the event "Jack shoves Ryan," which represents the first grid in the diagram, onto the canvas (Figure 6.f). Next, P4 attaches the two entities involved in this event to the designated box (Figure 6.g). Then, P4 connects the two entities (Figure 6.h1), clicks on the connection line, and edits the relationship attributes (Figure 6.e), such as emotion_type, action_type, relationship_strength, and relationship evolution. The "action_direction" attribute of the relationship is represented by the "connect node," which defaults to the starting entity and ending entity (e.g., "from Jack to Ryan"). However, for the event "confront each other" in the second grid, where the action is mutual, a toggle labeled "is bidirectional" is provided. When activated, this toggle automatically sets the action_direction to "bidirectional." By repeating this process, P4 completes the remaining three grids, linking the four event boxes to finalize the entire story framework (Figure 6.h2). Finally, P4 clicks the "Modify Story" button, edits the title and description, and assigns the four events to the appropriate stages of the story. The story is then evaluated on seven dimensions according to the same set of criteria (Figure 6.1), and a comprehensive suggestion is generated based on the feedback (Figure 6.m). Following this suggestion, P4 modifies aspects with lower scores, such as adding relationships to certain events. Afterward, P4 clicks the "Regenerate" button to produce a revised version. Finally, P4 clicks the "Export" button to obtain the completed story, the framework diagram, and the JSON file.
