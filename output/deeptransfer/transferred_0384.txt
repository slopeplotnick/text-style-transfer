We propose SR-GRPO, which leverages stable rank as a dense reward signal in reinforcement learning, thereby eliminating the need for preference datasets or external verification mechanisms. We demonstrate that SR-GRPO enhances reasoning performance across diverse benchmarks, thus establishing intrinsic geometric signals as a viable foundation for aligning language models. Beyond its application in reinforcement learning, we further show that stable rank serves as a robust zero-shot reward proxy for evaluating language model outputs and integrates seamlessly into best-of-N decoding frameworks. Specifically, we propose stable rank (Rudelson & Vershynin, 2007) as an unsupervised quality signal derived from language model representations. In this section, we define the metric, elucidate its geometric motivation, and validate its effectiveness as a reward proxy. The theoretical foundation for this approach stems from two key areas. First, the softmax bottleneck (Yang et al., 2018; Godey et al., 2024) suggests that expressive language modeling requires high-rank representations. Second, representation collapse is a well-documented phenomenon associated with degraded generation quality (Gao et al., 2019). Stable rank directly measures effective dimensionality, making it a compelling metric for assessing model quality. This relationship is further substantiated through empirical experiments and correlation analyses, as detailed in Section 5. To evaluate stable rank as a zero-shot proxy for human preference, we test its ability to predict the preferred response within a given pair. This evaluation examines whether stable rank can function as a reliable reward signal in the absence of model-specific training. For this analysis, we utilize RewardBench (Lambert et al., 2025), a comprehensive benchmark comprising 2,985 preference pairs across five distinct categories: Chat, Chat-Hard, Safety, Code, and Math. For each pair, we compute the stable rank for both responses and designate the response with the higher stable rank as the preferred one. We compare this approach against three baseline methods: (1) Pointwise Scoring (Point.) (Kim et al., 2024), which involves prompting the language model to assign a score to each response on a scale from 1 to 5; (2) Pairwise Comparison (Pair.) (Kim et al., 2024), which entails prompting the language model to directly compare two responses; and (3) IPO (Garg et al., 2025), which utilizes implicit preference scores derived from Yes/No token probabilities. We evaluate five models: Qwen2.5-1.5B-Instruct (Yang et al., 2024), Qwen3-0.6B (Yang et al., 2025), Qwen3-8B (Yang et al., 2025), Llama-3.1-8B-Instruct (Dubey et al., 2024), and Phi-3.5-mini-Instruct (Abdin et al., 2024). To compute stable rank, inputs are formatted as prompt-response pairs using the native chat template of each model, and final-layer outputs are subsequently extracted.
