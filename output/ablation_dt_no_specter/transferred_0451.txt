Using a structured, ontology-guided methodology, we describe both the original and stylized images as structured knowledge graphs. Subsequently, we compare the style-induced elements from each image with those characteristic of the Ghibli aesthetic. This comparison allows us to assess whether the modifications introduced during generation align with the visual semantics of the original films. When alignment is observed, we trace these stylistic elements to specific source films within the Ghibli corpus, providing evidence that the model has effectively internalized stylistic patterns from these works. More broadly, this analysis validates the system's ability to capture the core visual attributes of the Ghibli aesthetic. To extract semantic information from the images, we employ a multimodal tool integrating both textual and visual modalities. This process is guided by a domain-specific ontology designed to emphasize stylistic characteristics such as texture, color, mood, lighting, and compositional patterns.
