Building on these innovations, this study introduces Lang2Logic, an innovative framework designed to bridge the gap between natural language and computational logic. Lang2Logic transforms natural language inputs into Conjunctive Normal Form (CNF), a standardized format essential for logical reasoning tasks, thereby facilitating the translation of human-readable statements into machine-processable logical representations. The framework incorporates specialized computational tools and a proprietary methodology to ensure accurate transformation from natural language to CNF. This structured pipeline enables the conversion of natural language into a satisfiability (SAT) problem, a type of logical problem amenable to computational resolution, thus enhancing the applicability of SAT solvers to real-world scenarios. Lang2Logic consists of three core components: (1) Natural Language to Logical Expression, (2) Logical Expression to CNF Conversion, and (3) CNF Simplification. Each component is critical in ensuring an accurate and efficient transformation from natural language to a machine-readable CNF representation. The first stage utilizes the ChatGPT o1-mini model API to translate natural language input into a logical expression. The configuration of the o1-mini model was meticulously designed to identify recurring elements, generate logical expressions in a structured manner compatible with auxiliary systems, and ensure adherence to the input format required by the Sympy converter. Using the ChatGPT API eliminates the need for manually defined grammar rules, thereby streamlining the conversion process. However, this approach has limitations, such as increased computational costs and potential performance instability when processing larger inputs. To address these challenges, the Natural Language Toolkit (NLTK) is employed to preprocess the input data effectively. By using NLTK's Punkt tokenizer, the input text is segmented into discrete sentences, enabling the o1-mini model to process each sentence independently. This approach mitigates errors such as the conflation or omission of sentences, thereby enhancing the model's ability to generate precise logical representations.
