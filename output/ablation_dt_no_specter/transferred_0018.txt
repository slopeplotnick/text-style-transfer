2.3.1.3. Shared Strategy Analysis. The final step of the Phase Flow Analyses, outlined in Algorithm 3, focuses on extracting shared strategic subsequences employed by an agent across various tasks. This is achieved by analyzing the agent's actions in solving different problems. Algorithm 3 begins by processing a list of LANGUTORY instances to compute their phase transition sequences (lines 1-3). Subsequently, the Generalized Sequential Pattern (GSP) algorithm [43] is applied to identify the longest common subsequences across these phase transition sequences (line 4). Next, the inception of the identified common pattern is located within each LANGUTORY instance (line 7), enabling the determination of phase lengths using run-length encoding (lines 8-10). To address variations in phase lengths, Algorithm 3 selects the minimum run-length across all LANGUTORY instances (line 11) and adjusts the shared strategic pattern accordingly (line 12). 2.3.2 Pattern Detection. GRAPHECTORY and LANGUTORY provide robust structures for uncovering both known and unknown common patterns. While Phase Flow Analysis, particularly Shared Strategy Analysis, excels at identifying previously unknown patterns, Pattern Detection Analysis complements this by facilitating the search for known patterns within GRAPHECTORY or LANGUTORY. A key application of pattern detection is identifying known failure modes or inefficiencies within GRAPHECTORY. As discussed later (§3.4), this approach enables a systematic and scalable analysis of programming agents' failure modes. Researchers can examine a small subset of failures, identify patterns or anti-patterns within the sampled data, and subsequently automate the detection of these patterns across other executions. By leveraging GRAPHECTORY and LANGUTORY, researchers can systematically address key questions about the operational dynamics of programming agents.
