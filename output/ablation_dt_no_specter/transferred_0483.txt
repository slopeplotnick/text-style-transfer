To evaluate the feasibility of LLM-driven reasoning in addressing MRTA problems, we initially replicated the SMART-LLM framework (Kannan et al. 2024) as a baseline feasibility study. This replication was instrumental in identifying key challenges in LLM-based coordination, which informed the development of our enhanced framework. The evaluation utilized the SMART-LLM benchmark dataset, which comprises 36 tasks categorized into four complexity levels: Elemental (single-action tasks), Simple (multiple objects with homogeneous robots), Compound (heterogeneous robots with specialized skills), and Complex (requiring team formation and collaborative execution). These tasks were executed within the AI2-THOR simulation environment. For the LLM configuration, Claude 4 Sonnet was employed as the reasoning engine, with the temperature parameter set to 0.0 to ensure deterministic outputs and reproducible allocation decisions. Performance was assessed using the SMART-LLM methodology, which evaluates five metrics: Success Rate (SR), Task Completion Rate (TCR), Goal Condition Recall (GCR), Executability (EXE), and Robot Utilization (RU). Collectively, these metrics measure task completion accuracy and the efficiency of multi-robot coordination. However, during the SMART-LLM replication, validation inconsistencies and reliability issues with LLM outputs were identified. To address these challenges, we developed and evaluated the Self Corrective-Agent Architecture, which demonstrated that structured validation and hierarchical retry mechanisms can effectively resolve these issues. This framework introduced multi-stage validation processes with hierarchical retry mechanisms. Key parameters included a maximum of three local retries per agent, validation checkpoints at each stage (task decomposition, allocation, code generation), and structured feedback loops to enable iterative improvement.
