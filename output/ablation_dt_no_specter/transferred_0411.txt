The system exhibits enhanced performance by generating task-specific prompts tailored to the operational context, including factors such as system state, robot capabilities, workload distribution, and task phase. Consequently, this approach eliminates the need to embed an additional 5,000–6,000 example tokens in each prompt, which were previously redundant for task execution. Token efficiency is achieved through two key mechanisms. First, by focusing exclusively on task-relevant information, the system avoids extraneous processes such as task decomposition or supplementary code generation, which previously accounted for approximately 14,000 tokens per task. Second, example tokens are replaced with structured context provision, reducing the token count in prompts from 6,700 to 1,100. The framework’s efficacy in multi-robot task allocation was evaluated using metrics such as task completion success rates, workload distribution equity, and adaptability to varying operational conditions. This evaluation was conducted across three distinct configurations, wherein robots possessed differing capabilities while the task sequence remained constant, comprising 36 tasks. Each configuration emphasized specific robotic proficiencies by adjusting the probability of task success for individual robots. The results highlighted the framework’s ability to maintain robust performance while ensuring equitable task distribution, a critical consideration in domains such as construction, where operational efficiency and fairness in resource allocation are paramount. Notably, the Medium Excels configuration achieved the highest overall success rate (87.8%), leveraging the balanced capabilities of medium-skilled robots to optimize task execution. In this configuration, the allocation strategy predominantly favored the robot proficient in executing a diverse range of tasks, leading to a disparity in workload distribution. Success rates for specific task categories were 92.5% for precision-oriented tasks, 86.6% for tasks requiring dexterity, and 85% for tasks involving substantial weight. While this configuration yielded optimal overall performance, it underscored the potential for performance-centric strategies to result in imbalanced workload allocation.
