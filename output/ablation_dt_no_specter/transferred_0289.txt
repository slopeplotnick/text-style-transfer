Prompt engineering is a technical methodology designed to optimize and regulate how pre-trained language models respond to input instructions. Specifically, we employed prompt chaining, which enhances the model's capacity to process complex tasks by breaking them down into manageable sub-tasks. In the context of story parsing, this approach was applied by dividing the task into four distinct sub-tasks: extraction of entities, extraction of events, formulation of a story outline, and identification of relationships. The outcomes from each sub-task are subsequently utilized in the succeeding sub-task. Prompt frameworks are instrumental in ensuring models adhere to instructions with precision. In this study, we adopt the TIDD-EC prompt framework, which consists of five key components: task type, detailed instructions, dos and don'ts, examples, and user content. This framework is designed to enhance the accuracy and relevance of the model's responses. Table III presents the prompts used during the "Entity Extraction" task based on the TIDD-EC framework. Furthermore, we explored four distinct prompting strategies and evaluated their efficacy in converting narratives into JSON format: Zero-shot prompting, where the task was articulated in natural language without specific examples; implementation of the TIDD-EC framework to systematically configure the task; TIDD-EC + CoT, which extends the second strategy by integrating chain-of-thought (CoT) reasoning; and TIDD-EC + prompt chaining, which decomposes the parsing task into four distinct subtasks, each framed using the TIDD-EC framework, and sequentially connects these subtasks through prompt chaining.
