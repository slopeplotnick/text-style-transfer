Figure 1 illustrates the CoT output of the fine-tuned model. In this output, the process begins with extracting key attributes from the query and item descriptions, such as product names, brands, model specifications, target audiences, and more. Following this, the model evaluates the relevance between the query and the item by assessing the compatibility of these attributes. Through CoT tuning, the fine-tuned model not only predicts relevance labels with accuracy but also provides clear explanatory reasoning for its decisions. However, upon analyzing the outputs of the fine-tuned model, it becomes apparent that the model demonstrates a bias toward overly strict relevance determination. Specifically, it frequently classifies products as "Irrelevant" when certain attributes mentioned in the query are missing from the product description, even if these attributes are not critical to the purchasing decision. This over-strictness leads to an increase in false negatives, which, in turn, reduces the model's recall rate and negatively impacts the platform's transaction activity and revenue. To address this limitation and better align the model's predictions with real user behavior and feedback, we refine the fine-tuned model using user purchasing data. Specifically, we leverage the model to predict query-purchased item pairs from historical logs and identify those instances where the model incorrectly classified items as "Irrelevant." These overly strict predictions are treated as less favorable outcomes, while GPT-40 is utilized to generate "Relevant" CoT reasoning results for the same query-purchased item pairs, which are considered more favorable outcomes. Finally, the KTO algorithm is applied to align the fine-tuned model with these preferences. Unlike other alignment methods, the KTO algorithm directly uses binary labeled data for model alignment, thereby simplifying data construction and enabling a more efficient setup process.
