GraphMatch demonstrates strong performance in addressing the cold start problem, particularly for nodes without prior interactions, by effectively defaulting to text embeddings, similar to TextMatch. The architecture of GraphMatch in real-time deployment is composed of three key components: a feature store, an inference service, and a graph database. This modular design allows diverse GNN models to leverage customized node features while preserving a unified graph structure adaptable to various use cases. For inference, node sampling is performed using Cypher, enabling users to specify the required node and edge types. The feature store primarily contains aggregated statistics, such as counts and averages, which are systematically updated on an hourly basis through SQL Mesh ETL processes and stored within the Feast framework. Snowflake serves as the data warehouse, hosting replicas of production relational databases alongside business datasets. In cases where node features are unavailable in the graph or feature store, default values are utilized. The graph database, hosted on Neo4j Aura, is updated via two ETL pipelines: a near real-time Kafka pipeline for highly dynamic entities like job postings and an hourly batch pipeline using Airflow for other entities. To ensure precise subgraph sampling for inference, the graph database maintains minimal node properties, including type, ID, and creation timestamp. The inference service operates within a Python/FASTAPI microservice framework deployed on EC2 instances with Nvidia A10G GPUs. Autoscaling is based on requests per second, as GPU and CPU utilization are less reliable indicators of latency under high usage. To optimize inference efficiency, TextMatch embeddings are precomputed and cached whenever a freelancer profile or job post description is updated. Consequently, online inference is confined to the GNN layers, ensuring embedding generation times remain under 70 milliseconds per entity. This approach enhances scalability and supports real-time applications effectively.
