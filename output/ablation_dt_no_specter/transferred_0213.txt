UnresolvedRetry represents the scenario where an agent performs multiple consecutive edits on the same file, none of which succeed in producing a successful modification. For instance, Figure 12-a illustrates a case where SWE-agent Dev repeatedly executes str_replace commands on utils.py 183 times, ultimately reaching the cost limit without success. StrNotFound occurs when an edit fails because the specified old string cannot be found in the file, as shown in Figure 13-a. These failures typically arise due to formatting issues or minor textual differences. NoEffectEdit happens when the old and new strings are identical, resulting in a meaningless replacement. Figure 13-b demonstrates this scenario, where the command replaces a string with itself, leading to no change in the file and incurring unnecessary execution costs. AmbiguousTarget, on the other hand, refers to cases where the specified old string appears multiple times in the file, creating ambiguity about which occurrence should be replaced. Figure 13-c provides an example of this, where multiple identical if statements prevent the editor from deterministically applying the replacement, exposing a key limitation of string-based editing mechanisms. To better understand these inefficiency patterns, we formalized them and analyzed their prevalence across 4000 GRAPHEC-TORY cases. Figure 14 summarizes the distribution of these localization inefficiency patterns across all agents and models for both resolved (Figure 14-a) and unresolved instances (Figure 14-b). The percentages below the Venn diagrams indicate the proportion of instances exhibiting at least one inefficiency pattern. Notably, inefficiencies are common even in resolved instances, albeit to a lesser extent, underscoring the importance of process-centric analysis to better understand agent behavior. Unresolved cases frequently involve multiple inefficiency patterns within a single trajectory. Interestingly, stronger models such as Claude Sonnet 4 achieve higher success rates but also display a higher incidence of these patterns. Manual analysis suggests that these models engage in extended internal reasoning before producing solutions. While this approach proves effective for addressing complex problems, as evidenced by the higher success rates, it can also lead to inefficiency when additional steps fail to improve the solution.
