The MODOMA system provides a laboratory environment for conducting language acquisition experiments and is fully parametrized. This allows users to control the parameters of each experiment by selecting predefined settings. Crucially, the system includes all aspects of language acquisition, encompassing the adult agent, the daughter agent, and the associated language processes, all of which can be adjusted through configurable settings. MODOMA is capable of executing various language acquisition processes, similar to those discussed by Shakouri et al. in 2025. The first parameter in Table 1, concerning the activation of functional category learning, is consistently enabled across all experiments discussed here. The remaining parameters define essential components of the experimental framework. Specifically, the configuration for the mother agent parameter controls the structure of Delilah's linguistic output, determining whether sentences or noun phrases are produced. The training and test experiments systematically manipulate this parameter to explore its effects. Similarly, the minimum amount of data required for the daughter agent to process before acquiring functional and content categories is varied across all experimental conditions. These parameters define the experimental setup. In the training experiments, the acquisition of functional and content categories is initiated after processing 1,000 noun phrases and 1,000 sentences, subsequently increasing to 10,000 noun phrases and 10,000 sentences. This facilitates the determination of the requisite number of exemplars generated by Delilah to identify this statistical pattern. Furthermore, the parameter for functional category acquisition specifies the type-token ratio used to translate distributional differences between function and content words into discrete linguistic knowledge. The training sessions are used to ascertain appropriate values for these parameters, while the test experiments validate the chosen settings using novel datasets generated by Delilah.
