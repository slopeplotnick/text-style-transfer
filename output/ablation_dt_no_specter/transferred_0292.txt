Second, retrieving a fixed number of clips limits the model's ability to handle queries that require varying temporal scopes. For instance, a question like "Where did I leave my glasses?" may need only a few seconds of video, whereas "What happened in the second half of the soccer match?" demands a much longer temporal context. Existing approaches typically retrieve segments of a fixed length for simplicity [12, 13, 33]; however, this strategy overlooks the diverse temporal scales of real-world events, thereby reducing flexibility. To address this limitation, we introduce WorldMM, a novel memory-based framework that constructs separate textual and visual memories and employs an adaptive retrieval mechanism to select the optimal memory modality and temporal granularity for each query. The textual memory consists of two components: episodic memory, which stores sequences of events across various time scales, and semantic memory, which captures high-level, long-term knowledge such as relationships and habitual patterns, organized within knowledge graphs. Similarly, the visual memory divides extended video sequences into short-term segments indexed within a retrieval corpus, enabling efficient access to relevant visual information when needed. By leveraging a multimodal memory selection mechanism, the retrieval agent dynamically identifies the most relevant memory across modalities and temporal scales, ensuring that only the necessary information is retrieved for each query. This design prevents the model from conditioning on irrelevant modality memories during retrieval, thereby minimizing distractions and enhancing reasoning efficiency. Moreover, WorldMM retrieves information at varying levels of granularity over appropriate temporal ranges by utilizing multiple graphs that operate at different scales, such as seconds, minutes, and hours. When episodic memory is selected, the retrieval agent systematically examines each memory to gather potentially relevant information across all temporal levels. The collected candidates are then jointly evaluated to determine the most pertinent data for answering the query. Ultimately, the system dynamically accesses both short- and long-term video contexts to extract only the information necessary for reasoning. Furthermore, the model performs retrieval iteratively, repeatedly selecting memories and queries to explore diverse combinations and uncover additional possibilities.
