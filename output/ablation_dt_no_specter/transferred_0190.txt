Lastly, at the end of the unrolled program, CFAULTS embeds an assertion capturing all the specifications of the failing tests. Therefore, the unrolled program encapsulates the execution of all failing tests within a single program. Listing 2 exhibits a program segment generated through the unrolling process applied to Listing 1. CFAULTS establishes global variables to represent the inputs and outputs of each failing test, as illustrated in lines 1-3 of Listing 2. For simplicity, the depicted listing illustrates solely the initial scope corresponding to test 0 from the test suite outlined in Table 1, with distinct variables introduced for each failing test. Moreover, the scanf function call is substituted with input array operations (lines 8-10), while the printf calls are replaced with CFAULTS' print functions, which are akin to printf functions but direct output to a buffer. Ultimately, the unrolled program concludes with the following code: ```txt float _input_f0[3] = {1, 2, 3}; char _out_0[2] = "3"; int _ioff_f0 = 0, _off_0 = 0; // ... inputs and outputs for the other tests scope_0: int f_0, s_0, t_0; f_0 = _input_f0[_ioff_f0++] ; s_0 = _input_f0[_ioff_f0++] ; t_0 = _input_f0[_ioff_f0++] ; _off_0 = printInt(_out_0, _off_0, f_0); _off_0 = printInt(_out_0, _off_0, s_0); _off_0 = printInt(_out_0, _off_0, t_0); goto scope_1; } } // ... scope_1 and scope_2 final_step: assert(strcmp(_out_0, "3") != 0 || // other assertions); } ``` After integrating all possible executions and assertions from failing tests during the unrolling step, CFAULTS proceeds to instrumentalise the unrolled program by introducing relaxation variables for each program component, such as statements and instructions. These relaxation variables correspond to the healthy variables explained in Section 4. Specifically, each relaxation variable activates or deactivates the program component being relaxed when assigned a value of true or false, respectively. Furthermore, CFAULTS ensures that there are no conflicts between the names of the relaxation variables and the names of the program's original variables. For this step, CFAULTS requires the specification of the maximum number of iterations for which the program should be unrolled.
