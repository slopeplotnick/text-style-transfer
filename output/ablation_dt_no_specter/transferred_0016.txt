The dataset consists of 81 questions, each addressing a specific health issue and a potential treatment. These health issues span 50 distinct disease and condition categories, including "Cancer," "Low back pain in adults," and "AIDS," as well as a general well-being category labeled "Other," which includes topics such as weight management. Figure 2 highlights 10 representative disease and condition categories that are most frequently referenced in the health-related questions. The full list of questions and their respective categories can be found in Appendix Table A4. To explore how language models handle real-world biomedical knowledge conflicts, we developed five prompt templates to assess their performance across various question-answering scenarios. As shown in Table 2, for each annotated instance in the HEALTHCONTRADICT dataset, we generated five question prompts using these predefined templates: Question: { Question } Question: { Question } Question: { Question } Context: { Correct Document } Question: { Question } Context: { Incorrect Document }. Our selection of baseline models was guided by two main objectives: first, to determine whether biomedical fine-tuning improves performance in the biomedical domain, and second, to evaluate whether increasing model size leads to performance improvements. Additionally, we selected language models with extended context lengths to enable the processing of long documents. The specifications of the selected models are detailed in Table 3. Each biomedical model was derived by fine-tuning the corresponding general-domain model listed in the same row. "Instruct" refers to models fine-tuned to follow user instructions. In this study, we did not fine-tune any models; instead, we conducted zero-shot inference using the selected baseline models. We evaluated open-source language models ranging from 1 billion to 8 billion parameters to ensure their applicability in resource-constrained healthcare settings. As illustrated in Table 4, the performance differences among larger language models (7-8B) are minimal. Furthermore, the fine-tuned biomedical model, MEDITRON3-QWEN2.5-7B, underperforms compared to QWEN2.5-7B. These state-of-the-art evaluation benchmarks reveal limitations in distinguishing variations in model capabilities, as they primarily assess a model's parametric knowledge.
