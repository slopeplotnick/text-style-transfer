We propose SR-GRPO, which uses stable rank as a dense reward signal in reinforcement learning, thereby eliminating the dependency on preference datasets or external verifiers. We demonstrate that SR-GRPO improves reasoning across multiple benchmarks, thus establishing intrinsic geometric signals as a viable basis for aligning language models. Beyond the realm of reinforcement learning, we also show that stable rank offers a reliable zero-shot reward proxy for evaluating language model responses and integrates naturally into best-of-N decoding. We propose stable rank (Rudelson & Vershynin, 2007) as an unsupervised quality signal derived from language model representations. This section defines the metric, explains its geometric motivation, and validates its effectiveness as a reward proxy. The theoretical motivation comes from two lines of work. The softmax bottleneck (Yang et al., 2018; Godey et al., 2024) implies that expressive language modeling requires high-rank representations, while representation collapse is a known symptom of degraded generation quality (Gao et al., 2019). Stable rank directly measures this effective dimensionality, making it a natural candidate for quality assessment. We validate this connection empirically and through correlation analysis in Section 5. We evaluate stable rank as a zero-shot proxy for human preference by testing whether it can predict the preferred response in a pair. This assessment checks whether stable rank can serve as a reliable reward signal without any model-specific training. For the setup, we use RewardBench (Lambert et al., 2025), a benchmark containing 2,985 preference pairs across five categories: Chat, Chat-Hard, Safety, Code, and Math. For each pair, we compute the stable rank for both responses and predict the one with the higher stable rank as preferred. We compare against three baseline methods: (1) Pointwise Scoring (Point.) (Kim et al., 2024), which involves prompting the language model to score each response on a 1-5 scale; (2) Pairwise Comparison (Pair.) (Kim et al., 2024), which entails prompting the language model to directly compare two responses; and (3) IPO (Garg et al., 2025), which uses implicit preference scores derived from Yes/No token probabilities. We evaluate five models: Qwen2.5-1.5B-Instruct (Yang et al., 2024), Qwen3-0.6B (Yang et al., 2025), Qwen3-8B (Yang et al., 2025), Llama-3.1-8B-Instruct (Dubey et al., 2024), and Phi-3.5-mini-Instruct (Abdin et al., 2024). For stable rank, we format inputs as prompt-response pairs using each model's native chat template, followed by extracting outputs from the final layer.
