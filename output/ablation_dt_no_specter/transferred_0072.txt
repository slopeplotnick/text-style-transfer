This paper introduces a novel formula-based methodology for fault localisation in C programs and Boolean circuits, addressing multiple faults concurrently by encoding the problem as a Model-Based Diagnosis (MBD) with multiple observations in a single optimisation problem. By consolidating all failing test cases into a single MaxSAT formula, this approach ensures the generation of only minimal diagnoses capable of identifying all faulty components within the system. Unlike existing methods, which either produce excessive superfluous results or fail to yield the minimal set of corrections, our approach relaxes C programs directly at the code level, enabling seamless integration with other bounded model checkers. Moreover, while previous works, such as the method proposed by Graussam, introduce additional aggregation steps that may compromise minimality, our approach guarantees consistency by formulating standard MBD instances and resolving them using Hitting Set Dualization (HSD). This ensures that the diagnoses remain minimal for each failing test case. To further enhance fault localisation, we employ static analysers, such as CPPCHECK and CLANG-TIDY, to detect issues like uninitialised variables and potential runtime errors (e.g., division by zero) before unrolling the buggy program. If such issues are identified, they are immediately reported to the user; otherwise, the process proceeds with system unrolling, instrumentalisation, bounded model checking (CBMC), encoding to MaxSAT, and resolution via a MaxSAT solver. Input operations, such as scanf, are translated into read accesses to input arrays, while output operations, such as printf, are replaced by write operations into output arrays. Additionally, all uninitialised global variables are explicitly initialised to nondeterministic values to avoid the C compiler's default zero-initialisation. By integrating all observations into a unified framework, this methodology not only precludes the generation of superfluous results but also ensures that all faulty components are effectively identified.
