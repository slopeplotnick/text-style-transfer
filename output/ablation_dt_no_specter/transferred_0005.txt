Contribution. We present promptolution, a modular, lightweight, and extensible open-source Python framework for automatic prompt optimization, offering thoroughly tested and stable implementations. The framework supports multiple LLM interfaces, diverse NLP tasks, and state-of-the-art discrete prompt optimization methods, all of which can be used interchangeably or replaced with custom components. While promptolution enables single-prompt optimization for practitioners, its low abstraction level and built-in tools for systematic, reproducible experimentation make it particularly suited for researchers. Prompt Optimization. Automatic prompt optimization systematically explores prompt spaces using various strategies to refine both instruction and few-shot example components (Cui et al., 2025; Li et al., 2025; Wan et al., 2024). These strategies are typically classified into continuous approaches, which optimize numerical representations (Li and Liang, 2021; Lester et al., 2021; Qin and Eisner, 2021), and discrete approaches, which operate directly on textual data (Guo et al., 2024; Yang et al., 2024; Zhou et al., 2023). For comprehensive overviews, we refer to Li et al. (2025) and Cui et al. (2025). Promptolution focuses on discrete prompt optimization, emphasizing interpretability and LLM-agnostic design. It iteratively refines textual prompts by leveraging a meta-LLM to generate improved candidates. The framework implements the following optimizers: 1. OPRO (Yang et al., 2024), which uses LLMs to propose refined instructions based on task descriptions, examples, and previously scored candidates; 2. EvoPrompt (Guo et al., 2024), which employs evolutionary algorithms—specifically genetic algorithms (GA) and differential evolution (DE)—with the meta-LLM performing crossover and mutation; and 3. CAPO (Zehle et al., 2025), a recent GA-based optimizer that integrates AutoML techniques to enhance cost-efficiency and jointly refines both instructions and few-shot examples, outperforming the aforementioned discrete methodologies.
