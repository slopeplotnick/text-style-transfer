**Code Interpreter Agent** We utilize Jupyter Notebook as a code interpreter to address complex reasoning tasks. To this end, we curate a diverse set of problems across mathematics, logic, and data science, each requiring the model to employ code execution capabilities to derive precise and scalable solutions. **General Agent** To scale agent environments and tasks in reinforcement learning (RL), we employ an automatic environment-synthesis agent that generates 1,827 task-oriented environments. These tasks are challenging to solve yet relatively easy to verify. The synthesis pipeline primarily involves constructing environments and tools, formulating tasks, and generating solutions. Specifically, the process unfolds as follows. 1. Given a task category (e.g., planning a travel itinerary) and a sandbox equipped with a bash shell and a search tool, the agent first retrieves or generates relevant data from the Internet and stores it in the sandbox database. 2. The agent then synthesizes a suite of task-specific tools, each implemented as a function. 3. To construct tasks that are both challenging and amenable to automatic verification, the agent begins by proposing a simple task based on the current database, along with its corresponding solution and verification functions written in Python. The solution function is constrained to using only the tool functions or performing logical computations—it cannot invoke other functions or access the database directly. This constraint ensures that tasks can only be solved through the designated tool interface. Furthermore, the output produced by the solution function must be validated by the verification function. If the validation fails, the agent iteratively revises either the solution or the verification function until the output passes. The agent then incrementally increases the task’s difficulty, updating both the solution and verification functions accordingly. If the current toolset proves insufficient to solve the task, the agent augments it with additional tools.
