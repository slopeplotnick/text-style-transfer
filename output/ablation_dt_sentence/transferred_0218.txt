**Baselines and Models.** We use Gemini‑2.0‑Flash in LLM-only baselines without external knowledge, providing only the original question as input. We experiment with multiple ablations of CAIRNS: (1) Domain RAG (literature-only), which retrieves solely from the literature subset; and (2) Domain RAG (literature+data), which incorporates both literature and climate data through a two-stage API reasoning process. Gemini-2.0-Flash serves as the base model across all CAIRNS variants. To ensure a fair comparison, all models are evaluated using identical corpora, prompt structures, and experimental configurations. **Impact of ScholarGuide Prompt (SGP).** The ScholarGuide Prompt enhances multiple readability-related dimensions, including contextual richness, structural coherence, and linguistic fluency. In addition, its citation mechanism corrects inconsistencies across cited sources, thereby improving the reliability of referenced information. Although this mechanism results in a marginal reduction in overall citation frequency, it yields a higher FaithRate, reflecting improved factual grounding. By enforcing unified reference numbering and grounding each factual statement in explicit evidence, SGP enables the model to generate clearer, more verifiable, and location-specific responses. This effect is consistent in both zero-shot and few-shot settings, highlighting structured prompting as a key factor in CAIRNS's overall performance. **Impact of Multi-turn ReAct (MTR).** The multi-turn ReAct framework introduces an iterative reasoning loop that allows the model to progressively refine its outputs by continuously aligning retrieved literature and climate data. As a result, the model produces more contextually grounded and complete answers, as indicated by improved comprehensiveness. While MTR's impact is less pronounced than that of SGP, it complements the structured generation process and contributes to stronger performance on multi-source or data-intensive queries. **Location-Weighted Retrieval (LWR).** Removing the LWR component results in a slight decline in regional specificity, while other evaluation metrics remain largely unaffected. This suggests that LWR plays a valuable role in supporting the generation of geographically tailored responses, particularly for location-sensitive questions.
