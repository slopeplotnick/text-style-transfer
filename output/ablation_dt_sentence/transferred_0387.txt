The robot assesses its performance by evaluating task progress and current workload status. The decision-making process is guided by an analysis of the likelihood of successful outcomes, which influences subsequent actions. In this context, the system provides a concise rationale for its decision, elaborating on the reasoning behind it. Additionally, the analysis includes a projection of the workload following the decision, along with an evaluation of the confidence level, which is categorized as high, medium, or low. The process also entails a consideration of the trade-offs involved, particularly the elements that were compromised to reach the final outcome. To optimize this reasoning process, the system employs Nodes 2 and 3, which play integral roles in decision-making. Specifically, Node 2 generates contextually relevant prompts, while Node 3 utilizes these prompts to perform cognitive processing. As illustrated in Figure 11, Node 3 executes the reasoning process by invoking the LLM to generate responses based on the system's and user’s inputs. The prompts consist of two components: a system prompt that defines the agent’s overall decision-making approach, and a user prompt that adapts to the specific context. These prompts are combined into a structured input for the model, where the system prompt offers overarching guidance, and the user prompt provides task-specific details such as success probability, workload status, and progress stage. The combined prompt is transmitted to the LLM client via the invoke() function, which structures the sequence of messages for processing. The LLM then generates a natural language response, articulating the decision-making process, the expected likelihood of success, and the confidence level associated with the decision. This output is then subjected to a comprehensive verification process. The system processes the prompts, incorporating the static system prompt, which outlines the rules, and the dynamic user prompt, which reflects the current task context. These components are consolidated into a message sequence and passed to the LLM for inference. In this phase, the model generates a natural language explanation that encompasses the allocation decision, a detailed justification, anticipated success rates, and confidence levels. This reasoning is further informed by various settings, which include possible correct, incorrect, or contradictory contexts. Their impacts on the model’s output are carefully evaluated, ensuring that the resulting response aligns with the overall decision-making process.
