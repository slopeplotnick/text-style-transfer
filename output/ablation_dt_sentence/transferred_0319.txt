The Solver reward combines both synthetic and empirical supervision signals, modulated by the current curriculum difficulty, providing a competence-aware shaping signal that scales with task complexity. R-FeW preserves the same self-improving loop as R-ZERO but introduces a grounded and curriculum-informed data pipeline: the Challenger synthesizes tasks using few-shot examples anchored by human inputs, while the Solver attempts these tasks and estimates its success frequency. An online curriculum filter selects mid-difficulty tasks from a blend of synthetic and real-world data sources. We use Qwen3-4B-Base (Yang et al., 2025b) and Qwen3-8B-Base as our backbone models. For comparison, we evaluate against several baselines: (1) **Base Model** — the original pretrained checkpoint without any post-training, available at https://huggingface.co/Qwen/Qwen3-4B-Base (Qwen3-8B-Base); (2) **R-ZERO** (Huang et al., 2025) — the initial ungrounded self-play framework where the model autonomously generates both questions and answers, enabling self-improvement through internal reasoning; (3) **Absolute Zero** (Zhao et al., 2025a) — a code-specific self-play framework that uses Python execution for verification, showcasing grounded reasoning in a constrained domain; (4) **SPICE** (Liu et al., 2025a) — a grounded self-play system that retrieves relevant content from a large document corpus to create diverse, context-rich reasoning tasks with document-grounded answers. We reproduce baselines (1)-(2) using publicly available implementations under the same training conditions, while results for (3)-(4) are cited from Liu et al. (2025a).
