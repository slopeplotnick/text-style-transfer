The tool library comprises several components: the Segmentator Tool for region localization, the Analyzer Tool employing the Think with Image paradigm [19] for strategic region analysis planning, the Report Generator Tool utilizing template-based approaches for report creation, and the Quality Controller Tool, which performs quality assessments of radiology reports and provides feedback for iterative refinement. Together, these tools support the entire automated radiology reporting process. Figure 2 illustrates the operational workflow of the Radiologist Copilot. To validate the effectiveness of our proposed system, we leverage the liver radiology reporting task as a test case. We utilize the publicly available 3D CT dataset AMOS-MM [9], which includes over 2,000 CT scans accompanied by detailed radiology reports. Of these, 1,287 CT scans with corresponding reports are designated for training, while 400 CT scans with reports are reserved for validation. For the liver radiology reporting task, we filter the AMOS-MM dataset to extract reports specifically describing the liver, which are then used as liver radiology reports. This results in a training set consisting of 1,149 CT scans with liver reports, and a validation set containing 367 CT scans with liver reports for evaluation. The validation set is reserved to assess the performance of our method, while the training set is employed for report analysis. To begin, we generate report embeddings using BioBERT, which are subsequently clustered using K-means to derive template reports. These templates are categorized into liver-related components such as the liver surface, liver parenchyma, bile ducts, and liver lesions, which are incorporated into the Analyzer Tool. The Radiologist Copilot is built using the agentic framework OctoTools [14], implemented in Python 3.10.18, with experimentation carried out on NVIDIA L20 GPUs. The system operates without requiring additional training, relying instead on pre-trained models. The primary reasoning component is Qwen3-32B, while the Region Localization Tool is driven by the TotalSegmentator model to identify relevant regions. The Analyzer Tool uses the 3D medical vision-language model Hulu-Med for comprehensive CT scan analysis. The maximum number of execution steps is set to 10, with a time constraint of 500 seconds per case.
