Various systems have been proposed for managing memory in financial tasks, each designed to address specific challenges within the domain. FinMem[22] is a financial-domain memory system that implements a layered memory structure, encompassing short, mid, and long-term memory to inform and guide trading decisions. Similarly, MemP[5] offers a comprehensive framework that abstracts trajectories into both step-by-step instructions and high-level strategies, leveraging procedural memory to facilitate the execution of agentic tasks. In contrast, MemGPT functions as a resource management system, overseeing data storage and task scheduling to effectively expand the context window for large language models, thereby enhancing their operational capacity. Zep[14], on the other hand, represents a framework that incorporates temporal knowledge graphs to establish connections between historical relationships and evolving contexts. To evaluate the performance of these systems, we adopt Accuracy (ACC) and Matthews Correlation Coefficient (MCC) as the primary assessment metrics. ACC evaluates the overall correctness of model predictions, while MCC provides a more robust evaluation metric for performance under class imbalance—particularly relevant in stock prediction tasks where class distributions are often skewed. As shown in Table 1, our approach consistently outperformed all other systems across both ACC and MCC, further validating its superior performance compared to the baseline models. These results indicate that the proposed system demonstrates effective performance in the designated tasks. Furthermore, our tests reveal key issues with the other systems. For instance, FinMem lacks temporal event modeling, overlooking critical market fluctuations. MemP, by abstracting trajectories, overly simplifies the process and omits essential financial details. Similarly, MemGPT’s design fails to prioritize event-based awareness, which results in the omission of critical financial patterns during memory updates. Moreover, Zep’s event modeling lacks effective integration of inter-event relationships, missing crucial dependencies and correlations within complex financial environments. In contrast, our framework mitigates these issues by transforming unstructured news into structured temporal event knowledge. This method systematically captures the interrelationships between events, enabling traceability and logical reasoning, thereby enhancing the accuracy and reliability of financial predictions.
