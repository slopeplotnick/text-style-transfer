In this study, several classical machine learning classifiers were employed to analyze EEG data, with the primary focus on classifying motor imagery tasks. The classification process began with the application of feature extraction methods and preprocessing techniques, followed by the use of various classification algorithms. Logistic regression with elastic-net regularization was first applied, combining L1 and L2 penalties to manage sparse data and reduce the risk of overfitting. The optimization was carried out using the saga solver, which is particularly suited for large datasets. To address the varying feature scales, intercept scaling was set to 1000, and a random state of 42 was employed to ensure reproducibility. In addition, a random forest classifier was utilized, which builds an ensemble of decision trees to improve accuracy and mitigate overfitting. By aggregating the predictions from multiple trees, random forest is highly effective at handling non-linear feature interactions. This classifier demonstrated better resistance to overfitting compared to individual decision trees. Moreover, both linear and radial basis function (RBF) kernel support vector machines (SVMs) were employed. The linear SVM was applied to linearly separable data, such as features derived from CSP, while the RBF kernel SVM was used to handle non-linearly separable data by mapping it into a higher-dimensional space to capture more complex relationships. Linear Discriminant Analysis (LDA) was also incorporated, as it is effective in maximizing the between-class variance relative to within-class variance, making it particularly suitable for linearly separable datasets. Furthermore, a range of multilayer perceptrons (MLPs) with varying architectures was explored. The MLP configurations included models with different numbers of hidden layers and neurons, ranging from basic architectures with a single hidden layer to more complex models with three hidden layers, such as configurations of (10, 30, 10) or (20,) neurons. These models employed ReLU or logistic activation functions and were trained using either stochastic gradient descent (SGD) or Adam optimizers, which automatically adjust the learning rate during training. To prevent overfitting, L2 regularization was incorporated through the alpha parameter, with various values tested to determine the optimal level of regularization. Additionally, constant learning rates were used in some MLP configurations to ensure steady convergence during training. Both SGD and Adam solvers were fine-tuned to optimize performance across different feature extraction methods. For reproducibility and traceability, each unique MLP architecture was assigned a distinct identifier (MLP_1 to MLP_17), which was consistently applied across all experimental trials.
