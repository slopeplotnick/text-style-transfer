This study advances the application of large language models (LLMs) in financial forecasting and proposes a novel approach for designing memory architectures tailored to specialized domains. By developing a domain-specific memory system, we effectively address the challenges of adapting general frameworks to professional contexts, laying a robust foundation for future research in this area. Our contributions align with the track’s objectives in three key aspects: (1) **Structured Knowledge Extraction**: We convert unstructured web news into a temporally-structured event knowledge base, facilitating the scalable generation of web-based structured knowledge. (2) **Semantic-LLM Synergy**: Our dual-layer memory system enhances the integration between structured knowledge and the reasoning capabilities of LLMs. (3) **Web Application**: We demonstrate the practical value of this approach in financial prediction, thereby improving the interpretability of web news-based decision-making systems. Through these contributions, we address a critical challenge in knowledge organization and application, advancing the integration of structured event knowledge with traceable memory mechanisms. Our work also addresses the pressing issue of extracting dynamic, semantically rich knowledge from web corpora, which is closely aligned with the core objectives of this track. Memory mechanisms have become a central element in enhancing LLMs’ ability to tackle complex tasks, evolving from purely parametric internal representations to the incorporation of external memory systems. Parametric memory encodes knowledge within the model’s weights, offering rapid access and long-term retention, but it suffers from limited interpretability and difficulties in selective updating. To overcome these limitations, researchers have developed external memory architectures that address the constraints of LLMs, such as context length and knowledge integration, by enabling structured, selectively retrievable knowledge augmentation. The evolution of external memory follows a clear progression, initially exemplified by retrieval-augmented generation (RAG), which stores unstructured text in vector databases. While RAG addresses the issue of knowledge updating, its ability to capture deeper semantic or contextual nuances is limited. As research has advanced, the focus has shifted toward the systematic management of memory mechanisms, giving rise to innovative systems such as GraphRAG, which uses knowledge graphs for structured memory management, MemGPT, which functions as an operating system for memory, and Zep, which integrates temporal knowledge engines to link historical and dynamic information, significantly enhancing reasoning and memory management efficiency.
