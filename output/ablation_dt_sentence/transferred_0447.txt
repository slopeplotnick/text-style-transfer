The model loader then utilizes the init_adapter method to create the PEFT model. From this stage, we delegate the tasks of loading, training, and model saving to PEFT provider libraries and the LLaMA-Factory framework. In contrast to LLaMA-Factory, however, PEFT-FACTORY employs a dynamic loading mechanism for custom PEFT methods, thereby enhancing its extensibility and modularity. This approach enables researchers and practitioners to seamlessly integrate custom PEFT implementations without making any modifications to the core codebase of PEFT-FACTORY. To illustrate the functionality of our Custom PEFT Interface, we replicated two PEFT methods that are not included in any standard PEFT framework—BitFit (Ben Zaken et al., 2022) and SVFT (Lingam et al., 2024). During the dynamic loading process, the peftloader module automatically discovers and loads PEFT methods from a structured directory hierarchy. Each custom PEFT method is organized in its own subdirectory, comprising two essential components: a config.py file defining a PeftConfig subclass, and a model.py file implementing a BaseTuner subclass. The loader validates each implementation by ensuring the presence of required attributes, such as peft_type for configurations and prefix for model classes, before registering them. Furthermore, the loader dynamically incorporates the config and model subclasses through the register_peft_method function, adding them to the constants of the Hugging Face PEFT library. This procedural framework is also specified by Algorithm 1 in Appendix B.1. After dynamic loading, the custom PEFT method is processed similarly to standardized methods, as detailed in Section 3.1. To introduce a new method, it is necessary to align with the directory structure within the PEFT methods directory, which can be defined by the environment variable PEFT_DIR, with ./peft as the default setting. This ensures conformity with the organizational structure and class inheritance principles. Additional information about example method templates can be found in Appendix C and the documentation for PEFT-FACTORY.
