The AgentHarm public test dataset contains 176 samples from 44 unique tasks across 8 categories, such as disinformation and fraud. Each task can be expanded with two modes: one provides a hint indicating which tool should be called first, while the other offers a detailed prompt with step-by-step instructions. The combination of these modes results in four distinct modifications of each task description. For our experiments, we focus on the simplest subset to reduce costs and provide an upper bound on model capabilities, ensuring that the limiting factor is not the model itself but rather the context length, which primarily influences performance (see Section A). AgentHarm employs both an automatic scorer and LLM-judge evaluations (Zheng et al. 2023). We focus on two key metrics: (1) Harm score, a rubric-based completion score ranging from 0 to 1 for harmful tasks, according to manually implemented rubrics, and (2) Refusal rate, the fraction of samples flagged as refusals by the LLM model. Further details can be found in Section B. Harm Score serves as the primary metric, with semantic judgment excluded under the assumption that reliable evaluation can be performed on the simplest subset of tasks. For the refusal judge, we make minor adjustments to both the prompt and the underlying model, as described in Section E. To explore the effect of context length in a controlled environment, we experiment with four distinct padding types: random padding, which uses tokens randomly sampled from the tokenizer; non-relevant padding, which incorporates coherent text from fiction literature (spanning five genres: humor, mythology, sci-fi, crime, romance) unrelated to the task category; relevant padding, which integrates coherent text from Wikipedia articles pertinent to the task category; and multi-task padding, which samples task descriptions from the validation dataset. These padding types allow us to isolate different factors: random padding ensures full control over reproducibility, non-relevant and relevant padding provide coherent, in-distribution text, and multi-task padding tests the model's robustness to semantically confounding context. Additional information is provided in Sections F and G.
