Prompt engineering is a technical methodology designed to optimize how language models respond to specific instructions. In this study, we employed prompt chaining, a structured strategy that improves processing outcomes by breaking down complex tasks into smaller, sequential sub-tasks. For the task of story parsing, we decomposed it into four sub-tasks: extracting entities, extracting events, constructing a story outline, and identifying relationships. The outputs from each step are subsequently incorporated into the prompts for the next stage, enhancing the overall model performance. Furthermore, prompt frameworks play a pivotal role in ensuring models adhere to instructions accurately. To this end, we utilized the TIDD-EC prompt framework, which consists of five key components: task specification, detailed instructions, prescribed actions and prohibitions, illustrative examples, and user-generated content. This framework ensures the precision and relevance of the responses. Table III presents the prompts used in the "Entity Extraction" task, based on the TIDD-EC framework, with each prompt paired with its corresponding manual ground truth annotation, classified according to a four-level relevance scale (L1-L4). Additionally, we experimented with four distinct prompting strategies and evaluated their performance in transforming stories into JSON format: - Zero-shot prompting: The task was described in natural language without specific examples. - TIDD-EC framework: The task was framed using the TIDD-EC framework. - TIDD-EC + CoT: This strategy integrated chain-of-thought (CoT) reasoning. - TIDD-EC combined with prompt chaining: The task was divided into four components, each utilizing TIDD-EC, and these components were linked through prompt chaining.
