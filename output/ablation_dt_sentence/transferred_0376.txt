This method aims to promote fairness across tasks and groups by directly optimizing a smooth surrogate of balanced accuracy. Unlike standard CE loss, it explicitly addresses performance disparities between majority and minority groups, thereby enhancing consistency in multi-task fine-tuning. To evaluate the effectiveness of various training strategies, we conducted a comparative study. Specifically, we examined the impact of single-task versus multi-task fine-tuning approaches on mental health prediction performance. As part of this, we developed an iOS-based mental health evaluation application utilizing llama.cpp as the inference backend, with GGUF V3 models optimized for efficient performance on mobile devices. The models were converted from PyTorch to the GGUF format via a specialized conversion pipeline, enabling efficient execution on both CPUs and GPUs. The application itself was implemented using Swift/SwiftUI, integrating llama.cpp through a C++ bridge layer, which allows for on-device inference within the iOS runtime without reliance on external servers. At runtime, matrix operations are accelerated using Apple Metal, with automatic fallback to CPU processing when GPU utilization is saturated. Thread-level parallelism, up to 8 threads, is orchestrated via llama.cpp’s native scheduling interface to ensure efficient utilization across Apple’s heterogeneous core architecture. Additionally, model parameters are configured to minimize memory overhead, allowing for on-demand loading of components, reflecting a systematic optimization of resource utilization. To ensure stability, the system employs a 4,096-token context window, augmented with intelligent cache management and batched inference to handle extended input sequences without fragmentation. Long social media posts are truncated to a maximum of 6,000 characters. We evaluated three locally deployed models—Menta (2.33 GB), Phi-4 Mini (2.40 GB), and Qwen-3 (2.30 GB)—on an iPhone 15 Pro Max (A17 Pro chip, 8GB RAM) using open-source implementations. Furthermore, the framework supports alternative quantization schemes, offering trade-offs between computational latency and predictive accuracy. For the Menta model, we utilized four high-quality datasets curated specifically for detecting depression, stress, and suicidal ideation from Reddit. Disorder-related samples were excluded, and the remaining data were meticulously annotated by domain experts. These datasets were employed for further analysis in the study.
