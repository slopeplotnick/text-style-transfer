Retrieving a fixed number of clips limits the model's ability to handle queries that require varying temporal scopes. For example, a question like "Where did I leave my glasses?" may only require a brief segment of video, while a question such as "What happened in the second half of the soccer match?" necessitates a longer temporal context. Existing methods typically retrieve clips of a fixed length for simplicity, yet this approach overlooks the diverse temporal scales of real-world events, restricting flexibility. To overcome this limitation, we propose the WorldMM framework, a memory-based system that constructs separate textual and visual memories and employs an adaptive retrieval mechanism to select the most appropriate memory modality and temporal granularity for each query. The textual memory consists of two components: episodic memory, which captures events across various time scales, and semantic memory, which stores long-term knowledge, such as relationships and patterns, organized within knowledge graphs. Meanwhile, the visual memory divides extended video into short-term clips indexed in a retrieval corpus, enabling the model to access visual content as needed. The retrieval agent iteratively selects the most relevant memory across modalities and timescales, ensuring that only query-relevant information is retrieved. This design effectively prevents the model from conditioning on unnecessary modality memories during retrieval, minimizing potential distractions during reasoning. Additionally, WorldMM can retrieve information at varying levels of granularity across different time ranges, leveraging multiple graphs operating at different temporal scales, such as seconds, minutes, and hours. When episodic memory is selected, the retrieval agent searches each memory to gather relevant information from all temporal resolutions. The gathered data is then assessed to determine which elements are most pertinent to answering the query. Ultimately, the model dynamically accesses both short- and long-term video contexts to extract only the necessary information for accurate inference. Furthermore, the model performs retrieval in multiple iterations, selecting relevant memories and queries in turn, thereby expanding the scope of possible solutions.
