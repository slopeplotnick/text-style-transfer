In 2024, content is deconstructed into distinct functional and semantic sections, which are then summarized in multiple languages to facilitate interactive Q&A. To support these tasks, we utilize the transcribed multimodal ST output as context. However, while modern LLMs handle long contexts efficiently, their context window remains limited. To address this, we implement a strategy that divides lectures into chapters, preventing context overflow and ensuring clearer summaries, as each chapter focuses on a single topic. These chapters are translated into multiple languages and summarized for enhanced clarity. For each chapter, we generate several forms of compressed representations, including transcript compressions at various ratios (50%, 70%, 90%) and length-controlled summaries, the size of which is determined by the length of the original section. All summaries are initially generated in English to take advantage of LLMs' superior performance with English text and are subsequently translated into the target languages. For question-answering (QA), we follow a similar approach: the English transcript, segmented by chapters, is used within a Retrieval-Augmented Generation (RAG) framework to query an LLM, and the generated responses are then translated into the target languages. Another challenge arises in translating slides, which contain both editable text and images with embedded text. For the editable text, we employ a Python-based PowerPoint parser to extract the text and translate it using standard unimodal machine translation (MT), avoiding the computationally expensive multimodal models. Text embedded in images, however, cannot be directly extracted, often lacks sufficient surrounding linguistic context, and depends on visual elements for accurate interpretation. As such, a multimodal translation approach is necessary. After translation, the text is reintegrated into the original image to preserve both its visual structure and semantic integrity. To address this, we propose an image-translation pipeline that detects, reads, translates, and re-integrates text within slide images.
