Instances of non-deterministic generation were observed when using Claude 3.5 Haiku and GPT-4, where identical prompts resulted in divergent outputs, some executable and others containing errors. Moreover, GPT-4 occasionally reused previously presented examples, leading to semantic interference—such as substituting task-relevant objects with those from unrelated tasks, which induced execution errors. These inconsistencies highlighted the absence of error-checking mechanisms in the original system, prompting the incorporation of explicit validation and retry procedures within the LangGraph framework. This framework, which concatenates examples from three distinct components—task decomposition, assignment, and code generation—into a single unified prompt, faced further challenges. As more examples were incorporated to address complex tasks, the input length exceeded the system's capacity, causing failures in processing. This scalability limitation, where richer context improved accuracy but resulted in excessive input lengths, necessitated modifications to enhance input and context management within the LTAA framework. Consequently, these two challenges—output inconsistency and input length limitations—directly shaped the architectural requirements for reliable multi-robot coordination: the implementation of systematic validation mechanisms to ensure reasoning accuracy and the adoption of a modular design to address input constraints. To meet these needs, the researchers developed a system designed to detect errors, incorporating structured feedback and retry mechanisms. Building on the limitations identified during the SMART-LLM setup and to assess the practical feasibility of leveraging LLMs for robotic task execution, a Self Corrective-Agent Framework was introduced. Unlike the earlier single-agent configuration, this framework adopts a multi-agent architecture consisting of three specialized components: a Task Decomposition Agent to segment complex objectives, a Task Allocation Agent to assign subtasks, and a Code Generation Agent responsible for synthesizing executable code. As illustrated in Figure 2, each agent is equipped with an independent error-checking mechanism and coordinated through the LangGraph system. The first agent initiates the process by decomposing extensive instructions into manageable tasks, identifying necessary actions, objects, and their sequence. The subsequent agent allocates these tasks to the most appropriate robots based on their functional capabilities and available resources, while also determining the optimal execution sequence.
