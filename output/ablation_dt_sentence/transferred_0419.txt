Building upon these innovations, this study introduces Lang2Logic, a pioneering framework designed to bridge the gap between everyday language and computational logic. Lang2Logic enables the transformation of natural language inputs into Conjunctive Normal Form (CNF), which is essential for logical reasoning tasks. This process facilitates the translation of human-readable statements into machine-processable logical representations. Lang2Logic incorporates specialized computational tools and a bespoke linguistic representation to ensure precise transformation from natural language to CNF. Therefore, this structured pipeline allows for the translation of unstructured natural language into a canonical Satisfiability (SAT) problem representation, thereby extending the applicability of SAT solvers to real-world scenarios. Lang2Logic specifically addresses the disparity between natural language understanding and computational logic by converting English text into CNF, which is crucial for the functioning of SAT solvers. The framework comprises three core components: (1) Natural Language to Logical Expression, (2) Logical Expression to CNF Conversion, and (3) CNF Simplification. Each component plays a vital role in ensuring an accurate and effective transformation from natural language to a machine-readable CNF format. The initial stage utilizes the ChatGPT o1-mini model API to translate natural language input into a logical expression. The configuration of the o1-mini model was meticulously crafted to identify recurring variables across different clauses, generate structured logical expressions that are compatible with ancillary computational tools, and ensure conformance to the requisite format for processing by the Sympy converter. The use of the ChatGPT API obviates the need for intricate grammar rule specifications, thereby streamlining the conversion process. However, this approach may incur higher costs and pose challenges in handling larger input sizes. To address these issues, the NLTK library was employed to preprocess the input effectively. Specifically, NLTK's Punkt tokenizer segments the text into discrete sentences, enabling the o1-mini model to process each sentence independently. Consequently, this prevents errors such as sentence amalgamation or omission during processing. By handling each sentence individually, the o1-mini model can produce more accurate logical expressions.
