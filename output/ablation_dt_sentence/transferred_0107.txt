The advent of LLMs has created opportunities for a paradigm shift in event-driven prediction. Unlike traditional methods, LLMs can extract complete event structures—including event type, participants, and temporal information—directly from unstructured text. This preserves information integrity, thereby supporting causal inference and enabling transparent reasoning. However, existing research has yet to fully exploit the capabilities of LLMs. Approaches such as CAMEF[25] utilize LLMs for event extraction but subsequently compress the structured events into low-dimensional vectors for downstream processing by conventional neural networks. This effectively reduces LLMs to advanced feature extractors. As a result, such methods sacrifice critical event details during vectorization, lack explicit modeling of event relationships and temporal progression, and fail to establish a reusable or traceable memory system. Our work fundamentally diverges from these approaches. Rather than flattening rich event structures into compact embeddings, we retain them as foundational units for constructing a structured event memory. By explicitly modeling event tracking, integration, and sequencing, our framework enables comprehensive reasoning over event evolution and analogical patterns across different scenarios. This directly addresses the limitations of existing LLM-based methods in linking event sequences and identifying recurring patterns over time, and it constitutes the core contribution of this study. We present a structured event reasoning framework for stock price prediction. Our system dynamically builds a knowledge base of events from news corpora and iteratively refines it through model feedback.
