Benchmarking LLM inference power consumption is fundamentally different from measuring throughput or latency. Unlike conventional performance metrics, energy consumption is shaped by hardware heterogeneity, software stack complexity, and workload characteristics. These factors vary widely across use cases and deployment scenarios. However, current LLM evaluations offer limited support for this variability, as they typically rely on predefined configurations, fixed model sizes, and expensive instrumentation. As illustrated in Figure 1, TokenPowerBench addresses these limitations through a three-tiered framework: Configuration, Execution & Measurement, and Report Generation. It provides a modular, reproducible, and flexible methodology for evaluating energy use in modern LLM inference. The first step in using TokenPowerBench is to configure the benchmarking environment by selecting the model to run, the inference engine to use, and the prompt dataset. To streamline this process, TokenPowerBench provides three plug-and-play modules: a model pool (choose from any supported LLM), a prompt-dataset menu (featuring Alpaca, LongBench, or user-defined prompts), and an inference engine selector (vLLM, TensorRT-LLM, Transformers, or DeepSpeed). - **Model Pool**: We include models with diverse architectural designs to explore how these differences impact power consumption profiles. This includes standard decoder-only transformers (e.g., the LLaMA series) as well as Mixture-of-Experts (MoE) models (e.g., Mixtral), which differ notably in terms of parameter activation patterns and memory usage. The evaluation spans a wide range of model sizes, from lightweight models with under 1 billion parameters—suitable for single consumer GPUs—to frontier-scale models like Llama 3-405B, which demand multi-GPU or multinode distributed inference. This range enables detailed analysis of how energy consumption scales with model size and hardware complexity. - **Prompt-dataset menu**: Prompt length and syntactic complexity can significantly impact inference energy profiles. To account for this, TokenPowerBench includes two representative datasets: Alpaca, offering short, chat-style prompts, and LongBench, designed for extended contexts of up to 10,000 tokens. Alternatively, users can supply custom datasets in CSV or other compatible formats.
