The operation of the fine-tuned model is illustrated in Figure 1. Initially, key attributes are extracted from the query and item descriptions, including product names, brands, model specifications, and target audiences. Next, the model assesses the relevance between the query and item by evaluating the compatibility of these attributes. Through CoT tuning, the model not only predicts relevance labels with accuracy but also provides clear explanations for the underlying rationale. However, the outputs of the fine-tuned model often display an over-strict tendency, classifying products as "Irrelevant" when certain details from the query are missing in the product description, even if such details are non-essential to the user's purchasing decision. This over-strictness results in a higher incidence of false negatives, which lowers the model's recall rate and negatively impacts platform transaction activity and revenue. To address this issue, we align the model's predictions with actual user behavior and linguistic patterns. Specifically, we use the fine-tuned model to predict query-item pairs from historical purchase data, selecting those that the model classifies as "Irrelevant" to form a preference-based training set. These overly strict predictions are treated as incorrect, while GPT-40 generates "Relevant" reasoning outcomes for the original query-item pairs, which are considered correct. Subsequently, the KTO algorithm is employed to align the model with these preferences. In contrast to alternative alignment approaches, the KTO algorithm directly utilizes binary labeled data for model alignment, streamlining the data preparation process and improving setup efficiency.
