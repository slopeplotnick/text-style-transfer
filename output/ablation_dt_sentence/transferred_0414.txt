Programmatic Editing. Utilizing python-pptx for programmatic modifications of PowerPoint slides is a widely adopted approach in previous research. This method, illustrated at the top of Fig. 5, involves generating code to script these edits. It excels in executing repetitive, well-defined, and content-centric tasks such as performing a "find-and-replace" operation across all slides or translating text. However, it is not well-suited for complex structural modifications, like altering slide masters, themes, or specific layout geometries. Direct XML Editing. To overcome the limitations of programmatic techniques in handling structural and visual editing challenges, we have enhanced PPTPilot with the capability to read, parse, and rewrite raw OOXML files, as depicted in the top half of Fig. 5. This technique offers the precise control needed for structured tasks, allowing the manipulation of fine-grained properties such as specific element positions. Since OOXML encompasses most of the data within a PowerPoint, the XML path is well-aligned with existing modification methodologies. Nevertheless, the demanding context and stringent format requirements of XML make precise edits challenging, particularly when extensive modifications across numerous slides are necessary. In these situations, the programmatic method remains more reliable. Skill Routing. For determining the optimal editing skill based on specific user queries, we employ a tool that effectively routes the request to the appropriate method, as illustrated at the start of the branching in Fig. 5. Upon receiving an instruction, this tool analyzes the prompt in conjunction with the presentation's structure, including both visual and textual elements. It then directs the task to either the programmatic or XML editing path. Self-correction with Reflection.
