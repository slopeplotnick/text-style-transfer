In this paper, we propose a method to construct knowledge graphs (KGs) from images using multimodal large language models (LLMs) guided by domain-specific constraints. These constraints, formalized as an ontology, define the salient entities and relationships relevant to the domain and are embedded into the prompt to direct the model’s focus toward semantically meaningful aspects of the image. Upon receiving an image, the LLM generates a structured list of key elements, their attributes, and interrelations, all aligned with the predefined ontology. These elements are then converted into a graph that reflects the image content. Accordingly, the graph’s structure is strictly determined by the ontology specified during the formalization phase. Each image yields a distinct, interpretable subgraph, which we store in a graph database. While individual graphs correspond to specific images, many of their components—such as common attributes or entities—are shared due to the ontology’s constrained vocabulary. Consequently, all subgraphs are interconnected within a single unified graph structure. This global graph enables cross-image semantic comparison by analyzing overlapping subgraphs at a granular level. To ensure consistent interpretation, we employ a multimodal LLM to extract high-level semantic features from each image. These features correspond to core concepts defined by the ontology, which guarantees uniform and domain-aligned representations. To bridge the gap between the general-purpose capabilities of the LLM and the specialized nature of the ontology, we incorporate the rules explicitly into the prompt at inference time. This strategy enables the generation of structured per-image graphs and their seamless integration into a coherent global graph. The resulting subgraphs, linked via shared semantic nodes, support robust semantic analysis across the dataset.
