Other promising prompt optimizers not yet implemented in promptsolution include GEPA (Agrawal et al., 2025), TextGrad (Yuksekgonul et al., 2025), MIPRO (Opsahl-Ong et al., 2024), and PromptWizard (Agarwal et al., 2024). Most of these tools are confined to research environments and are hindered by infrequent updates, inadequate documentation, and insufficient testing. Consequently, they are challenging to utilize for both scientific benchmark experiments with other tools and practical applications. In the evolving landscape of prompt optimization, numerous actively maintained libraries and tools have emerged, both open-source and proprietary. Notably, several open-source libraries implement only a single prompt optimizer, such as TextGrad, AdalFlow, Microsoft's PromptWizard, and PromptIM, each using distinct methodologies. Conversely, prompt-ops employs a dual-optimizer approach specifically focused on optimizing prompts for Llama models. On the other hand, promptsolution offers a comprehensive framework with multiple optimizers that can be used interchangeably across various LLMs. DSPy is recognized as a leading framework for building modular LLM configurations, featuring an embedded prompt optimization component. It includes diverse optimizers like MIPROv2 and GEPA and can integrate LLM training with prompt optimization strategies. However, while DSPy is designed as a high-level program compiler encompassing prompt optimization as one element, promptolution is dedicated solely to prompt optimization, providing a flexible design suited for systematic studies, which caters particularly to researchers and advanced practitioners. Promptomatix, derived from DSPy, introduces a more streamlined approach with its unique prompt optimization methodology.
