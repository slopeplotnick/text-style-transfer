The type of padding used plays a significant role in model performance. Specifically, padding that mimics coherent text—whether relevant or non-relevant—outperforms random padding, which, in turn, surpasses multi-task padding. Additionally, padding position is crucial; placing the context after the task description has been shown to degrade performance more than positioning it before the task. This effect likely stems from the proximity of the task description and execution when the context precedes the task, enabling more effective operation of the attention mechanisms within the model’s distribution. LLM agents are AI systems in which pre-trained large language models (LLMs) are embedded into a decision-making loop to autonomously execute multi-step, multi-turn tasks using external tools. Context windows have significantly expanded, from 2,000 tokens in GPT-3 to 2 million in Grok 4 Fast, facilitated by advancements in position embeddings and attention mechanisms. However, these models still tend to emphasize more recent information and struggle with retaining earlier content, which results in diminished recall for distant inputs. Benchmarks such as NIAH and LongBench reveal that, although extended context windows enable access to more information, they do not inherently enhance reasoning capabilities or the effective use of that information. LLM safety evaluations typically cover toxicity, misinformation, and system vulnerabilities. LongSafety specifically investigates model robustness under extended input conditions, evaluating performance with prompt lengths of up to 5,000 tokens. Agent safety evaluations focus on interactive tasks, with AgentSecurity and Agent Dojo assessing robustness against prompt injection attacks. In contrast, RedCode and MobileSafetyBench focus on evaluating the risks of executing code. Notably, AgentHarm is designed to assess agents' responses to harmful tasks and their ability to perform multi-step agentic workflows effectively. We extend the AgentHarm benchmark to evaluate agent behavior and performance under long-context inputs for both benign and harmful tasks. Moreover, AgentHarm assesses agents’ proficiency in executing multi-step tool use. The benchmark incorporates manually configured tools that simulate real-world applications, such as Google Search or an API for posting on social media, allowing for comprehensive control over task execution.
