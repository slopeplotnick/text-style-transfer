Certain bug-finding techniques, such as SNIPER, tend to generate an excessive number of redundant diagnoses, whereas others, like BugAssIST, fail to return a minimal set of diagnoses sufficient for program repair. Recently, Graussam [65] proposed a model-based approach to software fault localisation for ANSI C, introducing a well-defined fault model that accommodates complex language features, including pointers and arrays. This approach builds on CBMC encodings, where the relaxation process is carried out at the CBMC level rather than within the code, in contrast to the methodology presented in this work. Moreover, Graussam’s approach handles multiple test failures by constructing standard Model-Based Diagnosis (MBD) instances and solving them with HSD, ensuring that the diagnoses for each failing test case are minimal. However, this method introduces an additional post-processing step following fix enumeration, which may compromise the minimality of the resulting diagnoses. For these reasons, we did not include Graussam’s tool in our evaluation. First, it requires manual annotations for the functions it analyzes, which is impractical given the scale of our work, which involves over 1500 programs. Second, the tool is limited to integers and floats in C, making it incompatible with the C-PACK-IPAs benchmark. In contrast, Model-Based Diagnosis has been successfully applied in various domains, such as the restoration of consistency in Boolean circuits [4, 5, 8, 9, 10, 2, 64], C software [7, 11, 12, 66], knowledge bases [13, 14, 15], and spreadsheets [16, 17]. Furthermore, program slicing [67, 57, 68] has emerged as a valuable technique for fault localisation. One approach uses program slicing to identify the minimal sets of fixes necessary to correct a malfunctioning program, while another examines discrepancies between different software versions to pinpoint the root cause of the issue. This paper introduces a novel formula-based fault localisation technique for C programs and Boolean circuits, capable of addressing an arbitrary number of faults. By employing Model-Based Diagnosis (MBD) across multiple failing observations, the proposed method consolidates all failing test cases into a unified MaxSAT formulation, ensuring consistency throughout the localisation process and avoiding the generation of superfluous diagnoses.
