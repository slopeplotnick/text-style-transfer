In this section, we illustrate the features of our interface using a use case scenario called "Picture Composition." This feature provides users with clear information, such as the number of entities and events and types of relationships, offering an overview to guide the creation process. Figure 5.a demonstrates a diagram for picture composition, while Figure 5.b shows the story creation process of P4 using TaleFrame. Initially, P4 drags the event "Jack shoves Ryan," which corresponds to the first section of the diagram, onto the canvas (Figure 6.f). Subsequently, P4 attaches the two entities involved in this event to the designated box (Figure 6.g). Then, P4 connects the two entities (Figure 6.h1), clicks on the connecting line, and edits the relationship attributes (Figure 6.e), such as emotion type, action type, relationship strength, and relationship evolution. The "action_direction" attribute of the relationship is indicated by the "connect node," which defaults to the start and end points (e.g., "from Jack to Ryan"). However, for the event "confront each other" in the second section, where the action is mutual, a switch labeled "is bidirectional" is available. When activated, this switch automatically sets the action_direction to "bidirectional." By repeating this process, P4 successfully completes the remaining three sections, thereby linking the four event boxes to finalize the entire story framework (Figure 6.h2). Finally, P4 clicks the "Modify Story" button, edits the title and description, and assigns the four events to their appropriate stages in the narrative. The story is evaluated across seven dimensions according to the same criteria (Figure 6.1). Moreover, a comprehensive suggestion is generated based on the feedback provided (Figure 6.m). Consequently, P4 adjusts components with lower scores, such as adding more relationships to certain events. After making these adjustments, P4 selects the "Regenerate" button to produce a new version. Finally, P4 clicks the "Export" button to obtain the completed narrative, the diagrammatic representation, and the JSON file.
