To determine whether LLM-driven reasoning is viable for addressing MRTA challenges, we first replicated the SMART-LLM framework described by Kannan et al. in 2024 as a baseline study. This approach helped us identify fundamental challenges in employing LLMs for coordination before developing our enhanced framework. We evaluated this using the SMART-LLM benchmark dataset comprising 36 tasks across four complexity tiers: Elemental (single-action tasks), Simple (multiple objects with homogeneous robots), Compound (heterogeneous robots with specialized abilities), and Complex (requiring team formation for collaborative execution). Tasks were executed in the AI2-THOR simulation environment. For LLM configuration, Claude 4 Sonnet functioned as the reasoning engine with the temperature parameter set to 0.0 to ensure deterministic outputs and reproducible decision-making. Following the SMART-LLM methodology, we assessed performance using five metrics: Success Rate (SR), Task Completion Rate (TCR), Goal Condition Recall (GCR), Executability (EXE), and Robot Utilization (RU), collectively gauging task completion accuracy and multi-robot coordination efficiency. Upon identifying validation inconsistencies and issues regarding the reliability of LLM outputs during SMART-LLM replication, we developed and evaluated the Self Corrective-Agent Architecture. This innovation demonstrated that systematic validation and retry mechanisms could effectively address these challenges and establish the feasibility of LLMs in MRTA applications. The Self Corrective-Agent Architecture deploys multi-stage validation processes with hierarchical retry mechanisms. Key framework parameters included a maximum of three retries per agent, validation checkpoints at each procedural stage, such as task decomposition, allocation, and code generation, along with structured feedback loops for iterative refinement.
