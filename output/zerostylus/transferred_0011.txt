The AgentHarm public test dataset comprises 176 examples from 44 distinct tasks across 8 categories, such as disinformation and fraud. Each task can be modified with two modes: one providing a hint regarding the initial tool to utilize, and the other offering comprehensive step-by-step guidance. By combining these options, each task description can be configured into four distinct versions. In our experimental setup, we prioritize the simplest subset to minimize costs and provide an upper bound on model capabilities, ensuring that these capabilities are not the limiting factor and that context length remains the primary variable influencing effectiveness (see Section A). The AgentHarm framework employs automated scoring and assessment methods conducted by LLM-based evaluators (Zheng et al., 2023). We assess two primary metrics: firstly, the Harm Score, which ranges from 0 to 1 and is derived from manually applied rubrics evaluating harmful tasks; secondly, the Refusal Rate, which represents the proportion of instances identified as refusals by the LLM model (see Section B). The primary emphasis is placed on the Harm Score, while semantic evaluation is not employed, under the assumption that the simplest tasks can be assessed reliably. In Section E, modifications to the prompt and model are detailed for the purpose of refusal judgment. To systematically examine the impact of context length, we employ four padding methodologies: random padding utilizes arbitrary tokens from the tokenizer; non-relevant padding uses text from fiction genres such as humor, mythology, sci-fi, crime, and romance that are unrelated to the task category; relevant padding involves text from Wikipedia that aligns with the task category; and multi-task padding incorporates task descriptions sourced from the validation dataset. These padding types facilitate the examination of distinct elements: random padding ensures full control over reproducibility, non-relevant and relevant padding employ text that aligns with the desired style, and multi-task padding evaluates the model's robustness in handling semantically confounding context (see Sections F and G).
