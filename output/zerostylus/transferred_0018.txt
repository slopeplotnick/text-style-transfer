**2.3.1.3. Shared Strategy Analysis.** The final stage of the Phase Flow Analyses, as outlined in Algorithm 3, focuses on extracting shared strategic subsequences utilized by an agent across various trajectories. These trajectories are derived from the sequence of actions executed to solve different problems. To achieve this, Algorithm 3 begins by processing a list of LANGUTORY instances to compute their respective phase transition sequences (lines 1-3). Subsequently, the Generalized Sequential Pattern (GSP) algorithm [43] is employed to identify the longest common subsequences across all phase transition sequences (line 4). In the following step, the algorithm determines the inception of the identified shared pattern within each LANGUTORY instance (line 7) and calculates the corresponding phase lengths using run-length encoding (lines 8-10). To address variations in phase durations, Algorithm 3 then adjusts the shared strategy pattern by taking the minimum run-length across all LANGUTORY instances (line 11) and refining the common pattern accordingly (line 12). **2.3.2. Pattern Detection.** The structures of GRAPHECTORY and LANGUTORY offer significant utility in uncovering both known and previously unidentified patterns. While Phase Flow Analysis—including Shared Strategy Analysis—proves effective in identifying unknown recurring patterns, Pattern Detection Analysis complements this by facilitating the targeted search for established patterns within GRAPHECTORY or LANGUTORY. A key application of pattern detection lies in identifying known failure modes or inefficiencies within GRAPHECTORY. As demonstrated later (§3.4), this process enables the systematic and large-scale analysis of programming agents' failure modes. Specifically, users can analyze a small subset of failures, manually derive a list of characteristic patterns or anti-patterns based on the sampled data, and subsequently automate the search for these patterns across additional runs. This capability eliminates the need for repetitive manual intervention while ensuring comprehensive coverage. Finally, we illustrate how GRAPHECTORY and LANGUTORY are instrumental in systematically analyzing agentic programming systems and addressing critical research questions regarding agent functionality.
