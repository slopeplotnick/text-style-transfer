Certain agent frameworks, such as Roo Code and Terminus, simulate interactions with tools through the exchange of user messages. However, these frameworks may not fully leverage enhanced reasoning persistence due to the constraints imposed by the context management protocols outlined earlier. Consequently, it is evident that employing models which do not engage in cognitive processing offers a viable solution for achieving optimal performance within such architectures. To address the coexistence of reasoning data (non-agentic) and non-reasoning agentic data, we propose a straightforward strategy that integrates these data types through the application of carefully designed prompts. Moreover, the model demonstrates a substantial capacity to follow explicit instructions with precision, facilitating the seamless integration of tool execution within the reasoning framework. To illustrate the functionality of the cold-start mechanism, we selectively sample training data as detailed in Appendix Tables 6-8. It is important to note that different tasks necessitate tailored system prompts. Specifically, Tables 6-8 provide illustrative examples corresponding to a competitive programming prompt. Table 6 exemplifies reasoning data, wherein the system prompt explicitly instructs the model to engage in reasoning prior to producing a final response, utilizing the specialized <think></think> tag to delineate the reasoning pathway. Similarly, Table 7 presents the system prompt for non-reasoning agentic data, which offers guidance on invoking tools. In contrast, Table 8 introduces a system prompt designed to direct the model in executing multiple tool calls during its reasoning process. Although reasoning patterns in tool-use may occasionally lack robustness, the model is capable of generating the desired trajectories under certain circumstances, thereby establishing a foundation for subsequent reinforcement learning stages. Furthermore, incorporating a diverse set of reinforcement learning tasks emerges as a crucial strategy for enhancing model robustness. For tasks such as information retrieval, code development, and code analysis, we employ practical tools, including web search APIs, programming utilities, and Jupyter Notebooks. However, while these reinforcement learning environments are realistic, the prompts utilized are predominantly sourced from online repositories or synthetically generated rather than derived from authentic user interactions.
