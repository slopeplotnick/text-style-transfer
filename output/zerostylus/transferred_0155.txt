We employ Jupyter Notebook as a code interpreter to address complex reasoning tasks encountered by the Code Interpreter Agent. To achieve this, a diverse set of problems is curated, encompassing domains such as mathematics, logic, and data science. Each problem necessitates the execution of code by the model to derive appropriate solutions. In order to scale agent environments and tasks within reinforcement learning (RL), a generalized agent is introduced, which autonomously synthesizes 1,827 task-oriented environments. These tasks, while challenging to solve, are notably straightforward to verify. The synthesis workflow consists of three primary components: constructing environments and tools, generating tasks, and formulating corresponding solutions. Specifically, the workflow proceeds as follows. First, given a task category (e.g., planning a travel itinerary) and a sandbox equipped with a bash environment and a search utility, the agent utilizes these tools to retrieve relevant online information, subsequently storing it within the sandbox database. Next, the agent synthesizes a set of task-specific tools, each implemented as an independent function. To ensure the creation of tasks that are both challenging and automatically verifiable, the agent begins by proposing a simple task derived from the current database. Alongside this task, solution and verification functions are developed in Python. Notably, the solution function is constrained to using only tool functions or performing logical operations; it cannot call other functions or directly access the database. This restriction ensures that tasks are exclusively solvable through the predefined tool interface. Furthermore, the outputs generated by the solution function are systematically evaluated by the verification function to ensure accuracy. If the solution does not pass verification, the agent iteratively revises the solution or verification functions until the desired validation is achieved. Once a valid solution is established, the agent incrementally enhances the complexity of the task, refining the associated solution and verification functions in tandem. Moreover, during this iterative process, if the current toolset is insufficient to address the evolving complexity of the task, the agent expands the toolset to accommodate the requirements.
