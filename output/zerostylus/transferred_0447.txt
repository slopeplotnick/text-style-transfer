To illustrate the process of preparing the PEFT model, the model loader efficiently utilizes the init_adapter method. Subsequently, the responsibilities of loading, training, and saving the model are entrusted to the PEFT provider libraries and the LLaMA-Factory framework. In contrast to LLaMA-Factory, PEFT-FACTORY implements a dynamic loading mechanism for custom PEFT methods, thereby enhancing its extensibility and modularity. This design allows researchers and practitioners to seamlessly integrate custom PEFT implementations without necessitating modifications to the core codebase of PEFT-FACTORY. To demonstrate the capabilities of our Custom PEFT Interface, we have replicated two PEFT methods that are not part of any existing PEFT framework, namely BitFit (Ben Zaken et al., 2022) and SVFT (Lingam et al., 2024). During dynamic loading, the peftloader module automatically identifies and loads PEFT methods from a structured directory hierarchy. Each custom PEFT method is organized within its own subdirectory, containing two essential components: a config.py file that defines a PeftConfig subclass, and a model.py file that implements a BaseTuner subclass. The loader ensures the correct configuration and compatibility of each method by verifying required attributes, such as `peft_type` for configurations and `prefix` for model classes, before registration. Moreover, the loader facilitates the incorporation of configuration and model subclasses into the Hugging Face PEFT library through the register_peft_method function, which systematically adds these elements to the library's constants. This process is further elaborated by Algorithm 1, as detailed in Appendix B.1. Once loaded, the custom PEFT method is managed similarly to standard methods, as outlined in Section 3.1. To integrate a new method, adherence to the established folder structure within the PEFT methods directory is necessary, which can be specified by setting the environment variable PEFT_DIR (defaulting to ./peft), thereby ensuring alignment with organizational and class inheritance protocols. Finally, clarity regarding the implementation of example method templates is provided in Appendix C, alongside the PEFT-FACTORY documentation.
