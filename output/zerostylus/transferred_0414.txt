**Refined Paragraph:** We present a method for programmatic editing of PowerPoint slides through code execution, primarily utilizing the python-pptx library. This technique, widely used in prior implementations, allows for the systematic modification of slides via code, making it particularly effective for repetitive and well-defined tasks, such as executing a "find-and-replace" operation across all slides or facilitating the translation of textual content. However, it is insufficient for executing substantial structural modifications, such as altering the primary design or layout. To address these limitations, we introduce PPTPilot, a tool capable of interpreting and modifying raw XML files of slides, thus allowing precise modifications, such as repositioning elements to specific coordinates with minimal computational effort. By leveraging XML's comprehensive data representation for PowerPoint, this approach integrates seamlessly with existing tools for precise editing. Nevertheless, the XML-only editing path requires precise alterations, especially when extensive modifications across numerous slides are necessary, thereby rendering programmatic methods more efficacious in such scenarios. In determining the appropriate methodology, we employ a sophisticated tool designed to select the optimal editing method based on user preferences. Upon receiving a user request, our tool evaluates the specified input alongside the presentation's configuration—including visual and textual components—and determines whether modifications should proceed via programmatically generated code or direct XML manipulation. Given the inherent complexity of PowerPoint editing, achieving precision on the initial attempt presents significant challenges; thus, our approach is informed by previous research and incorporates mechanisms for addressing errors in automated processes.
