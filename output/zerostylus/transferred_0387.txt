The robot systematically evaluates its task execution efficacy and current workload status to ensure an equitable distribution of responsibilities and optimal system utilization. Consequently, the system iteratively assesses the likelihood of success to determine the appropriate course of action. It further elucidates its decision-making process by providing a concise explanation within a few sentences. This evaluation is crucial as it projects the anticipated workload following decision-making and assesses the confidence level of the decision, categorized as high, medium, or low. Moreover, the discourse focuses on the trade-offs necessary to reach the decision point. Context-aware reasoning is implemented through Nodes 2 and 3, which facilitate intelligent decision-making processes. Specifically, Node 2 is responsible for crafting situation-appropriate prompts, which are then utilized by Node 3 for comprehensive deliberation and analysis, as depicted in Figure 11. Node 3 employs a structured method to process information by invoking the LLM, incorporating two components: a system prompt that guides overarching reasoning and decision-making, and a user prompt that dynamically adapts to contextual developments. Therefore, these prompts are assembled to collectively serve as input to the model. Prior to creating prompts, the system provides broad guidance, while the user prompt offers specific information regarding the probability of success, current workload intensity, and developmental phase status. The LLM client executes the call using the invoke() function, transmitting the aggregated prompt as a message. Consequently, the model generates a natural language response that outlines its decision rationale, estimated probability of success, and detailed confidence level. In the subsequent step, we confirm and validate this response to maintain workflow integrity. This process ensures that the system integrates both the predefined system prompt and the dynamic user prompt. The constructed message is transmitted to the LLM client to resolve the intended task. During execution, the model produces a natural-language explanation that includes an explicit decision, underlying reasoning, estimated success rate, and associated confidence level. The node processes and outputs the resulting parameter, ensuring clarity and alignment for subsequent stages, where it serves as an input to maintain procedural coherence and progression.
