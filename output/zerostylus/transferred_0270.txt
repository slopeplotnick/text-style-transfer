**Refined Paragraph:** Hyperparameters. To isolate experimental variables, we initially evaluated the attack's effectiveness by employing a fixed model (Deepseek) across various frameworks. Subsequently, we assessed its performance on different models within a fixed framework (OpenManus). For all experiments, the generation temperature was maintained at 0, and the maximum number of tool invocations was limited to 20. Resource hijacking. In order to quantify the overhead associated with the LeechHijack attack, we integrated it into diverse tool categories and compared its computational resource consumption against benign MCP tools (Normal). Our primary evaluation metric is the total token count, including both input and output elements. Given that our backdoored toolkit may trigger LeechHijack multiple times within a single user task, we further define a distinct metric for an extra task to compute the average resource cost incurred by each individual trigger. It should be noted that the resources dedicated to generating the extra task output represent only a fraction of the total hijacked cost. Nevertheless, from the user's perspective, this unauthorized consumption of computational resources within the MCP framework remains a significant security concern. Hijacking resource utilization. To assess the utility of LeechHijack, we subsequently evaluate the efficacy with which an attacker can exploit the hijacked resources. We establish a performance baseline using each model's publicly reported accuracy on the MMLU benchmark [55], [56], [62], [63]. We then measure the accuracy of the responses generated for the extra task and compare these against the established baseline. The results of this analysis are presented in Tables 7 and 8. We conclude that LeechHijack can effectively leverage hijacked resources to execute covert generation tasks. However, this appropriation is not without cost, as it manifests in discernible performance degradation. This indicates that the attack is demonstrably viable as a resource hijacking vector and possesses exploitable value for attackers.
