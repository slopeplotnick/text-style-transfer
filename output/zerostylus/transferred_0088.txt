The functionality of the fine-tuned model is illustrated in Figure 1, showcasing its outputs derived through CoT tuning. This process begins by extracting key attributes from the query and item descriptions, such as product names, brands, model specifications, and target audiences, which are critical for relevance assessment. Subsequently, the compatibility of these attributes is evaluated to determine the relevance between the query and the item. Notably, CoT tuning enables the model not only to predict relevance labels with precision but also to provide explicit reasoning for its determinations, enhancing interpretability. However, upon analyzing the outputs of the fine-tuned model, a notable bias toward strict relevance discrimination becomes evident. Specifically, the model often categorizes products as "Irrelevant" when certain attributes mentioned in the query are absent from the item description, even if these attributes are non-essential and do not significantly influence the purchasing decision. This overly stringent approach results in an increased occurrence of false negatives, thereby reducing the model's recall rate. Consequently, this reduction negatively impacts the platform's transaction activity and revenue generation, underscoring the need for an alignment process that better reflects real user behavior. To mitigate this issue, the model is aligned with user purchasing behavior to ensure predictions are consistent with genuine user preferences. This is achieved by constructing a preference training set using historical logs of query-item pairs that were purchased but categorized by the fine-tuned model as "Irrelevant." These overly strict predictions are treated as "loser" samples, while GPT-40 is employed to generate reasoning outputs classified as "Relevant" for the same query-item pairs, which are designated as "winner" samples. Subsequently, the KTO algorithm is applied to align the model with these preferences. In contrast to alternative alignment methods, the KTO algorithm utilizes straightforward binary-labeled data for alignment, simplifying data construction and enhancing efficiency.
