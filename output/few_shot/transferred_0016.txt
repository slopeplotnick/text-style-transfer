The dataset comprises 81 questions, each addressing a specific health issue alongside a potential treatment approach. These issues span 50 disease and condition categories, including examples such as "Cancer," "Low back pain in adults," and "AIDS," as well as a general category termed "Other," which incorporates topics such as weight management. Figure 2 highlights the 10 most frequently mentioned categories within the health-related questions, while the complete list of categories and questions is presented in Appendix Table A4. To investigate how language models resolve real-world conflicts in biomedical knowledge, five prompt templates were designed to assess model performance across varied question-answering contexts. As detailed in Table 2, for every sample in the HEALTHCONTRADICT dataset, five distinct question prompts were generated using the templates:   - *Question: { Question }*   - *Question: { Question }*   - *Question: { Question }*   - *Context: { Correct Document }, Question: { Question }*   - *Context: { Incorrect Document }, Question: { Question }*.    The baseline models were selected based on two primary criteria: (i) evaluating whether fine-tuning on biomedical topics enhances domain-specific performance and (ii) determining whether larger model architectures yield improved results. Additionally, models capable of processing extended documents were prioritized, as outlined in Table 3. Each biomedical model was fine-tuned from its corresponding general-purpose model listed within the same row, with "Instruct" denoting models trained specifically to align with user instructions. For the baseline models, zero-shot inference was employed without further fine-tuning. Open-source language models ranging from 1B to 8B parameters were utilized to ensure applicability in resource-constrained healthcare environments. As illustrated in Table 4, performance differences between larger models (7-8B) remain relatively minor. Furthermore, the fine-tuned biomedical model, MEDITRON3-QWEN2.5-7B, underperforms when compared to the general model QWEN2.5-7B. Current top-tier evaluation benchmarks primarily focus on assessing the inherent knowledge of models, which limits their ability to discern fine-grained differences in model capabilities and task-specific performance outcomes.
