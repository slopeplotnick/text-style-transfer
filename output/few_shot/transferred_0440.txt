Agent frameworks, such as Roo Code and Terminus, enable user interaction with tools through message-based interfaces. However, these frameworks may not fully leverage the enhanced reasoning persistence discussed previously, owing to the constraints imposed by context management rules. To address this, we propose the use of models that minimize autonomous reasoning to achieve better performance in such setups. Given the availability of reasoning data (non-agentic) and non-reasoning agentic data, these can be effectively combined through the use of carefully designed prompts. We hypothesize that models can reliably follow explicit instructions, thereby integrating tool execution within the reasoning process.  To demonstrate the cold-start mechanism, we selected specific training data, as detailed in Appendix Tables 6–8. Notably, the system prompts vary across tasks. For instance, Table 6 illustrates a competitive programming prompt using reasoning data; the system prompt instructs the model to "think" prior to providing a final answer, employing a dedicated <think></think> tag to delineate the reasoning path. Table 7 includes a prompt designed for non-reasoning agentic data, wherein the system provides guidance on tool invocation. Table 8 presents a system prompt specifically developed to direct the model towards employing multiple tool calls within its reasoning framework. While reasoning capabilities within tool usage patterns may initially be limited, the model is occasionally capable of constructing the required reasoning paths, which subsequently facilitates progression in reinforcement learning (RL) stages. A diverse set of RL tasks is essential to enhance model robustness. For tasks such as search, code engineering, and code interpretation, real-world tools, including web search APIs, coding platforms, and Jupyter Notebooks, are utilized. Although the RL environments in these instances employ authentic tools, the prompts are either curated from online sources or synthetically generated, rather than derived from genuine user interactions.
