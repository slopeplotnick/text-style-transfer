This study advances the application of large language models (LLMs) in financial forecasting by introducing a novel approach to designing memory systems tailored to domain-specific tasks. By developing a memory system customized to specific professional fields, the study addresses the challenges of adapting general frameworks to specialized applications, thereby establishing a robust foundation for future research in this domain. The proposed methodology aligns with the objectives of the associated research track in three principal ways: (1) it transforms unstructured web-based news into a structured event database, facilitating the synthesis of organized knowledge from online content; (2) it integrates a dual-layer memory system to enhance the interplay between structured knowledge and the reasoning capabilities of LLMs; and (3) it demonstrates how this framework can be effectively applied to financial prediction, contributing to the interpretability of web news-based decision-making systems. By tackling the critical issue of extracting meaningful and dynamic knowledge from web content, the study directly addresses the track's emphasis on advancing knowledge management systems.  Memory systems have emerged as a pivotal component in enabling LLMs to manage complex tasks, reflecting a transition from internal memory storage within model weights to the use of external memory systems. Internal memory, while enabling rapid and persistent knowledge retention, poses challenges for interpretability and adaptability. To mitigate these shortcomings, researchers have developed external memory architectures, which expand LLM capabilities by overcoming constraints such as limited context lengths and difficulties in integrating knowledge. The evolution of external memory systems has progressed through distinct stages, beginning with retrieval-augmented generation (RAG), which stores unstructured text in vector-based databases. Although RAG facilitates updates to knowledge, its matching processes are primarily superficial. Subsequent advancements have prioritized systematic memory management, resulting in innovative designs such as GraphRAG, which employs knowledge graphs to structure memory; MemGPT, which functions akin to an operating system for memory management; and Zep, which leverages temporal knowledge engines to integrate historical and dynamic information, thereby enhancing the efficiency of reasoning and memory usage.
