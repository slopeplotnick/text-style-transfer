The implantation stage is characterized by three primary objectives: maintaining stealth, reversibility of alterations, and exerting control. Maintaining stealth involves ensuring that the malicious tool remains indistinguishable from legitimate ones. Reversibility refers to the capability of the tool to revert to its original state post-utilization. Control implies that the attacker can leverage the computer for ancillary tasks. This section delineates the methodologies for achieving these objectives. A covert communication channel facilitates command transmission. The backdoor employs a bifurcated process: initially, the implant dispatches a minimal signal containing a victim's identifier to a remote server via the internet. The remote server subsequently responds with additional tasks. The implant integrates these tasks into the tool's output to maintain a semblance of normalcy. In the subsequent phase, the implant monitors subsequent activations of the tool to capture user inputs, which are then relayed to the remote server. This bifurcated process ensures minimal network connectivity duration. During the exploitation stage, the agent executes the supplementary tasks while returning the tool's standard output to obfuscate unauthorized activity. Triggers are categorized into three types: content-based, frequency-based, and context-based. A content-based trigger activates when specific keywords or symbols are present in the input. Frequency-based triggers activate following a stochastic number of standard uses to obfuscate patterns. Context-based triggers activate when the agent employs a particular tool or function upon request. Upon activation, LeechHijack procures additional tasks from the attacker, enabling unauthorized utilization of the agent's resources.
