GraphMatch demonstrates efficacy in handling cold start nodes, analogous to the performance of TextMatch. This capability indicates the model's proficiency in utilizing text embeddings in the absence of graph information, thereby addressing the cold start problem. The architecture of GraphMatch comprises three integral components: a feature store, an inference service, and a graph database. These components enable the application of diverse GNN models that leverage specific node features while maintaining a unified graph structure to cater to varying requirements. Node sampling is facilitated by Cypher queries, allowing users to select the necessary node and edge types for inference purposes. The feature store primarily contains statistical metrics such as counts and averages. Snowflake is employed to maintain replicas of production databases and business data, with feature tables being updated on an hourly basis via SQL Mesh jobs stored in Feast. In instances where node features are absent from the feature store, default values are utilized. The graph database is managed using Neo4j Aura, with updates conducted via two distinct pipelines: a Kafka pipeline for rapidly changing entities like job postings, and an hourly Airflow pipeline for other entities. The database retains fundamental node information, including type, ID, and timestamp, to facilitate subgraph sampling for inference tasks. The inference service operates the model within a Python/FASTAPI microservice environment, deployed on EC2 instances equipped with Nvidia A10G GPUs. Autoscaling is driven by requests per second, as GPU/CPU utilization metrics are less reliable for predicting latency-related issues. To enhance inference speed, TextMatch embeddings are cached whenever freelancer profiles or job post descriptions are updated, ensuring that online inference processes are restricted to the GNN layers. This approach maintains embedding generation times below 70 milliseconds per embedding across all entity types, thereby ensuring scalability and supporting real-time applications.
