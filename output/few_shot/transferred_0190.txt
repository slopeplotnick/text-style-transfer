At the conclusion of the process, CFAULTS introduces a verification mechanism to ensure that all failing test requirements are fully incorporated. This mechanism enables the system to aggregate all failing tests into a single entity. Listing 2 presents a partial implementation derived from unrolling the program in Listing 1. In the context of Listing 2, CFAULTS employs global variables to denote the inputs and outputs associated with each failing test case (lines 1–3). For simplicity, the example focuses exclusively on test case 0 from the test list provided in Table 1. Each failing test case is assigned distinct variables. Furthermore, CFAULTS replaces traditional input/output functions, such as `scanf` and `printf`, with customized mechanisms—input arrays (lines 8–10) for capturing inputs and CFAULTS-specific print functions, respectively. These print functions emulate the behavior of `printf` but redirect the output to a buffer. The unrolled program ultimately generates code resembling the following:  ```c float _input_f0[3] = {1, 2, 3};   char _out_0[2] = "3";   int _ioff_f0 = 0, _off_0 = 0;    // ... inputs and outputs for the other tests   scope_0:   int f_0, s_0, t_0;   f_0 = _input_f0[_ioff_f0++];   s_0 = _input_f0[_ioff_f0++];   t_0 = _input_f0[_ioff_f0++];   _off_0 = printInt(_out_0, _off_0, f_0);   _off_0 = printInt(_out_0, _off_0, s_0);   _off_0 = printInt(_out_0, _off_0, t_0);   goto scope_1;   } // ... scope_1 and scope_2   final_step:   assert(strcmp(_out_0, "3") != 0 || // other assertions);   ```  Following the incorporation of all the possible runs and associated checks derived from the failing tests, CFAULTS modifies the unrolled program by introducing relaxation variables for specific program components, such as statements or instructions. These relaxation variables are systematically linked to the healthy variables, as referenced in Section 4. Each relaxation variable serves as a control mechanism, enabling the selective activation or deactivation of specific program components through Boolean assignments (`true` or `false`). CFAULTS further ensures that relaxation variable names remain distinct from the original variable names within the program, thereby avoiding naming conflicts. The system requires knowledge of the maximum permissible unrolling iterations to implement these modifications effectively.
