Methods for software bug detection such as SNIPER tend to produce an excess of unnecessary results, whereas alternatives like BugAssIST fail to provide the minimal set of fixes required to resolve the issue. Recently, Graussam et al. (2023) introduced an approach for bug detection in ANSI C programs utilizing a specific fault model, effectively accommodating complex constructs such as pointers and arrays. This approach leverages CBMC encodings, performing the relaxation step at the CBMC level, which distinguishes it from our methodology. It addresses multiple test failures by generating standard Model-Based Diagnosis (MBD) cases and resolving them with Hierarchical Set Decomposition (HSD), ensuring minimal repairs for each failed test. However, Graussam's method introduces an additional step post-fix enumeration, potentially compromising the minimality of the final outcomes. We chose not to evaluate this tool for two primary reasons: firstly, it necessitates manual annotations for function verification, impractical given our scope of over 1500 programs; secondly, it is limited to handling integers and floats in C, thus incompatible with the C-PACK-IPAs benchmark. Model-Based Diagnosis has been successfully implemented in various domains such as Boolean circuit repair, C software, knowledge bases, and spreadsheets. Additionally, program slicing has been utilized for bug detection in software. One approach employs program slicing to identify the smallest fix sets for a malfunctioning program, while another examines disparities between software versions to identify problem sources. This study introduces a novel formula-based method for bug detection in C programs and Boolean circuits, capable of addressing multiple issues simultaneously. It integrates Model-Based Diagnosis with multiple test failures into a unified MaxSAT formula, maintaining consistency and minimizing superfluous results.
