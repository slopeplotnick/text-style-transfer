Certain algorithms, such as OPRO and EvoPrompt, operate without the need for few-shot examples yet demonstrate an ability to enhance the performance of large language models through straightforward example selection methods. PromptSolution integrates a module that facilitates post hoc example selection, employing random selection and random search to incorporate few-shot examples into a static instructional prompt. The initialization of prompts often necessitates an array of preliminary prompts, for which we offer tools to automatically generate prompts from a task description, a basic prompt, or dataset samples. Optimizers are equipped with callbacks that enable progress monitoring during the optimization process; these mechanisms can evaluate the optimizer's condition at each iteration and terminate the procedure if necessary. Examples of such callbacks include those that monitor token usage, halting the process if usage exceeds a specified threshold, and others that log prompts and corresponding scores to a file for subsequent analysis. To evaluate the efficacy of PromptSolution relative to alternative methodologies, we conducted prompt optimization exercises on the GSM8K dataset (mathematical problems) and the SST-5 dataset (sentiment classification), employing the Gemma-3-27B model as the primary language model, and occasionally as the meta-model for optimizers requiring such a configuration. Comprehensive details on the datasets and experimental setup can be found in Appendix A.2. For comparative analysis, we examined the performance of PromptSolution optimizers CAPO, EvoPromptGA, and OPRO, alongside leading optimizers from AdalFlow and DSPy. To assess the impact of optimization, we evaluated three manually crafted prompts for each dataset, calculating average results. Standardized settings were applied across all optimizers to ensure uniformity, with token usage constrained to one million for combined input and output, maintaining cost efficiency below $0.15 per model evaluation. All frameworks commenced with solely a task description, devoid of initial prompts, to assess autonomous functionality. The evaluation involved both the unoptimized prompts and the optimized outputs from each framework, as tested on a distinct test set.
