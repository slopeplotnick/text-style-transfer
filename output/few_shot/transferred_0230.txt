Our study employed a methodology to decompose narratives into constituent elements such as events, characters, and settings, subsequently converting them into a JSON format. This structured data served as input for the GPT-4 model, which generated new narratives that retained core themes while introducing novel components. The quality of these stories was evaluated using specific criteria, including coherence, creativity, readability, and authenticity. Additional AI models, including GPT-4o, assessed both the original and generated narratives, categorizing them as "Chosen" or "Rejected." The resultant data, annotated accordingly, was preserved in JSON format to construct a comprehensive dataset. This dataset, as depicted in Figure 4, encapsulated emotional patterns and other relevant attributes. It was partitioned into a training set and a test set, with the majority allocated for training purposes. The training set comprised 8,866 preference pairs for model enhancement, while the test set included 985 unseen pairs. The Llama-3-8B model underwent optimization using the AdamW optimizer and the LoRA fine-tuning technique, with specific configurations for learning rate, batch size, and training epochs, achieving a test loss of 0.038. These configurations were selected based on expert recommendations, empirical testing, and available computational resources. Additionally, we conducted experiments to ascertain the significance of various narrative components in producing quality stories. Starting with a baseline version of the Llama-3-8B model incorporating all elements, we iteratively removed elements such as "events," retrained the model, and adapted it to the modified structure. Consistent training protocols were employed across all models to ensure experimental validity. Performance assessment of each modified model was conducted using a separate test set, and narratives were evaluated according to the established criteria, encompassing seven domains such as creativity and clarity. The findings of these evaluations will be discussed in Section 6.
