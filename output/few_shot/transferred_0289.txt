The dataset utilized in this study was developed by GPT-4o. Comprehensive details regarding the prompts, datasets, and model configurations can be found in the supplementary materials. Prompt engineering serves as a method to ensure that language models execute desired actions when provided with specific instructions. This study employed a technique known as prompt chaining, which facilitates the decomposition of large tasks into more manageable subtasks, thereby enhancing the models' capabilities in handling them effectively. For story parsing, the task was segmented into four components: identification of entities, identification of events, construction of a story outline, and identification of relationships. The output from each stage was subsequently utilized in the following stage. Prompt frameworks are instrumental in ensuring that models adhere to instructions accurately. In this research, the TIDD-EC prompt framework was employed, comprising five components: task definition, detailed instructions, dos and don'ts, examples, and user content. This framework ensures that responses are both accurate and relevant. A table is presented to illustrate the prompts used for the "Entity Extraction" task within the TIDD-EC framework. Additionally, four different prompting strategies were evaluated and compared in their effectiveness at converting stories into JSON format:   1. Zero-shot prompting: The task was explained using natural language without providing examples. 2. TIDD-EC framework: The task was configured using the TIDD-EC framework. 3. TIDD-EC + CoT: Chain-of-thought reasoning was integrated into the second strategy. 4. TIDD-EC + prompt chaining: The task was divided into four segments, each utilizing the TIDD-EC framework, and linked through prompt chaining.
