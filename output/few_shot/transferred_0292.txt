The challenge of processing a fixed number of clips arises when a model faces queries requiring variable temporal durations. For instance, a query such as "Where did I leave my glasses?" might necessitate only a few seconds of video, whereas "What happened in the second half of the soccer match?" demands a substantially longer video sequence. The conventional approach of utilizing fixed-length clips, while convenient, fails to accommodate the diverse temporal nature of real-world events, thereby lacking flexibility. To address this, we propose WorldMM, an innovative system designed to handle text and video information through a memory-based approach, optimizing the selection of memory types and temporal spans according to each query's requirements.  WorldMM distinguishes itself by managing text memory in two components: episodic memory, which records discrete events over time, and semantic memory, which maintains comprehensive knowledge such as relationships and habits, structured in knowledge graphs. In parallel, video memory divides an extended video into short clips for efficient retrieval. The system dynamically selects the most pertinent memory segments across various types and temporal scales, thus extracting only the necessary information for each query. This architecture mitigates the need for superfluous memory usage during information retrieval, thereby enhancing the focus and efficiency of the model.  By employing multiple graphs operating at distinct temporal levels—seconds, minutes, and hours—WorldMM adeptly retrieves information across varying degrees of detail appropriate for the respective time span. When engaging episodic memory for information extraction, it meticulously examines each memory layer to source relevant data from all temporal dimensions and subsequently evaluates the aggregated data to determine its applicability in response to the query. Ultimately, the system leverages both brief and extensive video clips to isolate the essential information required for accurate inference.  Moreover, the model iteratively acquires information by repeatedly selecting memories and formulating queries, enabling an exploration of diverse permutations and enhancing the breadth of potential solutions.
