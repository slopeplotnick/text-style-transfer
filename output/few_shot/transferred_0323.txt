The efficacy of model performance is influenced by the type of padding utilized; padding that mimics authentic text demonstrates superior performance compared to random padding, which in turn outperforms multi-task padding. The placement of padding is also critical, as situating context after the task description can degrade model performance relative to placement beforehand. Large Language Model (LLM) agents constitute AI systems employing pre-trained language models in iterative loops for decision-making and multi-step task management, utilizing tools autonomously. There has been substantial enlargement of context windows, expanding from 2,000 tokens in GPT-3 to 2 million in Grok 4 Fast, enabled by advancements in position embeddings and attention mechanisms. However, these models often exhibit a recency bias and demonstrate limited retention of older information. Evaluations such as NIAH and LongBench reveal that increased context windows enable models to process greater volumes of information, yet do not necessarily enhance intellectual capabilities or the efficacy of information utilization. Safety evaluations for LLMs encompass aspects such as toxicity, misinformation dissemination, and system vulnerabilities, with LongSafety evaluating model performance with extended inputs up to 5,000 tokens. For agent safety evaluations, interactive task scenarios are emphasized, wherein AgentSecurity and Agent Dojo assess resilience to prompt injection attacks, while RedCode and MobileSafetyBench examine risks associated with code execution. AgentHarm is an evaluation focusing on the handling of harmful tasks and multi-step workflow efficiency. Enhancements to AgentHarm include assessments of agent behavior and performance using extended context inputs for both safe and harmful tasks. It also evaluates tool utilization efficiency in multi-step tasks, incorporating tools configured to simulate real-world applications such as Google Search or social media posting APIs, thereby facilitating comprehensive control over task execution.
