This configuration facilitates code reuse and enables rapid experimentation with novel Parameter-Efficient Fine-Tuning (PEFT) methods. Researchers can independently develop and test new methods, which are automatically integrated into the system upon execution. The dynamic loading feature is particularly beneficial for comparing various PEFT methods as it allows all methods to be evaluated under consistent conditions, mitigating the need to duplicate code or manage version discrepancies. For the SuperGLUE benchmark, seven datasets are categorized into four tasks: natural language inference (NLI), which encompasses the CB dataset; question answering, inclusive of MultiRC, ReCoRD, BoolQ, and COPA; word sense disambiguation, encompassing WiC; and coreference resolution, inclusive of WSC. Additionally, datasets pertinent to text generation, typically utilized to evaluate generative Large Language Models (LLMs), have been incorporated. These comprise six datasets for language reasoning and comprehension, divided into three tasks: question answering, including MMLU, PIQA, SIQA, and OBQA; natural language inference (NLI), incorporating Hellaswag; and commonsense reasoning, including WinoGrande. Furthermore, there are three datasets designated for mathematical problem solving, organized into three tasks: question answering, including MathQA; mathematical word problems, including GSM8K; and basic mathematical problems, incorporating SVAMP. Additionally, there are three datasets for code generation, which are Conala, CodeAlpacaPy, and APPS. Certain datasets may necessitate minor formatting adjustments to conform to the input configuration of PEFT-FACTORY, elaborated in Appendix B.2.
