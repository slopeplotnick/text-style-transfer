Inconsistent outputs are frequently observed when utilizing Claude 3.5 Haiku and GPT-4, despite posing identical queries; errors in code execution occasionally arise. Furthermore, GPT-4 has a tendency to repeat previously encountered examples, potentially leading to errors, such as the incorrect use of objects for specified tasks. This issue highlighted deficiencies in the original system's error-checking capabilities, prompting the integration of mechanisms to identify and rectify mistakes within the LangGraph setup. This configuration synthesizes three core processes—task decomposition, task assignment, and code generation—into a cohesive operation. However, the inclusion of additional examples to tackle complex tasks resulted in excessive input lengths, overwhelming the system's capacity and causing failure. This challenge, where enhanced context aids understanding but exceeds input limitations, necessitated alterations to better handle inputs and context within the LTAA system. The dual issues of inconsistent outputs and input size restrictions informed the development of robust robotic collaboration methodologies, prioritizing quality assurance and input management design. To address these issues, a system was developed emphasizing error detection, incorporating feedback loops and retry mechanisms when necessary. In response to challenges identified during the SMART-LLM setup, and to evaluate the efficacy of LLMs in robotic task assistance, a Self Corrective-Agent Framework was devised. Unlike the previous single-agent paradigm, this novel framework employs three agents, each with a specific function—task decomposition, task assignment, and code generation—illustrated in Figure 2. Each agent independently implements error-checking protocols, all coordinated by the LangGraph system. The initial agent deconstructs extensive instructions into manageable steps, determining required actions, necessary objects, and their sequencing. Subsequently, the second agent optimally aligns these tasks with suitable robots, considering their capabilities and available resources, and establishes the execution sequence.
