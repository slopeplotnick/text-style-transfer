The system demonstrates improved performance by generating specific prompts tailored to each task, considering current factors such as the system's state, robotic capabilities, workload, and task phase. Consequently, it eliminates the need for 5,000-6,000 additional example tokens typically included in prompts, deemed redundant for the task. The process reduces token usage in two primary ways: firstly, it concentrates on task-relevant elements, circumventing unnecessary processes like task decomposition or supplementary code generation, which previously consumed approximately 14,000 tokens per task. Secondly, it substitutes these example tokens with a structured contextual framework, thereby reducing prompt tokens from 6,700 to 1,100. The system's efficacy in task allocation across multiple robots was evaluated based on criteria such as task completion rate, workload distribution equity, and adaptability to varied contexts. It was tested in three configurations where robots possessed distinct skill sets, though the task sequence remained constant at 36 tasks. Each configuration emphasized different robotic strengths by varying the probability of task-specific success for each robot. The system maintained robust performance while ensuring equitable task distribution, a critical factor in environments like construction, where both efficiency and fairness are crucial. In the configuration termed Medium Excels, robots with intermediate skill levels achieved the highest success rate, completing 87.8% of tasks effectively. The system assigned the majority of tasks to the robot adept at handling diverse tasks, leading to some workload imbalance. In this configuration, success rates by task type were 92.5% for precision tasks, 86.6% for tasks requiring dexterity, and 85% for tasks involving heavy loads. Although this setup yielded superior overall results, it also highlighted that prioritizing performance can occasionally result in uneven workload distribution.
