The robotic system evaluates operational efficiency and workload intensity, making decisions based on success probabilities. It provides a rationale for its choices through concise explanations, also assessing post-decision workload impacts and confidence levels (categorized as high, medium, or low). Additionally, it identifies any trade-offs involved in the decision-making process. The architecture comprises two core components, Nodes 2 and 3, which collaborate to facilitate informed decision-making. Node 2 generates context-appropriate prompts, while Node 3 employs these prompts for analytical reasoning. As depicted in Figure 11, Node 3 utilizes a method of reasoning by engaging the Large Language Model (LLM). This involves two distinct prompt types: a system prompt that directs the overall cognitive and decision-making processes, and a user prompt that adapts to current situational dynamics. These prompts are amalgamated to serve as model input. The system prompt provides overarching guidance, whereas the user prompt conveys specific information, such as success likelihood, workload status, and progression stage. The LLM client executes the call via the invoke() function, dispatching the composite prompt as a message. Subsequently, the LLM delivers a natural language response that elaborates on its decision, anticipated success probability, and confidence level, which is subsequently subjected to verification and validation. The system consolidates these composite prompts, merging the static system prompt with regulatory directives and the dynamic user prompt containing specific particulars, into a message for the LLM client. During execution, the model employs this input to generate a natural-language rationale, inclusive of a decision, underlying reasoning, anticipated success rate, and confidence level. This resultant output from the node is integral to maintaining clarity and coherence in subsequent stages.
