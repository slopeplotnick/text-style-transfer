Large Language Models (LLMs) are being utilized to automate the resolution of errors in C programming assignments. One notable system, CFAULTS, operates in conjunction with LLMs by employing a methodology wherein buggy segments of a given C program are identified and subsequently removed, creating a modified version of the program. The LLM is then tasked with completing the program by generating fixes for the missing components, which are subsequently subjected to testing for validation. If the proposed solution fails, the LLM receives test-derived feedback to iteratively refine its corrections. This iterative feedback mechanism enables LLMs to rectify a greater number of programs while making more precise, localized modifications, as compared to alternative approaches that lack formula-based fault localisation (FBFL) techniques or symbolic reasoning tools for program repair.    Fault localisation methods are generally classified into two categories: spectrum-based fault localisation (SBFL) and formula-based fault localisation (FBFL). SBFL leverages test outcomes to infer potentially faulty components of a program; however, its diagnostic accuracy is constrained by the fact that identified components may not necessarily be the root cause of observed failures. Conversely, FBFL methods offer enhanced precision by framing fault localisation as the identification of the smallest set of components responsible for program failure. For each failing test case, FBFL methods systematically compute the minimal diagnosis specific to the failure and subsequently aggregate all individual diagnoses into a comprehensive explanation of the program's malfunction.
