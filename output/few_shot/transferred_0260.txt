The system operates utilizing Spring Boot, with PostgreSQL serving as the database management system. Agronomists employ Python or MATLAB to develop simulators. The IT team utilizes Cross, an extensive framework, as the primary platform for application code development. Initially designed for the creation of Proof of Concepts, the platform has evolved to serve as the foundational basis for finished products. The organization maintains seven different versions to accommodate the requirements of three Product Owners. New versions are tailored to specific client needs, typically released on an annual basis.   According to the FEF framework's Architecture Dimension levels, the focus is on constructing software and determining the production process within the software product line. At Level 1, architectures are developed for individual systems without emphasis on reuse. Progressing to Level 2, there is an inclination towards the reuse of third-party infrastructure and common software components, such as middleware, though there is no formal integration of domain-specific assets. At Level 3, prevalent domain features are integrated into a software platform, establishing a reference architecture applicable to all applications, with a primary focus on platform utilization. This platform, however, lacks the capability to manage diverse configurations.   Advancing to Level 4, both commonality and variability within the domain are addressed, establishing a reference architecture for the entire software product line. Domain assets are developed to facilitate product creation, emphasizing the management of variability within the software product line architecture. At Level 5, the reference architecture becomes the central focus, with application architectures exhibiting minimal deviation from it. Automated product creation is feasible through the use of scripts, tools, and high-level programming languages, with application development primarily involving configuration within the constraints of the reference architecture, thereby enabling automated product setup.
