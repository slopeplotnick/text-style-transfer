The tool library comprises the Segmentator Tool for region localization, the Analyzer Tool with the Think with Image paradigm for region analysis planning, the Report Generator Tool utilizing strategic template selection, and the Quality Controller Tool, which performs quality assessment of radiology reports and provides feedback for feedback-driven adaptive enhancement. These tools support the entire process of automated radiology reporting. Figure 2 provides an illustrative workflow of the Radiologist Copilot. In terms of datasets, we leverage the liver radiology reporting task to validate the effectiveness of our proposed Radiologist Copilot. Specifically, we utilize the publicly available 3D CT dataset, AMOS-MM, which includes more than 2,000 CT scans with comprehensive radiology reports. This dataset contains 1,287 CT scans with reports for training and 400 CT scans with reports for validation. For the liver radiology reporting task, we filter the reports in the AMOS-MM dataset to identify those containing liver descriptions, extracting these descriptions as liver radiology reports. Consequently, the training set consists of 1,149 CT scans with liver reports, while the validation set comprises 367 CT scans with liver reports. The validation set is reserved to evaluate our method, whereas the training set is used to conduct report analysis. Initially, we obtain report embeddings using BioBERT, followed by performing K-means clustering on these embeddings to derive template reports. These templates are then summarized into liver analysis items, including liver surface, liver parenchyma, bile ducts, and liver lesions, which are employed in the Analyzer Tool. Implementation details reveal that our Radiologist Copilot is implemented based on the agentic framework OctoTools using Python 3.10.18, and experiments are conducted on NVIDIA L20 GPUs. The system operates in a training-free manner using pre-trained models. The principal reasoning component is facilitated by Qwen3-32B, while the Segmentator Tool utilizes TotalSegmentator for region elucidation. Moreover, the Analyzer Tool leverages the 3D medical VLM Hulu-Med for CT analysis. The maximum number of procedural stages is set to 10, with a maximum execution time of 500 seconds per case.
