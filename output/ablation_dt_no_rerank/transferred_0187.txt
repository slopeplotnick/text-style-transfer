The temporal phase classification, workload balance quantification, and phase-specific strategic frameworks are seamlessly integrated into the workflow through Node 1 (Phase Detection), which acts as the first reasoning checkpoint in the nine-node LTAA architecture. This node assesses the system's state and computes the temporal context necessary for the subsequent reasoning stages. It evaluates task progress and updates workload-related metrics in the LTAA framework. As shown in Figure 9a, the node processes four essential state variables from the system: the number of completed tasks, total task count, current workload distribution among robots, and the ideal target workload. These parameters collectively define the allocation context at each process iteration. Within this node, the framework determines the current progress ratio and uses it to classify the operational phase as early, middle, or late. Each phase represents a distinct decision context that influences how subsequent reasoning nodes balance success rates and workload fairness. Additionally, the node calculates the balance score to quantify task distribution evenness and identify imbalance severity based on deviations from the ideal workload. These metrics succinctly capture both temporal progress and workload dynamics. The node concludes its activities by updating the system state with parameters—allocation_phase, balance_score, imbalance_severity, and operational_mode—subsequently passed to the next node. This ensures that all downstream reasoning stages benefit from up-to-date contextual data on progress and workload status. As illustrated in Figure 9a, this process constitutes a unidirectional flow where the Phase Detection Node converts raw operational data into a structured decision context for the ensuing reasoning phase. Nevertheless, the phase-adaptive allocation strategy requires reliable LLM reasoning to enable context-appropriate decisions. However, the inherent variability of LLM outputs may fail to meet the quality standards necessary for safety-critical construction applications. To rectify the inconsistencies identified in the SMART-LLM framework implementation, the authors developed a comprehensive validation framework that ensures reasoning quality through weighted multi-criteria assessment and structured feedback mechanisms.
