For GraphMatch, we observe that integrating random and hard negatives is vital for achieving optimal performance. GraphMatch trained only with random negatives performs at a level comparable to TextMatch-small. We perform an ablation over the node features used by GraphMatch: the "no-feat" variant employs only TextMatch node embeddings, the "no-text" variant utilizes numerical node features without text embeddings, and the "full" version combines TextMatch node embeddings with numerical node features. Notably, GraphMatch-full, when trained with adversarial negatives, delivers the best performance, while GraphMatch-no-feat reaches performance comparable to TextMatch-large, albeit with a significantly smaller model size. This underscores that textual context is essential for accurate predictions, as evidenced by the diminished accuracy of GraphMatch-no-text. Moreover, the importance of temporally accurate sampling cannot be understated. Ensuring point-in-time correct subgraphs and node features during training is necessary for a model to generalize well to unseen nodes. To verify this, we train GraphMatch in two configurations. The "no-temporal-nodes" setup does not utilize temporal node features during training but always employs the latest feature version in the training dataset. In contrast, the "no-temporal-graph" setup does not sample temporally relevant subgraphs but retains access to all graph edges during training.
