TCAS is widely regarded as a prominent benchmark frequently examined in fault localisation research, consisting of a C program developed by Siemens with 41 versions containing intentionally introduced faults whose positions and types are documented. Conversely, C-PACK-IPAs includes a collection of student programs from an introductory programming course. For this study, the complete C-PACK-IPAs benchmark was utilized, comprising twenty-five programming assignments and a total of 1431 faulty programs derived from three laboratory classes. These programs cover a variety of topics, including numeric operations, input-output processing, loops, character manipulation, and vector processing, underpinning its efficacy in evaluating diverse program analysis tasks. In facilitating the analysis of C programs, CFAULTS uses pycparser, while CBMC version 5.11 is employed to encode these into CNF formulae. Due to the unavailability or obsolescence of the original code for BugAssIST and SNIPER, novel iterations of these algorithms have been developed. The prior version of SNIPER was limited, being compatible only with certain C programs and struggling with loops, recursion, and specific variables. Furthermore, a new iteration of HSD has been implemented to pinpoint erroneous code segments within ANSI-C programs, incorporating optional core minimisation, since the previous version was restricted to Boolean circuits. Consequently, BugAssIST, SNIPER, and HSD now function effectively with ANSI-C software, integrating components of the CFAULTS framework. This rigorous evaluation ensures that all algorithms' outputs consistently adhere to predetermined criteria, with correctness verified through CBMC. However, the primary focus is on BugAssIST, given its potential to yield results inconsistent with certain failing test cases. In contrast, the MaxSAT solution employed by CFAULTS and the hitting set methodology of HSD invariably align with all observational data. Although SNIPER's aggregation method ensures valid diagnoses, these may not be subset-minimal. Finally, BugAssIST systematically iterates through its scoring algorithm results until identifying one that comprehensively aligns with the observed phenomena.
