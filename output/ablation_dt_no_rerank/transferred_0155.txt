Code Interpreter Agent We utilize Jupyter Notebook as a code interpreter to tackle complex reasoning tasks. To achieve this, we curate a diverse set of problems spanning mathematics, logic, and data science, each requiring the model to harness code execution capabilities to derive a solution. General Agent To expand agent environments and tasks in reinforcement learning (RL), we employ an automated environment-synthesis agent that generates 1,827 task-specific environments. These tasks, although challenging to solve, are straightforward to verify. The synthesis methodology primarily involves the formulation of environments and tools, the creation of tasks, and the development of solutions to solve those tasks. Specifically, the process unfolds as follows: Firstly, given a task category, such as planning a travel itinerary, and a setup equipped with a bash interface and a search tool, the agent initially uses these instruments to generate or retrieve relevant data from the Internet and stores it in the sandbox database. Subsequently, the agent synthesizes a series of task-specific tools, each implemented as an independent function. To design tasks that are both complex yet automatically verifiable, the agent starts with a simple task derived from the existing database and accompanies it with its corresponding solution and verification functions implemented in Python. The solution function is constrained to invoking tool functions or conducting logical computations, and is restricted from calling other functions or directly accessing the database, thereby ensuring that the task is resolvable solely through the tool interface. Furthermore, the outputs generated by the solution function must be validated by the verification function. If the output is not successfully validated, the agent will refine either the solution or verification functions until the output passes verification. Subsequently, the agent increases the complexity of the tasks and updates both the solution and verification functions accordingly. During this progression, if the existing toolset proves inadequate for task resolution, the agent will enhance the toolset by integrating additional tools.
