For simulated data to be effective in computational research, it is essential that certain subgroups are directly comparable. To test this, we split each study's simulated dataset into "Male" and "Female" participants and performed invariance testing between them. Should this approach succeed, it would be possible to conduct computational comparisons among specific demographics. This section outlines the common methodology used across all four studies, except where distinct variations are noted in their respective sections. Figure 1 presents the experimental workflow of all four studies. The simulated data were generated using GPT4o-mini, updated as of October 2023, with default settings (Temperature 1.0, Top P 1.0, Frequency penalty 0.0, Presence penalty 0.0). The model received a procedurally generated prompt to impersonate an individual with specified demographic attributes and respond to the psychometric scale we aimed to test. Consequently, the prompt included the scale items, answer key, and a request to return answers as a single string of comma-separated values to facilitate data processing. Each prompt was issued independently, ensuring no recollection of prior interactions, thereby eliminating influence from previous prompts. For instance, one of the prompts read: "Impersonate a/an [Ethnicity] [Gender] of [Age] years of age from the United Kingdom. Answer the following [Number of items]-Item questionnaire. Each item ranges from [Likert scale range]. Use this key: [Response Key]. The questionnaire is as follows: [Questionnaire Items]. Provide the answers as a single, comma-separated string."
