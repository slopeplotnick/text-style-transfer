In our study, narratives were dissected into fundamental components like events, characters, and settings, which were meticulously encoded in a JSON format. Using this structured data, GPT-4 generated new stories that preserved core themes and structure while fostering innovation. We applied evaluation criteria tailored to the qualitative assessment of stories, encompassing analysis across seven dimensions: functionality, creativity, readability, emotional authenticity, clarity, perspective, and depth. Subsequently, alternative AI tools, such as GPT-4o, evaluated both the original and newly created stories, categorizing them as "Chosen" or "Rejected." In addition, the structured information, along with labeled stories, was systematically archived in JSON format to form a comprehensive preference dataset, illustrating emotional distributions, as seen in Figure 4. The dataset was split into a 9:1 ratio, with most allocated for training and a smaller portion reserved for testing. The training dataset included 8,866 preference pairs for model enhancement, while 985 preference pairs remained unseen in the test set. We then employed the AdamW optimizer and the LoRA-based fine-tuning method for refining the Llama-3-8B model, using a learning rate of 5e-6, batch size of 10, and 10 epochs, achieving an evaluation loss of 0.038 on the test dataset. These configurations were chosen based on model documentation, empirical testing, and available computational resources. Additionally, an ablation study was conducted to evaluate the significance of individual compositional elements in story formation. Initiating with a baseline model like Llama-3-8B, we integrated all elements to construct coherent stories. Sequentially, elements like the "event" unit were omitted, retraining the model to accommodate new data structures. All models underwent training under consistent conditions to ensure fairness. Moreover, revised stories were evaluated using the same seven-dimensional criteria as previous studies, with results set to be detailed in Section 6.
