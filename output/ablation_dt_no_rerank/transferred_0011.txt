The AgentHarm public test dataset contains 176 samples from 44 unique tasks across 8 categories such as disinformation and fraud. Each task can be expanded using modes: one offers a hint regarding which tool to use first, while another provides detailed, step-by-step instructions. Combining these modes results in four modifications of each task description. In our experiments, we focus on the simplest subset to reduce costs and establish an upper bound on model capabilities, thereby ensuring that capability is not the limiting factor and context length predominantly influences performance (see Section A). AgentHarm employs automatic scoring alongside evaluation through LLM judges (Zheng et al., 2023). We focus on two metrics: first, the Harm Score, which is a rubric-based completion score ranging from 0 to 1 for harmful tasks based on manually implemented rubrics, and second, the Refusal Rate, representing the fraction of samples flagged as refusals by the LLM model. Section B contains further details. Importantly, the Harm Score is used as the main metric, while semantic evaluation is omitted based on the assumption of reliable evaluation for the simplest subset of tasks. For assessing refusal tendencies, we apply minor modifications to the prompt and underlying model, with specifics detailed in Section E. To evaluate the effect of context length within a controlled setting, we use four types of padding: random padding, which employs tokens sampled stochastically from the tokenizer; non-relevant padding, which uses coherent text from various fictional genres such as humor, mythology, science fiction, crime, and romance, unrelated to the task category; relevant padding, which involves coherent text extracted from Wikipedia articles related to the task category; and multi-task padding, which integrates task descriptions from the validation dataset. These different padding methodologies allow us to isolate various experimental factors: random padding ensures full reproducibility, non-relevant and relevant padding introduce coherent in-distribution text, and multi-task padding assesses the model's robustness against semantically confounding context. Refer to Sections F and G for a more detailed explanation.
