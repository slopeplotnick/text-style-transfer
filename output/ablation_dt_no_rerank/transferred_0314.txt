Guiding LLMs on automated program repair involves integrating CFAULTS with Large Language Models (LLMs), using zero-shot learning, to improve the automated repair process for C programming tasks. In this approach, CFAULTS isolates the buggy sections of a C program and then presents a version of the program without these faulty statements to the LLM. This hybrid method employs a Counterexample Guided Inductive Synthesis (CEGIS) loop to iteratively enhance the program. The LLM is tasked with synthesising the missing portions, which are subsequently validated against a test suite. If the synthesized program remains incorrect, a counterexample from the test suite is offered to the LLM to facilitate a revised synthesis. Consequently, this technique allows LLMs to repair more programs and produce smaller fixes, outperforming configurations that exclude FBFL methods and leading symbolic program repair tools. Fault localization techniques are typically categorized into two main types: spectrum-based (SBFL) and formula-based (FBFL). SBFL methods estimate the likelihood of a component being faulty based on test coverage data from both passing and failing test runs. Although SBFL techniques are generally swift, they may lack precision, as components identified this way may not always be responsible for the failures observed. Conversely, FBFL methods are deemed exact. These approaches treat fault localization as a Model-Based Diagnosis (MBD) problem, aiming to identify minimal sets of faulty components. Typically, FBFL techniques make a MaxSAT call for each failing test case, resulting in a minimal diagnosis for each isolated failure, rather than jointly addressing all failures. An aggregation procedure then combines these diagnoses into a comprehensive explanation of the system's inconsistency.
