During each epoch of RL training, we implement the same SFT procedure, focusing on the reasoning traces generated during that epoch. In addition to the latent tokens produced by the model, we randomly replace a proportion of sentences with these latent tokens, as we did in the SFT phase. We find that this approach further encourages the model to engage in efficient reasoning. Typically, during inference, the model defaults to a discrete reasoning mode. However, when it encounters implicit-thought tags, it transitions to a latent reasoning mode (refer to Figure 1). As previously mentioned, we distinguish between discrete and latent reasoning modes using implicit-thought tags. It’s important to note that these tags are not special tokens within the model's vocabulary. Therefore, instead of training the model to autonomously use these tags, we simply prompt it. The model predicts the number of latent tokens to produce by determining a numerical value. Initially, the use of these tags is minimal, but we observe that their frequency increases during early RL training.
