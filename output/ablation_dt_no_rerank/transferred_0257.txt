In this study, several classical machine learning classifiers were employed to analyze EEG data, focusing on classifying motor imagery tasks. The classification process began with feature extraction methods and preprocessing techniques, followed by various classification algorithms. We applied logistic regression with elastic-net regularization, which effectively handles sparse data and prevents overfitting by balancing L1 and L2 penalties. Moreover, the saga solver was used for optimization, given its suitability for large datasets. With intercept scaling set to 1000 to manage features on different scales, we ensured reproducibility by applying a random state of 42. Additionally, a random forest classifier was implemented to classify EEG signals, utilizing an ensemble of decision trees. This approach enhances accuracy and reduces overfitting, as it effectively manages non-linear interactions between features. Comparatively, random forest is less prone to overfitting than individual decision trees. Both linear support vector machine (SVM) and radial basis function (RBF) kernel SVM were employed for classification tasks. The linear SVM effectively separates linearly separable data, while the RBF kernel SVM addresses non-linearly separable data by mapping features into a higher-dimensional space to capture complex patterns. Linear Discriminant Analysis (LDA) was also applied; it excels at maximizing the ratio of between-class variance to within-class variance, making it a powerful tool for linearly separable datasets. Furthermore, we explored various configurations of multilayer perceptrons (MLPs) with different architectures for EEG data classification. These included basic architectures with a single hidden layer and more complex models with three hidden layers, such as (10, 30, 10) or (20,) neurons, using ReLU or logistic activation functions. We trained these models using stochastic gradient descent (SGD) solvers with constant learning rates or Adam solvers, tuned for adaptive learning rates. Importantly, MLPs incorporated L2 regularization through the alpha parameter to prevent overfitting, with different alpha values rigorously evaluated to ascertain effectiveness. A constant learning rate was applied in several MLP configurations to ensure steady convergence. Additionally, both SGD and Adam solvers were meticulously fine-tuned to optimize performance across various feature extraction methods. To ensure reproducibility and traceability, each unique MLP configuration was systematically indexed (MLP_1 to MLP_17) and consistently employed across all experimental evaluations.
