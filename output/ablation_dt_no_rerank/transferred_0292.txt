Second, retrieving a predetermined number of clips constrains the model's ability to handle queries that require varying temporal durations. For instance, a question like "Where did I leave my glasses?" might need only a few seconds of video, whereas "What happened in the second half of the soccer match?" demands a much longer temporal context. Existing methodologies conventionally retrieve video segments of a fixed length for simplicity; however, this approach overlooks the diverse temporal scales of real-world events, thus limiting flexibility. Therefore, the retriever should dynamically gather information at multiple temporal scales, combining hour-level summaries with minute-level details as needed. In response to this limitation, we present WorldMM, a novel memory-based system designed to address this challenge. WorldMM constructs separate textual and visual memories and employs an adaptive retrieval strategy to select the optimal memory modality and temporal granularity for each query. The textual memory consists of two components: episodic memory, which stores multiple events across different time scales, and semantic memory, which encapsulates high-level, long-term knowledge such as relationships and habits, organized within knowledge graphs. Meanwhile, visual memory divides extensive video sequences into concise clips, systematically archived to facilitate efficient retrieval. The retrieval agent iteratively selects the most relevant memory from a range of modalities and temporal frames, ensuring that the model retrieves only the information necessary for each query. This multimodal memory selection design therefore prevents the model from conditioning on paired yet unnecessary modality memories when retrieving information for a given query, minimizing potential distractions during reasoning. Moreover, WorldMM is capable of extracting information at varying levels of detail across appropriate temporal spans by leveraging multiple graphs that operate at distinct temporal scales, such as seconds, minutes, and hours. When episodic memory is selected for retrieval, the system intricately examines each memory to gather potentially relevant information from all temporal levels. Finally, the collected candidates are jointly evaluated to determine which pieces of information should be used to address the query. The system then dynamically accesses both short- and long-term video contexts to assemble only the necessary information for effective reasoning. Furthermore, the model engages in a multi-step retrieval process by iteratively selecting memories and queries, thereby expanding the range of possible combinations and allowing for exploration of diverse solutions.
