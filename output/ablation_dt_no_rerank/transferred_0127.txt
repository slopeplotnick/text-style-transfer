This research not only advances the application of Large Language Models (LLMs) in financial forecasting but also lays down a novel paradigm for designing specialized memory mechanisms. By constructing a domain-specific memory architecture, we effectively tackle the adaptation challenges posed by generalized frameworks in professional environments, thereby establishing a solid foundation for future research in this discipline. Our contributions align with the track's scope in three key aspects: (1) Structured Knowledge Extraction—We transform noisy web news into a temporally-structured event knowledge base, thereby supporting scalable creation of web-based structured knowledge. (2) Semantic-LLM Synergy—Our dual-layer memory system enhances collaboration between structured knowledge and the LLMs' reasoning capability. (3) Web Application—We demonstrate the practical utility in financial forecasting, thereby improving the interpretability of decision systems based on web news. Moreover, we address the substantial challenge of extracting dynamic semantic knowledge from web corpora, which aligns precisely with the track's focus. Memory mechanisms have become crucial for enhancing large language models' ability to handle complex tasks, undergoing an evolutionary path from parametric internal storage to the adoption of external memory systems. Parametric memory encodes knowledge within the model's weights, offering rapid access and sustained retention; however, it inherently suffers from poor interpretability and challenges in selective updating. To overcome these limitations, researchers have developed external memory augmentation mechanisms—these approaches effectively compensate for LLMs’ constraints in context length and knowledge integration capabilities. The evolution of external memory systems is characterized by distinct phases, starting with retrieval-augmented generation (RAG), which stores unstructured text fragments in vector embeddings. Although RAG addresses knowledge updating issues, it achieves only superficial semantic alignment. As research progresses, the focus has shifted towards systematic memory management, leading to pioneering architectures such as GraphRAG, which integrates knowledge graph-based structured memory; MemGPT, which employs an operating system-inspired framework for hierarchical memory management; and Zep, which combines temporal knowledge engines to facilitate concurrent retrieval of historical and dynamic contexts. Collectively, these advances significantly augment both the reasoning capabilities and the efficiency of memory systems.
