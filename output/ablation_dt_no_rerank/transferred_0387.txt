The robot begins by analyzing its operational effectiveness and current workload status, after which it determines the most appropriate course of action based on expected success rates. Consequently, it provides a detailed explanation of its decision-making process, offering a few sentences articulating the rationale behind its choice. This analysis further projects the anticipated workload post-decision and evaluates the confidence level in the decision, categorizing it as high, medium, or low confidence. Moreover, the analysis highlights the trade-offs encountered during the decision-making process. The decision-making framework relies on two integral components—Nodes 2 and 3—to facilitate informed decisions. Specifically, Node 2 is dedicated to generating contextually appropriate prompts, which Node 3 subsequently uses to execute its cognitive processes. As depicted in Figure 11, Node 3 employs a systematic approach to reasoning by engaging the large language model (LLM). This approach consists of two essential components: a system prompt that directs overall reasoning and decision-making and a dynamic user prompt that adapts to current conditions. These prompts are methodically combined to form the model's input, with the system prompt providing overarching guidelines and the user prompt offering specific data such as anticipated success probability, current workload intensity, and the operational phase. The invocation occurs via the invoke() function of the LLM client, which transmits the combined prompt as a structured message. Consequently, the LLM generates a natural language response elucidating its decision-making process, estimating the likelihood of its success, and assessing its confidence level. This response is subjected to scrutiny and validation in the subsequent phase. The system integrates the preceding prompts, encompassing the fixed system prompt that outlines the rules and the variable user prompt filled with specific details. These components are assembled into a structured message sequence and forwarded to the LLM client for analysis. During execution, the model interprets this contextual input to generate a natural-language explanation that includes an allocation decision, justification, expected success rate, and confidence level. This response acts as the node's output and is utilized in the subsequent reasoning parsing and validation stage, thereby maintaining clarity and continuity throughout the analytical workflow.
