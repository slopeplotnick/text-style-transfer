The dataset was developed utilizing GPT-4o, with supplementary materials providing comprehensive details regarding the prompts, datasets, and model configurations. Prompt engineering, a technical methodology, is designed to optimize and regulate how pre-trained language models respond to input instructions. Specifically, we used the technique known as prompt chaining, which facilitates the decomposition of complex tasks into manageable sub-tasks, thereby enhancing the accuracy and reliability of processing outcomes. For the task of story parsing, we decomposed it into four distinct components: extraction of entities, extraction of events, formulation of a story outline, and identification of relationships. The outputs generated from each sub-task are subsequently utilized to inform the next step. To ensure the precise execution of instructions by the models, we employed the TIDD-EC prompt framework in this study. This framework comprises five integral components: task description, comprehensive instructions, specifications on permitted and prohibited actions, illustrative examples, and user content. Furthermore, we experimented with four distinct prompting methodologies and evaluated their efficacy in parsing narratives into JSON format: Zero-shot prompting, where the parsing task was articulated in natural language devoid of specific examples; the implementation of the TIDD-EC framework, which provided structural guidelines for task configuration; TIDD-EC + CoT, which was enhanced by integrating chain-of-thought reasoning; and TIDD-EC + prompt chaining, which segmented the task into four distinct subtasks, each defined using the TIDD-EC framework and subsequently connected through prompt chaining.
