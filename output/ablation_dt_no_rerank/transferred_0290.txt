To address the latency bottleneck imposed by real-time computation, we adopted a hybrid deployment strategy combining offline pre-computation with online caching. Specifically, we sampled a batch of high-frequency query-item pairs from search logs. For each query, a variable number of items were sampled to construct query-item pairs, which were then processed via offline inference using the LLM.
