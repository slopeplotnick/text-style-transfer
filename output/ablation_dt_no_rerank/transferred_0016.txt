The dataset contains a total of 81 questions, each one addressing a health issue and a potential treatment. These issues encompass 50 disease and condition categories, such as "Cancer," "Low back pain in adults," and "AIDS," along with a general well-being category termed "Other," which includes topics like weight management. Figure 2 illustrates 10 example disease and condition categories most commonly addressed by these health questions. The complete list of all questions and their corresponding categories can be found in Appendix Table A4. To explore how language models handle conflicts within real-world biomedical knowledge, we have developed five prompt templates to assess their performance in various question-answering contexts. As shown in Table 2, for each annotated instance from the HEALTHCONTRADICT dataset, we formulate five question prompts using these predefined structures: Question: { Question } Question: { Question } Question: { Question } Context: { Correct Document } Question: { Question } Context: { Incorrect Document }. Our baseline model selection was guided by two primary objectives: (i) to determine if fine-tuning within the biomedical domain enhances model performance, and (ii) to ascertain if larger model sizes correlate with improved performance outcomes. Additionally, we selected language models capable of processing extended context lengths for long documents. The specifics of the selected models are detailed in Table 3. Each biomedical model was derived by fine-tuning a general-domain model listed in the corresponding row. The term "Instruct" refers to models that have been fine-tuned to follow user instructions. In this study, we do not fine-tune any models; instead, we perform zero-shot inference using the selected baseline models. We evaluate open-source language models with sizes ranging from 1 billion to 8 billion parameters to ensure their applicability in resource-limited healthcare environments. As demonstrated in Table 4, the differences among larger language models (7-8B) are minor. Moreover, the fine-tuned biomedical model MEDITRON3-QWEN2.5-7B underperforms when compared to QWEN2.5-7B. These state-of-the-art evaluation benchmarks are limited in their ability to comprehend the variations in model capabilities because they primarily focus on a model's parametric knowledge.
