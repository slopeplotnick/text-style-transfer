Building on these innovations, this study introduces Lang2Logic, a novel framework designed to bridge the gap between natural language and computational logic. Lang2Logic transforms natural language inputs into Conjunctive Normal Form (CNF), a requisite format for logical reasoning tasks, thereby facilitating the translation of human-readable statements into machine-processable logical representations. Furthermore, the Lang2Logic framework integrates advanced computational tools and a unique linguistic processing method to ensure accurate transformation from natural language to CNF. Consequently, this structured pipeline enables the conversion of unstructured natural language into a canonical Satisfiability (SAT) problem representation, making SAT solvers accessible for practical real-world challenges. Lang2Logic aims to effectively bridge the gap between natural language comprehension and computational logic by converting English text into CNF—essential for SAT solvers, which operate on CNF structures. The Lang2Logic framework comprises three core components: Natural Language to Logical Expression, Logical Expression to CNF Conversion, and CNF Simplification. Each component is pivotal in ensuring an accurate and efficient transition from natural language input to a machine-readable CNF output. Initially, the first stage employs the ChatGPT o1-mini model API to translate natural language into logical expressions. The configuration of the o1-mini model was meticulously designed to recognize repeated variables across different clauses, output fixed logical expressions compatible with downstream processing, and ensure the output aligns with the necessary format for the Sympy converter. Using the ChatGPT API obviates the need for intricate grammar rule creation, thereby simplifying the transformation process. However, this approach is not without limitations, including elevated costs and potential instability as input size increases. To mitigate these issues, the Natural Language Toolkit (NLTK) is utilized for preliminary input processing. Specifically, utilizing the Punkt tokenizer provided by NLTK segments the text into individual sentences, enabling the o1-mini model to process each sentence autonomously. Therefore, this approach effectively mitigates errors such as sentence merging or omission. By employing a sentence-by-sentence methodology, the o1-mini model is capable of generating more precise logical expressions.
