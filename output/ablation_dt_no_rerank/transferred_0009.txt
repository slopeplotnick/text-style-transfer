(1) Synchronization. We assess the frame-level temporal correspondence between the source and edited videos using four correlation-based metrics: speech, gaze, blink, and pose. Each of these metrics captures a distinct aspect of motion dynamics, with mouth aspect ratio for speech, iris trajectory for gaze, eye aspect ratio for blinking, and upper-body joint angles for pose. Although identical to the metrics used in our training data filtering (subsection 3.2), they exclusively serve to curate the dataset and facilitate the final evaluation. Importantly, these metrics are not employed as a loss function in the model's training objective. (2) Edit Fidelity. To ensure the precise application and consistency of edits throughout the video, we rely on two complementary CLIP-based metrics. Directional CLIP Score. Initially developed for image editing, this metric has been adapted to the video domain to determine how consistently the per-frame visual transformation aligns with the overall edit direction in CLIP's embedding space. We offer two variants: an image-based version, which evaluates alignment with the visual edit implied by the edited first frame, and a text-dual version, which assesses alignment with the semantic edit described by the text prompt. The inclusion of the text-dual variant ensures fairness, considering that some baselines, like LucyEdit, rely solely on textual guidance and do not use the edited first frame. Essentially, the image-based version inquires if the transition from source to edited frames visually matches the change between the unedited and edited first frames, whereas the text-dual version checks if that visual change corresponds with the edit text's suggested transformation. CLIP-Text Alignment Score. To evaluate semantic accuracy further, we measure the extent to which each generated frame matches the textual description in CLIP space. This score gauges whether the video retains fidelity to the prompt semantics over time, complementing the directional measure explained above. Contrasting with the directional score, the CLIP-Text Alignment Score captures the semantic continuity of the video.
