This efficiency gain stems primarily from dynamic prompt generation: the system constructs task-specific prompts incorporating only current system state parameters such as task attributes, robot capabilities, workload specifics, and phase indicators, thereby eliminating the redundant 5,000-6,000 tokens of few-shot examples previously appended to every prompt irrespective of task requirements. This token reduction reflects two pivotal strategies: firstly, focused allocation scope that eliminates unnecessary procedures like decomposition and code generation, which previously accounted for around 14,000 tokens per task; and secondly, dynamic prompt generation which replaces the concatenation of redundant examples with a structured context provision, thus decreasing prompts from 6,700 to 1,100 tokens. The evaluation of the framework's efficacy in task allocation for multi-robot scenarios demonstrated its effectiveness through metrics such as task completion success rate, workload distribution uniformity, and adaptability to varying conditions. Empirical testing was conducted across three distinct configurations with varying robotic capabilities while maintaining the same sequence of 36 tasks. Each configuration emphasized different robot proficiencies by adjusting the probabilities of task success rates across diverse scenarios. This approach validated the system's capability to maintain competitive performance while ensuring equitable task distribution, which is critical in construction environments where operational efficiency and equitable resource allocation matter. The Medium Excels scenario, which exemplified balanced proficiency across medium-capability robots, achieved the highest overall success rate of 87.8%, thereby confirming the adeptness of the robots in task execution. While the system predominantly allocated tasks to the balanced-generalist robot, showcasing proficient handling across diverse task types, it resulted in workload distribution imbalance. Within this framework, feature-specific success rates were: careful tasks at 92.5%, dexterous tasks at 86.6%, and heavy tasks at 85%. Although this strategy maximized performance optimization, it concurrently highlighted the intrinsic trade-off between performance optimization and fairness in workload distribution decisions.
