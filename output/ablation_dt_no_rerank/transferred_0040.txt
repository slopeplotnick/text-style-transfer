Generic systems typically store information using isolated documents or facts. However, the domain of financial prediction necessitates structured event sequences to effectively capture temporal dependencies and joint effects among events. Stock prediction relies heavily on analogical reasoning rooted in historically similar scenarios; therefore, traditional single-document retrieval methods, which focus solely on semantic similarity, prove insufficient. Moreover, the conventional recency-based forgetting strategies or simplistic human forgetting simulations often conflict with the financial market's requirement to preserve effective long-term patterns. To address these challenges, this study proposes a dedicated event memory enhancement framework for financial markets, designed to construct a continuously evolving and precise repository of financial knowledge for language models. The main contributions of this work are as follows: First, we design a structured event-centric memory architecture that transforms unstructured market texts into annotated memory units with timestamps, event types, and relevant entities like companies and industries. This framework enables explicit modeling of temporal dependencies, organizing market information into semantically connected structured sequences, thus laying a solid foundation for subsequent retrieval and reasoning. Furthermore, we develop an event sequence similarity-based retrieval mechanism that transcends the limitations of traditional semantic retrieval. By using the current event sequence as a query, our framework accurately locates complex historical patterns akin to the present market context, thus transitioning from text matching to sophisticated pattern discovery. Finally, through systematic experiments, we validate the framework's effectiveness, showing superior stock prediction accuracy in comparison to robust baseline models. The explicit modeling of event sequences allows the framework to identify and present key events influencing stock price trends and their dynamic evolution paths, significantly enhancing prediction credibility and transparency in the decision-making process.
