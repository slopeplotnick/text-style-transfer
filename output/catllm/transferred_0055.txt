In order to simplify a program statement, it is encapsulated within an if-statement utilizing a condition defined by a relaxation variable. Specifically, in the program depicted in Listings 3, lines 5 and 6 are modified by CFAULTS through the application of relaxation variables _rv1 and _rv2, which subsequently appear as lines 11 and 12 in Listings 4. When if-statements are relaxed, the content within the then and else segments adheres to the same relaxation principle. However, for the conditions of if-statements, a ternary operator is employed, as illustrated in line 14 of Listings 4. If the relaxation variable evaluates to true, the original if condition is executed; otherwise, an alternative relaxation variable, such as _ev4 in Listings 4, determines whether the program proceeds to the then-block or the else-block, if one exists. These relaxation variables are tailored to each failing test and facilitate decision-making regarding entry into the then or else-block. Regarding expression lists, CFAULTS applies a similar approach to general program statements, substituting each expression with a ternary operator rather than an if-statement. If a program component is disabled, the expression defaults to 1; for instance, the initialization of variable i in line 11 of Listings 3 is transformed into a ternary operation in line 17 of Listings 4. All relaxation variables within a loop are defined as Boolean vectors to facilitate the relaxation of statements throughout the loop. Each vector component serves to relax the loop's statements for each iteration. The maximum number of loop iterations is established by the CFAULTS user, and CFAULTS similarly addresses inner loops by creating arrays of arrays. For basic program statements within a loop, CFAULTS encompasses them with if-statements, associating relaxation variables with the iteration number. Each loop possesses its unique offsets to index relaxation variables, which are initialized immediately prior to the loop and incremented at the conclusion of each iteration, as exemplified in line 19 of Listing 4.
