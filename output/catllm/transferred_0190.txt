These variables are associated with the healthy variables delineated in Section 4. Each relaxation variable possesses the capability to activate or deactivate a program segment by being assigned a boolean value. CFAULTS ensures that the nomenclature of relaxation variables does not conflict with the original variable names present in the program. Consequently, CFAULTS necessitates awareness regarding the maximum permissible number of times the program should undergo unrolling.
