The present study explores Lang2Logic, an innovative methodology aimed at bridging everyday language with computational logic. Specifically, Lang2Logic transforms ordinary language into a format known as Conjunctive Normal Form (CNF), which is essential for logical reasoning tasks. This transformation facilitates the conversion of natural language into a format comprehensible by computers. Lang2Logic employs specialized computational tools and a proprietary language processing technique to ensure accurate conversion from standard language to CNF. Consequently, this framework enables the translation of everyday language into a SAT problem, a type of logical problem solvable by computers, thereby simplifying the application of SAT solvers to practical issues. The objective of Lang2Logic is to integrate natural language comprehension with computer logic by converting English into CNF, a necessary format for SAT solvers given their reliance on CNF. Lang2Logic comprises three primary components: the transformation of ordinary language into a logical expression, the conversion of the logical expression into CNF, and the simplification of CNF. Each component is crucial to ensuring the accuracy and efficiency of the conversion from everyday language to CNF. Initially, the ChatGPT o1-mini model API is utilized to transform ordinary language into a logical expression. The configuration for the o1-mini model was designed to identify repetitive elements, provide logical expressions compatible with other tools, and conform to the format requisite for the Sympy converter. The utilization of the ChatGPT API obviates the need for intricate grammar rule construction, thereby simplifying the transformation process; however, it may incur higher costs and demonstrate reduced efficacy with larger inputs. In order to address these challenges, NLTK was employed for input preparation. Specifically, NLTK's Punkt tokenizer segments the text into individual sentences, enabling the o1-mini model to process each sentence independently, thereby mitigating errors such as sentence mixing or omission. By processing text sentence-by-sentence, the o1-mini model can generate more accurate logical expressions.
