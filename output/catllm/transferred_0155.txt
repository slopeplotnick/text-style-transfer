The implementation of a code interpreter agent, utilizing Jupyter Notebook, facilitates the resolution of complex problems across domains such as mathematics, logic, and data science, requiring the execution of code to ascertain solutions. Furthermore, in the realm of reinforcement learning (RL), a general agent is employed to expand agent environments and task scales, generating 1,827 task-focused environments. Specifically, the creation of these environments involves a systematic process of developing environments and tools, constructing tasks, and devising solutions. Initially, for a given task type, such as planning a trip, and with a setup that incorporates bash and search-based tools, data is procured from online sources and stored within a database. Subsequently, the agent formulates a suite of tools for the task, each instantiated as a function. Consequently, to generate tasks that are challenging yet amenable to automatic verification, the agent commences with a straightforward task, utilizing the current database, alongside its corresponding answer and verification functions developed in Python. The answer function is restricted to employing tool functions or performing logical calculations, precluding the invocation of other functions or direct database utilization, thereby ensuring that the task is solvable exclusively through the designated tools. It is imperative that the outcomes derived from the answer function undergo scrutiny by the verification function. In instances where the verification is unsuccessful, adjustments are made to the answer or verification functions until acceptance is achieved. The complexity of the task is incrementally enhanced, with corresponding updates to the answer and verification functions. Should the existing tools prove insufficient for task resolution, additional tools will be integrated by the agent.
