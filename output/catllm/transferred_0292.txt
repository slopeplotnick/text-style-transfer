The challenge of utilizing a fixed number of clips poses significant limitations for models tasked with addressing queries that necessitate varying temporal lengths. For instance, a query such as "Where did I leave my glasses?" may only require a brief segment of video, whereas a question like "What happened in the second half of the soccer match?" demands a considerably extended video duration. Traditionally, clips of fixed lengths are employed due to ease of implementation; however, this approach fails to accommodate the inherent variability in real-life event durations and thus lacks flexibility. To address this issue, WorldMM has been developed as an innovative system. This system leverages memory to independently manage text and video, employing an intelligent mechanism to select the most suitable type of memory and temporal length for each query. The text memory is bifurcated into episodic memory, which tracks discrete events temporally, and semantic memory, which encompasses overarching knowledge such as relationships and patterns, organized within knowledge graphs. The video memory component segments lengthy videos into manageable clips, organized for efficient retrieval. The system strategically selects the most pertinent memory from diverse types and temporal spans, ensuring that only the necessary information is retrieved for each query. This design mitigates the need for the model to employ superfluous memory types, thereby enhancing focus. WorldMM is capable of extracting information at various levels of detail across appropriate temporal spans by utilizing multiple graphs that operate at different time scales, such as seconds, minutes, and hours. When episodic memory is employed to retrieve information, each memory is scrutinized to extract useful data from all temporal levels. Subsequently, all collected information is evaluated to determine its relevance to the query. Ultimately, both short and long video clips are utilized to extract only the information necessary to resolve the query. Additionally, the model engages in a multi-step information retrieval process by iteratively selecting memories and queries, allowing for the exploration of various combinations and the identification of additional options.
