The present study enhances the application of large language models (LLMs) in the domain of financial forecasting and introduces an innovative approach to the design of memory systems tailored to specific professional fields. By developing a memory system customized for particular areas of work, issues related to adapting general frameworks to professional situations are addressed, thereby establishing a robust foundation for future research in this domain. Specifically, the objectives of the track are fulfilled in three primary dimensions: Firstly, disorganized web news is systematically structured into an event database, facilitating the generation of organized knowledge from web content. Secondly, a dual-layer memory system is employed, augmenting the interaction between structured knowledge and the reasoning capacities of LLMs. Thirdly, the applicability of this approach in financial prediction is demonstrated, thereby simplifying the comprehension of web news-based decision systems. The study addresses the significant challenge of extracting meaningful and dynamic knowledge from web content, aligning with the track's focus. Memory systems have emerged as crucial components in aiding LLMs to manage intricate tasks, transitioning from internal information storage within the model to the utilization of external memory systems. Internal memory incorporates knowledge within the model's weights, ensuring rapidness and durability, yet presents challenges in terms of interpretability and updates. To mitigate these issues, external memory systems have been developed, facilitating LLMs in overcoming limitations such as short context lengths and difficulties in knowledge integration. The evolution of external memory has occurred in stages, initially marked by retrieval-augmented generation (RAG), which maintains unstructured text within vector databases. While RAG aids in updating knowledge, it achieves only a basic level of information matching. As research has advanced, emphasis has shifted towards systematic memory management, resulting in novel designs such as GraphRAG, which utilizes knowledge graphs for structured memory, MemGPT, functioning as an operating system for memory management, and Zep, integrating time-based knowledge engines to link historical and dynamic information, thereby enhancing reasoning and memory efficiency.
