In this study, the components of the system are designed to operate collaboratively through a shared configuration, facilitating the interchangeability of these components while ensuring seamless integration within the system. Each component can be configured independently; however, a consolidated configuration option is available via ExperimentConfig, which simplifies the management of all settings in a centralized location. The module pertaining to large language models (LLM) is employed to extract responses from any large language model, with its primary configuration supporting concurrent operations and maintaining an account of token usage. Specifically, three types are delineated: APILLM is utilized to access models via an API, such as those provided by OpenAI or Anthropic, and an illustrative setup via the DeepInfra API is provided. LocalLLM is designated for employing models locally on one's computer utilizing transformers. VLLM leverages the v11m library to efficiently manage numerous requests and is optimized for GPU compatibility. The predictor module is responsible for extracting answers from the model's output. For classification tasks, the predicted category is selected, while for mathematical problems, the final answer is extracted. One predictor variant identifies the initial occurrence of a potential answer, whereas a more robust variant seeks answers demarcated by specific tags. For instance, to compute the total number of fish across all fishbowls, incremental additions are performed, such as adding 62 fish to 3 fish, resulting in 65 fish. The task module retains data and other pertinent information related to the task at hand, and it also determines the testing approach for prompts, ensuring that unnecessary tests are avoided to conserve resources. This module is crucial for achieving optimal results efficiently. Tasks have been configured to be beneficial for natural language processing applications. Moreover, technical terminology is employed consistently, with domain-specific concepts clearly defined, maintaining precision throughout.
