The reliance on fixed-length video clips introduces challenges for computational models tasked with addressing questions that require varying temporal contexts. For instance, a query such as "Where did I leave my glasses?" may only necessitate a few seconds of video analysis. Conversely, a question like "What happened in the second half of the soccer match?" demands examination of significantly longer time segments. Conventional approaches typically involve processing video clips of predetermined durations, as this simplifies implementation. However, such methods fail to accommodate the diverse temporal dynamics of real-world events, thereby limiting flexibility and accuracy.    To address these limitations, we propose **WorldMM**, an innovative system designed to enhance both memory management and temporal adaptability. WorldMM incorporates distinct memory architectures for text and video, employing a strategically optimized mechanism to select the most relevant memory type and temporal scope for each query. The textual memory system is bifurcated into *episodic memory*, which records sequential events over time, and *semantic memory*, which encapsulates overarching knowledge, such as relationships and behavioral patterns, organized within knowledge graphs. For video memory, long-form videos are segmented into shorter clips, which are stored in a manner that facilitates efficient retrieval when required.    The WorldMM framework dynamically selects the most contextually relevant memory—considering both type and duration—to extract only the information pertinent to answering a given query. By avoiding irrelevant memory retrievals, this approach ensures computational efficiency while maintaining focus on the task at hand. Furthermore, the system operates across multiple temporal granularities (e.g., seconds, minutes, and hours) by utilizing a series of graphs corresponding to these distinct time scales. When episodic memory is engaged, the system systematically evaluates all memory entries across these levels of temporal resolution to identify the most informative content. Subsequently, the collated information undergoes further refinement to determine its relevance for the query.    Ultimately, WorldMM integrates both short and extended video segments to extract precise information needed for reasoning. Additionally, the model employs an iterative multi-step process for memory selection and query refinement, enabling it to explore diverse combinations and identify alternative solutions. Through this iterative approach, the system ensures adaptability and robustness in handling a wide range of questions requiring variable temporal and contextual resolutions.
