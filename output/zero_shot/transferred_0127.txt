This study advances the application of large language models (LLMs) in financial forecasting and proposes a novel framework for designing domain-specific memory systems. By developing a memory architecture tailored to specialized fields, this research addresses challenges associated with adapting general-purpose frameworks to professional contexts and establishes a robust foundation for future investigations in this domain. The contributions of this study align with the objectives of the track in three key dimensions. First, it systematizes unstructured web-based news content by transforming it into a structured event database, thereby facilitating the derivation of organized knowledge from web data. Second, it introduces a dual-layer memory system that enhances the integration of structured knowledge with the reasoning capabilities of LLMs. Third, it demonstrates the applicability of this framework in the domain of financial forecasting, improving the interpretability of web news-based decision-making systems. The study tackles the significant challenge of extracting actionable, dynamic knowledge from web content, in alignment with the overarching goals of the track.  Memory systems have emerged as critical components in enabling LLMs to manage complex tasks, evolving from internal knowledge storage mechanisms to the incorporation of external memory systems. Internal memory stores information within the model’s parameters, offering high-speed access and longevity. However, these systems are inherently opaque and challenging to update. To address these limitations, researchers have developed external memory systems, which mitigate constraints such as limited context length and the difficulty of integrating diverse knowledge sources. The evolution of external memory systems has progressed incrementally. Early approaches, such as retrieval-augmented generation (RAG), utilized vector databases for the storage and retrieval of unstructured text. While RAG facilitated the updating of knowledge, it predominantly operated at a superficial level of information matching. Subsequent advancements in memory technology have focused on the systematic organization of information, leading to innovative designs. Examples include GraphRAG, which employs knowledge graphs to enable structured memory; MemGPT, which emulates an operating system for efficient memory management; and Zep, which integrates temporal knowledge engines to bridge historical and dynamic information. These advancements collectively enhance the reasoning and memory capabilities of LLMs, addressing critical limitations in their ability to perform knowledge-intensive tasks.
