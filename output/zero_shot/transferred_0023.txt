Certain algorithms, such as OPRO and EvoPrompt, function effectively without the use of few-shot examples, yet they enhance the performance of large language models, even when basic example selection methods are applied. The promptsolution framework integrates a module that facilitates post hoc example selection, employing techniques such as random selection and random search to incorporate few-shot examples within a fixed instruction. For initial prompts, many optimization processes require a foundational set of prompts. To address this, we have developed tools that automatically generate prompts based on task descriptions, basic prompts, or dataset examples. Furthermore, optimizers in this framework are equipped with callbacks that monitor the optimization process, assessing the optimizer’s state at each step and halting the process if necessary. Illustrative examples include a callback that tracks token usage and terminates if a specified limit is exceeded, as well as another that archives prompts and their corresponding scores for future analysis.  To evaluate the efficacy of the promptsolution framework in comparison to alternative tools, we conducted a series of prompt optimization tests using the GSM8K dataset (mathematical problems) and the SST-5 dataset (sentiment classification). In these tests, the gemma-3-27B model served as the primary language model and occasionally as the meta-model for optimizers necessitating such a component. Additional details regarding the datasets and configuration protocols can be found in Appendix A.2. For comparative purposes, we examined the optimizers CAPO, EvoPromptGA, and OPRO within the promptsolution framework, alongside leading optimizers from AdalFlow and DSPy. To assess the impact of optimization, we also evaluated three manually crafted prompts for each dataset, averaging their results. To ensure fairness, we standardized the settings across all optimizers and imposed a token budget constraint of one million for both input and output, maintaining total costs below $0.15 for this model. All frameworks commenced with merely a task description, devoid of initial prompts, to ascertain their autonomous performance quality. Both unoptimized prompts and those optimized by each optimizer were assessed using a separate test set.
