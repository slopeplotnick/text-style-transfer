The implantation phase is characterized by three primary objectives: maintaining concealment, facilitating reversibility, and exercising control. Concealment involves ensuring that the malicious tool is indistinguishable from legitimate ones. Reversibility refers to the capability of the tool to revert to its original state post-utilization. Control signifies the attacker's ability to commandeer the computer for supplementary activities. In this section, we delineate the methodologies for achieving these objectives. A covert mechanism is employed for the transmission and reception of commands. The backdoor operates via a bifurcated procedure: initially, the implant conveys a minimal signal containing the victim's identifier to a remote server via the Internet. The remote server subsequently dispatches additional tasks. The implant integrates these tasks into the tool's output, rendering it ostensibly normal. In the subsequent phase, the implant monitors the tool's ensuing utilization to capture user inputs and relay them to the remote server. This dual-phase procedure ensures that the network connection remains brief. During the exploitation phase, the agent executes the additional tasks and then restores the tool's customary output, thereby ensuring that the user remains oblivious to any alterations. Triggers are categorized into three types: content-based, frequency-based, and context-based. A content-based trigger is initiated if the tool's input contains a specific term or symbol. A frequency-based trigger is activated after a stochastic number of normal utilizations to circumvent detectable patterns. A context-based trigger is activated when the agent employs a particular tool or function in response to a request. Upon activation of a trigger, LeechHijack procures supplementary tasks from the attacker, enabling unauthorized usage of the agent's resources.
