**Code Interpreter Agent**   The application of a Jupyter Notebook framework facilitates the resolution of complex problems across various domains, including mathematics, logic, and data science. These problems necessitate executing code to derive solutions.  **General Agent**   To expand the scope of agent environments and tasks in reinforcement learning (RL), an automated agent is employed to generate 1,827 task-specific environments. These tasks are characterized by their complexity in terms of solution derivation while maintaining simplicity in validation. The process of task development and solution generation encompasses three primary steps:    1. **Data Acquisition and Storage**: For a specific task type, such as trip planning, the agent utilizes predefined tools, including bash scripts and web-based search utilities, to gather relevant data from online sources. This data is subsequently stored in the database for further processing.   2. **Tool Construction**: The agent creates a series of task-specific tools, each implemented as distinct functions, to facilitate task execution.   3. **Task Generation and Refinement**: To ensure the tasks are challenging yet verifiable, the agent initializes with a basic task leveraging the existing database. The creation process involves developing solution functions and verification functions in Python. Constraints are imposed on the solution function to restrict its operations solely to logical calculations or the utilization of tool functions; direct interaction with the database or other functions is prohibited. This limitation ensures that tasks can only be solved using the defined tools. Moreover, the solution output generated by the answer function must pass validation through the verification function. If discrepancies arise during validation, the agent iteratively refines the solution or verification functions until successful validation is achieved. Subsequently, the agent increases the complexity of the task and updates the corresponding solution and verification functions. In instances where the existing set of tools proves insufficient to address the increased complexity, additional tools are incorporated into the system.    This systematic approach supports the development of progressively challenging yet manageable and automatically verifiable tasks, thereby contributing to the advancement of RL environments and applications.
