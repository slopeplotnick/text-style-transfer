To ensure the validity of the simulated data for computational research, it is essential that the data's distinct groups are comparable. To examine this, the simulated data was divided into two groups, "Male" and "Female," and their consistency with each other was evaluated. Successful consistency would indicate that specific subgroups within the data could be reliably compared. This section outlines the general methodology employed across all four studies, except in cases where deviations are explicitly noted in the respective sections. Figure 1 illustrates the experimental setup applied uniformly to all four studies.   The simulated data was generated using GPT4o-mini, an iteration of the GPT-4 model updated as of October 2023. Default model parameters were utilized, including a temperature setting of 1.0 and a top-p value of 1.0, with no frequency or presence penalties applied. Each prompt provided to the model described a hypothetical individual characterized by attributes such as age, gender, and ethnicity. The model was instructed to complete a pre-designed questionnaire intended for validation purposes. The prompt included the questionnaire items, response options, and specific instructions requiring the model to return its responses as a single string of values, separated by commas, to facilitate post-processing.   Furthermore, each prompt submission was executed independently, with no retention of memory from prior prompts. This ensured that responses to subsequent prompts were not influenced by earlier interactions. An example of the prompt structure is as follows: "Pretend to be a [Ethnicity] [Gender] who is [Age] years old and resides in the UK. Answer this [Number of items]-item questionnaire. Each question uses a Likert scale from [Likert scale range]. Use this key to answer: [Response Key]. The questions are: [Questionnaire Items]. Provide your responses as a single string of values separated by commas."
