Upon completion of the process, the CFAULTS system incorporates a verification step to ensure the inclusion of all failing test requirements. This procedure consolidates all failing tests into a singular entity. Listing 2 presents a segment of a program generated by unrolling the code found in Listing 1. In this context, CFAULTS employs global variables to delineate the inputs and outputs associated with each failing test, as demonstrated in lines 1 through 3 of Listing 2. For illustrative simplicity, this example focuses solely on the component corresponding to test 0 from the compilation of tests enumerated in Table 1. Each failing test is assigned distinct variables. Additionally, input arrays are utilized in lieu of the scanf function (as depicted in lines 8 through 10), whereas CFAULTS' custom print functions, which mimic the functionality of printf but direct output to a buffer, replace the printf function. Consequently, the unrolled program culminates in code resembling the following:  ```cpp float _input_f0[3] = {1, 2, 3};  char _out_0[2] = "3";  int _ioff_f0 = 0, _off_0 = 0;  // ... inputs and outputs for the other tests  scope_0:  int f_0, s_0, t_0;  f_0 = _input_f0[_ioff_f0++];  s_0 = _input_f0[_ioff_f0++];  t_0 = _input_f0[_ioff_f0++];  _off_0 = printInt(_out_0, _off_0, f_0);  _off_0 = printInt(_out_0, _off_0, s_0);  _off_0 = printInt(_out_0, _off_0, t_0);  goto scope_1;  }  }  // ... scope_1 and scope_2  final_step:  assert(strcmp(_out_0, "3") != 0 || // other assertions);  } ```  Following the incorporation of all conceivable executions and verifications derived from the failing tests, CFAULTS further modifies the unrolled program by introducing relaxation variables for each segment of the program, such as statements or instructions. These variables are associated with the healthy variables discussed in Section 4. A relaxation variable may enable or disable a program segment by being configured to true or false, respectively. CFAULTS ensures that the names of the relaxation variables do not conflict with those of the original variables within the program. To achieve this, it is essential for CFAULTS to ascertain the maximum permissible unrolling iterations for the program.
