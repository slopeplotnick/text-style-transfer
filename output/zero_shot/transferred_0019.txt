The research employs a layered modeling approach to integrate distinct statistical distributions that independently address various components of the statistical process. This methodology demonstrates the independence among certain factors within the system. For example, while central processing units (CPUs) with identical specifications executing different instructions may exhibit varying energy consumption patterns, these variations are shown to be mutually independent. The proposed approach establishes a Worst-Case Energy Consumption (WCEC) model to estimate the overall energy usage of a device. This model comprises two primary phases, as illustrated in Figure 1: (1) the measurement phase, which quantifies the energy consumed by benchmarks executed on the hardware, and (2) the modeling phase, which constructs a Bayesian model to estimate energy consumption attributable to the programming language.  The study focuses on statically typed programming languages designed for the Java Virtual Machine (JVM). To ensure a unified modeling framework for these languages, the approach measures the energy consumption of bytecode patterns, which are generated when the source code of the programming language is compiled into bytecode (as depicted in Figure 2). To achieve this, microbenchmarks are designed, with each microbenchmark representing a specific source code statement encompassing all possible data types and sizes for a given operation (see Figure 3). Energy measurements for each microbenchmark are obtained by monitoring current, voltage, and execution time during each measurement cycle. Each cycle begins with configuring the multimeter to ensure accurate measurement readiness. To mitigate potential memory noise, the garbage collector is activated prior to each cycle to clear residual memory. For robustness, each microbenchmark cycle is executed ten times to account for variability in measurements. Furthermore, a split-plot experimental design is employed, in which the order of microbenchmark cycles is randomized to prevent bias arising from sequence effects.
