The robotic system evaluates its operational performance and workload, making decisions based on the probability of success. It articulates its rationale for each decision in a concise manner. Furthermore, it assesses the anticipated workload following the decision and expresses its level of confidence in the decision as high, medium, or low. The system also addresses the trade-offs involved in reaching the decision. This decision-making process is facilitated by two components, referred to as Node 2 and Node 3. Node 2 generates context-appropriate prompts, which are then processed by Node 3. Within Node 3, as illustrated in Figure 11, a reasoning methodology is employed by invoking the Large Language Model (LLM). This process involves two distinct parts: a system prompt that directs the overall reasoning and decision-making, and a user prompt that adapts according to the current context. These prompts are amalgamated to form the input for the model. The system prompt provides general guidance, while the user prompt offers specific details such as the likelihood of success, the current workload, and the operational stage. The LLM client executes the invocation using the invoke() function, transmitting the combined prompt as a message. Subsequently, the LLM generates a response in natural language, elucidating its decision, the likelihood of success, and the associated confidence level. This response undergoes verification and validation in the subsequent step. The system consolidates the fixed system prompt, containing overarching rules, with the dynamic user prompt, encompassing specific details. These combined prompts are then conveyed as a message to the LLM client for analysis. During operation, the model utilizes this input to generate a natural-language explanation encompassing the decision, reasoning, expected success rate, and confidence level. This outcome serves as the output of the node and is integral to maintaining transparency and alignment in subsequent processes.
