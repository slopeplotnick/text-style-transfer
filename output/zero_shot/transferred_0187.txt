The classification of temporal phases, workload balancing, and the development of phase-specific strategies constitute integral components of the workflow initiated at Node 1, the Phase Detection Node. Node 1 represents the initial checkpoint within the nine-node framework known as LTAA. This node assesses the current state of the system and determines the temporal context necessary for subsequent procedural steps. Specifically, the Phase Detection Node evaluates task progress and updates workload metrics. As illustrated in Figure 9a, this node draws upon four primary inputs from the system: the number of completed tasks relative to the total number of tasks, the distribution of workload among robots, and the ideal workload distribution. These inputs collectively facilitate the establishment of contextual parameters for the ensuing stages of the process.  Within this node, the framework computes the progress level and categorizes the system into one of three temporal phases: early, middle, or late. Each of these phases corresponds to a distinct decision-making scenario, thereby influencing subsequent nodes in terms of balancing task completion rates and ensuring equitable workload distribution. Additionally, the node calculates a balance score to evaluate the uniformity of task allocation and quantify the discrepancy between the actual workload distribution and the optimal configuration. These metrics serve to encapsulate both procedural progress and workload dynamics in a streamlined manner.  Upon completion of its operations, the Phase Detection Node updates the system state by generating key variables: *allocation_phase*, *balance_score*, *imbalance_severity*, and *operational_mode*. These updated parameters are transferred to the next node to ensure that subsequent processes are informed by the most current data regarding task progress and workload distribution. As depicted in Figure 9a, the workflow within the Phase Detection Node is structured as a linear flow, transforming raw data into structured decision-making information for the succeeding phase.  The allocation strategy employed within this node necessitates robust reasoning capabilities derived from large language models (LLMs) to inform effective decision-making processes. However, the inherent variability in LLM outputs poses challenges, particularly in critical applications such as construction tasks. To address the limitations identified during the implementation of the SMART-LLM framework, the authors developed a validation mechanism. This framework evaluates reasoning quality through a weighted assessment and feedback system, thereby enhancing the reliability and accuracy of decision-making processes within the LTAA framework.
