In this study, we employed a methodology to decompose narratives into fundamental components such as events, characters, and settings, subsequently transforming them into a JSON format. Utilizing this structured data, GPT-4 was tasked with generating novel stories that retained the core concepts while integrating innovative elements. To evaluate the quality of the generated stories, we established specific criteria, assessing dimensions such as coherence, creativity, readability, and authenticity. Additional AI tools, notably GPT-4o, were engaged to scrutinize both the original and newly generated narratives, categorizing them as either "Chosen" or "Rejected." The information extracted from these stories, including the annotations, was preserved in JSON format to construct a comprehensive dataset. This dataset illustrated emotional patterns and various other details, presented in Figure 4. For analytical purposes, the dataset was bifurcated into training and testing subsets, with the majority allocated for training. The training set comprised 8,866 preference pairs to enhance model performance, whereas the test set included 985 novel pairs. We refined the Llama-3-8B model using the AdamW optimizer in combination with the LoRA fine-tuning method, configuring parameters such as learning rate, batch size, and training iterations, culminating in a test loss rate of 0.038. These configurations were selected based on expert recommendations, empirical validation, and available computational resources. Additionally, we conducted experiments to ascertain the significance of various narrative components in the generation of high-quality stories. Beginning with a standard implementation of the Llama-3-8B model, which incorporated all narrative elements, we systematically excluded components such as "events" individually, retrained the model, and adapted it to accommodate the modified structure. All models were trained under consistent conditions to ensure the validity of comparative analyses. Each modified model's performance was evaluated using an independent test set, with ratings applied according to the previously established criteria across seven domains, including creativity and clarity. The findings of these experiments will be detailed in Section 6.
