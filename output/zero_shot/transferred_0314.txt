Large Language Models (LLMs) are increasingly being employed to autonomously address issues in C programming assignments. The system known as CFAULTS integrates LLMs through a methodology that identifies faulty segments within a C program and subsequently presents the LLM with a version of the program where these erroneous sections have been excised. The LLM is then tasked with completing the absent portions, after which the proposed corrections undergo testing to assess their efficacy. In instances where the correction proves ineffective, the LLM receives feedback from the test results to attempt revision. This iterative process enables LLMs to rectify a greater number of programs while making more precise modifications compared to alternative approaches that do not utilize Formula-Based Fault Localization (FBFL) techniques or symbolic tools for program repair. Fault localization methods are categorized into two primary types: spectrum-based (SBFL) and formula-based (FBFL). SBFL relies on test outcomes to hypothesize which sections of the program may be flawed. However, SBFL's accuracy is limited as it does not ensure those identified sections are indeed responsible for the error. Conversely, FBFL methods offer greater precision by conceptualizing fault localization as a task of identifying the minimal set of erroneous components. For each failed test, FBFL methodologies employ a process to establish the minimal diagnosis specific to that failure, subsequently amalgamating all findings into a singular explanation for the program's malfunction.
