Certain agent frameworks, such as Roo Code and Terminus, facilitate user interaction with tools via messages. However, these frameworks may not fully capitalize on enhanced reasoning persistence due to the context management rules previously discussed. Consequently, it is recommended to utilize models that do not engage in reasoning for improved performance within these configurations. Given the availability of both reasoning data (non-agentic) and non-reasoning agentic data, one straightforward approach to integrate these is through the application of well-structured prompts. It is posited that the model's ability to adhere to explicit instructions enhances its capability to incorporate tool execution into the reasoning process. To illustrate the functionality of the cold-start mechanism, selected training data is presented in Appendix Tables 6-8. It is noteworthy that different tasks necessitate distinct system prompts. Tables 6-8 provide examples pertaining to a competitive programming prompt. Despite potential limitations in reasoning within tool-use patterns, the model occasionally generates necessary pathways, which prove beneficial in subsequent stages of reinforcement learning. A diverse array of reinforcement learning tasks is vital to augmenting the model's robustness. For tasks such as search, code engineering, and code interpretation, authentic tools are employed, including web search APIs, coding tools, and Jupyter Notebooks. Although these reinforcement learning environments are genuine, the prompts utilized are either sourced from the Internet or fabricated, rather than derived from actual user interactions.
