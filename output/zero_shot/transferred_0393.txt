The TCAS program is a widely recognized testing framework frequently employed in fault localization research within software engineering. TCAS is a C program developed by Siemens, consisting of 41 versions with deliberately introduced faults. In contrast, the C-PACK-IPAs dataset comprises student-written programs generated during an introductory programming course. Specifically, for this study, the complete C-PACK-IPAs dataset was utilized, encompassing 25 programming assignments and 1,431 buggy programs from three laboratory classes. These programs address fundamental concepts in programming, including numerical computations, input-output operations, loop constructs, character handling, and vector manipulation. The C-PACK-IPAs dataset has been instrumental in facilitating the evaluation of diverse program analysis techniques.  The proposed framework, CFAULTS, employs the pycparser library for parsing C programs and utilizes the CBMC tool (version 5.11) to translate C programs into Conjunctive Normal Form (CNF) formulas. As part of the bug localization process, it was necessary to redevelop the algorithms used in BugAssIST and SNIPER because the original codebases for these tools were either unavailable or nonfunctional. The prior version of SNIPER exhibited limitations, as it was only compatible with a subset of C programs and encountered difficulties in handling loops, recursion, and certain variable types. Additionally, modifications were made to the HSD algorithm to extend its applicability to fault localization in C programs, both with and without the core minimization feature, as the original implementation was restricted to Boolean circuit analysis. Consequently, the redeveloped versions of BugAssIST, SNIPER, and HSD were adapted to work seamlessly with C programs, leveraging components from CFAULTS.  The study rigorously evaluated the algorithms using criteria to ensure correctness of fault localization results, primarily validated through CBMC. While BugAssIST is prone to producing results that do not satisfy all failing test cases, the MaxSAT solution provided by CFAULTS and the method implemented in HSD consistently align with all observations. SNIPER, although capable of generating correct results, does not always guarantee the minimality or simplicity of its output. For BugAssIST, results ranked based on a scoring mechanism were systematically reviewed until an outcome matching all observed test failures was identified.
