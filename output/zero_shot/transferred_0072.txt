Certain methodologies for identifying bugs in software have notable limitations. For example, approaches such as SNIPER often produce an excessive number of irrelevant results, while tools like BugAssIST fail to identify the minimal set of fixes necessary to resolve a given issue. A more recent method, proposed by Graussam, addresses the problem of bug detection in ANSI C programs by employing a specific fault model capable of handling advanced program features, including pointers and arrays. This approach leverages CBMC (C Bounded Model Checker) encodings, with relaxations applied directly at the CBMC level rather than modifying the source code itself, distinguishing it from alternative strategies. The method is designed to address multiple test failures by formulating them as standard Model-Based Diagnosis (MBD) problems and solving these using Hitting Set Dualization (HSD) to ensure the proposed fixes are minimal for each test failure. However, Graussam’s approach introduces an additional step following the identification of fixes, which may compromise the minimality of the final solution set.   The present study does not analyze Graussam’s tool for two primary reasons: (1) it requires manual annotation of checked functions, a process that is impractical for large-scale projects (e.g., over 1,500 programs, as in the present research), and (2) it operates exclusively on programs involving integers and floating-point variables in C, rendering it inapplicable to benchmarks such as C-PACK-IPAs. Beyond this specific method, Model-Based Diagnosis has been successfully utilized in various domains, including troubleshooting Boolean circuits, C programs, knowledge bases, and spreadsheets. Another prominent approach is program slicing, which has been used for fault localization in software. One program slicing approach identifies all minimal sets of potential fixes for a malfunctioning program, while another examines differences across software versions to isolate the root cause of errors.  This paper introduces a novel, formula-based approach to fault localization in C programs and Boolean circuits, capable of addressing multiple simultaneous failures. The proposed method employs Model-Based Diagnosis to integrate all failed tests into a unified MaxSAT formula, ensuring consistency and eliminating superfluous results. This approach advances the state of the art by providing a robust mechanism to identify minimal and accurate solutions for fault localization in complex systems.
