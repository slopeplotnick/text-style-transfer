The dataset comprises 81 inquiries, each addressing a specific health issue and its corresponding treatment option. These inquiries span 50 categories of diseases and conditions, including "Cancer," "Low back pain in adults," and "AIDS," as well as a general well-being category labeled "Other," which encompasses aspects such as weight management. The analysis identifies ten representative categories frequently referenced within health-related inquiries, as depicted in Figure 2. The comprehensive list of questions and their corresponding categories is available in Appendix Table A4. To explore the capacity of language models to address real-world conflicts in biomedical knowledge, we have developed five distinct prompt templates aimed at assessing their performance across various question-answering scenarios. For each instance within the HEALTHCONTRADICT dataset, we generate five question prompts using the following templates: Question: { Question } Question: { Question } Question: { Question } Context: { Correct Document } Question: { Question } Context: { Incorrect Document }, as illustrated in Table 2. The selection of baseline models was guided by two primary objectives: first, to evaluate whether fine-tuning enhances performance in biomedical domains, and second, to determine whether larger models exhibit superior performance. Moreover, the selected language models are specifically designed to accommodate long-form documents, as detailed in Table 3. The fine-tuning process of each biomedical model, derived from a general model listed in the same row, is depicted in Figure 1. The term "Instruct" refers to models that have been fine-tuned to adhere to user instructions. For the selected baseline models, we perform zero-shot inference without implementing any model fine-tuning strategies. We evaluate open-source language models ranging from 1B to 8B parameters to ensure their effectiveness in resource-limited healthcare settings. As shown in Table 4, the variations among larger language models, specifically those in the 7-8 billion parameter range, are minimal. However, the fine-tuned biomedical model, MEDITRON3-QWEN2.5-7B, demonstrates inferior performance compared to the QWEN2.5-7B model. The predominant evaluation benchmarks are insufficient in discerning the differences in model capabilities, as they primarily focus on assessing the model's inherent knowledge.
