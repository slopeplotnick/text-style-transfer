Retrieving a fixed number of clips constrains the model's capacity to address queries necessitating variable temporal durations. For instance, a question such as "Where did I leave my glasses?" may require only a few seconds of video footage, while a query like "What occurred during the second half of the soccer match?" demands a much longer temporal context. Current methodologies, which necessitate a predetermined length of video segments, offer simplicity but fail to account for the diverse temporal scales of real-world events, thereby reducing adaptability. To address this limitation, our development of WorldMM seeks to provide a robust solution. This system autonomously selects the optimal memory type and duration for each query, effectively managing text and video data independently to optimize performance. The textual memory comprises two components: episodic memory, which chronicles distinct events across different time scales, and semantic memory, which retains comprehensive knowledge such as relationships and habits, systematically organized in knowledge graphs. In parallel, the video memory divides a long video into short-term segments, enabling efficient access when required. The system iteratively selects the most pertinent memory across various types and temporal dimensions, ensuring that only the necessary information pertinent to each inquiry is acquired. By preventing the model from utilizing superfluous memory types during information retrieval, this design helps maintain focus. Moreover, WorldMM retrieves information across varying levels of granularity by employing multiple graphs that operate over distinct temporal scopes, such as seconds, minutes, or hours. When episodic memory is selected for retrieval, the agent systematically examines each memory to extract useful information from all temporal levels. The gathered information is then evaluated to determine the most appropriate elements for addressing the query. Ultimately, the process integrates both brief and extended video segments to acquire only the essential information required for resolution. Furthermore, the iterative process by which the model acquires information involves repeatedly selecting memories and questions, enabling the exploration of various combinations and uncovering additional possibilities.
