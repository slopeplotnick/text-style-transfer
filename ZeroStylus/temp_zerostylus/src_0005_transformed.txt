Contribution. We introduce a tool known as promptolution, which serves as a modular, lightweight, and extensible open-source framework for automatic prompt optimization in Python. This framework offers thoroughly tested and stable implementations. It facilitates interfacing with multiple language models, accommodates various NLP tasks, and incorporates contemporary discrete prompt optimization methods. These methods can be used interchangeably or replaced by custom implementations, thereby enhancing the framework's adaptability. While promptolution aids practitioners in optimizing single prompts, it also supports researchers by providing a low level of abstraction and auxiliary tools for systematic, reproducible experiments. Finally, we propose potential directions for future enhancement (§5). Prompt Optimization. Automatic prompt optimization involves systematically exploring prompt spaces using various automated strategies. These strategies optimize both the instruction and few-shot example components of a prompt (Cui et al., 2025; Li et al., 2025; Wan et al., 2024). This process is commonly categorized into continuous and discrete approaches based on the nature of the prompt space (Li and Liang, 2021; Lester et al., 2021; Qin and Eisner, 2021; Guo et al., 2024; Yang et al., 2024; Zhou et al., 2023). For comprehensive overviews, we refer to Li et al. (2025) and Cui et al. (2025). Promptolution focuses on LLM-agnostic and interpretable discrete prompt optimization, iteratively refining textual prompts directly. Furthermore, it often employs another "meta"-LLM<sup>1</sup> to generate improved candidates. Optimizers Implemented. The following optimizers are integrated within promptolution: 1. OPRO (Yang et al., 2024) utilizes LLMs as optimizers by providing a task description, examples, and previously scored candidates to the meta-LLM, which then proposes refined instructions. 2. EvoPrompt (Guo et al., 2024) enhances instructions using evolutionary algorithms, including (a) a genetic algorithm (GA) and (b) differential evolution (DE), with the meta-LLM conducting crossover and mutation. 3. CAPO (Zehle et al., 2025) represents a recent GA-based alternative that leverages AutoML techniques to improve cost-efficiency and simultaneously optimizes both instructions and few-shot examples, thereby outperforming the aforementioned discrete optimizers.
