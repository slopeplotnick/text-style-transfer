This research not only advances the application of large language models (LLMs) in the domain of financial forecasting but also introduces an innovative paradigm for the design of memory mechanisms tailored for specialized domains. By constructing a domain-specific memory system, we effectively address the challenges associated with adapting general frameworks to professional scenarios, thereby establishing a solid foundation for future related research. Our contributions align with the track's scope in three key aspects: (1) Structured Knowledge Extraction: We transform disorganized web news into a structured event database, which facilitates the scalable creation of web-based structured knowledge; (2) Semantic-LLM Synergy: Our dual-layer memory system enhances the collaboration between structured knowledge and the reasoning capabilities of LLMs; (3) Web Application: We demonstrate the practical value in financial prediction, thereby enhancing the interpretability of web news-based decision-making systems. Our work addresses the critical challenge of extracting dynamic and meaningful knowledge from web content, aligning closely with the track's focus on advancing the generation of structured, evolving information. Memory mechanisms have become essential for enhancing LLMs' capacity to handle complex tasks, transitioning from embedding information within the model to leveraging external memory systems. Intrinsic or parametric memory encodes knowledge within the model's parameters, offering advantages of rapid access and enduring retention. However, it inherently exhibits challenges in interpretability and selective updating. Therefore, to overcome these limitations, researchers have developed external memory augmentation mechanisms. These approaches effectively compensate for LLMs’ constraints in context length and knowledge integration capabilities by constructing sustainable, precisely accessible external knowledge systems. The development of external memory demonstrates distinct phased characteristics: initially represented by retrieval-augmented generation (RAG), which stores unstructured text fragments in vector databases. While RAG partially addresses knowledge updating issues, it only achieves shallow semantic matching. As research progresses, the focus has gradually shifted from simple information storage to systematic memory management. Consequently, this progression has catalyzed the development of advanced architectures such as GraphRAG, which leverages knowledge graph-based structured memory; MemGPT, designed to function as an operating system for memory management; and Zep, which integrates temporal knowledge engines to support joint retrieval of historical relationships and dynamic contexts. Collectively, these innovations significantly enhance the reasoning capabilities and management efficiency of memory systems.
