Enhanced prompts are designed to combine the original context with targeted feedback, thereby facilitating improved reasoning during retries. This approach is implemented through phase-adaptive strategies that utilize sophisticated language model integration to translate strategic weights into contextual reasoning guidance. The prompt engineering system dynamically incorporates phase-specific priorities and natural language instructions, ensuring that the language model applies appropriate trade-off logic at each project stage. For example, during the early phase of allocation, prompts emphasize maximizing success rates with directives such as "prioritize robots with the highest success rates" and "accept moderate workload imbalances." However, as the project progresses to later phases, the focus shifts to workload balancing, incorporating instructions like "favor workload equity" and "consider balance as the primary factor." Consequently, this adaptive prompt mechanism enables the language model to naturally implement the strategic frameworks defined in the phase-adaptive approach. The authors operationalize this integration through a tripartite methodology: first, they employ probabilistic robot capability modeling to compute task-specific success rates, promoting equitable utilization; second, they generate structured prompts embedding quantitative priors and workload context; and third, they format responses in a standardized manner to enable reliable parsing and validation. The classification of robots into Light, Medium, and Heavy categories reflects strategic differentiation in capabilities, with each type offering distinct strengths and probabilistic success profiles. These success profiles are derived from probabilistic associations between task features and robot capabilities, following the formulation of Faruq et al. (2018), where task completion likelihoods are modeled as expected success probabilities based on the uncertainty of feature-capability alignment. Each robot's overall success rate for a given task is thus obtained by aggregating its feature-conditioned success values. Furthermore, a robot's ability to perform a given task depends on the alignment between the task's required features and the robot's capability distribution. Tasks are sequentially processed from a queue initialized with all 36 tasks from the TEACH dataset (Padmakumar et al. 2022). This sequential processing involves passing each task through the complete LangGraph workflow, which includes phase detection, prompt generation, reasoning, validation, and allocation, before proceeding to the next task. Upon the completion of each task, the system updates progress metrics and recalibrates the remaining task count until all assignments have been successfully allocated.
