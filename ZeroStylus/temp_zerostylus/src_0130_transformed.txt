Each component of the system operates within a unified framework, permitting interchangeable configurations and thereby facilitating seamless integration and compatibility with other components. While each module can be configured independently, an alternative approach involves utilizing an ExperimentConfig. This facilitates the centralized management of all configuration parameters within a single construct, thereby enhancing coherence. The LLM component provides an interface for obtaining responses from any large language model implementation. Its base class enables parallel operations and efficient monitoring of token utilization. Specifically, APILLM facilitates interaction with models via an API, including those provided by OpenAI and Anthropic, and offers a practical demonstration for integration through the DeepInfra API. Meanwhile, the LocalLLM component provides a framework for utilizing models on personal computers with transformer technology. Furthermore, VLLM leverages the v11m library for efficient handling of high-volume requests and is optimized for deployment on GPU architectures. As illustrated in Figure 2, the Predictor component determines the methodology by which answers are extracted from the model's output. For classification tasks, it identifies the predicted category, while for mathematical problem-solving, it extracts the final computed solution, thereby streamlining task-specific outputs with precision and consistency. The FirstOccurrencePredictor identifies the initial occurrence of a potential answer and selects it as the basis for prediction, facilitating systematic and consistent application across diverse scenarios. Conversely, the MarkerBasedPredictor systematically identifies responses by detecting and extracting answers enclosed within predefined tags, ensuring enhanced reliability and consistency in output evaluation. The Task component is responsible for maintaining the data and associated details necessary for defining and executing the required operations. This ensures that prompts are selectively tested, preventing unnecessary evaluations, thereby optimizing efficiency. Moreover, this aspect holds considerable significance as it ensures the achievement of optimal outcomes while minimizing unnecessary expenditure of resources.
